# Mythras Imperative 系统资源文档

---
## 简介

_Mythras Imperative_ 是 _Mythras_ 规则集的开源（ORC许可）版本。本文件提供了一套详尽但非穷尽的规则，包括角色创建、技能、特定典型情况下的规则、战斗和魔法——足以让玩家和游戏主持人（Games Master）入门，并为进一步发展打下坚实的基础。_Mythras Imperative_ 与 Mythras 核心规则及其他基于 ORC 许可的百分制游戏系统兼容。其配套书册 _Classic Fantasy Imperative_ 也完全兼容并以 ORC 协议发布，这意味着这两个版本可以轻松组合使用。

非英语语言的翻译由人工智能完成。欢迎社区提供建议！

## ORC 许可

_Mythras Imperative_ 使用 ORC 许可发布。ORC 许可为游戏创作者提供了一种公开分享其游戏机制的途径，并允许下游用户自由使用、修改和重新分享这些游戏机制的改编版本。

在 ORC 下公开分享的内容被称为_**许可材料（Licensed Material）**_，包括游戏的功能性要素，如数据块、游戏规则、角色属性、玩游戏所固有的方法和系统，以及许可方明确希望分享的其他任何内容。该许可范围广泛，允许您在与印刷书籍、电子游戏、播客、人工智能或任何未来可能存在或被创造的技术相关联时在全球范围内使用许可材料。_Mythras Imperative_ 中发现的大部分内容构成了许可材料。

_不_ 在 ORC 下分享的内容被称为_**保留材料（Reserved Material）**_，包括商标、世界背景设定、故事线、独特角色和视觉艺术。我们在下方的 ORC 声明中列出了保留材料。

在 ORC 许可下，您可以根据自己的意愿使用、分享、改编和构建许可材料，只要您在已发布的作品中以声明的形式给予适当的署名。该声明既归功于上游许可方及其对作品的贡献，也为下游用户提供了一种简便的方式来标明声明所在作品的作者。通过使用在 ORC 下许可的材料，您即自动同意根据相同的条款在您发布的作品中许可您的游戏机制。如果您开发了自己的保留材料，那将是您的独有财产。

## d100 新手入门？

_Mythras Imperative_ 是一个 d100 或百分制系统。百分制骰子（即 1d100）用于解决关键行动——技能使用、战斗、魔法施放等。这是一个掷骰低于目标值的系统，意味着目标数值以百分比表示（例如：体能 65%），游戏主持人和玩家都希望使用 1d100 掷出等于或低于该目标数值的结果，以实现成功。如果愿意，将 1d100 替换为 d20 也非常容易，只需将所有百分比除以 5（向上取整）即可获得 d20 的目标数值。在我们的例子中，体能 65% 将变为体能 13。

然而，1d100 提供了贯穿整个游戏的巨大灵活性和细微差别，因此我们的建议是先尝试 1d100 方法。虽然必须掷出“低于”某个数值可能显得不合直觉（在许多游戏中，数值越高越好！），但拥有一个需要在此范围内掷骰的目标数值范围，可以简单直观地看出成功的几率，并允许许多“骰子技巧”，如对抗掷骰、大成功和大失误，以及后续规则中探讨的其他一些内容。百分制角色扮演游戏自角色扮演游戏诞生之初就已存在，是一个久经考验、灵活、直观且在游戏过程中往往会融入背景的核心系统。

## 简化

_**Mythras**_ 的资深玩家会注意到，_Mythras Imperative_ 的规则在某些地方进行了简化。这样做是为了让游戏主持人能够以最少的麻烦快速向新玩家介绍这款游戏。

---
## 数字与结果的取整

在某些情况下，您需要进行除法运算——通常是在评估技能等级时（例如确定大成功时，即技能数值的 1/10）。每当除法结果产生小数时，请始终向上取整为整数。例如，63% 的 1/10 是 6.3；向上取整为 7。

## 使用的骰子

_Mythras Imperative_ 使用标准的几何多面体骰子组：d4、d6、d8、d10、d12、d20 和 d100。此外，还需要使用以下骰子：

d2：投掷任何骰子。奇数等于 1，偶数等于 2。或者抛硬币。

d3：投掷一颗六面骰；1-2 = 1，3-4 = 2，5-6 = 3
