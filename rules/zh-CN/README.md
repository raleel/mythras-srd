# Mythras Imperative 系统资源文档

---
## 简介

_Mythras Imperative_ 是 _Mythras_ 规则集的公开且受 ORC 许可的版本。本文件提供了一套全面但不详尽的规则，包括角色创建、技能、特定典型情况的规则、战斗以及魔法——足以让玩家和游戏主持人（Games Master）上手，并为进一步的发展奠定坚实的基础。_Mythras Imperative_ 与 Mythras 核心规则以及其他受 ORC 许可的百分制游戏系统兼容。其配套卷 _Classic Fantasy Imperative_ 也完全兼容并以 ORC 协议发布，这意味着这两个 Imperative 版本可以轻松结合使用。

除英语外的翻译均由人工智能完成。欢迎社区提供建议！

## ORC 许可

_Mythras Imperative_ 是使用 ORC 许可发布的。ORC 许可为游戏创作者提供了一种公开分享其游戏机制的方式，并允许下游用户自由使用、修改和重新分享这些游戏机制的改编版本。

在 ORC 下公开分享的内容被称为 _**许可材料 (Licensed Material)**_，包括游戏的广泛功能要素，例如数据块、游戏规则、角色属性以及进行游戏时固有的方法和系统，以及许可方明确希望分享的任何其他内容。该许可范围广泛，允许您在全球范围内将许可材料用于印刷书籍、电子游戏、播客、人工智能或未来可能存在或创造的任何其他技术。_Mythras Imperative_ 中绝大部分内容均构成许可材料。

在 ORC 下 _不_ 分享的内容被称为 _**保留材料 (Reserved Material)**_，包括商标、世界观设定、故事弧、独特的角色和视觉艺术。我们在下方的 ORC 通知中列出了保留材料。

在 ORC 许可下，只要您在出版作品中以声明的形式给予适当的署名，您就可以根据自己的意愿使用、分享、改编和构建许可材料。此声明既认可了上游许可方及其对作品的贡献，也为下游用户提供了一种简便的方式来注明该声明所出现作品的作者。通过使用受 ORC 许可的材料，您即自动同意以相同的条款在您的出版作品中许可您的游戏机制。如果您开发了自己的保留材料，则该材料为您的专属财产。

## 对 d100 不了解？

_Mythras Imperative_ 是一个 d100 或百分制系统。百分制骰子或 1d100 用于解决关键行动——技能使用、战斗、魔法施放等。这是一种“掷点低于目标值”的系统，意味着目标数值以百分比表示（例如：运动 65%），游戏主持人和玩家都需要使用 1d100 掷出等于或小于该目标数值的点数，以获得成功。如果需要，可以很容易地将 1d100 替换为 d20，所有百分比都可以除以 5（向上取整）来获得 d20 投掷的目标数值。例如，运动 65% 将变为运动 13。

然而，1d100 提供了极大的灵活性和细微差别，这是整个游戏的基石，因此我们建议先尝试 1d100 方案。虽然必须掷出 _小于_ 某个数值看起来可能有些反直觉（在许多游戏中，通常数值越高越好！），但将目标数值表示为一个需要掷入范围内的百分比，可以简单直观地看出成功的几率，并允许进行相当多的“骰子技巧”，例如对抗投掷（Opposed Rolls）、大成功（Criticals）和大失败（Fumbles），以及这些规则后面探讨的其他一些内容。百分制角色扮演游戏自角色扮演游戏诞生之初就已存在，是一个久经考验且根基稳固的游戏系统，它灵活、直观，并且倾向于在游戏过程中隐入背景。

## 简化

_**Mythras**_ 的老玩家会注意到，_Mythras Imperative_ 规则在某些地方进行了简化。这样做的目的是为了让游戏主持人能以最少的繁琐步骤，更迅速地向新玩家介绍游戏。

---
## 数值与结果的取整

在某些情况下，您需要对数字进行除法运算——通常是技能等级（例如为了确定大成功，即技能数值的 1/10）。每当除法结果产生分数时，始终向上取整为整数。例如，63% 的 1/10 是 6.3；向上取整为 7。

## 使用的骰子

_Mythras Imperative_ 使用标准的多元骰子组合：d4、d6、d8、d10、d12、d20 和 d100。此外，还需要以下骰子：

d2：掷任何骰子。奇数点等于 1，偶数点等于 2。或者掷硬币。

d3：掷一个六面骰子；1-2 = 1，3-4 = 2，5-6 = 3
