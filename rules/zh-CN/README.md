## 介绍

_Mythras Imperative_ 是 _Mythras_ 规则集的一个开放、ORC 许可版本。本文档提供了一套全面但不详尽的规则，包括角色创建、技能、某些典型情境的规则、战斗和魔法——足以让玩家和游戏管理员入门，并为进一步发展奠定坚实基础。_Mythras Imperative_ 与 Mythras 核心规则以及其他 ORC 许可的百分骰游戏系统兼容。其配套卷册 _Classic Fantasy Imperative_ 也完全兼容并以 ORC 许可发布，这意味着这两个 Imperative 版本可以轻松结合。

## ORC 许可

_Mythras Imperative_ 使用 ORC 许可发布。ORC 许可为游戏创作者提供了一种公开分享其游戏机制的方式，并允许下游用户自由使用、修改和重新分享这些游戏机制的改编版本。

根据 ORC 公开分享的内容被称为 **_许可材料_**，包括游戏的广泛功能元素，例如属性块、游戏规则、角色属性，以及游戏内在的方法和系统，以及许可方明确希望分享的任何其他内容。此许可范围广泛，允许您在全球范围内将许可材料用于印刷书籍、视频游戏、播客、AI 或任何可能存在或将来创建的其他技术。_Mythras Imperative_ 中绝大部分内容均构成许可材料。

根据 ORC **_不_** 分享的内容被称为 **_保留材料_**，包括商标、世界传说、故事线、独特角色和视觉艺术。我们已在下方的 ORC 通知中列出了保留材料。

根据 ORC 许可，您可以随意使用、分享、改编和基于许可材料进行创作，只要您在发布的著作中以通知的形式给予适当的署名。此通知既表彰了上游许可方及其对作品的贡献，也为下游用户提供了在该通知出现的作品中署名作者的便捷方式。通过使用 ORC 许可的材料，您自动同意以相同条款许可您发布的著作中的游戏机制。如果您开发了自己的保留材料，则其为您的专属财产。

## 不熟悉 d100？

_Mythras Imperative_ 是一个 d100 或百分骰系统。百分骰，即 1d100，用于解决关键行动——技能使用、战斗、魔法施放等。这是一个掷点“低即成功”的系统，这意味着目标数字以百分比表示（例如，运动 65%），游戏管理员和玩家都旨在掷出等于或小于此目标数字的结果，使用 1d100，以实现成功。如果喜欢，可以很容易地用 d20 替换 1d100，并且所有百分比都可以除以 5（向上取整）以获得 d20 掷骰的目标数字。在我们的示例中，运动 65% 将变为运动 13。

然而，1d100 提供了大量的灵活性和细微之处，这是整个游戏的基础，因此我们建议首先尝试 1d100 方法。虽然掷出“小于”某个数字可能看起来有悖常理（在许多游戏中，通常是越高越好！），但将目标数字表示为一个需要掷入的百分比范围，可以轻松简单地看到您的成功几率，并允许进行许多“掷骰技巧”，例如对抗掷骰、暴击和失误，以及这些规则中稍后探讨的其他一些内容。百分比角色扮演自角色扮演的早期就已经存在，是一个坚实成熟的游戏系统，其核心机制经过反复验证，灵活、直观，并且在游玩时趋于融入背景。

## 简化

_**Mythras**_ 的长期拥有者会注意到，在某些地方 _Mythras Imperative_ 的规则已被简化。这样做是为了让游戏管理员能够更快地向新玩家介绍游戏，最大限度地减少麻烦。

---
## 数字和结果的四舍五入

在某些情况下，您需要除以数字——通常是技能的评级（例如确定暴击成功，其值为技能值的 1/10）。每当除法结果产生小数时，始终向上取整到整数。例如，63% 的 1/10 是 6.3；这向上取整为 7。

## 所用骰子

_Mythras Imperative_ 使用标准多面骰子套装：d4、d6、d8、d10、d12、d20 和 d100。此外，还需要以下骰子：

d2：掷任意骰子。奇数等于 1，偶数等于 2。或者抛硬币。

d3：掷一个六面骰子；1-2 = 1，3-4 = 2，5-6 = 3
