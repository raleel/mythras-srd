# 游戏系统

在 _Mythras Imperative_ 游戏中会发生许多不同的事情。有些通过技能使用或诸如战斗或魔法等主要游戏机制来解决；其他的则需要各自的规则来进行裁决。本章为玩家在游戏过程中会遇到的各种不同场景提供了规则和指导。

该列表并不详尽，但应涵盖最常见的情况。如果游戏主持人（Games Master）发现还有其他需要某种形式的游戏系统裁决的情况，并且这些情况似乎频繁发生，那么鼓励他们使用本章中给出的规则作为复制或开发的基础，制定自己的规则来涵盖这些特殊情况。

## 窒息

角色屏住呼吸的秒数等于其耐力（耐力）技能值。然而，角色必须有所准备（肺部尽可能多地吸入空气）；如果不是，那么如果角色处于被动状态，该周期会减半；如果角色正在进行剧烈活动，则减少到五分之一。

一旦屏住呼吸的时间结束，角色必须进行一次耐力（耐力）检定：

- 如果检定为大成功（Critical Success），则不会再出现进一步的恶化。
- 如果检定为成功（Successful），角色会额外累积一级疲劳（疲劳）。
- 如果检定失败（Fails），该回合内角色额外承受 1d2 级疲劳。
- 如果检定为大失误（Fumbled），该回合内角色额外承受 1d3 级疲劳。

如果没有援助，因窒息而死亡通常很快。如果窒息在角色死亡前结束，他们恢复因窒息而损失的疲劳等级相对较快，每分钟恢复一级。

根据窒息的方法，游戏主持人可能希望防止完全恢复，施加一个持久的疲劳等级（参考关于 [疲劳](0004_Game_System.md?id=fatigue) 的部分），以代表烟雾或吸入水对肺部造成的伤害。

## 角色提升

每个 _Mythras Imperative_ 角色都可以随着时间和经验而提升。提升可以在以下几个方面进行：

- 提升现有技能
- 提升激情（激情）
- 学习新技能
- 学习新能力

#### 经验检定

大多数角色提升的机制是经验检定（Experience Rolls）。游戏主持人会在战役中的适当节点分配经验检定：在每个成功的剧本或故事线结束时；或者如果故事很长，需要时间来完成，则在进行两三次游戏会话后。频率由游戏主持人自行决定。高频率的经验检定将导致角色以更快的速度发展。

没有所谓的给予经验检定的正确或错误时间，但故事中的自然停顿可能暗示了合适的时机。然而，游戏主持人始终是这里的决策者。虽然玩家不能要求经验检定，但他们有权在某些节点期待它们——因为没有它们，他们的角色将无法发展。

授予的经验检定数量也由游戏主持人决定。然而，一个好的经验法则是自上次授予以来，每次会话奖励 1-3 次经验检定。

#### 提升现有技能

角色卡（角色 Record）上的任何标准技能（标准 Skills）或专业技能（专业技能），都可以通过消耗一次经验检定来提升。玩家可以选择不将经验检定用于提升技能，而是积累起来用于提升其他东西——例如职业（职业）能力（见下文）。

玩家掷 1d100 并将其与要提升的技能进行比较。角色的智力（智力）会加到掷骰结果上。

- 如果掷出的数字等于或大于要提升的技能，则技能提升 1d4+1%。
- 如果掷出的数字小于所选技能，技能仍然会提升，但仅提升 1%。
- 如果角色在上一次会话中——即上一次经验检定集和本次经验检定集之间——对任何技能进行了大失误（Fumbled），该大失误的技能获得 1% 的免费提升。我们从错误中学到的比从成功中学到的更多，这代表了角色在灾难性失败后所经历的反思。同一技能的多次大失误不会叠加。在大失误的技能同时通过经验检定进行提升的情况下，来自大失误的 1% 会在进行提升掷骰之前应用。

同一技能在每次会话中不得从超过一次的经验检定中受益。

#### 提升激情

如 [激情](0002_Characters.md?id=step-8-passions) 部分中关于激情的描述，激情的值可以通过经验检定以与技能相同的方式增加。如果游戏中有支撑，游戏主持人甚至可能允许使用经验检定来降低激情。

_例如，来自单相思的持续拒绝最终可能会磨损哪怕是最热情的恋人的激情，特别是那些希望追求一段关系而不希望过去阴影困扰他们的人。_

#### 学习新技能

一些角色可能希望学习他们从未有机会从其文化中学习的专业技能。在他们开始投入经验检定之前，他们必须首先找到可以学习的知识来源。这可以是像订单或行会提供的专业导师这样平淡无奇的事物。或者，它可能是一个更具异国情调的教育来源，例如古老而破碎的训练卷轴。

一旦找到教育来源，角色必须花费整整一个月的时间进行学习和练习，以获得该技能的基本基础（在基础等级学习）。这需要消耗 3 次经验检定，外加支付教师（如果存在）所需的任何游戏内费用，以及购买（或租用）可能需要的任何设备和工具。

## 疾病与毒药

一些最令人恐惧的、能够影响角色的事物是滋生在世界上阴暗和冷酷之地的无数疾病和毒药。没有什么比在角色家乡城市爆发的瘟疫更令人不安的了，尤其是当他们还在城墙内时。同样，在床上发现毒蛇或受到巨型蝎子的攻击也可能成为高戏剧性的时刻。

疾病和毒药的种类近乎无限，但出于游戏目的，它们以同样的方式处理。

#### 疾病和毒药特征

所有疾病和毒药都表现出若干对其效果至关重要的特征。

**应用（Application）：** 疾病或毒药引入受害者的途径。

- **摄入（Ingestion）：** 通过进食或饮水产生效果。
- **吸入（Inhaled）：** 通过呼吸或鼻吸产生效果。
- **接触（Contact）：** 通过皮肤吸收产生效果。
- **注射（Injected）：** 当物质通过刺伤被注入身体时产生效果。

**效力（Potency）：** 疾病或毒药的毒性。该值在对抗检定中与适当的抵抗技能（通常是耐力或意志力）相对抗。如果角色赢得了检定，他们摆脱其影响。如果他们输掉了检定，那么他们会在适当的时间承受所有疾病或毒药状态（Conditions）。

**抵抗（Resistance）：** 如何抵抗疾病或毒药——通常是耐力（耐力）或意志力（意志力），但也可能有更异国情调的抵抗要求。抵抗可以在接触时掷骰，也可以推迟到发作时间（Onset Time），以隐瞒角色可能已经感染或中毒的事实。

**发作时间（Onset Time）：** 许多疾病和毒药不会立即生效。这种延迟被称为发作时间，这可能是几秒、几分钟、几小时甚至更长时间。具有多种效果的毒药或疾病可能对每种效果有不同的发作时间，如状态表中所述。

**持续时间（Duration）：** 疾病或毒药的状态持续多长时间。

**状态（Conditions）：** 每种毒素都有一个或多个状态。这些状态具有下文状态表中所述的具体效果，如果受害者未能抵抗，他将承受所描述的所有状态。

**解毒剂/治疗（Antidote/Cure）：** 如果该毒素可以治疗，将在此注明。成功的治疗可以防止任何进一步的状态发生，但在某些情况下可能会留下受害者承受已经造成的持久影响。

##### 状态表

| 状态 | 效果 |
| :-- | :-- |
| 剧痛（Agony） | 受害者受到剧烈疼痛的阻碍。无论是在身体的某个部位还是全身，任何涉及使用受影响区域的技能检定必须同时小于或等于角色的意志力（意志力），否则尝试失败，且他们会因痛苦而呻吟或尖叫。 |
| 窒息（Asphyxiation） | 受害者遭受窒息——他会丧失行动能力而倒下，无法呼吸。使用 [窒息](0004_Game_System.md?id=asphyxiation) 部分的规则。窒息可能是哮喘性的，意味着受害者只会感到呼吸急促，或者是导致死亡的完全呼吸衰竭。在后一种情况下，受害者可以通过在急救（急救）技能的对抗检定中胜过疾病或毒药的效力来维持生命。 |
| 出血（Bleeding） | 受害者遭受内出血或表面出血，这会导致下文 [疲劳](0004_Game_System.md?id=fatigue) 和 [失血](0004_Game_System.md?id=blood-loss) 部分中描述的疲劳和恢复时间。 |
| 传染（Contagious） | 受害者可以通过触摸传播毒药或疾病。 |
| 死亡（Death） | 受害者丧失行动能力倒下，并在等于其体质（体质）特征值的回合数后死亡。 |
| 发热（Fever） | 受害者的体温剧烈波动——从热到冷——并且肌肉酸痛。所有技能承受困难（困难）的难度等级。 |
| 狂躁（Mania） | 受害者被迫遵循某种强迫症，例如避免接触水、偏执、自残等等。疾病或毒药引发的狂躁将在其描述中注明。 |
| 恶心（Nausea） | 受害者无法进食，并且每次执行紧张的身体活动时都必须针对其耐力进行检定，以避免身体呕吐。呕吐持续 1d3 回合，在此期间他无法行动。长期的恶心可能会导致饥饿。 |
| 麻痹（Paralysis） | 受害者在身体上无法移动。受影响的区域（如果是特定位置）在持续时间内无法使用。如果它影响全身，角色根本无法移动。 |

#### 疾病范例：红痘（Red Pox）

红痘是一种恶心的疾病，通过与已经感染的人的皮肤接触，或与其接触过的东西接触而传播。从物体上感染该疾病的几率在接触后会持续 1d3 天，这使得一旦疫情爆发，控制该疾病变得相当困难。

受害者最初会出现轻微的皮疹，但一天之内就会出现严重的持续高烧，通常使他们在此期间一直卧床不起。在此期间，皮疹演变成令人毛骨悚然的瘙痒脓疱，在轻微的移动下就会破裂，流出涓涓细血——尤其是从腋下和腹股沟。这个阶段可以持续一周或更长时间，并可能导致死亡。

- **应用：** 接触
- **效力：** 50
- **抵抗：** 耐力
- **发作时间：** 1d6+6 小时
- **持续时间：** 1d6+3 天
- **状态：** 一旦疾病表现出来，受害者就具有传染性（Contagious）。1 天后，他们开始遭受发热（Fever）和出血（Bleeding）。每天脓疱流血，受害者失去一级疲劳，直到疾病持续时间结束才会恢复。
- **解毒剂/治疗：** 可以通过治疗（Healing）技能治愈。

## 坠落

坠落造成的伤害量取决于坠落的距离。护甲点数（护甲 Points）不会减少坠落伤害，但坠落角色或生物的伤害修正（伤害 修正值）适用于从坠落中受到的伤害。

##### 坠落距离表

| 坠落距离 | 承受伤害 |
| :-- | :-- |
| 1 米或以下 | 无伤害。 |
| 2-5 米 | 1d6 点伤害至一个随机位置。 |
| 6-10 米 | 2d6 点伤害至两个随机位置。 |
| 11-15 米 | 3d6 点伤害至三个随机位置。 |
| 16-20 米 | 4d6 点伤害至四个随机位置。 |
| 每 +5 米 | +1d6 伤害。 |

#### 坠落物体

坠落物体根据其体型（体型）和坠落距离赋予一定量的伤害。物体每 6 点体型（或其分数）造成 1d6 伤害，加上等于坠落距离表中的“承受伤害”列的伤害量——包括对较小物体尺寸的任何减免。

## 疲劳

疲劳衡量疲倦及其递增的影响。它用于追踪许多不同的事情，从剧烈活动到疾病的衰弱影响。

累积疲劳的主要方式是进行某种形式的身体活动。锻炼或工作越艰苦，角色疲劳得就越快。由游戏主持人决定，角色必须进行适当的技能检定——体能（体能）、蛮力（蛮力）或耐力（耐力）——以抵抗获得一级疲劳。

每次检定失败都会累积一级疲劳。每一级疲劳都会对技能使用、移动、先攻（先攻）和行动点数（行动点数）产生减值。窒息、失血以及其他依赖于设定的效果也会导致疲劳累积。

对于大多数角色来说，当达到丧失行动能力（丧失行动能力）级别时，任何形式的活动都变得几乎不可能。在此阶段，角色仍然清醒，但除了最绝望的活动外，无法进行任何活动。

超过丧失行动能力，角色将无法进行任何活动（无法进行任何活动）。疲劳等级——半昏迷（半昏迷）、昏迷（昏迷）和死亡（死亡）——通常保留用于衡量窒息、疾病、失血、饥饿、暴露等最极端的影响。

#### 从疲劳中恢复

角色从疲劳中恢复取决于他们的治疗速率（治疗速率）。从每一级累积疲劳中恢复所需的完全休息时间等于恢复周期（恢复 Period）除以角色的治疗速率。

## 火焰

当作为武器使用或失去控制狂暴时，火焰总是危险的来源。下方的火焰强度表给出了五种不同强度的热伤害，并附带了一些示例。每回合造成的伤害在“伤害”列中给出。由于强度 1 和 2 的来源相对较小，其伤害适用于单个命中部位，通常是接触来源的部位。强度 3 和 4 的来源较大，适用于最近的 1d4+1 个命中部位，表示辐射热的程度。强度 5 的来源同时影响所有命中部位。

火焰可以点燃易燃材料。如果不立即熄灭，此类材料会在火焰强度指示的回合数内燃烧。一旦点燃，易燃材料将持续燃烧直到物理熄灭。伤害直接作用于材料的生命值，忽略护甲点数，并作用于其下的任何肉体。如果任其失控，它每回合会蔓延到等于其强度的命中部位数量。

##### 火焰强度表

| 强度 | 示例 | 点燃时间 | 伤害 |
| :-: | :-- | :-: | :-: |
| 1 | 蜡烛 | 1d4 | 1d2 |
| 2 | 火把 | 1d3 | 1d4 |
| 3 | 营火 | 1d2 | 1d6 |
| 4 | 充满房间的火灾 | 1d2 | 2d6 |
| 5 | 火山熔岩 | 瞬间 | 3d6 |

火系攻击通常有百分比几率点燃易燃材料，因为它们通常在一回合内结束。除非另有说明，此几率对于火系攻击为“掷出的伤害值 x 5%”，对于电系攻击为“掷出的伤害值 x 1%”。一旦点燃，易燃材料每回合燃烧 1d3-1 点伤害，直到物理熄灭。将此伤害直接应用于材料的生命值，忽略护甲点数，并应用于其下的任何肉体。然而，生物的天然护甲提供其正常的保护。受害者可以尝试通过卧倒并进行一次成功的体能（体能）检定来扑灭火焰，这需要一个行动点数，并且可以在每一轮尝试。如果其他人以某种方式协助扑灭火焰，则检定难度等级会简单一级。如果伤害掷骰结果为零，火焰在该位置已自行熄灭。对于每个自行熄灭的位置，扑灭火焰的检定难度等级也简单一级。

## 游戏时间

在 _Mythras Imperative_ 中，时间是一个重要因素，主要用于确定什么事情以什么顺序发生，以便在应该应用游戏机制时应用它们。请记住，游戏内时间通常不等同于游玩时间。有时，游戏主持人可能需要用一句话概括许多天发生的事件，例如“你们花了一周时间才到达安特拉克斯城堡”，而有时，特别是在战斗中，仅几秒钟的动作可能需要几分钟或更长时间来解决。

以下是游戏时间的重要区别：

#### 战斗回合（Combat Rounds）

一个战斗回合代表五秒的真实时间。它们用于衡量需要瞬间完成的简短、狂热的活动爆发，或衡量需要逐个细节解析的非常详细的活动。例如，猎人和猎物之间的追逐，其中每一回合决定了追逐的曲折。

#### 技能时间（技能 Time）

技能时间代表几分钟到几小时，用于衡量不需要战斗回合那种详细关注，但需要明确的努力深思并产生确定结果的活动。开锁可能需要五分钟，而观察守卫团队在城堡城墙周围的巡逻可能需要几个小时，这些都是技能时间的例子。#### 叙事时间

这是当游戏主持人向玩家叙述，或者玩家正在讨论时所消耗的时间。除非有特定的原因，否则大部分的实际角色扮演都在叙事时间内进行。在角色扮演时，叙事时间类似于现实时间，一场对话所花费的时间与实际游玩时所花费的时间相同。如果游戏环节包含漫长的旅行，或者精确时间无关紧要的活动期间，那么时间会被大幅压缩，仅剩下游戏时间里的片刻。

## 命中部位

大多数成功的（武器）攻击会命中特定的命中部位。这可以通过随机确定，或者在某些情况下通过特殊效果（例如“选择部位”）来选定。要随机计算命中的位置，掷 1d20 并将掷骰结果与相关的人形生物或生物命中部位表进行比较。

动物和怪物通常拥有与人形生物略有不同的命中部位表，以反映它们独特的生理构造。这些表列在每个生物的描述中，通常仅供游戏主持人使用。

此处重复列出人形生物命中部位表以供参考。

##### 人形生物命中部位

| 1d20 | 命中部位 |
| :-: | :-- |
| 1-3 | 右腿 |
| 4-6 | 左腿 |
| 7-9 | 腹部 |
| 10-12 | 胸部 |
| 13-15 | 右臂 |
| 16-18 | 左臂 |
| 19-20 | 头部 |

请注意，某些攻击，特别是魔法、技术攻击或由特定怪物产生的攻击（例如龙的烈焰吐息或爆炸的手榴弹），可能会同时击中多个命中部位。单个命中部位可能有护甲，这来自于穿着的防护装备或生物外表的自然坚韧。在考虑下方的伤害和伤口等级时，这一点非常重要。

## 伤害和伤口等级

如果攻击成功命中，它将根据该武器的伤害等级造成伤害。例如，短剑造成 1d6 伤害。

武器或攻击的掷骰伤害会根据特定条件按以下顺序进行修正：

1. 应用进行攻击的角色的伤害修正。
2. 修正来自任何武器强化（或减弱）魔法的伤害。
3. 如果进行了格挡，根据对比武器尺寸适当减少伤害。
4. 如果命中部位有护甲，则减去护甲点的数值。

如果攻击造成的伤害大于零，则该命中部位会承受相应数额的伤害，伤害总量将立即从该部位的生命值中扣除。注意该部位剩余的生命值，以及随之产生的伤口类别。

- **轻伤：** 命中部位生命值仍为正数。
- **重伤：** 命中部位生命值降至零或以下。
- **致命伤：** 命中部位受到的伤害达到或超过其初始生命值（即生命值降至负数，且绝对值大于等于初始生命值）。

如果某个部位受到重伤或致命伤，请使用以下规则。注意，需要耐力检定的伤口要在抵消投骰中对照原始攻击的掷骰结果进行测试。这反映了高技能战士能够制造更致命打击的能力。除非该部位再次受伤，否则不会重复进行耐力检定。

### 轻伤

轻伤是割伤、擦伤、淤青和扭伤。它们会引起疼痛，可能会流血，但严重程度不足以减缓或阻碍受害者。

### 重伤

如果某个部位的生命值降至零或以下，受害者会受到重伤。该部位会留下永久性疤痕，且受害者由于受到打击的震惊或疼痛分心，在接下来的 1d3 轮内无法攻击或开始施放法术（但仍可以闪避或进行格挡）。

遭受肢体重伤的角色必须立即将其耐力与敌人的成功攻击掷骰进行抵消投骰。失败将导致该肢体失效，直到该部位恢复到正数生命值。如果是腿部受伤，受害者会倒地。如果是手臂受伤，除非物体被固定在身上，否则所持物体会掉落（此处请运用常识）。

遭受腹部、胸部或头部重伤的角色必须立即将其耐力与敌人的成功攻击掷骰进行抵消投骰。失败将导致昏迷，持续时间（以分钟计）等于造成该重伤的攻击所造成的伤害数值。急救或治疗技能可用于帮助昏迷的受害者恢复意识。

由游戏主持人决定，即使角色仍能行动，所有需要使用该命中部位的任务都将受到一个难度等级的持续减值，直到伤情减轻为轻伤。

### 致命伤

如果某个部位的生命值降至等于或超过其初始生命值的负数，则该角色会受到致命伤。角色立即丧失行动能力，无法继续战斗。肢体因致命伤而被切断、贯穿、粉碎或撕裂。角色倒地，身体丧失行动能力，并且必须立即将其耐力与敌人的成功攻击掷骰进行抵消投骰。失败将导致因剧痛而昏迷。如果被切断、贯穿或撕裂的部位没有在等于其治疗速率五倍的分钟数内得到处理，角色将因失血和休克而死亡。

腹部、胸部或头部受到致命伤的受害者会陷入昏迷，完全丧失行动能力，并且必须立即将其耐力与敌人的成功攻击掷骰进行抵消投骰。失败会导致瞬间且惨烈的死亡（斩首、被劈成两半、心脏被贯穿、身体被撕裂等等）。如果他们幸存下来，且该部位没有在等于角色治疗速率两倍的战斗轮数内得到处理，他们仍会因失血和休克而死亡。

由于大多数致命伤需要某种形式的手术或强大的魔法才能治愈，受伤者极不可能在战斗结束前从致命伤中恢复。根据可用的治疗手段，受伤部位可能会留下残疾（参见下方的[从伤害中恢复](0004_Game_System.md?id=healing-from-injury)）。

### 失血

由通常在战斗中遭受的外部和内部伤口引起的失血，可以迅速拖垮一个角色。其影响通过疲劳等级的积累来衡量，类似于窒息。不受控制的失血通常会在没有某种形式医疗护理的情况下导致死亡。与窒息不同，严重失血对疲劳的影响是持续的。角色恢复因流血而损失的疲劳速率为每天一级，从失血停止后的第二天开始计算。

### 英勇最后一击

在关键角色受到致命伤的特殊情况下，游戏主持人可能会允许进行一次英勇的最后一击——例如喷出最后一道法术、试图砍倒杀死他们的人、爬走躲藏，或者试图为自己的伤口止血。他们必须拥有适用于该行动且未受损的肢体，并消耗一点幸运点数。他们有唯一一次尝试行动的机会，随后立即昏迷，并很可能死亡。

## 从伤害中恢复

从伤口和损伤中的自然恢复基于角色的治疗速率。治疗速率决定了根据伤口性质，该部位恢复多少生命值：

- **轻伤：** 天
- **重伤：** 周
- **致命伤：** 月

因此，一位治疗速率为 3 的角色若受损导致某个命中部位降至 –3（即重伤），他将以每周 3 点生命值的速度自然恢复，直到伤口恢复到零以上，然后以每天 3 点生命值的速度恢复，直到完全康复。

自然恢复有一些限制：

- 正在恢复的角色不能从事剧烈活动：否则，治疗速率会减少 1d3。因此，即使是从轻伤中恢复的角色，如果他们决定从事任何可能加剧伤势的体力任务，其恢复进程也可能受阻。
- 在受害者接受过成功的急救检定或某种形式的治疗魔法之前，致命伤不会开始自然愈合。若未在等于治疗技能二十分之一的天数内得到处理，非截肢类的致命伤将变得残疾，永久减少该部位的生命值。

## 无生命物体

所有无生命物体都拥有护甲点和生命值，用于确定其对伤害的抵抗力及损毁程度。在生命值受到影响之前，护甲点会先减少伤害。一旦物体的生命值降至零，它便报废了。

破坏尝试要求角色根据情况进行蛮力、徒手或战斗风格检定来造成伤害。成功则会对物品造成伤害。

#### 武器 vs 无生命物体

对护甲点等于或高于武器护甲点的无生命物体使用武器，会对物体和武器双方都造成伤害。例如，用斧头砍铁门可能会损坏门，但斧头本身会在铁门损毁前很久就报废。游戏主持人应根据具体情况判断哪些武器或工具可以影响哪些物体。例如，凿子明确设计用于雕刻木头或石头，而剑虽然锋利，却并非如此。因此，凿子在雕刻它本该雕刻的物体时不会受到损伤，而剑很可能（会受到损伤）。

## 幸运点数

幸运点数有助于将英雄与普通人区分开来。它们代表了角色将失败转化为成功，甚至死里逃生的潜力。

幸运点数可以在游玩过程中使用，并在下一节开始时补充到其通常的数值。

#### 使用幸运点数

幸运点数可以用多种方式使用。在支持特定的行动时只能使用一点幸运点数。幸运点数不能用于经验或训练检定。以下每个选项都需要消耗一点幸运点数。

#### 逆转命运

角色可以使用一点幸运点数来重新投掷或交换（例如，75 会变成 57）他们所作出的任何掷骰结果。这可以是技能检定、伤害掷骰，或其他任何具有某种效果的掷骰。角色甚至可以强迫对手重投针对他们所作的攻击或伤害掷骰。

#### 绝望尝试

如果角色在战斗中耗尽了所有行动点数，并需要寻找最后的一线生机来避免惨痛的结局，他们可以消耗一点幸运点数来获得额外的行动点数。

#### 减轻伤害

受到致命伤的角色可以消耗一点幸运点数将伤势降级为重伤。这将使受到的伤害减少到比造成致命伤所需伤害少一点的程度。
