# Documento de Recurso do Sistema Mythras Imperative

---
## Introdução

O _Mythras Imperative_ é uma versão aberta e licenciada pela ORC do conjunto de regras de _Mythras_. Este documento oferece um conjunto de regras abrangente, embora não exaustivo, que inclui a criação de personagens, perícias, regras para certas situações típicas, combate e magia — mais do que suficiente para iniciar tanto os jogadores quanto os Mestres de Jogo, formando uma base sólida para desenvolvimentos futuros. O _Mythras Imperative_ é compatível com as regras básicas de _Mythras_ e outros sistemas de jogos percentuais licenciados pela ORC. Seu volume companheiro, _Classic Fantasy Imperative_, também é totalmente compatível e lançado sob a ORC, o que significa que os dois Imperatives podem ser facilmente combinados.

Traduções que não sejam em inglês são feitas por IA. A contribuição da comunidade é bem-vinda!

## Novo em d100?

O _Mythras Imperative_ é um sistema de d100 ou percentual. Dados percentuais, ou 1d100, são usados para resolver ações-chave — uso de perícias, combate, lançamento de magia e assim por diante. É um sistema de rolar abaixo (roll-under), o que significa que o número-alvo é expresso como uma porcentagem (Atletismo 65%, por exemplo), e tanto o Mestre de Jogo quanto o jogador tentam rolar igual ou menos do que esse número-alvo, usando 1d100, para alcançar um Sucesso. É bastante fácil substituir o 1d100 por um d20, se preferir, e todas as porcentagens podem ser divididas por 5 (arredondando para cima) para obter o número-alvo para uma rolagem de d20. Atletismo 65% se tornaria Atletismo 13, em nosso exemplo.

No entanto, o d100 oferece uma grande dose de flexibilidade e nuance que fundamenta todo o jogo, portanto, nossa recomendação é tentar a abordagem do d100 primeiro. Embora possa parecer contra-intuitivo ter que rolar _menos_ do que algo (em muitos jogos, valores mais altos costumam ser melhores!), ter um número-alvo expresso como um intervalo percentual dentro do qual é preciso rolar torna fácil e simples ver suas chances de sucesso, e permite vários 'truques de dados', como Testes Opostos, Críticos e Desastres, e algumas outras coisas exploradas mais adiante nestas regras. O RPG percentual existe desde os primeiros dias do RPG e é um sistema de jogo firmemente estabelecido com uma mecânica central testada e comprovada que é flexível, intuitiva e tende a desaparecer em segundo plano durante o jogo.

## Simplificação

Veteranos de _**Mythras**_ notarão que em alguns lugares as regras de _Mythras Imperative_ foram simplificadas. Isso foi feito para que um Mestre de Jogo possa introduzir o jogo mais rapidamente a novos jogadores com o mínimo de complicações.

---
## Arredondamento de Números e Resultados

Em algumas ocasiões, você precisará dividir números — tipicamente a graduação em uma perícia (como para determinar um Sucesso Crítico, que é 1/10 do valor da perícia). Sempre que o resultado de uma divisão gerar uma fração, arredonde sempre para cima para o número inteiro. Portanto, por exemplo, 1/10 de 63% é 6,3; isso é arredondado para cima para 7.

## Dados Utilizados

O _Mythras Imperative_ usa o conjunto padrão de dados poliédricos: d4, d6, d8, d10, d12, d20 e d100. Além disso, os seguintes dados são necessários:

d2: Role qualquer dado. Um número ímpar equivale a 1 e par equivale a 2. Ou jogue uma moeda.

d3: Role um dado de seis faces; 1-2 = 1, 3-4 = 2, 5-6 = 3.
