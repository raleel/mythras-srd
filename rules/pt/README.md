# Documento de Recursos do Sistema Mythras Imperative

## Introdução

_Mythras Imperative_ é uma versão Aberta, Licenciada sob ORC, do conjunto de regras de _Mythras_. Este documento oferece um conjunto abrangente, mas não exaustivo, de regras, incluindo criação de personagens, perícias, regras para certas situações típicas, combate e magia – mais do que suficiente para que tanto jogadores quanto Mestres de Jogo comecem, e formem uma base sólida para desenvolvimento futuro. _Mythras Imperative_ é compatível com as regras centrais de Mythras e outros sistemas de jogo percentuais licenciados sob ORC. Seu volume complementar, _Classic Fantasy Imperative_, também é completamente compatível e lançado sob ORC, o que significa que os dois Imperativos podem ser facilmente combinados.

Traduções que não são em inglês são feitas por IA. A contribuição da comunidade é bem-vinda!

## Novo em d100?

_Mythras Imperative_ é um sistema d100 ou percentual. Dados percentuais, ou 1d100, são usados para resolver ações chave – uso de perícias, combate, conjuração de magia, e assim por diante. É um sistema de rolagem abaixo, significando que o número alvo é expresso como uma porcentagem (Atletismo 65%, por exemplo), e tanto o Mestre de Jogo quanto o jogador procuram rolar igual ou menor que este número alvo, usando 1d100, para alcançar um Sucesso. É bastante fácil substituir o 1d100 por um d20 se preferir, e todas as porcentagens podem ser divididas por 5 (arredondar para cima) para obter o número alvo para uma rolagem de d20. Atletismo 65% se tornaria Atletismo 13, em nosso exemplo.

No entanto, o 1d100 oferece uma grande flexibilidade e nuances que sustentam todo o jogo, então nossa recomendação é experimentar a abordagem do 1d100 primeiro. Embora possa parecer contraintuitivo ter que rolar _menos_ do que algo (em muitos jogos, geralmente maior é melhor!), ter um número alvo expresso como uma faixa percentual dentro da qual se precisa rolar torna fácil e simples ver suas chances de sucesso, e permite muitos 'truques de dados', como Rolagens Opostas, Críticos e Falhas, e algumas outras coisas exploradas mais adiante nestas regras. O RPG percentual existe desde os primórdios do RPG e é um sistema de jogo firmemente estabelecido com uma mecânica central testada e aprovada que é flexível, intuitiva e tende a desaparecer em segundo plano durante o jogo.

## Simplificação

Proprietários de longa data de _**Mythras**_ notarão que em alguns lugares as regras de _Mythras Imperative_ foram simplificadas. Isso foi feito para que um Mestre de Jogo possa introduzir o jogo mais rapidamente a novos jogadores com o mínimo de confusão.

---
## Arredondamento de Números e Resultados

Em algumas ocasiões, você será obrigado a dividir números – tipicamente a classificação em uma perícia (como para determinar um Sucesso Crítico, que é 1/10 do valor da perícia). Sempre que o resultado de uma divisão criar uma fração, arredonde sempre para o número inteiro. Assim, por exemplo, 1/10 de 63% é 6.3; isso é arredondado para 7.

## Dados Usados

_Mythras Imperative_ usa o conjunto padrão de dados poliédricos: d4, d6, d8, d10, d12, d20 e d100. Além disso, os seguintes dados são solicitados:

d2: Role qualquer dado. Um número ímpar equivale a 1 e par a 2. Ou jogue uma moeda.

d3: Role um dado de seis lados; 1-2 = 1, 3-4 = 2, 5-6 = 3
