# Передумови

1. Базове розуміння [мови розмітки markdown](https://www.markdownguide.org/basic-syntax/).

2. Вам потрібно створити безкоштовний обліковий запис [github](https://github.com/), якщо у вас його немає. Рекомендую використовувати назву вашої RPG, оскільки вона стане частиною URL-адреси, яку люди використовуватимуть для доступу до вашої SRD.

3. Ви можете виконати весь цей процес через браузер, не знаючи git. Хоча вивчення github desktop дозволить вам тестувати будь-які зміни локально перед їх розгортанням для публічного доступу.

> Якщо у вас зареєстровано доменне ім'я, ви можете використовувати його з цим процесом для створення SRD, як це зробив я https://srd.7thextinctionrpg.com

# Процес

## Створення репозиторію на Github

1. Увійдіть у Github

2. Перейдіть до публічного шаблону https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Натисніть "Use this template"

![Step3](/_media/Step3.png)

4. Оберіть "Create a new repository"

5. Введіть назву репозиторію

![Step5](/_media/Step5.png)

6. Оберіть 'Private' (Приватний)

7. Оберіть 'Create repository'

Копіювання шаблону займе 5-30 секунд, після чого ви матимете власну копію.

8. Переконайтеся, що у вас є файл ".nojekyll" — це порожній файл, який необхідний під час розміщення вебсайту на Github, інакше SRD не відображатиметься належним чином. *(Повідомляє GitHub Pages не запускати опубліковані файли через Jekyll).*


## Додавання вашого контенту

### Файли *.md

Файли .md — це файли markdown, Markdown — це легка мова розмітки, яку ви можете використовувати для додавання елементів форматування до документів із звичайним текстом. Залежно від обсягу вашого контенту, ви можете розмістити всю інформацію про вашу гру в одному файлі *.md або, як я це зробив на [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), створити окремі файли для кожного розділу. Файл "sample.md" містить кілька прикладів форматування.

Мову Markdown дуже легко вивчити, використовуйте посилання, наведене в пункті 2 розділу "Передумови" вище, щоб отримати повний перелік синтаксису.

### _Sidebar.md

Це ваше меню, навігаційна панель у лівій частині вебсайту. Після того, як ви додали файл markdown до свого репозиторію, вам потрібно додати файл сюди, щоб його вміст був включений. Дотримуйтесь існуючого форматування.


## Увімкнення Github Pages для перетворення репозиторію на вебсайт

1. У своєму репозиторії натисніть 'Settings' (Налаштування)

![Website-Step1](/_media/Website-Step1.png)

2. Оберіть 'Pages' у меню ліворуч

![Website-Step2](/_media/Website-Step2.png)

3. Якщо ви не зробили репозиторій 'public', у вас є два варіанти:
    a. Зробити репозиторій публічним, що дозволить вам використовувати Github pages для безкоштовного розміщення вашого вебсайту SRD
    b. Оновити свій обліковий запис Github (на момент написання цього тексту це коштує $4 на місяць або $48 щорічного внеску)

4. У розділі 'Branch' оберіть 'main' і натисніть save (зберегти)

5. Зачекайте 10-20 секунд, а потім оновіть сторінку

6. Тепер ви побачите свою URL-адресу, наприклад https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## Використання плагіна Fontawesome та/або Material Icons для відображення безкоштовних іконок у вашій SRD

### Fontawesome

Використовуйте Fontawesome, щоб отримати безкоштовні іконки та анімовані іконки. Підписані користувачі можуть використовувати Pro Icons

1. Знайдіть іконку на [Fontawesome](https://fontawesome.com/icons)
2. Оберіть іконку
3. У спливаючому вікні, на вкладці HTML, скопіюйте все між " "

```EXAMPLE
<i Клас="fa-solid fa-dice-d20"></i>
```

4. Помістіть скопійований текст між `:` без пробілів

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Використовуйте Material Icons для отримання додаткових безкоштовних іконок

1. Знайдіть іконки на [Material Icons](https://fonts.google.com/icons)
2. Скопіюйте та вставте веб-посилання span безпосередньо у ваші файли markdown

```markup
<span Клас="material-icons">face</span>
```
