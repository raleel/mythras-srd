# หัวข้อคู่มือสไตล์

ใช้หัวข้อระดับ h1 (`# Heading Title`) สำหรับชื่อบทหลัก หัวข้อ hx ทั้งหมดจะปรากฏในแถบด้านข้างเป็นบุ๊กมาร์ก

หากชื่อเรื่องไม่ใช่หัวข้อ h1 แถบด้านข้างจะแสดงข้อผิดพลาดที่ซ้ำซ้อนโดยแสดงหน้าและหัวข้อ h2 'ชื่อเรื่อง'

---
## หัวข้อส่วนต่างๆ (h2)

ใช้หัวข้อระดับ h2 (`## Section Heading`) ที่นำหน้าด้วยเส้นแบ่ง (`---`) สำหรับแต่ละส่วนหลักใหม่

### หัวข้อย่อยที่มีระดับ h เพิ่มขึ้น 1

ใช้หัวข้อระดับ h3 (`### Subsection Heading`) สำหรับแต่ละส่วนย่อยใหม่ และหัวข้อระดับ h4 (`#### Sub-Subsection Heading`) สำหรับแต่ละส่วนย่อยของส่วนย่อย

### การเพิ่มระดับของหัวข้อย่อย: 2 > 3 > 4

หัวข้อย่อยจะสับสนในแถบด้านข้างหากการเพิ่มระดับของ h ไม่ได้รับการจัดการอย่างถูกต้อง

เครื่องหมายหัวข้อควรเพิ่มขึ้นทีละหนึ่งหรือคงเดิม

h2 ตามด้วย h2 หรือ h3 นั้นใช้ได้ h3 ตามด้วย h3 หรือ h4 ก็ใช้ได้เช่นกัน

### ข้อผิดพลาดของหัวข้อย่อย
h2 ตามด้วย h4 ทำให้เกิดปัญหา แถบด้านข้างจะวางหัวข้อย่อยไว้ที่ไหนสักแห่งเหนือหัวข้อในสารบัญ

### การลดระดับของ h

ดูเหมือนจะไม่มีปัญหา เช่น h4 เป็น h3 หรือ h2 นั้นใช้ได้

## แบบแผนการจัดรูปแบบ

รูปแบบต่อไปนี้เป็นมาตรฐานสำหรับ SRD แบบ _จำเป็น_ ในรูปแบบ Markdown

### ตัวหนา ตัวเอียง และเส้นแบ่ง

- ใช้ดอกจันสองตัว (`**Bold**`) สำหรับข้อความ **ตัวหนา**
- ใช้ขีดล่าง (`_Italic_`) สำหรับข้อความ _ตัวเอียง_
   - _หมายเหตุ: หลีกเลี่ยงการใช้ดอกจันเดี่ยวสำหรับตัวเอียง!_
- ใช้แบ็กสแลช (`\_`) เพื่อ 'ละเว้น' อักขระ: \_ไม่เป็นตัวเอียง\_
- ใช้เครื่องหมายคำพูดมุม (``` `code` ```) เพื่อสร้าง `code blocks`
- ใช้ยัติภังค์สามตัว (`---`) เพื่อแทรกเส้นแบ่งแนวนอน

### แบบแผนสำหรับตัวหนาและตัวเอียง

พยายามยึดตามรูปแบบต่อไปนี้...

#### ชื่อเรื่องตัวหนา

ใช้ชื่อเรื่องตัวหนาสำหรับเมื่ออธิบายเวทมนตร์ ผลลัพธ์ ฯลฯ
- **ชื่อเวทมนตร์:** คำบรรยาย

#### ชื่อเรื่องตัวเอียง

ใช้ชื่อเรื่องตัวเอียงสำหรับ 'รายการย่อย' ของเวทมนตร์รูปแบบต่างๆ ฯลฯ
- **เวทมนตร์:** คำบรรยาย
  - **_เวทมนตร์รูปแบบ A:_** คำบรรยาย
  - **_เวทมนตร์รูปแบบ B:_** คำบรรยาย

#### การอ้างอิงชื่อเรื่องตัวเอียง

ใช้ชื่อเรื่องตัวเอียงเมื่ออ้างอิงถึงหนังสือ เช่น _Mythras Imperative_ หรือกฎพื้นฐานของ _Mythras_

## การจัดรูปแบบรายการ

### รายการแบบไม่มีลำดับ / จุดแสดงรายการ

- รายการแบบไม่มีลำดับสร้างด้วยยัติภังค์
- รายการแบบไม่มีลำดับสร้างด้วยยัติภังค์
  - เพิ่มระดับการเยื้องด้วยช่องว่าง 2 ช่องหรือแท็บ

### รายการแบบมีลำดับ / จุดที่เป็นตัวเลข

1. รายการแบบมีลำดับสร้างด้วยตัวเลขและจุด
2. รายการแบบมีลำดับสร้างด้วยตัวเลขและจุด
- ผสมกับจุดแสดงรายการ
	- และการเยื้อง
3. ผสมตัวเลขกลับเข้ามา
   - และจุดแสดงรายการ

### รายการที่มีหัวข้อ

สำหรับรายการของหัวข้อย่อยที่เกี่ยวข้อง ให้ทำตัวหนาที่ชื่อเรื่องและตามด้วยทวิภาค
- **ตัวอย่างที่ 1:** บลา บลา บลา...
- **ตัวอย่างที่ 2:** บลา บลา บลา...

### รายการที่มีหัวข้อตัวเอียง

สำหรับรายการของหัวข้อย่อยที่เกี่ยวข้อง ให้ทำตัวหนาและตัวเอียงที่ชื่อเรื่องและตามด้วยทวิภาค
- **_ตัวอย่างที่ 1:_** บลา บลา บลา...
- **_ตัวอย่างที่ 2:_** บลา บลา บลา...

## ตาราง

กำหนดหัวข้อย่อยให้ตารางเพื่อให้ปรากฏเป็นบุ๊กมาร์กในแถบด้านข้าง โดยเยื้องหนึ่งระดับจากส่วนหลัก

~ทำให้แถวหัวเรื่องเป็นข้อความตัวหนา~
การทำให้แถวหัวเรื่องเป็นตัวหนาจะแสดงผลเป็นข้อความปกติ CSS เริ่มต้นได้กำหนดให้แถวนั้นเป็นตัวหนาอยู่แล้ว

### การจัดแนวข้อความในตาราง

ใช้แถวที่ 2 สำหรับการจัดแนวเนื้อหา: `:--`, `:-:` หรือ `--:`
สิ่งนี้จะมีผลกับทั้งคอลัมน์

#### รูปแบบพื้นฐานของตาราง

| **คอลัมน์ 1** | **คอลัมน์ 2** |
| :-: | :-- |
| 1 | อัลฟ่า |
| 2 | เบต้า |
| 3 | แกมม่า |

### แบบแผนการจัดแนวข้อความ

- ใช้การจัดแนวกลางสำหรับตัวเลขหรือรายการค่าที่คล้ายกัน
- ใช้การจัดแนวซ้ายสำหรับประโยคข้อความ

#### ตารางตัวอย่างการจัดแนว

| **ตัวเลข** | **คำบรรยาย** |
| :-: | :-- |
| 1 | ข้อความบรรยาย |
| 2 | ข้อความบรรยาย |
| 3 | ข้อความบรรยาย |

#### ตัวอย่าง: ตารางความรุนแรงของไฟ

| **ความรุนแรง** | **ตัวอย่าง** | **เวลาในการจุดไฟ** | **ความเสียหาย** |
| :-: | :-- | :-: | :-: |
| 1 | เทียน | 1d4 | 1d2 |
| 2 | คบเพลิง | 1d3 | 1d4 |
| 3 | กองไฟ | 1d2 | 1d6 |
| 4 | ไฟไหม้เต็มห้อง | 1d2 | 2d6 |
| 5 | ลาวาภูเขาไฟ | ทันที | 3d6 |

## รายการเวทมนตร์และพลัง

เริ่มต้นส่วน 'สะอาด' ด้วยหัวข้อ h2 สำหรับรายการเวทมนตร์ พลัง ฯลฯ ที่มีอยู่ จากนั้นใช้ h3 สำหรับแต่ละรายการ

เวทมนตร์และพลังมักจะถูกนำเสนอในรายการเดียวแบบเรียบตามประเภทเวทมนตร์ (เวทมนตร์พื้นบ้าน, เทวนิยม ฯลฯ) แต่หากรายการต้องการส่วนย่อยของตัวเอง เช่น โรงเรียนหรือความเชี่ยวชาญของลัทธิ ให้เพิ่มระดับหัวข้อตามความเหมาะสม ตัวอย่างเช่น h2 สำหรับรายการปาฏิหาริย์เทวนิยม, h3 สำหรับลัทธิ: Mithras และ h4 สำหรับแต่ละปาฏิหาริย์ของลัทธิ Mithras

โดยเฉพาะในกรณีของเวทมนตร์ แต่ในการบรรยายใดๆ ที่ใช้คุณลักษณะที่เป็นคำสำคัญ ให้แสดงรายการในข้อความตัวเอียง

ข้อความบรรยายและกฎพิเศษใช้ข้อความปกติ

### การจัดรูปแบบรายการเวทมนตร์

```
## h2 List name

### List item

_Attributes_

Description text.
```

## บล็อกสถิติสิ่งมีชีวิต
เริ่มต้นส่วน 'สะอาด' ด้วยหัวข้อ h2 สำหรับรายการ บล็อกสถิติสิ่งมีชีวิตใช้ตารางและซับซ้อนกว่าในแง่ของการจัดรูปแบบและความต้องการพื้นที่ เพื่อความชัดเจน ให้หลีกเลี่ยงส่วนย่อยและเพิ่มเส้นแบ่งระหว่างรายการ

แต่ละตัวอย่างที่แสดงรายการควรมีดังต่อไปนี้...

- **ชื่อสิ่งมีชีวิต:** เส้นแบ่งตามด้วยหัวข้อ h3 สำหรับชื่อสิ่งมีชีวิต

- **รายการ MEG:** ลิงก์ภายนอกไปยังสิ่งมีชีวิตที่ระบุบน [Mythras Encounter Generator](https://mythras.skoll.xyz/)

- **รายละเอียดหลัก:** ชื่อ/ประเภทสิ่งมีชีวิต, คุณลักษณะ, ทักษะ และคำบรรยายพิเศษหรือหมายเหตุตัวละครตามที่ต้องการ

- **รายละเอียดอาวุธ:** คำบรรยายแบบย่อพร้อมคอลัมน์สำหรับชื่ออาวุธและคุณลักษณะต่อไปนี้: ขนาดตัว (รวมพลังที่นี่), ระยะเอื้อม (รวมระยะยิงที่นี่), ความเสียหาย, เกราะ/HP และกฎพิเศษใดๆ

- **ตำแหน่งที่ถูกโจมตีและเกราะ:** ตารางตำแหน่งจะแตกต่างกันไปตามกายวิภาคของสิ่งมีชีวิตที่แตกต่างกัน แต่ควรถูกรวมไว้แม้กระทั่งสำหรับมนุษย์ทั่วไป เพื่อเป็นวิธีในการติดตามเกราะและความเสียหาย

## ข้อผิดพลาดของชุมชน

### การพิมพ์ผิดและความสับสน

การแก้ไขเพื่อ 'ทำความสะอาด' ข้อความของผู้เขียนควรทำเพียงเล็กน้อย แต่การพิมพ์ผิดและข้อผิดพลาดอื่นๆ ควรเปลี่ยนแบบอินไลน์โดยไม่มีการทำเครื่องหมายใดๆ

### แผงข้อมูลข้อผิดพลาด

ในกรณีที่กฎที่กำหนดมีความคลุมเครือ ไม่สมบูรณ์ หรือผิดพลาด ให้เพิ่มหมายเหตุข้อผิดพลาดของชุมชนที่พับเก็บได้

อธิบายปัญหาโดยใช้ตัวเอียงโดยใช้ตัวหนาตัวเอียงสำหรับชื่อเรื่องของปัญหาเท่านั้น - _ไม่มีหัวข้อ h(x)!_ - เพื่อไม่ให้สร้างรายการแถบด้านข้างที่สับสน

หากเพิ่มข้อความทดแทน ให้ใส่ไว้ในเครื่องหมายคำพูดตัวหนาตัวเอียง นำหน้าด้วย "_Community Errata:_" ในตัวเอียงน้ำหนักปกติ

กฎเพิ่มเติมหากจำเป็น ควรนำเสนอในข้อความน้ำหนักปกติ

## คำเตือนเบ็ดเตล็ด

### บรรทัดว่าง / การขึ้นบรรทัดใหม่

เว้นบรรทัดว่างระหว่างประเภทของรายการที่แตกต่างกัน หัวข้อ, เส้นแบ่ง, ตาราง ฯลฯ สิ่งเหล่านี้จะไม่แสดงให้เห็นในมุมมองการอ่าน แต่การขาดหายไปของมันอาจทำให้เกิดปัญหาในการจัดรูปแบบ

### ข้อความหนาหรือเอียงหลายย่อหน้า

แต่ละย่อหน้าต้องถูกทำเครื่องหมายว่าเป็นข้อความตัวหนาหรือตัวเอียง บรรทัดใหม่ระหว่างย่อหน้าจะทำลายการจัดรูปแบบและทิ้งเครื่องหมายจัดรูปแบบที่ไม่มีคู่

### การสะกดคำแบบระหว่างประเทศ

ผู้มีอำนาจที่ล้าหลังและน่ารังเกียจได้เห็นสมควรที่จะลบการสะกดคำแบบอังกฤษทั้งหมดออกเพื่อสนับสนุนเวอร์ชันสหรัฐฯ ที่อ่อนแอกว่าในทางวัตถุ ให้ระวังคำ -OUR ในภาษาอังกฤษ: _armour_, _favour_ ฯลฯ
