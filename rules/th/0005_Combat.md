# การต่อสู้

การต่อสู้เป็นคุณลักษณะสำคัญของเกมเล่นบทบาทสมมติ การเผชิญหน้าด้วยความรุนแรงเป็นหนทางในการแก้ปัญหามาโดยตลอด ตั้งแต่การต่อสู้ด้วยแรงแค้นระหว่างคู่ปรับ ไปจนถึงการปะทะกันของกองทัพในยามสงคราม อย่างไรก็ตาม การต่อสู้ไม่จำเป็นต้องเป็นการต่อสู้ถึงตายเสมอไป การเผชิญหน้าบางครั้งอาจเป็นเพียงการดวลดาบที่จบลงโดยไม่มีใครบาดเจ็บ หรืออาจเป็นการวิวาทในบาร์แบบขำขัน _Mythras Imperative_ ใช้คำศัพท์หลายคำเพื่ออธิบายองค์ประกอบหลักของการต่อสู้ ซึ่งจะอธิบายในหัวข้อถัดไป แต่โดยภาพรวมแล้ว ได้แก่:
- **รูปแบบการต่อสู้:** ทักษะในการใช้อาวุธกลุ่มหนึ่งซึ่งเรียนรู้มาในฐานะส่วนหนึ่งของวัฒนธรรมหรือวิชาชีพ
- **รอบการต่อสู้:** ช่วงเวลาที่ใช้ในการบันทึกข้อมูล ครั้งละ 5 วินาที
- **การกระทำในการต่อสู้:** การกระทำที่เป็นไปได้ซึ่งตัวละครสามารถทำได้ระหว่างรอบโดยการใช้แต้มปฏิบัติการ
- **ขนาดอาวุธ:** ความยากในการปัดป้องอาวุธชนิดนั้นๆ
- **การปะทะ:** เมื่อนักสู้สามารถโจมตีหรือถูกโจมตีโดยคู่ต่อสู้โดยตรง ขึ้นอยู่กับสถานการณ์
- **ผลพิเศษ:** กลวิธีในการต่อสู้ที่สามารถใช้ได้หากนักสู้ฝ่ายใดฝ่ายหนึ่งได้เปรียบ

## รูปแบบการต่อสู้

รูปแบบการต่อสู้แสดงถึง "ชุด" ของอาวุธหลายชนิดที่เกี่ยวข้องกันตามธรรมชาติ ซึ่งช่วยลดความจำเป็นในการเรียนรู้อาวุธแต่ละชนิดแยกกัน

ประเด็นที่สำคัญที่สุดของทักษะการต่อสู้คือ ตัวละครจะได้เรียนรู้วิธีการใช้อาวุธแต่ละชนิดในทักษะ ทั้งแบบเดี่ยวและแบบผสมเพื่อให้สามารถสลับเปลี่ยนอาวุธได้ตามความจำเป็น การฝึกฝนการต่อสู้ไม่ได้เน้นเพียงแค่การใช้อาวุธเฉพาะอย่างภายใต้สภาวะที่ดีที่สุดเท่านั้น แต่ยังครอบคลุมถึงสิ่งที่ต้องทำเมื่อตกอยู่ในสถานการณ์ที่เสียเปรียบอย่างหนัก การฝึกฝนข้ามสายเช่นนี้เป็นส่วนสำคัญในการเตรียมความพร้อมให้นักสู้รับมือกับเหตุการณ์ที่ไม่คาดคิดในสนามรบ ซึ่งการที่อาวุธแตกหักหรือถูกปลดอาวุธนั้นเป็นไปได้เสมอ

ดังนั้น นักรบเถื่อนชาวไฮเปอร์โบเรียนอาจถูกคาดหวังให้รู้วิธีใช้หอก ขวานมือ หอกซัด และโล่ ในขณะที่นักรบชาวซูเมเรียนอาจถูกฝึกให้ใช้ดาบสั้น กระบอง โล่ และคันธนูแทน การตัดสินใจว่าจะรวมอาวุธไว้ในรูปแบบเดียวจำนวนเท่าใดนั้น สุดท้ายแล้วเป็นทางเลือกที่กำหนดโดยผู้คุมเกมและฉากของเกม

ตัวละครที่พยายามใช้อาวุธที่ไม่ครอบคลุมอยู่ในรูปแบบของตน ควรได้รับบทลงโทษทักษะหนึ่งระดับความยากหรือมากกว่านั้น

รูปแบบการต่อสู้ยังมีฟังก์ชันอื่นนอกเหนือจากการเรียนรู้กลุ่มทักษะอาวุธ เนื่องจากแต่ละรูปแบบได้รับการสอนโดยวัฒนธรรมหรืออาชีพเฉพาะ จึงได้รับการปรับให้เหมาะสมกับสภาพแวดล้อมหรือยุทธวิธีทางทหารที่กลุ่มนั้นต่อสู้อยู่เป็นปกติ ตัวอย่างเช่น คนเร่ร่อนบนหลังม้าจะเรียนรู้การต่อสู้จากบนอานม้า หรือทหารราบจะฝึกฝนการต่อสู้ในรูปแบบแถวชิด ดังนั้น ในฐานะโบนัสเพิ่มเติม รูปแบบการต่อสู้บางรูปแบบอาจได้รับคุณสมบัติหนึ่งอย่างหรือมากกว่า ซึ่งจะมอบความได้เปรียบภายใต้สถานการณ์บางอย่าง คุณสมบัติมีไว้เพื่อใช้กับอาวุธและสถานการณ์ของรูปแบบนั้นๆ เท่านั้น แน่นอนว่ามีคุณสมบัติมากมายนับไม่ถ้วน ซึ่งหลายอย่างเป็นเรื่องเฉพาะของยุคสมัยหรือโลกของแคมเปญนั้นๆ

##### ตารางคุณสมบัติรูปแบบการต่อสู้

| คุณสมบัติ | คำบรรยาย |
| :-- | :-- |
| นักหอกบนหลังสัตว์ | การชาร์จขณะอยู่บนหลังสัตว์ด้วยรูปแบบการต่อสู้ไม่มีบทลงโทษความยากหนึ่งขั้นในการโจมตี |
| การต่อสู้ในที่มืด | อนุญาตให้ผู้ใช้เพิกเฉยต่อบทลงโทษใดๆ ที่เกิดจากแสงสว่างไม่เพียงพอหรือการตาบอดชั่วคราว |
| บ้าระห่ำ | สามารถใช้ทักษะหลบหลีกเพื่อหลบการโจมตีในการต่อสู้ประชิดตัวโดยไม่ล้มลงกับพื้น |
| เน้นการป้องกัน | เพิ่มขนาดของอาวุธของคุณเมื่อปัดป้องขึ้นหนึ่งขั้น หากไม่มีการกระทำเชิงรุกใดๆ ในรอบนั้น |
| การต่อสู้แบบแถวชิด | อนุญาตให้กลุ่มนักรบสามคนขึ้นไปที่ไม่ได้ถูกล้อมเข้าสู่การตั้งแถวชิด ทำให้คู่ต่อสู้ที่เปิดช่องโหว่หรือกระจัดกระจายเสียเปรียบ และลดแต้มปฏิบัติการของศัตรูแต่ละตัวลงหนึ่งแต้มหากเข้ามาปะทะ |
| หมัดน็อคเอาท์ | เมื่อโจมตีโดยไม่ให้ตัวตั้งตัว ให้ถือว่าตำแหน่งที่ถูกทำให้มึนงงนั้นคงอยู่เป็นเวลาหลายนาทีแทนที่จะเป็นหลายเทิร์น |
| การต่อสู้บนหลังม้า | อนุญาตให้ตัวละครเพิกเฉยต่อขีดจำกัดทักษะที่กำหนดไว้บนการทอยการต่อสู้ด้วยทักษะการขี่ |
| นักแม่นปืนระยะไกล | เมื่อใช้อาวุธระยะไกล ให้เปลี่ยนการทอยตำแหน่งที่ถูกโจมตีแบบสุ่มไปยังตำแหน่งร่างกายข้างเคียง |
| การรบกองโจร | รูปแบบนี้อนุญาตให้โจมตีระยะไกลในขณะที่เดินหรือวิ่งได้ |
| อาวุธขว้าง | อาวุธประชิดใดๆ ในรูปแบบสามารถขว้างได้โดยไม่มีบทลงโทษต่อทักษะ แต่เมื่อใช้ในลักษณะนี้ ความเสียหายของอาวุธจะลดลงครึ่งหนึ่ง |
| ความสามารถมือเปล่า | อนุญาตให้ผู้ใช้ถือว่าการป้องกันและการปัดป้องด้วยมือเปล่าของเขามีขนาด 'ปานกลาง' ทำให้สามารถป้องกันตนเองจากคู่ต่อสู้ที่มีอาวุธได้ดีขึ้น |

## การดำเนินการต่อสู้

เพื่อเน้นย้ำถึงธรรมชาติที่แท้จริง การต่อสู้จะถูกติดตามแบบหมัดต่อหมัด เพื่อความสะดวกในการบันทึกข้อมูล การต่อสู้จะแบ่งออกเป็นรอบการต่อสู้ละห้าวินาที ในช่วงเวลานี้ นักสู้สามารถโจมตีประชิดหรือป้องกันการโจมตี เคลื่อนที่เข้าและออกจากระยะการต่อสู้ ยิงหรือขว้างอาวุธระยะไกล และอื่นๆ เช่นเดียวกับชีวิตจริง การปะทะกันส่วนใหญ่เมื่อเริ่มแล้วจะจบลงภายในเวลาไม่กี่วินาทีแทนที่จะเป็นนาที ในแง่ของเกม หมายถึงหลายรอบการต่อสู้ เว้นแต่ผู้เข้าร่วมจะถอยออกเพื่อตั้งค่าความไวใหม่ ประเมินสถานการณ์ทางยุทธวิธีใหม่ หรือเพียงแค่หยุดพักชั่วครู่ก่อนที่จะกลับมาปะทะกันอีกครั้ง เฉพาะการต่อสู้ระหว่างคู่ต่อสู้ที่สูสีกันหรือลำดับของคู่ต่อสู้เท่านั้นที่มีแนวโน้มจะยาวนานกว่านั้น

## อาวุธปืน

หากใช้อาวุธปืนในเกม _Mythras Imperative_ มีบางสิ่งที่ต้องพิจารณาจากความรุนแรงของการดวลปืน ประการแรก แทบจะเป็นไปไม่ได้เลยที่จะหลบเลเซอร์หรือกระสุนที่เดินทางเร็วกว่าปฏิกิริยาตอบสนองของมนุษย์ การใช้กฎการต่อสู้ตามที่นำเสนอ หมายความว่าเว้นแต่จะพยายามกระโดดหลบออกจากพื้นที่โดยใช้การหลบหลีก การโจมตีใดๆ จะทำให้เหยื่อเผชิญกับผลพิเศษหนึ่งอย่างหรือมากกว่าในทันที นอกจากนี้ยังเปลี่ยนเศรษฐศาสตร์ของแต้มปฏิบัติการ หากคุณไม่สามารถใช้แต้มเพื่อป้องกันตนเองเชิงรับได้ ตัวละครส่วนใหญ่จะจบลงด้วยการใช้การกระทำทั้งหมดเพื่อยิงโต้ตอบ โดยเสี่ยงดวงกับความไร้ความสามารถของศัตรู เพื่อจัดการกับการเปลี่ยนแปลงกระบวนทัศน์นี้ ทั้งผู้คุมเกมและผู้เล่นอาจจำเป็นต้องเปลี่ยนวิธีที่พวกเขามองและเข้าถึงการต่อสู้ด้วยปืน สิ่งที่ควรทราบคือ:

- การต่อสู้ด้วยปืนนั้นอันตราย!
- โดยรวมแล้ว ผู้คนให้ความสำคัญกับการไม่ถูกยิงมากกว่าการยิงผู้อื่น
- วิธีป้องกันที่พบบ่อยที่สุดคือการหาที่กำบัง
- การยิงกดดันเป็นวิธีที่ดีที่สุดในการป้องกันไม่ให้ศัตรูยิงโต้ตอบ
- อาวุธปืนมีความแม่นยำต่ำอย่างน่าประหลาดใจ เว้นแต่จะใช้เวลาในการพิงและ/หรือเล็ง
- เมื่อคุณถูกยิง สิ่งเลวร้ายจะเกิดขึ้น

การป้องกันตนเองจากปืนส่วนใหญ่กลายเป็นเรื่องของเกราะป้องกันร่างกาย การใช้ที่กำบัง และการพยายามป้องกันไม่ให้คู่ต่อสู้สามารถยิงโต้ตอบได้ ดังนั้น การต่อสู้ด้วยปืนส่วนใหญ่จึงกลายเป็นเรื่องยุทธวิธีอย่างมาก ทั้งการยิงกดดัน การเคลื่อนที่อ้อมข้าง และการไล่ศัตรูออกจากที่กำบังที่แน่นหนา ซึ่งตัวละครอาจใช้เวลาทั้งรอบการต่อสู้ไปกับการถูกตรึงไว้และไม่สามารถตอบโต้ได้จนกว่าฝ่ายตรงข้ามจะหยุดยิง... ซึ่งผู้เล่นบางคนอาจพบว่าน่าเบื่อหน่ายอย่างยิ่ง

มีความเป็นไปได้โดยสมบูรณ์ที่การต่อสู้ด้วยปืนทั้งการต่อสู้จะไม่มีใครได้รับบาดเจ็บเลย เพียงแค่ฝ่ายหนึ่งยอมแพ้เนื่องจากกระสุนหมดหรือหนีออกจากการต่อสู้ไปเลย ท้ายที่สุดแล้ว มีคนไม่กี่คนที่ต้องการเสี่ยงที่จะถูกกระสุนจากอาวุธแบบอัตโนมัติเต็มรูปแบบพุ่งเข้าใส่

ตลอดกฎการต่อสู้เหล่านี้ ประเภทการกระทำบางอย่าง ผลพิเศษ และสถานการณ์ต่างๆ จะใช้กับการต่อสู้ด้วยอาวุธปืนเท่านั้น และสิ่งเหล่านี้จะถูกทำเครื่องหมายไว้ตามนั้น

## รอบการต่อสู้และความไว

รอบการต่อสู้ใช้คำศัพท์ที่สำคัญหลายคำ:

- **ความไว:** ลำดับของผู้ที่กระทำเมื่อใดในระหว่างเทิร์นของรอบการต่อสู้ ผู้คุมเกมจะนับถอยหลังผ่านค่าความไวจากสูงสุดไปต่ำสุด เพื่อให้ผู้เข้าร่วมแต่ละคนมีโอกาสใช้เทิร์นของตนเมื่อถึงหมายเลขของตน
- **เทิร์น:** ในระหว่างรอบการต่อสู้ละ 5 วินาที ผู้เข้าร่วมแต่ละคนมีโอกาสใช้หนึ่งเทิร์นหรือมากกว่า ขึ้นอยู่กับจำนวนแต้มปฏิบัติการที่พวกเขามี และวิธีที่พวกเขาใช้แต้มเหล่านั้น ในเทิร์นของตน ผู้เข้าร่วมจะดำเนินการหนึ่งการกระทำในการต่อสู้ ซึ่งประกอบด้วยการประกาศ การเคลื่อนที่เป็นไปได้ การทอยลูกเต๋าที่จำเป็น (รวมถึงปฏิกิริยาตอบสนอง) และการตัดสินผลของการกระทำ หากผู้เข้าร่วมคนใดมีแต้มปฏิบัติการเหลืออยู่ ผู้เล่นอาจผลัดกันใช้เทิร์นถัดไปตามลำดับความไว เมื่อไม่มีแต้มปฏิบัติการเหลืออยู่ หรือแต้มที่เหลืออยู่ถูกเก็บไว้สำหรับปฏิกิริยาตอบสนอง การเล่นจะดำเนินต่อไปสู่รอบการต่อสู้ถัดไป

คำศัพท์แต่ละคำจะถูกอธิบายโดยละเอียดด้านล่าง

#### ความไว

ความไวจะกำหนดลำดับการกระทำของผู้เข้าร่วมในรอบการต่อสู้ จะมีการทอยเมื่อเริ่มการต่อสู้และกำหนดว่าตัวละครแต่ละตัวจะกระทำเมื่อใด เว้นแต่จะมีบางอย่างเกิดขึ้นเพื่อเปลี่ยนสถานการณ์ เช่น การกระทำในการต่อสู้หรือผลพิเศษบางอย่าง ความไวจะยังคงมีผลจนกว่าจะถูกบังคับให้ทอยใหม่

ความไวคำนวณโดยผู้เข้าร่วมแต่ละคนทอย 1d10 และบวกตัวปรับความไว ใครก็ตามที่ได้ผลลัพธ์สูงสุดจะกระทำก่อน ตามด้วยผลลัพธ์สูงสุดอันดับสองและอื่นๆ เมื่อผู้เข้าร่วมสองคนขึ้นไปได้คะแนนเท่ากัน ผู้ที่มีความคล่องแคล่วสูงกว่าจะกระทำก่อน หากยังคงเสมอกัน ให้แต่ละคนทอยลูกเต๋าโดยผู้ที่ทอยได้แต้มสูงกว่าจะได้กระทำก่อนอีกฝ่าย

#### การกระทำในการต่อสู้

เมื่อกำหนดความไวแล้ว ผู้เข้าร่วมจะมีศักยภาพในการดำเนินการต่อสู้หลายอย่างในระหว่างแต่ละรอบการต่อสู้ ตัวละครทุกตัวได้รับ 2 แต้มปฏิบัติการต่อรอบ แต่เวลาที่พวกเขาสามารถกระทำได้นั้นจำกัดอยู่เพียงว่าการกระทำนั้นเป็นเชิงรุกหรือเชิงรับ

การกระทำเชิงรุกสามารถพยายามทำได้ในเทิร์นของตัวละครเองเท่านั้น นั่นคือ ในระหว่างความไวของเขา การกระทำเชิงรุกคือการกระทำที่ตัวละครเป็นผู้ริเริ่ม เช่น การโจมตีด้วยอาวุธ

การกระทำเชิงรับคือการกระทำที่ตัวละครทำเพื่อโต้ตอบหรือต้านทานการกระทำที่ทำต่อพวกเขา อนุญาตให้พยายามโต้ตอบได้เพียงหนึ่งครั้งต่อหนึ่งภัยคุกคาม ตัวอย่างเช่น การพยายามปัดป้องการโจมตี

แต้มปฏิบัติการที่ไม่ได้ใช้จะไม่ถูกสะสมจากรอบหนึ่งไปสู่อีกรอบหนึ่ง

## การกระทำในการต่อสู้

การกระทำในการต่อสู้คือการกระทำที่สามารถทำได้ระหว่างการต่อสู้ การชักอาวุธ การร่ายเวท หรือการกระโดดหลบการโจมตี ล้วนเป็นตัวอย่างของการกระทำในการต่อสู้ ส่วนใหญ่จะเกี่ยวข้องกับองค์ประกอบของการต่อสู้เอง แต่บางอย่างเกี่ยวข้องกับกิจกรรมภายนอกขอบเขตของเวทมนตร์และอาวุธ

ตามที่กล่าวไว้ก่อนหน้านี้ ความถี่ที่ตัวละครสามารถกระทำได้ต่อรอบจะถูกจำกัดด้วยแต้มปฏิบัติการที่มีอยู่ของพวกเขา แต้มเหล่านี้จะถูกใช้ตลอดรอบการต่อสู้เพื่อดำเนินการต่างๆ ในการต่อสู้ เมื่อแต้มปฏิบัติการของนักสู้หมดลง พวกเขาจะไม่สามารถกระทำได้อีกในช่วงที่เหลือของรอบนั้น และต้องรอจนกว่าแต้มจะรีเซ็ตที่จุดเริ่มต้นของรอบถัดไป

เว้นแต่จะระบุไว้เป็นอย่างอื่น การกระทำในการต่อสู้ใดๆ (ยกเว้นการกระทำ "ฟรี") จะมีค่าใช้จ่ายหนึ่งแต้มปฏิบัติการ ดังนั้น นักสู้จำเป็นต้องพิจารณาอย่างรอบคอบว่าจะใช้แต้มปฏิบัติการของตนอย่างไรและเมื่อใด พวกเขาอาจกระทำอย่างดุดันหรือตั้งรับตามที่ต้องการ โดยโต้ตอบกับสถานการณ์การต่อสู้ที่กำลังพัฒนาไปอย่างมีพลวัต

### การกระทำเชิงรุก

ต่อไปนี้คือกิจกรรมที่ตัวละครสามารถพยายามทำในเทิร์นของตนได้โดยการใช้แต้มปฏิบัติการ โปรดทราบว่าการกระทำบางอย่าง เช่น การร่ายเวทหรือการบรรจุกระสุนใหม่อาจต้องใช้เวลาหลายเทิร์นจึงจะสำเร็จ แต่ละเทิร์นจะใช้แต้มปฏิบัติการของตนเอง

#### โจมตี

ตัวละครสามารถพยายามโจมตีด้วยอาวุธประชิดหรือใช้อาวุธระยะไกล

#### เตรียมพร้อมรับแรงกระแทก

ตัวละครเตรียมพร้อมรับแรงกระแทกโดยยืนในท่าที่มั่นคงและเอนตัวไปในทิศทางของการโจมตีที่กำลังจะมาถึง เพื่อวัตถุประสงค์ในการต้านทานการผลักถอยหลังหรือการโจมตีแบบกระโดด ขนาดตัวของตัวละครจะถูกถือว่าใหญ่ขึ้น 50% เมื่อเทียบกับผลพิเศษกระแทก ขนาดตัวจะถูกคูณสอง

#### ร่ายเวท/ใช้พลังจิต

ตัวละครสามารถพยายามร่ายเวท เรียกใช้พลังบางอย่าง และอื่นๆ เวทมนตร์ที่ซับซ้อนอาจต้องใช้หลายการกระทำในการร่ายให้เสร็จสิ้น เมื่อเสร็จสิ้น เวทมนตร์จะสามารถปล่อยออกมาได้ทุกเมื่อจนถึงเทิร์นถัดไปของผู้ร่าย ซึ่ง ณ จุดนั้นจะสามารถเก็บไว้เพื่อผลลัพธ์ในภายหลังได้ แต่ต้องใช้การกระทำเก็บเวท/พลังจิต (ดูด้านล่าง) เพื่อรักษาไว้เพื่อเตรียมการสำหรับการปล่อยในภายหลัง

#### เปลี่ยนระยะ

ตัวละครสามารถพยายามเข้าใกล้หรือถอยห่างจากคู่ต่อสู้ ตราบใดที่พวกเขาไม่ได้ติดพันในการต่อสู้ประชิดตัวกับคู่ต่อสู้หรือถูกตรึงโดยการยิงของศัตรูในสถานการณ์การต่อสู้ระยะไกล

#### ชาร์จ

การกระทำชาร์จช่วยให้ตัวละครเคลื่อนที่เข้าสู่ระยะปะทะด้วยความเร็วในการวิ่งหรือวิ่งเต็มสปีด โดยใช้โมเมนตัมของการชาร์จเพื่อทำการโจมตีระยะประชิดที่รุนแรงขึ้น กฎเหล่านี้ครอบคลุมโดยละเอียดมากขึ้นในหัวข้อ [การชาร์จ](0005_Combat.md?id=charging) ด้านล่าง

#### หน่วงเวลา

ตัวละครสำรองการกระทำหนึ่งอย่างหรือมากกว่าเพื่อดำเนินการเชิงรับในภายหลัง เช่น การขัดจังหวะหรือการปัดป้อง ค่าใช้จ่ายแต้มปฏิบัติการของการหน่วงเวลาจะถูกครอบคลุมโดยการกระทำใดก็ตามที่ทำจริงในที่สุด หากการกระทำที่หน่วงเวลาไม่ได้ทำก่อนเทิร์นถัดไปของตัวละคร ตัวละครจะถือว่ามีความลังเล (ดูด้านล่าง) และแต้มปฏิบัติการจะสูญเสียไป

#### ลังเล

ตัวเลือกเริ่มต้นหากไม่ได้เลือกการกระทำอื่น ตัวละครเพียงแค่เสียเทิร์นไปโดยไม่ได้ทำอะไรที่มีประโยชน์

#### เก็บเวท/พลังจิต

เมื่อการร่ายเสร็จสิ้น ตัวละครอาจเก็บเวทหรือพลังจิตไว้ชั่วคราว เพื่อรอเวลาที่เหมาะสมที่สุดในการปล่อยออกมา เวทมนตร์อาจถูกเก็บไว้ตราบเท่าที่ตัวละครยังคงดำเนินการนี้ในเทิร์นต่อๆ ไป แต่นี่จะอนุญาตให้ศัตรูใช้ปฏิกิริยาโต้ตอบเวทมนตร์ได้ฟรีหากเกี่ยวข้องกับเวทมนตร์นั้น การทอยทักษะจริงเพื่อร่ายเวทที่เก็บไว้นั้นจะไม่ทำจนกว่าจะปล่อยเวทออกมา

#### ขึ้นขี่

ตัวละครสามารถขึ้นหรือลงจากสัตว์พาหนะหรือยานพาหนะ พาหนะที่ตัวใหญ่เป็นพิเศษอาจต้องใช้เวลาหลายเทิร์นจึงจะสำเร็จ

#### เคลื่อนที่

หากไม่ได้ติดพันกับคู่ต่อสู้ ตัวละครสามารถเคลื่อนที่ในระยะทางใดก็ได้ที่ผู้คุมเกมเห็นว่าเหมาะสมกับสถานการณ์

#### ชิงความได้เปรียบ

ตัวละครสามารถต่อสู้กับคู่ต่อสู้หลายคนในการทอยแบบต่อต้านกลุ่มของทักษะการหลบหลีก ผู้ที่ทอยสู้เขาไม่ได้จะไม่สามารถโจมตีเขาได้ในรอบการต่อสู้นั้น ดูส่วนเกี่ยวกับ [การชิงความได้เปรียบ](0005_Combat.md?id=outmaneuvering) ด้านล่าง

#### เตรียมอาวุธ

ตัวละครอาจหยิบ ชัก เก็บ ถอน หรือบรรจุกระสุนอาวุธหรือวัตถุอื่นๆ การหยิบวัตถุที่ตกอยู่ใกล้ๆ ต้องใช้ 2 การกระทำ: หนึ่งการกระทำเพื่อเคลื่อนที่และเอื้อมลงไปหยิบวัตถุ และการกระทำที่สองเพื่อกลับสู่ท่ายืนเตรียมพร้อม อาวุธขีปนาวุธบางชนิดต้องใช้หลายการกระทำในการบรรจุกระสุนใหม่

#### บรรจุกระสุนใหม่ (อาวุธปืน)

เช่นเดียวกับการเตรียมอาวุธ เวลาในการบรรจุกระสุนใหม่อาจแตกต่างกันไปอย่างมากตามประเภทของอาวุธ ปืนคาบศิลาแบบใช้ดินปืนแบบยิงทีละนัดจะใช้เวลาบรรจุกระสุนนานกว่าการเปลี่ยนซองกระสุนหรือแหล่งพลังงานมาก

#### กู้คืนท่ายืน

หากไม่ได้ติดพันกับคู่ต่อสู้ ตัวละครสามารถกู้คืนท่ายืนของตนจากการถูกทำให้ล้มหรือล้มลงได้โดยอัตโนมัติ หากติดพันอยู่ ตัวละครต้องชนะการทอยแบบต่อต้านพละกำลังหรือกรีฑากับคู่ต่อสู้ก่อนที่จะยืนขึ้น การแข่งขันนี้ไม่มีค่าใช้จ่ายแต้มปฏิบัติการใดๆ ในการตัดสินผล

#### แอบมอง (อาวุธปืน)

การแอบมองช่วยให้คนที่กำลังหลบอยู่หลังที่กำบังสามารถแอบดูได้อย่างรวดเร็วเพื่อตัดสินว่าสถานการณ์ทางยุทธวิธีเป็นอย่างไร การกระทำนี้ปลอดภัยโดยพื้นฐาน ซึ่งอนุญาตให้ผู้สังเกตการณ์ทอยการรับรู้ได้หนึ่งครั้งก่อนจะก้มหลบกลับไปหลังที่กำบัง อย่างไรก็ตาม หากการทดสอบการรับรู้พลาดขั้นรุนแรง พวกเขาจะยื่นหัวออกไปมากเกินไปอย่างโง่เขลาหรือยังคงอยู่ในระยะสายตานานพอที่ศัตรูจะยิงใส่ได้

#### ประคองอาวุธ (อาวุธปืน)

ช่วยให้ตัวละครสร้างท่าการยิงที่มั่นคงและประคองอาวุธอัตโนมัติเพื่อให้คงที่ ต้องให้ตัวละครเปิดเผยตัวอย่างน้อยบางส่วนและไม่ได้รับความคุ้มครองโดยที่กำบังโดยสมบูรณ์ ประโยชน์หลักคือการลดบทลงโทษการถีบกลับของการยิงแบบเบิรสต์หรืออัตโนมัติเต็มรูปแบบลงหนึ่งขั้น ผลกระทบนี้เหมือนกับการเตรียมพร้อมรับแรงกระแทกในแง่ที่ว่าประโยชน์ของมันจะคงอยู่จนกว่าตัวละครจะเคลื่อนที่

#### ดิ้นรน

หากตัวละครตกเป็นเหยื่อของการโจมตีหรือผลพิเศษบางประเภท พวกเขาอาจพยายามแยกตัวออกจากสถานการณ์นั้น ตัวอย่างเช่น การดิ้นให้หลุดจากการจับของศัตรู

#### เปลี่ยนโหมดการยิง (อาวุธปืน)

การเปลี่ยนโหมดการยิงช่วยให้ผู้ใช้ปืนอัตโนมัติหรืออาวุธปืนแบบสองวัตถุประสงค์สามารถเปลี่ยนตัวเลือกบนอาวุธเพื่อใช้ประโยชน์จากโหมดการยิงอื่นๆ ได้ ดังนั้น ปืนไรเฟิลจู่โจมอาจถูกเปลี่ยนจากกึ่งอัตโนมัติเป็นเบิรสต์ เลือกกระสุนประเภทอื่น หรือระบบเสริม เช่น เครื่องยิงลูกระเบิดในตัว ในขณะที่อาวุธสมัยใหม่ต้องใช้แต้มปฏิบัติการในเทิร์นของตัวละครในการเปลี่ยนโหมด อาวุธปืนเทคโนโลยีขั้นสูงอาจอนุญาตให้ทำได้เป็นการกระทำฟรี ซึ่งกระตุ้นโดยการฝังอุปกรณ์อิเล็กทรอนิกส์หรือการอ่านจิตใจของผู้ใช้

#### เข้าที่กำบัง

การเข้าที่กำบังเป็นการกระทำเชิงรุกที่ช่วยให้นักยิงสามารถก้มหลบหลังที่กำบังที่มีอยู่ในบริเวณใกล้เคียง ทำให้ได้รับระดับความคุ้มครองบางอย่างจากการยิงที่เข้ามา ต่างจากการหลบหลีกตรงที่มันไม่ทำให้ผู้ใช้ล้มลง แต่ต้องอาศัยที่กำบังที่มีอยู่ เช่น การหลบกลับไปรอบมุมในทางเดินหรือก้มลงหลังโต๊ะในบาร์ ขึ้นอยู่กับสถานการณ์ ที่กำบังที่มีอยู่อาจเพียงพอหรือไม่เพียงพอที่จะปกป้องตัวละครได้อย่างสมบูรณ์ ประเภทของที่กำบังจะกำหนดคุณภาพการป้องกันด้วย เช่น ประตูเหล็กหนาอาจพิสูจน์ได้ว่าไม่สามารถทะลุทะลวงได้ด้วยกระสุน ในขณะที่ผนังไม้บางอาจให้แต้มเกราะเพียง 4 แต้ม สำหรับแนวทางทั่วไปเกี่ยวกับคุณภาพการป้องกันของวัสดุบางอย่าง ดูตารางในส่วน [วัตถุไม่มีชีวิต](0004_Game_System.md?id=inanimate-objects)

### การกระทำเชิงรับ

รายการนี้ระบุปฏิกิริยาตอบสนองที่สามารถใช้ได้ตลอดเวลาในระหว่างรอบการต่อสู้เพื่อตอบสนองต่อภัยคุกคามที่กำลังจะเกิดขึ้น เช่นเดียวกับรายการก่อนหน้า ปฏิกิริยาตอบสนองมีค่าใช้จ่ายหนึ่งแต้มปฏิบัติการในการดำเนินการ

#### โต้ตอบเวทมนตร์

ตัวละครสามารถพยายามยกเลิกหรือโต้ตอบเวทมนตร์ที่เข้ามาได้ โดยสมมติว่าเวทมนตร์ที่ใช้โต้ตอบมีเวลาในการร่ายหนึ่งเทิร์น มิฉะนั้นจะต้องเตรียมการล่วงหน้าและเก็บไว้ชั่วคราวโดยใช้การกระทำเก็บเวทมนตร์ การสกัดกั้นเวทมนตร์ได้สำเร็จในลักษณะนี้ถือว่าเป็นการลบล้างเวทมนตร์ทั้งหมด แม้กระทั่งเวทมนตร์ที่มีเป้าหมายหลายเป้าหมายหรือพื้นที่ที่มีผล

#### หลบหลีก

ตัวละครสามารถใช้ทักษะการหลบหลีกเพื่อพยายามกระโดดออกจากภัยคุกคาม เช่น ขีปนาวุธที่เข้ามาหรือการโจมตีแบบชาร์จ สิ่งนี้ทำให้ตัวละครอยู่ในสถานะล้มลง เว้นแต่จะได้รับการบรรเทาโดยความสามารถหรือสถานการณ์พิเศษ ดังนั้น เทิร์นถัดไปของตัวละครจึงมักใช้ไปกับการดำเนินการกู้คืนท่ายืนเพื่อยืนขึ้นอีกครั้ง

#### ขัดจังหวะ

เฉพาะตัวละครที่หน่วงเวลาเท่านั้น การกระทำเชิงรับนี้จะหยุดเทิร์นของคู่ต่อสู้ไว้ ณ จุดใดก็ตามเพื่อดำเนินการกระทำในเทิร์นที่หน่วงไว้ หากไม่มีการเปลี่ยนแปลงในสถานการณ์ทางยุทธวิธี คู่ต่อสู้จะดำเนินเทิร์นต่อไปหลังจากเทิร์นของตัวละครเสร็จสิ้น หากไม่สามารถบรรลุการประกาศเดิมได้ แต้มปฏิบัติการของคู่ต่อสู้จะสูญเปล่า การขัดจังหวะยังสามารถใช้เพื่อโจมตีฉวยโอกาสต่อทุกคนที่ผ่านเข้ามาใกล้ตัวละครที่กำลังหน่วงเวลาและอยู่ในระยะอาวุธ

#### ปัดป้อง

ตัวละครสามารถพยายามป้องกันการโจมตีที่เข้ามาโดยใช้การผสมผสานระหว่างการปัดป้อง การเอนตัว การก้มหลบ และการก้าวเท้าเพื่อลดความเสียหายของการโจมตี

### การกระทำฟรี

การกระทำฟรี (ระบุไว้ด้านล่าง) สามารถดำเนินการได้ตลอดเวลาในระหว่างรอบการต่อสู้และไม่มีค่าใช้จ่ายแต้มปฏิบัติการในการดำเนินการ

#### ประเมินสถานการณ์

หากไม่ได้ติดพันอยู่ ตัวละครสามารถทอยการรับรู้ได้โดยไม่มีค่าใช้จ่ายแต้มปฏิบัติการ ความสำเร็จจะเปิดเผยการเปลี่ยนแปลงที่เกี่ยวข้องในสถานการณ์ทางยุทธวิธี (เช่น การพบศัตรูที่กำลังเริ่มชาร์จ) การประเมินในขณะที่กำลังวิ่งส่งผลให้การทอยการรับรู้เป็นแบบยาก การวิ่งเต็มสปีดจะส่งผลให้เป็นการทอยแบบโหดหิน

#### ทิ้งไอเท็ม

การทิ้งไอเท็มเป็นการกระทำฟรี

#### ส่งสัญญาณ

หากไม่ได้ติดพันอยู่ การใช้ท่าทางหรือการส่งสัญญาณไปยังผู้เข้าร่วมหนึ่งคนหรือมากกว่า (หากพวกเขาสามารถรับรู้สัญญาณได้) เป็นการกระทำฟรี

#### พูด

ตัวละครสามารถพูดได้ตลอดเวลาในระหว่างการต่อสู้ แต่สิ่งที่พูดควรจำกัดอยู่ที่วลีสั้นๆ ที่สามารถเปล่งออกมาได้ในห้าวินาทีหรือน้อยกว่า ตัวอย่างเช่น "ระวังข้างหลัง!" หรือ "ไปลงนรกซะ!"

#### ใช้แต้มโชคลาภ

การใช้แต้มโชคลาภ เช่น เพื่อทอยผลลัพธ์เฉพาะใหม่ เป็นการกระทำฟรี#### ตำแหน่งป้องกัน

ตัวละครจะคอยเฝ้าระวังไม่ให้มีการโจมตีถูกตำแหน่งที่ถูกโจมตี (Hit ตำแหน่ง) เฉพาะจุดโดยการใช้อาวุธของเขาปิดกั้นบริเวณนั้นไว้แบบรับ (Passive) การโจมตีใดก็ตามที่เข้ามาถูกตำแหน่งดังกล่าวจะถูกลดความเสียหายลงโดยอัตโนมัติตามปกติเช่นเดียวกับการใช้ขนาดอาวุธในการปัดป้อง การป้องกันนี้จะดำเนินต่อไปจนกว่าอาวุธที่ใช้จะถูกนำไปใช้โจมตีหรือปัดป้อง (Parry) แบบรุก การกำหนดหรือเปลี่ยนตำแหน่งที่ถูกโจมตีที่ต้องการคุ้มครองจะต้องทำก่อนที่ฝ่ายตรงข้ามจะทอยลูกเต๋าโจมตีตัวละคร เนื่องจากรูปแบบการออกแบบ โล่จึงสามารถคุ้มครองได้หลายตำแหน่งพร้อมกัน

สำหรับคำอธิบายเพิ่มเติม โปรดดู [การป้องกันแบบรับ (Passive Blocking)](0005_Combat.md?id=passive-blocking) ด้านล่าง

## การเคลื่อนที่

กฎต่อไปนี้เป็นกฎที่ใช้ในการเผชิญหน้าในการต่อสู้:

- การเคลื่อนที่กระทำได้โดยการใช้การกระทำเคลื่อนที่ (Move) หรือพุ่งตัว (Charge)
- การกระทำเคลื่อนที่ช่วยให้ตัวละครเคลื่อนที่ได้เป็นระยะทางเท่ากับอัตราการเคลื่อนที่พื้นฐาน (Base อัตราการเคลื่อนที่)
- การเคลื่อนที่จะทำได้เฉพาะตัวละครที่ไม่ได้อยู่ในการต่อสู้เท่านั้น (ยกเว้นกรณีพิเศษ เช่น การหลบหลีก/Outmaneuvering)
- ยกเว้นในบางกรณี (เช่น การพุ่งตัว) การเคลื่อนที่ที่สำคัญทั้งหมดจะสิ้นสุดลงเมื่อตัวละครเข้าสู่ระยะการเผชิญหน้าของฝ่ายตรงข้ามที่ตั้งใจไว้
- เว้นแต่จะพุ่งตัวผ่านจุดปะทะ การเคลื่อนที่เข้าสู่โซนการเผชิญหน้าของฝ่ายตรงข้ามจะทำให้ทั้งสองฝ่ายถือว่าอยู่ในการเผชิญหน้าซึ่งกันและกัน
- เมื่อเข้าสู่การต่อสู้แล้ว ตัวละครไม่สามารถเคลื่อนที่หนีจากฝ่ายตรงข้ามได้เว้นแต่จะถอนตัว (Withdraw) จากการต่อสู้ระยะประชิดก่อน
- การพยายามเคลื่อนที่ผ่านศัตรูที่ไม่ได้อยู่ในการต่อสู้และกำลังใช้การกระทำต่อสู้แบบรอจังหวะ (Delay Combat Action) จะอนุญาต (ในฐานะข้อยกเว้นเฉพาะ) ให้ฝ่ายตรงข้ามนั้นโจมตีตัวละครที่กำลังเคลื่อนที่ขณะผ่านไป หรือขัดขวางความคืบหน้าของตัวละคร ซึ่งจะนำไปสู่การต่อสู้ระยะประชิดในเทิร์นหรือรอบถัดไป

### อัตราการเคลื่อนที่ตามสถานการณ์

อัตราการเคลื่อนที่เหล่านี้ขึ้นอยู่กับสถานการณ์และไม่ใช่ตัวเลือกที่มีให้ใช้เสมอไป รายละเอียดหลายอย่างถูกระบุไว้ที่อื่นแต่จะรวมไว้ที่นี่เพื่อความสะดวก อัตราตามสถานการณ์เหล่านี้ส่วนใหญ่สามารถใช้เพิ่มเติมจากอัตราการเคลื่อนที่ปกติภายใต้ข้อจำกัดที่กำหนดไว้ ข้อมูลดังกล่าวมีรายละเอียดอยู่ในคำอธิบายเฉพาะด้านล่าง

#### การปีนป่าย

ตัวละครที่เคลื่อนที่ไปยังพื้นที่ที่ติดกัน หรือเริ่มเทิร์นถัดจากพื้นผิวหรือวัตถุที่สามารถปีนได้ สามารถปีนป่ายได้ในอัตราเท่ากับอัตราการเคลื่อนที่พื้นฐาน ตัวละครต้องไม่เคลื่อนที่เร็วกว่าการเดิน (Walk) และต้องมีระยะการเคลื่อนที่เหลืออยู่ โดยระยะทางที่ปีนได้จะลดลงตามการเคลื่อนที่ที่ใช้ไปแล้ว เกราะที่สวมใส่อยู่จะขัดขวางการปีนป่ายโดยอิงตามคะแนนเกราะ (เกราะ Points) ทั้งหมดที่สวมใส่

##### ตารางบทลงโทษการเคลื่อนที่ของเกราะ

| คะแนนเกราะทั้งหมดที่สวมใส่ | หมวดหมู่น้ำหนักบรรทุก | การเคลื่อนที่ |
| :-: | :-: | :-: |
| 0-7 | ไม่มี | 0 |
| 8-15 | เบา | -1 |
| 16-23 | ปานกลาง | -2 |
| 24-31 | หนัก | -3 |
| 32-39 | โหดหิน | -4 |
| 40+ | เหนือมนุษย์ | -5 |

## การต่อสู้ทำงานอย่างไร

การต่อสู้ใน _Mythras Imperative_ จะตัดสินด้วยการโจมตีหรือปัดป้องแต่ละครั้ง ซึ่งหมายถึงการแทง, การฟัน, การร่ายเวทมนตร์, หรือการยิงอาวุธหนึ่งครั้ง การกระทำเชิงรุกใดๆ จะเปิดโอกาสให้ฝ่ายตรงข้ามต้านทานด้วยการกระทำโต้ตอบ ดังนั้นแม้ตัวละครจะโจมตีโดนฝ่ายตรงข้าม แต่ศัตรูก็ได้รับอนุญาตให้ทอยลูกเต๋าเพื่อดูว่าพวกเขาสามารถปัดป้องการโจมตีก่อนที่มันจะสร้างความเสียหายได้หรือไม่ แนวคิดเดียวกันนี้ใช้ไม่ว่าจะเป็นการใช้อาวุธยิงใส่เป้าหมายที่พยายามดำน้ำหลบ หรือพยายามหลุดจากการเกาะกุมของปลาหมึกยักษ์

### การโจมตีและการปัดป้อง

การต่อสู้ระยะประชิดดำเนินการตามขั้นตอนดังนี้:

1. ในเทิร์นของตน ผู้โจมตีจะใช้แต้มปฏิบัติการ (แต้มปฏิบัติการ) ทอยลูกเต๋าเทียบกับทักษะการต่อสู้ (Combat ทักษะ) ของตน และจดบันทึกผลลัพธ์
2. หากต้องการ ผู้ป้องกันจะใช้แต้มปฏิบัติการ (แต้มปฏิบัติการ) เพื่อปัดป้อง (Parry) ทอยลูกเต๋าเทียบกับทักษะการต่อสู้ของตน และจดบันทึกผลลัพธ์
3. ระดับความสำเร็จของผลลัพธ์จะถูกเปรียบเทียบตามกฎการทอยแบบส่วนต่าง (Differential Roll)
4. ความแตกต่างใดๆ ที่เกิดขึ้นจะมอบผลพิเศษ (ผลพิเศษ) อย่างน้อยหนึ่งรายการให้แก่ฝ่ายที่ประสบความสำเร็จด้วยผลการทอยที่เหนือกว่า
5. หากผู้โจมตีทำได้สำเร็จ (Success) หรือสำเร็จขั้นรุนแรง (Critical) พวกเขาอาจทอยความเสียหายของอาวุธและใช้ตัวปรับความเสียหาย (ความเสียหาย ตัวปรับ) (ถ้ามี) หากเกี่ยวข้อง จะมีการกำหนดตำแหน่งที่ถูกโจมตี (Hit ตำแหน่ง) สำหรับการโจมตีนั้น
6. หากผู้ป้องกันทำได้สำเร็จ (Success) หรือสำเร็จขั้นรุนแรง (Critical) ให้ลดความเสียหายที่เกิดขึ้นตามขนาดเปรียบเทียบของอาวุธที่เกี่ยวข้อง
7. ลดความเสียหายที่เหลือด้วยคะแนนเกราะ (เกราะ Points) ของการป้องกันตามธรรมชาติหรือที่สวมใส่

โปรดทราบว่าผลพิเศษ (ผลพิเศษ) ใดๆ ที่เกิดจากการแลกเปลี่ยนการโจมตีนั้นไม่ขึ้นอยู่กับว่ามีการสร้างความเสียหายหรือไม่ เป็นไปได้มากที่ผู้ป้องกันจะได้รับระดับความสำเร็จที่สูงกว่า แต่ยังคงได้รับบาดเจ็บ

### ขนาดอาวุธ

อาวุธทุกชนิดใน _Mythras Imperative_ มีคุณลักษณะหลายประการตั้งแต่ความเสียหายที่สร้างได้ไปจนถึงจำนวนมือที่ต้องใช้ในการถือ ขนาดเป็นส่วนผสมของมวล, พลังงัด, และความเสถียรของอาวุธ และใช้เพื่อกำหนดความสามารถของอาวุธในการสร้างและปัดป้องความเสียหาย หมวดหมู่ขนาดคือ เล็ก, กลาง, ใหญ่, ยักษ์, และมหาศาล การโจมตีด้วยมือเปล่าของสิ่งมีชีวิตจะถูกกำหนดหมวดหมู่ที่คล้ายคลึงกันตามคุณสมบัติทางกายภาพของพวกมัน

### การลดความเสียหาย

หากผู้ป้องกันประสบความสำเร็จในการปัดป้อง พวกเขาจะสามารถลดความเสียหายของผู้โจมตี (ถ้ามี) ตามขนาดเปรียบเทียบของอาวุธที่ใช้

- การปัดป้องการโจมตีด้วยอาวุธหรือโล่ที่มีขนาดเท่ากันหรือใหญ่กว่าจะหักล้างความเสียหายทั้งหมด
- การปัดป้องด้วยอาวุธหรือโล่ที่มีขนาดเล็กกว่าหนึ่งระดับจะหักล้างความเสียหายได้เพียงครึ่งเดียว
- การปัดป้องด้วยอาวุธหรือโล่ที่มีขนาดเล็กกว่าสองระดับขึ้นไปจะไม่สามารถหักล้างความเสียหายใดๆ ได้

_ตัวอย่างเช่น การปัดป้องขวานยักษ์ (Huge) ด้วยโล่ไคท์ (Huge เช่นกัน) จะป้องกันความเสียหายทั้งหมด; การปัดป้องด้วยดาบยาว (Large) จะลดความเสียหายลงครึ่งหนึ่ง และการปัดป้องด้วยดาบสั้น (Medium) จะไม่สามารถป้องกันความเสียหายได้เลย_

### เกราะ

ความเสียหายใดๆ ที่ทะลุการปัดป้องของผู้ป้องกันจะถูกลดทอนลงอีกด้วยคะแนนเกราะ (เกราะ Points) ของการป้องกันตามธรรมชาติ (เช่น เกล็ดหรือกระดอง) หรือเกราะที่สวมใส่ หากผู้ป้องกันมีทั้งสองอย่าง ทั้งสองค่าจะรวมกันเพื่อลดความเสียหาย

เนื่องจากมวลและข้อจำกัดในการเคลื่อนที่ ค่าคะแนนเกราะที่สูงที่สุดของเกราะที่ตัวละครสวมใส่จะทำหน้าที่เป็นบทลงโทษต่อการทอยความไว (ความไว) ของพวกเขา

### การปัดป้องการโจมตีที่พลาด

หากผู้โจมตีทอยการโจมตีเริ่มต้นพลาด ผู้ป้องกันมีทางเลือกในการใช้แต้มปฏิบัติการ (แต้มปฏิบัติการ) เพื่อปัดป้อง (Parry) แม้ว่าการปัดป้องการโจมตีที่พลาดไปแล้วอาจดูไม่สมเหตุสมผล แต่ผู้ป้องกันที่มีทักษะสามารถใช้จุดนี้ให้เป็นประโยชน์เพื่อรับผลพิเศษ (ผลพิเศษ) อย่างน้อยหนึ่งอย่าง ซึ่งอาจทำให้ศัตรูอ่อนแอลงหรือหมดสภาพต่อสู้ และเก็บรักษาเทิร์นถัดไปเพื่อใช้ในการกระทำอื่นๆ ได้

### ไม่สามารถหรือไม่เต็มใจที่จะปัดป้อง

ในสถานการณ์ที่ผู้ป้องกันไม่สามารถปัดป้องได้เนื่องจากไม่มีแต้มปฏิบัติการ (แต้มปฏิบัติการ) เหลือ หรือเนื่องจากมีความมั่นใจในความสามารถของตนที่จะรับมือการโจมตี จึงเลือกที่จะไม่ปัดป้อง พวกเขาจะถูกปฏิบัติเสมือนว่าทอยได้ความล้มเหลว (Failure) โดยอัตโนมัติ ซึ่งส่งผลให้ผู้โจมตีที่สำเร็จได้รับผลพิเศษ (ผลพิเศษ) อย่างน้อยหนึ่งรายการ

### การทอยที่ไม่สำเร็จและความพลาดขั้นรุนแรง (พลาดขั้นรุนแรง)

หากทั้งสองฝ่ายทอยทักษะล้มเหลว หรือผู้ป้องกันตัดสินใจไม่ใช้ประโยชน์จากการโจมตีที่พลาดไป ลำดับการโจมตี-ปัดป้องจะสิ้นสุดลง และการต่อสู้จะดำเนินต่อไปยังผู้เข้าร่วมที่มีค่าความไว (ความไว) สูงที่สุดในลำดับถัดไป

## ผลพิเศษ (ผลพิเศษ)

การต่อสู้เป็นอะไรที่มากกว่าการบาดเจ็บหรือการฆ่าคู่ต่อสู้ ศิลปะการต่อสู้สอนวิธีการมากมายในการเอาชนะศัตรู อาจทำให้พวกเขาช่วยเหลือตัวเองไม่ได้ หรือบังคับให้พวกเขาอยู่ในสถานการณ์ที่ต้องยอมจำนน โดยไม่จำเป็นต้องสร้างความเสียหายแก่พวกเขา ผลพิเศษ (ผลพิเศษ) เป็นตัวแทนของเทคนิคเหล่านี้และควบคุมวิธีการที่พวกมันเกิดขึ้นในเกม

เมื่อใดก็ตามที่คู่ต่อสู้เข้าสู่การทอยแบบส่วนต่าง (Differential Roll) ของทักษะการต่อสู้ของตน ความแตกต่างใดๆ ที่เกิดขึ้นในระดับความสำเร็จจะบ่งบอกถึงโอกาสที่ผลพิเศษ (ผลพิเศษ) จะเกิดขึ้น สิ่งนี้สะท้อนให้เห็นถึงการที่นักสู้ฝ่ายหนึ่งกำลังจัดวางคู่ต่อสู้ให้อยู่ในสถานการณ์ที่เสียเปรียบ ซึ่งสามารถใช้เล่ห์เหลี่ยมหรือกลยุทธ์เข้าทำได้

จำนวนของผลพิเศษที่ได้รับขึ้นอยู่กับความแตกต่างระหว่างระดับความสำเร็จ ดังที่แสดงในตารางระดับความสำเร็จแบบส่วนต่าง

หากได้รับผลพิเศษระหว่างการแลกเปลี่ยนการโจมตี จะต้องเลือกผลเหล่านั้นก่อนการทอยเพื่อหาความเสียหายและตำแหน่งที่ถูกโจมตี (Hit ตำแหน่ง) ในกรณีที่ผู้รับได้รับบาดเจ็บสาหัสเพิ่มเติมจากการได้รับผลพิเศษ การทอยความทรหด (ความทรหด) จะถูกตัดสินหลังจากใช้ผลดังกล่าวแล้ว

ผลพิเศษครอบคลุมสถานการณ์และเทคนิคที่หลากหลาย บางอย่างถูกออกแบบมาเพื่อการโจมตีโดยเฉพาะ ในขณะที่บางอย่างมีไว้สำหรับการป้องกัน และบางอย่างสามารถปรับใช้ได้กับทั้งสองกรณี ผลพิเศษบางอย่างยังสามารถจำกัดไว้ที่ประเภทอาวุธเฉพาะหรือการทอยลูกเต๋าเฉพาะ เช่น จำเป็นต้องได้รับผลการทอยสำเร็จขั้นรุนแรง (Critical) หรือพลาดขั้นรุนแรง (พลาดขั้นรุนแรง) ในการตรวจสอบทักษะ

เมื่อได้รับผลพิเศษตั้งแต่สองรายการขึ้นไป นักสู้สามารถผสมและเลือกรายการที่ต้องการได้อย่างอิสระ โดยมีเงื่อนไขว่าต้องเป็นไปตามข้อกำหนดเบื้องต้นสำหรับแต่ละรายการ ผลบางอย่างสามารถนำมาซ้อนกันได้ ตัวอย่างเช่น ผู้โจมตีที่ทอยได้สำเร็จขั้นรุนแรง (Critical Success) และชนะผลพิเศษสองรายการ อาจเลือก "เพิ่มความเสียหายสูงสุด (Maximize ความเสียหาย)" สองครั้ง แทนที่จะเลือกกลยุทธ์เชิงรุกแยกกันสองรายการ

### คำอธิบายผลพิเศษ

#### การบาดเจ็บโดยอุบัติเหตุ

ผู้ป้องกันปัดป้องหรือเบี่ยงการโจมตีของคู่ต่อสู้ในลักษณะที่ผู้โจมตีทำพลาดขั้นรุนแรง (พลาดขั้นรุนแรง) จนทำให้ตนเองได้รับบาดเจ็บ ผู้โจมตีต้องทอยความเสียหายใส่ตัวเองในตำแหน่งที่ถูกโจมตี (Hit ตำแหน่ง) แบบสุ่มโดยใช้อาวุธที่ใช้โจมตี หากมือเปล่า ผู้โจมตีจะฉีกขาดหรือทำให้อวัยวะภายในเสียหาย การทอยความเสียหายนี้จะไม่สนใจเกราะใดๆ

#### ลุกขึ้น

อนุญาตให้ผู้ป้องกันใช้จังหวะเปิดในช่วงสั้นๆ เพื่อลุกขึ้นยืน

#### กระแทก

ผู้โจมตีจงใจกระแทกคู่ต่อสู้จนเสียสมดุล ระยะที่ผู้ป้องกันจะเซถอยหลังหรือไปด้านข้างขึ้นอยู่กับอาวุธที่ใช้ โล่จะกระแทกคู่ต่อสู้ถอยหลังหนึ่งเมตรสำหรับทุกๆ 2 คะแนนความเสียหายที่ทอยได้ (ก่อนหักลบด้วยเกราะ, การปัดป้อง, และอื่นๆ) ในขณะที่อาวุธทุบจะกระแทกถอยหลังหนึ่งเมตรสำหรับทุกๆ สามคะแนน การกระแทกใช้ได้กับสิ่งมีชีวิตที่มีขนาด (ขนาด) สูงสุดไม่เกินสองเท่าของผู้โจมตีเท่านั้น หากผู้รับการโจมตีถูกผลักถอยหลังเข้ากับสิ่งกีดขวาง พวกเขาจะต้องทอยทักษะกายกรรม (Acrobatics) - หรือกรีฑา (กรีฑา) ที่ความยากระดับโหดหิน (ยาก) - เพื่อหลีกเลี่ยงการล้มหรือสะดุด สำหรับอาวุธปืน เนื่องจาก "การกระแทก" พึ่งพาการทำให้คู่ต่อสู้เสียสมดุลมากกว่าการผลักด้วยแรงกาย จึงสมเหตุสมผลที่กระสุนจะทำให้เป้าหมายเซหากถูกจุดที่เป็นอวัยวะ อาวุธพลังงานมีโอกาสน้อยที่จะสร้างผลกระทบเช่นนี้ เว้นแต่ฟิสิกส์ของลำแสงจะทำให้เกิดการระเบิดที่พื้นผิว

#### ทำให้เลือดไหล

การโจมตีทำให้เส้นเลือดใหญ่ฉีกขาด หากการโจมตีทะลุคะแนนเกราะและสร้างความเสียหายแก่เป้าหมาย ผู้ป้องกันต้องทำการทอยแบบส่วนต่าง (Opposed Roll) ของความทรหด (ความทรหด) เทียบกับการทอยการโจมตีเดิม หากผู้ป้องกันล้มเหลว (Fail) พวกเขาจะเริ่มมีเลือดไหลออกมามาก ในช่วงเริ่มต้นของแต่ละรอบการต่อสู้ ผู้รับจะเสียระดับความล้า (ความล้า) หนึ่งระดับ จนกว่าพวกเขาจะหมดสภาพและอาจตายได้ บาดแผลที่เลือดไหลสามารถห้ามได้ด้วยการทอยทักษะการปฐมพยาบาล (การปฐมพยาบาล) สำเร็จ แต่ผู้รับจะไม่สามารถทำการกระทำที่หนักหน่วงหรือรุนแรงได้อีกโดยไม่ทำให้แผลเปิดอีกครั้ง ดูการเสียเลือด ในส่วนระบบเกม สำหรับอาวุธปืน เนื่องจากอาวุธปืนส่วนใหญ่สร้างทางบาดแผลที่แคบมาก จึงเป็นเรื่องยากที่จะตัดหรือทำให้เส้นเลือดใหญ่ขาดมากกว่าการใช้อาวุธมีคมหรืออาวุธแทง ดังนั้นผล "ทำให้เลือดไหล" ควรเกิดขึ้นเฉพาะกรณีความสำเร็จขั้นรุนแรง (Critical Success) เท่านั้น - เว้นแต่ปืนนั้นจะเป็นอาวุธประหลาดบางชนิดที่ยิงดาวกระจาย, ลูกดอกมีดโกน, สนามพลังแบนราบ หรือกระสุนแปลกใหม่อื่นๆ

#### ทำให้คู่ต่อสู้ตาบอด

เมื่อได้ความสำเร็จขั้นรุนแรง (Critical) ผู้ป้องกันจะทำให้คู่ต่อสู้ตาบอดชั่วขณะโดยการปาเม็ดทราย, การสะท้อนแสงอาทิตย์จากโล่, หรือกลยุทธ์อื่นๆ ที่รบกวนการมองเห็นของผู้โจมตีชั่วคราว ผู้โจมตีต้องทำการทอยแบบส่วนต่าง (Opposed Roll) ของทักษะหลบหลีก (หลบหลีก) (หรือทักษะอาวุธหากใช้โล่) เทียบกับการทอยการปัดป้องเดิมของผู้ป้องกัน หากผู้โจมตีล้มเหลว (Fail) พวกเขาจะได้รับตัวปรับตามสถานการณ์ระดับยาก (ยาก) หรือโหดหิน (โหดหิน) สำหรับ 1d3 เทิร์นถัดไป ขึ้นอยู่กับวิธีการทำให้ตาบอด#### ข้ามเกราะ

ในการทอยลูกเต๋าได้พลาดขั้นรุนแรง ผู้โจมตีจะพบช่องว่างในเกราะธรรมชาติหรือเกราะที่ผู้ป้องกันสวมใส่ หากผู้ป้องกันสวมเกราะที่มีระดับการป้องกันสูงกว่าเกราะธรรมชาติ ผู้โจมตีจะต้องตัดสินใจว่าจะข้ามเกราะส่วนใดในสองส่วนนี้ ผลลัพธ์นี้สามารถทับซ้อนกันเพื่อข้ามเกราะทั้งสองอย่างได้ สำหรับวัตถุประสงค์ของผลลัพธ์นี้ การป้องกันทางกายภาพที่ได้รับจากเวทมนตร์จะถือว่าเป็นเกราะที่สวมใส่อยู่ แม้ว่าโดยทั่วไปแล้วการข้ามเกราะจะสามารถใช้กับการโจมตีรูปแบบใดก็ได้ แต่อาวุธบางประเภทอาจถูกจำกัดไม่ให้ใช้ผลลัพธ์นี้ (เช่น กระสุนลูกซองเนื่องจากมีการกระจายตัว) หรืออาจถูกรวมไว้ในประสิทธิภาพพื้นฐานของอาวุธนั้นๆ ทำให้ได้รับผลพิเศษนี้เป็นโบนัสเพิ่มเติมจากผลอื่นๆ ที่ได้รับ (เช่น กระสุนเทเลพอร์ต) ทั้งนี้ขึ้นอยู่กับว่าเกมมาสเตอร์ต้องการจำลองอาวุธนั้นอย่างไร

#### เลือกตำแหน่ง

เมื่อใช้อาวุธระยะประชิด ผู้โจมตีสามารถเลือกตำแหน่งที่การโจมตีจะเข้าปะทะได้อย่างอิสระ ตราบใดที่ตำแหน่งนั้นอยู่ในระยะเอื้อม หากใช้อาวุธระยะไกล รวมถึงอาวุธปืน การเลือกตำแหน่งจะใช้ได้เฉพาะกับการทอยลูกเต๋าได้พลาดขั้นรุนแรงเท่านั้น เว้นแต่เป้าหมายจะอยู่ในระยะประชิดและอยู่นิ่งหรือไม่รู้ตัวถึงการมาของผู้โจมตี สำหรับอาวุธปืน กล้องเล็งระยะไกลอาจช่วยขยายระยะนี้ได้

#### เลี่ยงการปัดป้อง

ในการทอยลูกเต๋าได้พลาดขั้นรุนแรง ผู้โจมตีสามารถเลี่ยงการปัดป้องที่ประสบความสำเร็จของฝ่ายตรงข้ามได้อย่างสมบูรณ์

#### ทำลายอาวุธ

อนุญาตให้ตัวละครสร้างความเสียหายแก่อาวุธของคู่ต่อสู้โดยเป็นส่วนหนึ่งของการโจมตีหรือการปัดป้อง หากเป็นฝ่ายโจมตี ตัวละครจะเล็งไปที่อาวุธที่ใช้ปัดป้องของฝ่ายป้องกันโดยเฉพาะและใช้ค่าความเสียหายของตนกับอาวุธนั้นแทนที่จะเป็นผู้ถือ อาวุธที่ถูกเล็งจะใช้ค่าเกราะของตัวเองในการต้านทานความเสียหาย หากค่าพลังชีวิตลดลงเหลือศูนย์ อาวุธนั้นจะพัง สำหรับอาวุธปืน เนื่องจากว่าการเล็งเป้าหมายที่อาวุธในมือในระยะไกลนั้นยากกว่าการเล็งตำแหน่งร่างกายเฉพาะเจาะจง จึงควรสงวนความสามารถนี้ไว้สำหรับการทอยลูกเต๋าได้พลาดขั้นรุนแรงเท่านั้น อย่างไรก็ตามมีข้อยกเว้นหลายประการ ประการแรกคือโล่ควรจะถูกโจมตีได้ง่ายกว่าโดยธรรมชาติ ประการที่สองคืออาวุธแปลกใหม่ที่ยิงลำแสงรูปกรวยซึ่งสามารถเล็งเป้าหมายวัตถุในมือภายในพื้นที่ที่ได้รับผลกระทบ เช่น ปืนเหนี่ยวนำที่ให้ความร้อนแก่โลหะ

#### ปลดอาวุธคู่ต่อสู้

ตัวละครปัด กระชาก หรือบิดอาวุธของคู่ต่อสู้ออกจากมือ คู่ต่อสู้จะต้องทำการทอยลูกเต๋าแบบประชันกันโดยใช้รูปแบบการต่อสู้ของเขาเทียบกับการทอยเดิมของตัวละคร หากผู้ถูกปลดอาวุธแพ้ อาวุธของเขาจะกระเด็นออกไปเป็นระยะทางเท่ากับผลการทอยตัวปรับความเสียหายของผู้ปลดอาวุธ (หน่วยเป็นเมตร) หากไม่มีตัวปรับความเสียหาย อาวุธจะตกอยู่ที่เท้าของคนที่ถูกปลดอาวุธ ขนาดที่แตกต่างกันของอาวุธจะมีผลต่อการทอย แต่ละขั้นที่อาวุธของผู้ปลดอาวุธใหญ่กว่าจะเพิ่มความยากในการทอยของคู่ต่อสู้ขึ้นหนึ่งระดับ ในทางกลับกัน แต่ละขั้นที่อาวุธของผู้ปลดอาวุธเล็กกว่าจะทำให้ความยากง่ายลงหนึ่งระดับ การปลดอาวุธใช้ได้กับสิ่งมีชีวิตที่มีค่ากำลังไม่เกินสองเท่าของตัวโจมตีเท่านั้น

#### ล้มเป้าหมาย

การโจมตี, อาวุธปืนเท่านั้น สมมติว่าเป้าหมายได้รับบาดเจ็บอย่างน้อยเล็กน้อยจากการยิง พวกเขาจะถูกบังคับให้ทำการทอยลูกเต๋าแบบประชันกันระหว่างค่าความทรหดของเขากับการทอยลูกเต๋าโจมตีของผู้โจมตี หากล้มเหลวแสดงว่าเป้าหมายทนต่ออาการช็อกและความเจ็บปวดไม่ไหว จนหมดสภาพต่อสู้และไม่สามารถต่อสู้ต่อไปได้ การฟื้นตัวจากการหมดสภาพต่อสู้สามารถทำได้โดยการตรวจสอบการปฐมพยาบาลที่ประสบความสำเร็จ หรือใช้เทคโนโลยีหรือยากระตุ้นหากมีอยู่ในแคมเปญ มิฉะนั้นอาการหมดสภาพต่อสู้ชั่วคราวจะคงอยู่เป็นระยะเวลาหนึ่งชั่วโมงหารด้วยอัตราการรักษาของเป้าหมาย

#### หลบเข้าที่กำบัง

การโจมตี, อาวุธปืนเท่านั้น ผลพิเศษนี้ช่วยให้ผู้ยิงสามารถหลบกลับเข้าที่กำบังได้ทันที โดยไม่ต้องรอให้ถึงรอบถัดไปเพื่อใช้การกระทำเข้าที่กำบัง ตัวละครจะต้องยืนหรือหมอบอยู่ใกล้กับที่กำบังรูปแบบใดรูปแบบหนึ่งจึงจะสามารถใช้การหลบเข้าที่กำบังได้

#### เสริมการปัดป้อง

ในการทอยลูกเต๋าได้พลาดขั้นรุนแรง ผู้ป้องกันจะสามารถเบี่ยงเบนแรงทั้งหมดของการโจมตีได้ ไม่ว่าขนาดของอาวุธนั้นจะเป็นอย่างไร

#### พันธนาการ

อนุญาตให้ตัวละครที่ใช้อาวุธประเภทพันธนาการ เช่น แส้หรือตาข่าย ทำให้ตำแหน่งที่ถูกโจมตีไม่สามารถเคลื่อนไหวได้ แขนที่ถูกพันธนาการจะไม่สามารถใช้อาวุธที่ถืออยู่ได้ ขาที่ถูกจับจะไม่สามารถเคลื่อนที่ได้ ส่วนศีรษะ หน้าอก หรือช่องท้องที่ถูกพันธนาการจะทำให้การทอยทักษะทั้งหมดมีระดับความยากเพิ่มขึ้นหนึ่งระดับ ในรอบถัดไป ผู้ใช้อาวุธสามารถใช้แต้มปฏิบัติการเพื่อพยายามทำให้เป้าหมายล้มโดยอัตโนมัติ เหยื่อที่ถูกพันธนาการสามารถพยายามปลดปล่อยตัวเองในรอบของตนโดยการพยายามทอยลูกเต๋าแบบประชันกันโดยใช้พละกำลังเพื่อกระชากตัวออก หรือโดยการชนะผลพิเศษและเลือกทำลายอาวุธ, ปลดอาวุธคู่ต่อสู้, หรือหลุดจากการพันธนาการ

#### บังคับความล้มเหลว

ใช้เมื่อคู่ต่อสู้พลาดขั้นรุนแรง ตัวละครสามารถรวมบังคับความล้มเหลวเข้ากับผลพิเศษอื่นใดที่ต้องใช้การทอยลูกเต๋าแบบประชันกัน บังคับความล้มเหลวจะทำให้คู่ต่อสู้ล้มเหลวในการทอยต้านทานโดยปริยาย ซึ่งส่งผลให้ถูกปลดอาวุธ ถูกทำให้ล้ม และอื่นๆ โดยอัตโนมัติ

#### ยึดจับ

หากคู่ต่อสู้อยู่ในระยะการต่อสู้มือเปล่าของผู้โจมตี พวกเขาสามารถใช้มือว่าง (หรือรยางค์ที่สามารถยึดจับได้) เพื่อยึดตัวคู่ต่อสู้ไว้ ทำให้คู่ต่อสู้ไม่สามารถถอยห่างจากการต่อสู้ได้ คู่ต่อสู้อาจพยายามดิ้นให้หลุดในรอบของตน ซึ่งต้องใช้การทอยลูกเต๋าแบบประชันกันระหว่างพละกำลังหรือมือเปล่า เทียบกับทักษะที่ผู้ยึดจับเลือก

#### แทงทะลุ

ทอยลูกเต๋าความเสียหายของอาวุธสองครั้ง โดยผู้โจมตีเป็นผู้เลือกว่าจะใช้ผลลัพธ์ใดในการโจมตี หากอาวุธนั้นเป็นอาวุธระยะประชิดและสามารถเจาะเกราะจนเกิดบาดแผลได้ ผู้โจมตีจะมีตัวเลือกที่จะทิ้งอาวุธไว้ในบาดแผลหรือกระชากออกในรอบถัดไป การทิ้งอาวุธไว้ในบาดแผลจะสร้างบทลงโทษความยากให้กับการทอยทักษะในอนาคตของเหยื่อ ความรุนแรงของบทลงโทษขึ้นอยู่กับขนาดของทั้งสิ่งมีชีวิตและอาวุธที่แทงทะลุตามที่ระบุไว้ในตารางผลลัพธ์การแทงทะลุด้านล่าง เพื่อความเรียบง่าย การแทงทะลุเพิ่มเติมด้วยอาวุธขนาดเดียวกันจะไม่สร้างบทลงโทษเพิ่ม การจะดึงอาวุธที่แทงทะลุออกระหว่างการต่อสู้ระยะประชิดต้องใช้การกระทำต่อสู้เตรียมพร้อมอาวุธ ผู้ถือจะต้องทอยพละกำลังให้สำเร็จ (หรือชนะการทอยพละกำลังแบบประชันกันหากคู่ต่อสู้ต้านทาน) ความสำเร็จจะดึงอาวุธออกมาได้สำเร็จ ทำให้เกิดบาดแผลเพิ่มเติมที่ตำแหน่งเดิมเท่ากับครึ่งหนึ่งของความเสียหายปกติของอาวุธนั้น แต่ไม่มีตัวปรับความเสียหาย ความล้มเหลวหมายความว่าอาวุธยังคงติดอยู่ในบาดแผลโดยไม่มีผลเพิ่มเติม อย่างไรก็ตามผู้ถือสามารถลองใหม่ได้ในรอบถัดไป โดยเฉพาะอาวุธที่มีเงี่ยง (เช่น ฉมวก) จะสร้างความเสียหายปกติ เกราะไม่สามารถลดความเสียหายจากการดึงอาวุธออกได้ ในขณะที่ยังแทงทะลุอยู่ ผู้โจมตีจะไม่สามารถใช้อาวุธนั้นในการปัดป้องได้

#### แม่นปืน

อนุญาตให้ผู้ยิงเลื่อนตำแหน่งที่ถูกโจมตีจากนัดที่ยิงไปได้หนึ่งขั้น ไปยังพื้นที่ร่างกายที่อยู่ติดกัน สรีรวิทยาจะมีอิทธิพลต่อสิ่งที่สามารถเล็งใหม่ได้และควรใช้สามัญสำนึกประกอบ ดังนั้น การใช้ผลพิเศษนี้กับมนุษย์จะอนุญาตให้ผู้โจมตีที่ทอยได้ตำแหน่งขา สามารถเลื่อนขึ้นไปยังช่องท้องแทนได้ ในทางกลับกัน การยิงกริฟฟินที่หน้าอกจะอนุญาตให้เลือกเล็งที่ขาหน้า ปีก หรือศีรษะได้

#### เพิ่มความเสียหายสูงสุด

ในการทอยลูกเต๋าได้พลาดขั้นรุนแรง ตัวละครสามารถแทนที่ลูกเต๋าความเสียหายหนึ่งลูกของอาวุธด้วยค่าสูงสุดได้ ตัวอย่างเช่น ขวานมือที่ปกติทำความเสียหาย 1d6 จะถูกคิดเป็น 6 แทน ในขณะที่กระบองใหญ่ที่ทำความเสียหาย 2d6 จะสร้างความเสียหาย 1d6+6 แทน ผลพิเศษนี้สามารถทับซ้อนกันได้ แม้ว่าจะสามารถใช้กับอาวุธธรรมชาติได้เช่นกัน แต่การเพิ่มความเสียหายสูงสุดจะไม่มีผลต่อตัวปรับความเสียหายของผู้โจมตี ซึ่งยังต้องทำการทอยตามปกติ

#### เจาะทะลุ

พลาดขั้นรุนแรง, อาวุธปืนเท่านั้น หากยิงใส่คู่ต่อสู้ที่ยืนเรียงแถวหรือกลุ่มคนที่หนาแน่น ผลพิเศษนี้จะช่วยให้กระสุนเดินทางทะลุผ่านเหยื่อรายแรกไปโดนรายที่สองที่อยู่ด้านหลังได้ หากกระสุนนั้นเอาชนะเกราะร่างกายของเป้าหมายแรกได้ อย่างไรก็ตามเหยื่อรายที่สองจะได้รับความเสียหายเพียงครึ่งเดียวเนื่องจากการสูญเสียพลังงานหรือความเร็วของกระสุน การเจาะทะลุโดยทั่วไปจะมีประโยชน์มากกว่ากับอาวุธพลังทำลายสูงที่สร้างความเสียหายได้มากหรืออาวุธที่มีความสามารถเจาะเกราะ ผลพิเศษใดๆ ที่เกิดขึ้นกับเป้าหมายแรกจะไม่ถูกนำไปใช้กับเป้าหมายที่สอง

#### ตรึงเป้าหมาย

อาวุธปืนเท่านั้น เช่นเดียวกับการกดดันเพื่อให้ได้เปรียบ ผลพิเศษนี้บังคับให้เป้าหมายต้องทำการทอยลูกเต๋าแบบประชันกันระหว่างค่าความมุ่งมั่นของเขากับการทอยลูกเต๋าโจมตีของผู้โจมตี หากล้มเหลวหมายความว่าเป้าหมายต้องก้มตัวหลบอยู่หลังที่กำบังใดก็ตามที่มีและไม่สามารถยิงตอบโต้ในรอบถัดไปได้ โปรดทราบว่าการตรึงเป้าหมายทำงานได้แม้ว่าจะไม่มีความเสียหายเกิดขึ้นจริงกับเป้าหมาย (อาจเป็นเพราะการหลบหลีกที่ประสบความสำเร็จหรือกระสุนไปโดนที่กำบังแทน) เนื่องจากผลลัพธ์นี้อาศัยผลทางจิตวิทยาจากการที่กระสุนปืนเฉียดผ่านไปในระยะใกล้มาก

แม้ว่าเหยื่อที่ถูกตรึงจะไม่สามารถยิงตอบโต้ได้ในระยะเวลาที่กำหนด แต่พวกเขาสามารถดำเนินการอื่นๆ ได้หากไม่ทำให้ตนเองเสี่ยงต่อการถูกยิง เช่น คลานหนีไปยังที่กำบังใหม่ สื่อสารกับผู้อื่น บรรจุกระสุนใหม่ และอื่นๆ

#### เตรียมโต้กลับ

ผู้ป้องกันอ่านรูปแบบการโจมตีของศัตรูและเตรียมการโต้กลับผลพิเศษเฉพาะอย่าง (ซึ่งควรจดบันทึกไว้อย่างลับๆ) หากคู่ต่อสู้พยายามสร้างผลพิเศษที่เลือกไว้กับเขาในระหว่างการต่อสู้ ผู้ป้องกันจะแทนที่ผลลัพธ์ของผู้โจมตีด้วยผลลัพธ์ของตนเองในทันที ซึ่งจะสำเร็จโดยอัตโนมัติ

#### บรรจุกระสุนเร็ว

เมื่อใช้อาวุธระยะไกล ผู้โจมตีจะลดเวลาในการบรรจุกระสุนสำหรับนัดถัดไปลงหนึ่งหน่วย ผลลัพธ์นี้สามารถทับซ้อนกันได้ สำหรับอาวุธปืน แม้จะมีประโยชน์สำหรับปืนดินดำหรือปืนบรรจุนัดเดียว แต่ผลลัพธ์นี้มีผลที่ชัดเจนน้อยกว่าเมื่อใช้กับอาวุธกึ่งอัตโนมัติหรืออัตโนมัติที่กระสุนนัดถัดไปจะเข้าสู่รังเพลิงโดยทันที อย่างไรก็ตาม การบรรจุกระสุนเร็วสามารถใช้เพื่อเปลี่ยนแม็กกาซีนอาวุธอย่างรวดเร็วแทนได้ นอกจากนี้ยังอาจใช้กับอาวุธพลังงานที่มีรอบเวลาในการชาร์จประจุไฟฟ้าหรือรอให้ลำกล้องปืนเย็นลง

#### สร้างรอยแผลให้ศัตรู

นักสู้สร้างรอยแผลให้กับคู่ต่อสู้ที่จะกลายเป็นเรื่องเล่าขานไปตลอดชีวิต เช่น คอที่เกือบขาด หรือตัวอักษร 'Z' ที่ถูกกรีดไว้อย่างวิจิตรบนหน้าอก

#### เลือกเป้าหมายใหม่

เมื่อผู้โจมตีพลาดขั้นรุนแรง ผู้ป้องกันอาจเคลื่อนไหวหรือปัดป้องการโจมตีให้ไปโดนผู้ที่อยู่ใกล้เคียงแทน สิ่งนี้กำหนดให้เป้าหมายใหม่ต้องอยู่ในระยะของอาวุธระยะประชิดของผู้โจมตี หรือในกรณีของการโจมตีระยะไกล ต้องยืนอยู่ในแนววิถีกระสุน เหยื่อรายใหม่จะถูกโจมตีโดยไม่ทันตั้งตัวจากอุบัติเหตุที่ไม่คาดคิดและไม่มีโอกาสที่จะหลบหลีกการโจมตีซึ่งจะโดนตัวโดยอัตโนมัติ อย่างไรก็ตาม เพื่อเป็นการชดเชย เหยื่อรายนี้จะไม่ได้รับผลพิเศษใดๆ

#### หลุดจากการพันธนาการ

ในการทอยลูกเต๋าได้พลาดขั้นรุนแรง ผู้ป้องกันสามารถหลบหนีจากการถูกพันธนาการ ยึดจับ หรือตรึงเป้าหมายได้โดยอัตโนมัติ

#### มึนงงในตำแหน่งนั้น

ผู้โจมตีสามารถใช้อาวุธกระแทกเพื่อทำให้ส่วนของร่างกายที่ถูกโจมตีมึนงงชั่วคราว หากการโจมตีเอาชนะค่าเกราะและทำให้เป้าหมายบาดเจ็บ ผู้ป้องกันจะต้องทำการทอยลูกเต๋าแบบประชันกันระหว่างค่าความทรหดกับการทอยลูกเต๋าโจมตีเดิม หากผู้ป้องกันล้มเหลว ตำแหน่งที่ถูกโจมตีจะหมดสภาพต่อสู้เป็นเวลาจำนวนรอบเท่ากับความเสียหายที่ได้รับ การโจมตีที่ลำตัวจะทำให้ผู้ป้องกันเซจนหายใจไม่ทันและสามารถทำได้เพียงป้องกันเท่านั้น การโจมตีที่ศีรษะจะทำให้ศัตรูหมดสติชั่วคราวและไม่สามารถกระทำใดๆ ได้

#### แยกส่วน

ผู้โจมตีอาจใช้อาวุธที่เหมาะสม เช่น ขวาน เพื่อสร้างความเสียหายแก่เกราะหรือการป้องกันธรรมชาติของคู่ต่อสู้ ความเสียหายของอาวุธหลังจากลดค่าจากการปัดป้องหรือเวทมนตร์แล้ว จะถูกนำไปใช้กับค่าเกราะของตำแหน่งนั้น ความเสียหายส่วนเกินจากค่าเกราะจะถูกนำไปลดค่าเกราะของตำแหน่งนั้นๆ ไม่ว่าจะเป็นการฉีกสายรัด ทำลายห่วง กรีดแผ่นเกราะ หรือฉีกผิวหนัง เกล็ด หรือเปลือกแข็งของสัตว์ประหลาด หากยังคงมีความเสียหายเหลืออยู่หลังจากเกราะถูกลดค่าลงเหลือศูนย์ ความเสียหายนั้นจะส่งต่อไปยังค่าพลังชีวิตของตำแหน่งที่ถูกโจมตี สำหรับอาวุธปืน การแยกส่วนจะเหมาะกับอาวุธปืนพลังงานที่ออกแบบมาเพื่อทำลายเกราะหรือแนวคิดแปลกใหม่เช่นปืนคลื่นแรงโน้มถ่วง

#### ทำให้คู่ต่อสู้ล้ม

ตัวละครพยายามทำให้คู่ต่อสู้เสียหลักหรือทุ่มลงกับพื้น คู่ต่อสู้จะต้องทำการทอยลูกเต๋าแบบประชันกันระหว่างพละกำลัง หลบหลีก หรือกรีฑา เทียบกับการทอยลูกเต๋าเดิมของตัวละคร หากเป้าหมายล้มเหลว พวกเขาจะล้มลงกับพื้น คู่ต่อสู้ที่เป็นสัตว์สี่เท้า (หรือสิ่งมีชีวิตที่มีขามากกว่านั้น) อาจใช้ทักษะกรีฑาแทนการหลบหลีกและถือว่าการทอยนั้นง่ายลงหนึ่งระดับความยาก สำหรับอาวุธปืน สมมติว่าอาวุธปืนนั้นยิงกระสุนที่มีมวล ไม่มีเหตุผลที่ผลลัพธ์นี้จะไม่สามารถใช้เมื่อยิงไปที่ขาของคู่ต่อสู้ แม้ว่าความเสียหายจะไม่ทะลุเกราะที่สวมใส่อยู่ก็ตาม

#### อาวุธขัดข้อง

ผู้โจมตีพลาดขั้นรุนแรง, อาวุธปืนเท่านั้น อาวุธปืนของผู้โจมตีเกิดความขัดข้องจนไม่สามารถใช้งานได้จนกว่าจะมีเวลาถอดชิ้นส่วนและทำความสะอาดในภาคสนาม

#### ถอนตัว

ผู้ป้องกันสามารถถอนตัวออกจากระยะการโจมตีได้โดยอัตโนมัติ เป็นการยุติการต่อสู้กับคู่ต่อสู้คนนั้น

## การต่อสู้ระยะประชิด

การต่อสู้ระยะประชิดคือการต่อสู้มือเปล่าหรือใช้อาวุธในความหมายคลาสสิก เมื่อนักสู้โจมตีกันและกันด้วยอาวุธที่ถืออยู่หรืออาวุธธรรมชาติ แนวทางปฏิบัติต่อไปนี้จะเสนอวิธีทำให้การต่อสู้ระยะประชิดน่าสนใจยิ่งขึ้น และช่วยอธิบายแนวคิดบางอย่างที่ได้กล่าวถึงไว้ก่อนหน้านี้ในบทนี้

### ตัวปรับตามสถานการณ์

ตัวปรับตามสถานการณ์อาจถูกนำมาใช้เมื่อต่อสู้ในสภาวะเฉพาะ หรือเป็นผลลัพธ์มาจากผลพิเศษ ตัวอย่างเช่น การต่อสู้ในความมืดอาจได้รับบทลงโทษความยากระดับโหดหิน เว้นแต่จะระบุไว้เป็นอย่างอื่น ตัวปรับจะถูกตัดสินโดยเกมมาสเตอร์ ในกรณีที่มีสถานการณ์ตั้งแต่สองอย่างขึ้นไปที่เกี่ยวข้องกับตัวละคร ให้ใช้สถานการณ์ที่รุนแรงที่สุด

ตัวปรับบางอย่างขึ้นอยู่กับสถานการณ์ แต่แทนที่จะใช้ระดับความยาก ทักษะการต่อสู้จะถูกจำกัดด้วยทักษะที่เกี่ยวข้อง ตัวอย่างเช่น การต่อสู้บนหลังม้าจะจำกัดทักษะการต่อสู้ของนักสู้ด้วยทักษะการขี่ ในขณะที่การต่อสู้ในน้ำอาจจำกัดทักษะด้วยค่าของทักษะการว่ายน้ำของตัวละคร#### ตัวปรับสถานการณ์การต่อสู้ระยะประชิด

### การปะทะ (Engagement)

ตัวละครจะถือว่าเข้าสู่การปะทะหากอยู่ในระยะอาวุธประชิดของฝ่ายตรงข้าม ซึ่งไม่จำเป็นว่านักสู้ทั้งสองต้องเข้าถึงตัวกันได้เสมอไป เพียงแค่คนหนึ่งคนใดสามารถถูกโจมตีโดยอีกฝ่ายได้ก็ถือว่าเข้าสู่การปะทะแล้ว เมื่อตัวละครเข้าปะทะกับคู่ต่อสู้แล้ว พวกเขาจะไม่สามารถถอยจากการต่อสู้นั้นได้อย่างอิสระ (การชาร์จผ่านไปถือเป็นข้อยกเว้นพิเศษ) การจะเลิกปะทะกับศัตรูจำเป็นต้องใช้การกระทำที่ตั้งใจทำ โดยปกติจะทำผ่านแต้มปฏิบัติการเช่น Outmaneuver หรือการใช้ผลพิเศษ Withdraw

### การชาร์จ (Charging)

การกระทำแบบชาร์จคือการเคลื่อนที่อย่างรวดเร็วเพื่อเพิ่มพลังและแรงปะทะของการโจมตี การชาร์จกำหนดให้ผู้โจมตีต้องเลือกการกระทำแบบชาร์จ โดยเคลื่อนที่ด้วยท่าวิ่ง (Run) หรือท่าวิ่งเต็มสปีด (Sprint) - ดูหัวข้อ [อัตราการเคลื่อนที่](0002_Characters.md?id=movement-rate) ด้านบน กฎการเคลื่อนที่ระบุไว้อย่างครบถ้วนในหนังสือหลัก _Mythras_

หากการเคลื่อนที่นี้ทำให้พวกเขาเข้าถึงตัวคู่ต่อสู้ พวกเขาต้องหยุดตรงนั้นและดำเนินการโจมตีโดยมีตัวปรับสำหรับการชาร์จ ไม่มีระยะทางขั้นต่ำที่กำหนดไว้ก่อนที่จะทำการชาร์จได้ เนื่องจากระยะทางที่เคลื่อนที่นั้นไม่ใช่ปัจจัยสำคัญเท่ากับโมเมนตัมที่ได้รับ จึงต้องใช้การวิ่งหรือวิ่งเต็มสปีด

ในขณะชาร์จ ทอยลูกเต๋าโจมตีจะมีระดับความยากอยู่ที่ระดับยาก เพื่อแลกกับการที่การชาร์จจะเพิ่มขนาดตัว (ขนาดตัว) ของอาวุธที่ใช้โจมตีขึ้นหนึ่งขั้น และเพิ่มตัวปรับความเสียหาย (ความเสียหาย ตัวปรับ) ของผู้โจมตีที่เป็นสองขาขึ้นหนึ่งขั้น หรือสองขั้นหากเป็นสัตว์สี่ขา (หรือมากกว่า) ตัวละครที่อยู่บนหลังสัตว์ขี่อาจใช้ตัวปรับความเสียหายของสัตว์ขี่แทนของตนเองได้ ตำแหน่งสุดท้ายของตัวละครที่ชาร์จขึ้นอยู่กับผลลัพธ์ของการแลกเปลี่ยนและการที่ผู้โจมตีต้องการหยุดหรือกวาดผ่านไป ซึ่งจะทำให้การปะทะสิ้นสุดลงทันที

แทนที่จะปัดป้อง (Parry) หรือหลบหลีก (หลบหลีก) ผู้ที่ถูกชาร์จสามารถสวนกลับผู้โจมตีที่กำลังชาร์จเข้ามาได้พร้อมกัน ในกรณีนี้ผู้ที่ใช้อาวุธยาวกว่าจะโจมตีก่อน หากอาวุธนั้นสามารถตั้งรับการชาร์จได้ (เช่น หอก) ผู้รับการโจมตีอาจใช้ตัวปรับความเสียหายของผู้ที่ชาร์จเข้ามาแทนที่ตัวปรับความเสียหายของตนเอง

### ที่กำบัง (Cover)

คู่ต่อสู้ใช้ที่กำบังเพื่อขัดขวางการโจมตีที่มุ่งมายังตน โดยอาจเป็นทางกายภาพที่ช่วยป้องกันการโจมตีเนื่องจากความแข็งแกร่งของวัสดุที่ขวางอยู่ หรือโดยการบดบังตำแหน่งที่แน่นอนของศัตรู ค่าที่แน่นอนของที่กำบังขึ้นอยู่กับความหนาของวัสดุป้องกันและขอบเขตของการครอบคลุม

การโจมตีที่มุ่งเป้าไปที่ตำแหน่งที่ถูกโจมตี (Hit ตำแหน่ง) ซึ่งถูกบดบัง จะถูกปิดกั้นตามระดับการป้องกันที่มีอยู่ในที่กำบังนั้น ที่กำบังอาจถูกหักล้างบางส่วนได้โดยการใช้ผลพิเศษ Choose ตำแหน่ง เพื่อเล็งไปยังส่วนที่มองเห็นได้ของเป้าหมาย หรือโจมตีทะลุที่กำบังหากอาวุธนั้นสามารถเจาะทะลุได้

ในสถานการณ์ที่ที่กำบังนั้นปิดมิดชิดทั้งหมด แต่ผู้โจมตีเชื่อว่าการโจมตีของตนจะเจาะทะลุเข้าไปได้ พวกเขาอาจโจมตีแบบสุ่มไปยังเป้าหมายที่ซ่อนอยู่ ในกรณีเช่นนี้ การทอยลูกเต๋าโจมตีจะยากขึ้นอีกหนึ่งระดับ และไม่สามารถเลือกใช้ผลพิเศษ Choose ตำแหน่ง ได้หากทอยได้สำเร็จ ทั้งนี้ถือว่าผู้โจมตีรู้ตำแหน่งของเป้าหมายหลังที่กำบังนั้นค่อนข้างแม่นยำ

### การหลบหลีก (Evading)

การหลบหลีกในการต่อสู้คือการกระโดดออกจากการโจมตีที่รุนแรง การทำเช่นนี้ต้องใช้การทอยแบบต้านกัน (Opposed Roll) ระหว่างทักษะการหลบหลีก (หลบหลีก) ของผู้ป้องกัน กับการทอยที่เกี่ยวข้องของผู้โจมตี ซึ่งอาจเป็นอะไรก็ได้ตั้งแต่ทักษะการขับขี่ (การขับขี่) ของรถถังที่กำลังพุ่งเข้าชน ไปจนถึงทักษะการใช้เวทมนตร์ของผู้จอมเวท หากผู้โจมตีชนะ พวกเขาจะสร้างความเสียหายตามปกติ หากผู้ป้องกันชนะ ความเสียหายจะถูกหลีกเลี่ยงไปโดยสิ้นเชิง

หากผู้ชนะในการทอยแบบต้านกันทำระดับความสำเร็จได้มากกว่าคู่ต่อสู้หนึ่งระดับขึ้นไป พวกเขาสามารถเลือกผลพิเศษที่เหมาะสมได้ตามการต่อสู้ปกติ ไม่ว่าผลลัพธ์จะเป็นอย่างไร การหลบหลีกจะทำให้ผู้ป้องกันเสียหลักล้มลง ซึ่งปกติจะต้องให้ตัวละครพยายามทรงตัวใหม่ในเทิร์นถัดไป เว้นแต่พวกเขาจะสามารถใช้ผลพิเศษ Arise ได้

### การกระแทกถอยหลัง (Knockback)

การโจมตีที่สร้างความเสียหายมากกว่าขนาดตัว (ขนาด) ของผู้รับ โดยค่าเริ่มต้นจะส่งผลให้ตัวละครกระแทกถอยหลัง ความเสียหายในสถานการณ์นี้เป็นค่าก่อนการหักลบจากการปัดป้องหรือเกราะ เมื่อได้รับความเสียหายเช่นนั้น ผู้รับต้องผ่านการทอยทักษะกรีฑา (กรีฑา) ระดับมาตรฐาน หรือทักษะกายกรรม (Acrobatics) ระดับง่าย เพื่อหลีกเลี่ยงการล้มลง พวกเขายังจะถูกผลักออกไปหนึ่งเมตรต่อทุกๆ 5 แต้มของความเสียหาย (หรือเศษส่วน) ที่เกินกว่าค่าขนาดตัว (ขนาด) ของพวกเขา การใช้การกระทำแบบ Brace จะช่วยลดหรือขจัดผลของการกระแทกถอยหลังได้

### การโจมตีแบบกระโดด (Leaping Attacks)

การโจมตีแบบกระโดดสามารถเปิดฉากได้จากหลากหลายสถานการณ์ ส่วนใหญ่จะเกิดขึ้นเพื่อเป็นส่วนหนึ่งของการซุ่มโจมตีหรือเมื่อสิ้นสุดการชาร์จ แต่สัตว์บางชนิดสามารถกระโดดขึ้นไปบนตัวคู่ต่อสู้ได้โดยไม่จำเป็นต้องวิ่งส่งตัวหรือมีระดับความสูงที่เหนือกว่า

การโจมตีแบบกระโดดตัดสินด้วยการทอยแบบต้านกันระหว่างทักษะกรีฑา (กรีฑา) ของผู้กระโดด กับทักษะพละกำลัง (พละกำลัง) หรือการหลบหลีก (หลบหลีก) ของผู้ป้องกัน เป้าหมายที่เป็นสัตว์สี่ขาจะทำให้การทอยโจมตีมีความยากเพิ่มขึ้นหนึ่งระดับ หากผู้กระโดดชนะ ผู้ป้องกันจะล้มลงโดยอัตโนมัติพร้อมกับมีผู้โจมตีคร่อมอยู่ด้านบน หากล้มเหลวหมายความว่าผู้ป้องกันสามารถทนรับหรือหลบการปะทะนั้นได้ หากผู้ชนะในการทอยแบบต้านกันทำระดับความสำเร็จได้มากกว่าคู่ต่อสู้หนึ่งระดับขึ้นไป พวกเขาสามารถเลือกผลพิเศษที่เหมาะสมได้ตามปกติ

ไม่มีการสร้างความเสียหายจากการกระโดด อย่างไรก็ตามเหยื่อที่ล้มลงจะไม่สามารถทรงตัวได้จนกว่าผู้โจมตีจะจากไป หรือจนกว่าพวกเขาจะชนะการทอยจนได้ผลพิเศษที่อนุญาตให้ Arise นอกจากนี้การโจมตีแบบกระโดดจะได้ผลกับคู่ต่อสู้ที่มีขนาดตัว (ขนาด) สูงสุดไม่เกินสองเท่าของผู้โจมตีเท่านั้น เป้าหมายสามารถทำให้ตนเองถูกผลักล้มได้ยากขึ้นโดยการใช้การกระทำแบบ Brace เชิงรุก หากพวกเขารู้ตัวว่ากำลังจะถูกโจมตีแบบกระโดด

### การชิงจังหวะ (Outmaneuvering)

ตัวละครที่เผชิญหน้ากับคู่ต่อสู้หลายคนสามารถใช้การเคลื่อนที่เพื่อจำกัดจำนวนศัตรูที่สามารถโจมตีตนได้ในเวลาใดเวลาหนึ่ง โดยการเปลี่ยนตำแหน่งอย่างต่อเนื่องเพื่อบีบให้ศัตรูขัดขวางกันเอง การชิงจังหวะต้องการพื้นที่ให้ตัวละครเคลื่อนที่ไปมาและไม่ได้ถูกต้อนจนมุมในพื้นที่แคบ

การชิงจังหวะกำหนดให้ตัวละครต้องมีส่วนร่วมกับคู่ต่อสู้ในการทอยแบบต้านกันกลุ่มโดยใช้ทักษะการหลบหลีก (หลบหลีก) ผู้เข้าร่วมทุกคน ทั้งตัวละครที่กำลังชิงจังหวะและศัตรูที่ต้องการต้อนเขา ต้องใช้แต้มปฏิบัติการ (Action Point) จากนั้นทุกคนจะทอยลูกเต๋าคนละหนึ่งครั้ง และผู้ที่ไม่สามารถทอยได้ชนะตัวละครที่ชิงจังหวะจะไม่สามารถโจมตีเขาได้ตลอดรอบการต่อสู้ที่เหลือ เนื่องจากถูกขัดขวางโดยพันธมิตรของตนเองหรือลักษณะภูมิประเทศ

หากตัวละครที่ชิงจังหวะสามารถเอาชนะคู่ต่อสู้ทุกคนได้ เขาจะมีทางเลือกว่าจะเข้าปะทะกับศัตรูเพียงคนเดียวอย่างปลอดภัยตลอดรอบที่เหลือ หรือจะถอนตัว (Withdraw) ออกจากการต่อสู้โดยสมบูรณ์

### การป้องกันแบบรับ (Passive Blocking)

การป้องกันแบบรับอนุญาตให้ตัวละครที่ถืออาวุธอยู่ถือในลักษณะที่ครอบคลุมตำแหน่งที่เลือกไว้ (หรือหลายตำแหน่งเมื่อใช้โล่) แต่ต้องแลกกับการที่ไม่สามารถปัดป้อง (Parry) ได้อย่างกระฉับกระเฉง (ดู Ward ตำแหน่ง) การโจมตีใดๆ ที่โดนตำแหน่งเหล่านั้นจะได้รับประโยชน์จากการป้องกันของอาวุธหรือโล่โดยอัตโนมัติ ซึ่งจะลดความเสียหายตามปกติ เทคนิคนี้มักใช้เมื่อนักรบต้องการป้องกันจุดอ่อนหรือตำแหน่งที่ได้รับบาดเจ็บ ไม่มีสิ่งใดขัดขวางนักสู้ที่ใช้อาวุธคู่ หรืออาวุธและโล่จากการใช้อีกอาวุธหนึ่งในการปัดป้องอย่างกระฉับกระเฉง

เนื่องจากการป้องกันแบบรับทำงานในลักษณะเดียวกับที่กำบัง ผลพิเศษ Choose ตำแหน่ง จึงไม่สามารถนำมาใช้เพื่อข้ามการป้องกันนี้ในการต่อสู้ระยะประชิดได้ แม้ว่าคู่ต่อสู้จะยังสามารถใช้ผลพิเศษเพื่อโจมตีพื้นที่อื่นที่ไม่ได้ป้องกันไว้ การหมอบลงหลังโล่จะช่วยให้ตัวละครเพิ่มจำนวนตำแหน่งที่ป้องกันได้เป็นสองเท่าในขณะที่ใช้การป้องกันแบบรับ

### การเซอร์ไพรส์ (Surprise)

การเซอร์ไพรส์เกิดขึ้นเมื่อมีการเปิดฉากโจมตีอย่างไม่คาดคิดต่อคู่ต่อสู้ที่ไม่รู้ตัวถึงการปรากฏตัวหรือเจตนาของผู้โจมตี การซุ่มโจมตีเป็นตัวอย่างของแบบแรก ในขณะที่การหักหลังหันเข้าทำร้ายพันธมิตรที่ไม่ระแวงในระหว่างบทสนทนาที่เป็นมิตรแสดงให้เห็นถึงแบบที่สอง

ผลของการเซอร์ไพรส์ต่อเป้าหมายนั้นรุนแรง:

- เป้าหมายได้รับบทลงโทษ –10 ต่อค่าความไว (ความไว)
- จนกว่าจะถึงลำดับความไวของเป้าหมาย พวกเขาจะถือว่าเสียหลัก (flat-footed) และไม่สามารถป้องกันตนเองได้
- การโจมตีครั้งแรกต่อเป้าหมายหากสำเร็จ จะได้รับผลพิเศษโบนัส
- ตลอดรอบที่เหลือ พวกเขาจะไม่สามารถดำเนินการกระทำใดๆ ที่เป็นการรุกได้

### การโจมตีแบบกวาด (Sweep Attacks)

การโจมตีแบบกวาดเกิดขึ้นตามการตัดสินใจของผู้คุมเกม (Games Master) เมื่ออาวุธหรือสิ่งมีชีวิตที่มีขนาดใหญ่ผิดปกติโจมตีกลุ่มคู่ต่อสู้ที่รวมตัวกันอย่างหนาแน่น เช่น หางที่กวาดของมังกรยักษ์หรือการชาร์จที่หยุดไม่อยู่ของไทรเซอราทอปส์ยักษ์ ซึ่งโจมตีศัตรูหลายคนพร้อมกัน

การโจมตีแบบกวาดทำได้โดยการใช้การทอยโจมตีครั้งเดียวของอาวุธหรือสิ่งมีชีวิตนั้นกับเป้าหมายทุกตัวในเส้นทางของมัน ผู้ป้องกันแต่ละคนต้องจัดการกับผลของการโจมตีแยกจากกัน และผลพิเศษใดๆ ที่บังคับใช้กับผู้โจมตีจะถือว่าเกิดขึ้นพร้อมกัน

## การต่อสู้ระยะไกล (Ranged Combat)

การต่อสู้ระยะไกลรวมถึงอาวุธทุกรูปแบบที่ต้องยิง ขว้าง หรือเหวี่ยงเพื่อโจมตีเป้าหมาย การโจมตีระยะไกลตัดสินในลักษณะเดียวกันกับการต่อสู้ระยะประชิด อย่างไรก็ตาม โดยปกติแล้วอาวุธระยะไกลสามารถปัดป้องได้ด้วยโล่เท่านั้น ผู้ที่ไม่มีโล่ต้องอาศัยที่กำบังตามธรรมชาติหรือใช้การหลบหลีก (หลบหลีก) เพื่อพุ่งตัวออกจากแนวการยิง ดังนั้นเมื่อต้องสู้กับศัตรูที่มีเกราะเบา อาวุธระยะไกลอาจเป็นเครื่องยับยั้งที่น่าเกรงขาม

อาวุธระยะไกลแต่ละชนิดมีคุณสมบัติเฉพาะหลายประการที่กำหนดประสิทธิภาพของมัน สิ่งที่มีผลสำคัญต่อการต่อสู้มีดังนี้:

- **แรงปะทะ (Force):** เทียบเท่ากับขนาดตัว (ขนาดตัว) ของการต่อสู้ระยะไกล เป็นการวัดความสามารถในการเจาะทะลุของอาวุธหรือกระสุนในเชิงนามธรรม เพื่อพิจารณาว่าการโจมตีนั้นสามารถเอาชนะการปัดป้อง (ด้วยโล่) ได้หรือไม่
- **ตัวปรับความเสียหาย (ความเสียหาย ตัวปรับ):** คุณสมบัตินี้แสดงให้เห็นว่าตัวปรับความเสียหายของผู้โจมตีสามารถนำมาใช้เพื่อเพิ่มค่าความเสียหายจากการทอยของอาวุธระยะไกลได้หรือไม่ โดยทั่วไปแล้ว มีเพียงธนูที่น้าวด้วยตนเองและอาวุธขว้างเท่านั้นที่อนุญาตให้ผู้ใช้ใช้ตัวปรับความเสียหายของตนได้
- **ระยะยิง (ระยะยิง):** ตัวเลขสามชุดคั่นด้วยเครื่องหมายทับ แสดงถึงระยะใกล้ (Close), ระยะหวังผล (Effective), และระยะไกล (Long) ของอาวุธหรือกระสุน ระยะใกล้คือระยะที่สามารถใช้ผลพิเศษ Choose ตำแหน่ง ได้ โดยมีเงื่อนไขว่าเป้าหมายจะต้องหยุดนิ่งหรือไม่รู้ตัวถึงการโจมตีที่กำลังจะมาถึง ระยะหวังผลไม่มีตัวปรับที่สำคัญ ที่ระยะไกล อาวุธยังสามารถสร้างความเสียหายได้ แต่ปริมาณความเสียหายจะถูกหารครึ่ง และแรงปะทะ (Force) จะลดลงหนึ่งขั้น
- **การบรรจุกระสุน (Load):** เวลาในหน่วยรอบ (Turns) ที่ใช้ในการบรรจุหรือบรรจุกระสุนใหม่สำหรับอาวุธที่ใช้กระสุน ตัวละครสามารถลดเวลาที่ใช้ในการบรรจุหรือเตรียมอาวุธโดยการใช้ผลพิเศษ Rapid การบรรจุกระสุนใหม่
- **ขนาดอาวุธแทง (Impale ขนาดตัว):** ขนาดของอาวุธที่แทงติดจะแตกต่างจากแรงปะทะที่ใช้โจมตี อาวุธระยะไกลประเภทแทงจะมีคอลัมน์พิเศษระบุขนาดจริงของมันเมื่อพิจารณาถึงอุปสรรคที่เกิดจากผลพิเศษ Impale

เช่นเดียวกับการต่อสู้ระยะประชิด อาจมีการใช้ตัวปรับสถานการณ์เมื่อใช้อาวุธระยะไกลในสภาวะเฉพาะ ทักษะการต่อสู้ของตัวละครอาจถูกจำกัดเมื่อใช้อาวุธในสถานการณ์ที่ยากลำบาก เช่น การขว้างหอกขณะขี่ม้า

### การเล็ง (Aiming)

การใช้เวลาเพิ่มเติมในการเล็งอาวุธระยะไกล ตัวละครอาจเพิ่มโอกาสในการโจมตีให้สำเร็จได้ การเล็งต้องใช้เวลาทั้งรอบการต่อสู้ในการทำให้อาวุธนิ่งและรอโอกาสที่ดีที่สุดในการยิง เช่น การชะลอการยิงธนูเพื่อรอช่วงลมสงบชั่วขณะ หรือจนกว่าเป้าหมายจะเคลื่อนที่ผ่านระหว่างสิ่งกีดขวางสองอย่าง การเล็งจะทำให้ตัวละครลดความยากของตัวปรับระยะหรือสถานการณ์ลงได้หนึ่งระดับ การใช้เวลาเล็งเพิ่มในรอบต่อๆ ไปจะไม่ได้รับข้อได้เปรียบเพิ่มเติม

### การยิงอัตโนมัติ (อัตโนมัติ Fire)

อาวุธปืนบางชนิดสามารถบรรจุกระสุนนัดถัดไปได้โดยอัตโนมัติ โดยใช้แรงขับเคลื่อนจากก๊าซส่วนเกิน แรงสะท้อน หรือพลังงานจากการยิงนัดก่อนหน้า โดยไม่ต้องง้างนกใหม่ ทำให้ปืนมีอัตราการยิงที่หลากหลาย ซึ่งขึ้นอยู่กับปริมาณกระสุนที่ผู้ใช้ต้องการยิงออกไป

โหมดการยิงเหล่านี้ประกอบด้วย กึ่งอัตโนมัติ (Semi-อัตโนมัติ), การยิงชุด (Burst) และอัตโนมัติเต็มรูปแบบ (Full-อัตโนมัติ) แม้ว่าความสามารถนี้จะทำให้ปืนบางชนิดสามารถสร้างความเสียหายที่น่าสะพรึงกลัวได้ แต่การรักษาความแม่นยำด้วยอาวุธที่มีแรงสะท้อนนั้นเป็นปัญหา ให้ถือว่ากฎต่อไปนี้ใช้กับอาวุธที่ยิงอัตโนมัติเป็นหลัก

#### กึ่งอัตโนมัติ (Semi-อัตโนมัติ)

นี่คืออัตราการยิงเริ่มต้นสำหรับปืนส่วนใหญ่ ซึ่งการเหนี่ยวไกแต่ละครั้งจะยิงออกไปหนึ่งนัดและบรรจุกระสุนนัดถัดไปโดยอัตโนมัติ

#### การยิงชุด (Burst)

สำหรับการยิงชุด การเหนี่ยวไกแต่ละครั้งจะปล่อยกระสุนออกมาจำนวนหนึ่ง โดยปกติไม่เกิน 3 ถึง 5 นัด ขึ้นอยู่กับอาวุธ จุดประสงค์ดั้งเดิมคือเพื่ออนุญาตให้มีการยิงกดดันอย่างจำกัดแต่จำกัดการใช้กระสุนที่สิ้นเปลือง ไม่ได้มีจุดประสงค์เพื่อเพิ่มโอกาสในการยิงโดนของผู้ยิง เนื่องจากแรงสะท้อนต่อเนื่องที่รวดเร็วจะทำให้ตัวปืนสั่นจนเล็งผิดเป้า การยิงในโหมดชุดจะมีบทลงโทษระดับยากในการทอยโจมตี อย่างไรก็ตามหากการโจมตีสำเร็จ ผู้ยิงจะทอยลูกเต๋าเพื่อดูว่ากระสุนในชุดนั้นโดนเป้าหมายกี่นัด ดังนั้นการยิงชุด 3 นัดจะใช้ 1d3 ให้ทอยตำแหน่งที่โดนและความเสียหายแยกกันสำหรับกระสุนแต่ละนัดที่โดน

#### อัตโนมัติเต็มรูปแบบ (Full-อัตโนมัติ)

ปกติจะใช้สำหรับการยิงกดดันอย่างเต็มที่เพื่อตรึงเป้าหมายหลายตัวเอาไว้ อัตโนมัติเต็มรูปแบบอาจทำลายล้างได้หากยิงเข้าไปในกลุ่มศัตรูที่อยู่รวมตัวกันอย่างหนาแน่น ผู้ยิงตัดสินใจว่าจะยิงกระสุนกี่นัด (สูงสุดตามขีดจำกัดของอัตราการทำงานของอาวุธ) ซึ่งจะถูกกระจายอย่างเท่าเทียมกันทั่วทั้งเป้าหมายที่อยู่ในแนวการยิง กระสุนที่เหลือจะถือว่าสูญเปล่าในขณะที่กวาดลำกล้อง (ดังนั้นการยิง 15 นัดใส่เป้าหมาย 6 ตัว จะโดนเป้าหมายละ 2 นัด) ให้ทำการทอยโจมตีแยกกันสำหรับเป้าหมายแต่ละตัว แต่จะมีระดับความยากที่ระดับโหดหินเนื่องจากผลของแรงสะท้อนที่เพิ่มขึ้นจากการยิงต่อเนื่อง เป้าหมายที่ถูกยิงจะได้รับความเสียหายตามจำนวนกระสุนที่สุ่มได้เช่นเดียวกับการยิงชุด

โปรดทราบว่ามีเพียงนัดแรกที่โดนเป้าหมายระหว่างการยิงชุดหรือการยิงอัตโนมัติเต็มรูปแบบเท่านั้นที่จะได้รับประโยชน์จากผลพิเศษ ดังนั้นการทอยโจมตีได้ Critical ในขณะที่ยิงโหมดอัตโนมัติจะอนุญาตให้เลือกผล Maximize ความเสียหาย ได้เฉพาะกับนัดแรกเท่านั้น แม้ว่ากระสุนที่เหลือจะโดนเป้าหมายทั้งหมดก็ตาม#### ทำไมการยิงแบบอัตโนมัติถึงถูกลดทอนประสิทธิภาพลงอย่างหนักหน่วง?

กฎสำหรับการยิงแบบอัตโนมัติอาจดูเหมือนเข้มงวดเกินไปเมื่อเปรียบเทียบกับความแม่นยำของอาวุธปืนสมัยใหม่ เหตุผลที่ต้องเป็นเช่นนั้นมีอยู่หลายประการ โดยเหตุผลหลักคือเพื่อให้ระบบเกมมีความกระชับและสมดุล ผู้เล่นที่วิจารณ์ว่าตัวละครของตนยิงไม่แม่นควรได้รับการเตือนว่า กฎที่ปรับเปลี่ยนเหล่านั้นก็จะถูกนำมาใช้กับตัวพวกเขาเองด้วยเช่นกัน ซึ่งเมื่อพิจารณาถึงความร้ายแรงของการยิงรัวแล้ว ก็นับเป็นสิ่งที่ควรฉุกคิด

แน่นอนว่าบทลงโทษจากแรงดีดบางส่วนสามารถบรรเทาได้ เช่น การใช้ทักษะ Steady Weapon เพื่อยึดอาวุธปืนแบบอัตโนมัติไว้ ทว่าความจริงก็คือการต่อสู้ด้วยอาวุธปืนนั้นแตกต่างจากการยิงเป้าในสนามซ้อมอย่างสิ้นเชิง สัญชาตญาณที่จะหาที่กำบังเมื่อกระสุนบินว่อน ความจำเป็นที่ต้องเคลื่อนที่ตลอดเวลา และทุกนัดที่ยิงออกไปจะเปิดเผยตำแหน่งของผู้ยิงผ่านแสงวาบที่ปากกระบอกปืนหรือเสียง มักจะทำให้โอกาสในการเล็งหรือการจัดท่าทางยิงแทบจะเป็นไปไม่ได้เลย วลีที่ว่า 'กราดยิงแล้วภาวนา' (Spray and Pray) จึงถือกำเนิดขึ้นด้วยเหตุผลที่ดีนั่นเอง!

### การใช้อาวุธปืนสองมือ

ตัวละครสามารถใช้อาวุธปืนสองมือ โดยยิงอาวุธทั้งสองพร้อมกันระหว่างเทิร์นของตนเพื่อเพิ่มอัตราการยิงให้เร็วขึ้น อย่างไรก็ตาม วิธีนี้มีบทลงโทษต่อความแม่นยำ การยิงปืนพกมือละกระบอกจะได้รับบทลงโทษระดับ ยาก ในการโจมตีเป้าหมาย ส่วนผู้ที่พยายามยิงคาร์ไบน์หรือ SMG มือละกระบอกพร้อมกันจะได้รับบทลงโทษระดับ โหดหิน

### การยิงเข้าไปในฝูงชน

การยิงเข้าไปในความโกลาหลของการตะลุมบอนอาจเป็นเรื่องที่เสี่ยง ดังนั้นจึงมีความเสี่ยงที่จะยิงพลาดไปโดนคนอื่นที่ไม่ใช่เป้าหมายที่เล็งไว้เสมอ เมื่อยิงไปที่เป้าหมายเฉพาะที่อยู่บริเวณขอบของฝูงชนหรือการตะลุมบอน การโจมตีนั้นจะได้รับบทลงโทษ ระดับความยาก คือ ยาก หากพยายามยิงทะลุผ่านฝูงชนเข้าไป ระดับความยากควรเพิ่มขึ้นเป็น โหดหิน การเล็งเป้ายังคงได้รับอนุญาตเพื่อช่วยบรรเทาอันตรายดังกล่าว

แม่นปืนที่ทอยลูกเต๋าผ่านบทลงโทษระดับความยากได้สำเร็จถือว่าเล็งเป้าได้แม่นยำและจะโดนเป้าหมายที่ตั้งใจไว้ อย่างไรก็ตาม หากแม่นปืนทอยพลาด แต่หากไม่มีบทลงโทษ 'การยิงเข้าไปในฝูงชน' แล้วทอยได้สำเร็จ ผลจะกลายเป็นว่าไปโดนเหยื่อที่อยู่ติดกันแทน (ซึ่งสามารถเลือก หลบหลีก หรือ ป้องกัน ตามปกติ)

หากมีเป้าหมายมากกว่าหนึ่งคนอยู่ในแนววิถีกระสุน เกมมาสเตอร์ควรสุ่มหาตัวเหยื่อ ผลพิเศษ ใดๆ ที่ได้รับจากการโจมตีจะมีผลกับเป้าหมายเดิมเท่านั้น ไม่ใช่ผู้ที่ถูกลูกหลง

### การพลาดขั้นรุนแรงกับอาวุธปืน

เนื่องจากการยิงปืนมักไม่ได้ถูกต้านทานด้วยทักษะของฝ่ายตรงข้าม จึงควรมีข้อกำหนดพิเศษเมื่อผู้ยิงทอยลูกเต๋าได้ พลาดขั้นรุนแรง ในกรณีนี้ ผู้ที่เป็นเป้าหมายจะได้รับอนุญาตให้เลือก ผลพิเศษ ของการพลาดขั้นรุนแรง ซึ่งผู้ยิงจะต้องได้รับผลนั้น โปรดดู ผลพิเศษ ของการพลาดขั้นรุนแรงเพียงอย่างเดียว - อาวุธขัดข้อง

### การป้องกันการยิงด้วยโล่

ดังที่กล่าวไปก่อนหน้านี้ แทบจะเป็นไปไม่ได้เลยที่จะป้องกันกระสุนความเร็วเหนือเสียงหรือลำแสงพลังงานโดยเจตนา อย่างไรก็ตาม โล่ยังคงให้การป้องกันในระดับหนึ่งเนื่องจากในความเป็นจริงโล่เปรียบเสมือน 'ที่กำบัง' แบบพกพา ในการใช้โล่ระหว่างการยิงปืน ให้ใช้กฎการบล็อกแบบพาสซีฟจากส่วน [การต่อสู้ระยะประชิด](0005_Combat.md?id=passive-blocking) ด้านบน

สำหรับอาวุธปืนสมัยใหม่หรืออาวุธประเภทไซไฟ เกมมาสเตอร์อาจต้องการมอบค่า เกราะ ให้กับโล่แทนการกำหนด ขนาดตัว ตามวัสดุที่ใช้ทำโล่นั้น ตัวอย่างเช่น โล่ไม้ อาจถือว่ามี 4 เกราะ, โล่ทางยุทธวิธีเคฟล่าร์มี 8 เกราะ และโล่พลังงานกำไล Ulysses 31 มี 15 เกราะ

### กล้องเล็งระยะไกล (Telescopic Sights)

กล้องเล็งระยะไกลช่วยปรับปรุงความแม่นยำของอาวุธปืนในระยะทางที่ไกลขึ้นเมื่อผู้ใช้สละเวลาเล็งอย่างถูกต้อง (ดู การเล็งเป้า) กล้องเล็งระยะไกลขั้นพื้นฐานที่สุดเป็นเพียงเลนส์ขยาย แต่เมื่อเทคโนโลยีพัฒนาขึ้น กล้องจะเริ่มรวมเครื่องวัดระยะ, เครื่องคำนวณวิถีกระสุน, เซ็นเซอร์ตรวจจับการเคลื่อนที่ของอากาศ, ตัวชดเชยการหักเหของบรรยากาศ, เครื่องขยายสัญญาณ IR หรือแสงน้อย และอุปกรณ์อื่นๆ อีกมากมายที่ช่วยปรับปรุงระยะ 'ยิงโดน' ที่มีประสิทธิภาพ

กล้องเล็งระยะไกลทำให้การทอยทักษะง่ายขึ้นหนึ่ง ระดับ หรือมากกว่านั้น (ดู [การปรับทักษะ](0003_Skills.md?id=modifying-skills)) ขึ้นอยู่กับความซับซ้อนของกล้อง ไม่มีกล้องใดที่ทำให้การทอยทักษะกลายเป็นการสำเร็จแบบ อัตโนมัติ ได้ ดังนั้น ระดับ สูงสุดที่ทำได้คือ ง่ายมาก
