# ข้อกำหนดเบื้องต้น

1. ความเข้าใจพื้นฐานเกี่ยวกับ [ภาษา markdown](https://www.markdownguide.org/basic-syntax/)

2. คุณจะต้องสร้างบัญชี [github](https://github.com/) ฟรีหากคุณยังไม่มี ขอแนะนำให้คุณใช้ชื่อ RPG ของคุณเนื่องจากสิ่งนี้จะกลายเป็นส่วนหนึ่งของ URL ที่ผู้คนจะใช้เข้าถึง SRD ของคุณ

3. คุณสามารถทำกระบวนการทั้งหมดนี้ผ่านเบราว์เซอร์โดยไม่จำเป็นต้องรู้เรื่อง git แม้ว่าการเรียนรู้ github desktop จะช่วยให้คุณสามารถทดสอบการเปลี่ยนแปลงใดๆ ได้ในเครื่องก่อนที่จะนำไปใช้จริงเพื่อให้โลกเห็น

> หากคุณมีชื่อโดเมนที่จดทะเบียนไว้ คุณสามารถใช้ชื่อนี้ร่วมกับกระบวนการนี้เพื่อสร้าง SRD เหมือนกับที่ผมทำ https://srd.7thextinctionrpg.com

# กระบวนการ

## การสร้างคลังข้อมูล (Repository) บน Github

1. เข้าสู่ระบบ Github

2. ไปที่เทมเพลตสาธารณะ https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. คลิก "Use this template"

![Step3](/_media/Step3.png)

4. เลือก "Create a new repository"

5. ใส่ชื่อคลังข้อมูล

![Step5](/_media/Step5.png)

6. เลือก 'Private'

7. เลือก 'Create repository'

ระบบจะใช้เวลา 5-30 วินาทีในการคัดลอกเทมเพลต จากนั้นคุณจะมีสำเนาเป็นของตัวเอง

8. ตรวจสอบให้แน่ใจว่าคุณมีไฟล์ ".nojekyll" ซึ่งเป็นไฟล์ว่างที่จำเป็นเมื่อโฮสต์เว็บไซต์บน Github มิฉะนั้น SRD จะไม่แสดงผลอย่างถูกต้อง *(บอกให้ Github Pages ไม่ต้องรันไฟล์ที่เผยแพร่ผ่าน Jekyll)*


## การเพิ่มเนื้อหาของคุณ

### ไฟล์ *.md

ไฟล์ .md คือไฟล์ markdown ซึ่ง Markdown เป็นภาษาแบบมาร์กอัปที่มีน้ำหนักเบาที่คุณสามารถใช้เพื่อเพิ่มองค์ประกอบการจัดรูปแบบให้กับเอกสารข้อความธรรมดา ขึ้นอยู่กับขนาดเนื้อหาของคุณ คุณสามารถวางข้อมูลเกมทั้งหมดของคุณไว้ในไฟล์ *.md ไฟล์เดียว หรือสร้างไฟล์แยกต่างหากสำหรับแต่ละบทเหมือนที่ผมทำที่ [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) ไฟล์ "sample.md" มีตัวอย่างการจัดรูปแบบบางอย่างไว้ให้

ภาษา Markdown เรียนรู้ได้ง่ายมาก ใช้ลิงก์ที่ให้ไว้ในข้อ 2 ภายใต้ข้อกำหนดเบื้องต้นด้านบนเพื่อดูรายการไวยากรณ์ทั้งหมด

### _Sidebar.md

นี่คือเมนูของคุณ แถบนำทางที่ด้านซ้ายของเว็บไซต์ เมื่อคุณเพิ่มไฟล์ markdown ลงในคลังข้อมูลของคุณแล้ว คุณต้องเพิ่มไฟล์ที่นี่เพื่อให้รวมเนื้อหาไว้ด้วย ให้ทำตามการจัดรูปแบบที่มีอยู่เดิม


## การเปิดใช้งาน Github Pages เพื่อเปลี่ยนคลังข้อมูลให้เป็นเว็บไซต์

1. ในคลังข้อมูลของคุณ ให้คลิกที่ 'Settings'

![Website-Step1](/_media/Website-Step1.png)

2. เลือก 'Pages' บนเมนูด้านซ้ายมือ

![Website-Step2](/_media/Website-Step2.png)

3. หากคุณยังไม่ได้ตั้งค่าคลังข้อมูลเป็น 'public' คุณมีสองทางเลือก:
    a. ทำให้คลังข้อมูลเป็นสาธารณะ (public) ซึ่งจะช่วยให้คุณใช้ Github pages เพื่อโฮสต์เว็บไซต์ SRD ของคุณได้ฟรี
    b. อัปเกรดบัญชี Github ของคุณ (ณ เวลาที่เขียนบทความนี้ มีค่าใช้จ่าย $4 ต่อเดือน หรือค่าธรรมเนียมรายปี $48)

4. ภายใต้ 'Branch' ให้เลือก 'main' แล้วคลิก save

5. รอ 10-20 วินาทีแล้วรีเฟรชหน้าเว็บ

6. ตอนนี้คุณจะเห็น URL ของคุณ เช่น https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## การใช้ปลั๊กอิน Fontawesome และ/หรือ Material Icons เพื่อแสดงไอคอนฟรีใน SRD ของคุณ

### Fontawesome

ใช้ Fontawesome เพื่อรับไอคอนฟรีและไอคอนแบบเคลื่อนไหว ผู้ใช้แบบสมัครสมาชิกสามารถใช้ Pro Icons ได้

1. ค้นหาไอคอนบน [Fontawesome](https://fontawesome.com/icons)
2. เลือกไอคอน
3. ในหน้าต่างป๊อปอัป ใต้แท็บ HTML ให้คัดลอกทุกอย่างระหว่าง " "

```EXAMPLE
<i ชนชั้น="fa-solid fa-dice-d20"></i>
```

4. วางข้อความที่คัดลอกมาระหว่าง `:` โดยไม่ต้องเว้นวรรค

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

ใช้ Material Icons สำหรับไอคอนฟรีเพิ่มเติม

1. ค้นหาไอคอนบน [Material Icons](https://fonts.google.com/icons)
2. คัดลอกและแทรกลิงก์ web span ลงในไฟล์ markdown ของคุณโดยตรง

```markup
<span ชนชั้น="material-icons">face</span>
```
