# キャラクター

『Mythras Imperative』のすべてのプレイヤーはキャラクターを操作します。キャラクターとはプレイヤーの分身であり、通常、精神的にも肉体的にもプレイヤーとは大きく異なります。キャラクターはゲームの設定に応じてさまざまな種族から選択できます。歴史的な設定であれば人間のみとなりますが、ファンタジー設定であればドワーフ、エルフ、さらにはリザードマンなどが登場することもあります。基本的なキャラクターは、その能力を記述する一連の異なる要素によって定義されます。これらの要素は以下の通りです。

- **能力値:** 筋力や魅力など
- **特性値:** 身長や移動速度など
- **技能:** 基本的な能力に対する熟練度

これらの要素のほとんどは数値で表され、一部は他の数値に依存していたり、他の数値から算出されたりします。各要素の意味と決定方法は、以下のセクションで説明します。

---
## ステップ1：キャラクターコンセプト

どのようなキャラクターをプレイしたいか、例えば「ずる賢い戦士」や「悪知恵の働く密輸業者」といったアイデアを持つことが、最初の一歩として最適です。あるいは、「勤勉な学者」や「賢明な魔術師」を好むかもしれません。この段階でキャラクターコンセプトを練り上げる必要はありません。文化や経歴といった選択を導くためのアイデアがあるだけで十分です。

---
## ステップ2：能力値

すべてのキャラクターは7つの能力値によって定義されます。これらはキャラクターの強さや速さ、賢さや健康状態を示します。能力値はすべての『Mythras Imperative』のキャラクターの核心であり、特性値や技能といった他のほとんどの要素の基礎となります。7つの能力値は以下の通りです。

- 筋力 (筋力)
- 体力 (体力)
- 体格 (体格)
- 敏捷性 (敏捷性)
- 知力 (知力)
- 霊力 (霊力)
- 魅力 (魅力)

能力値を算出する前に、各能力値が何を表しているのかを次のセクションで説明します。

#### 筋力 (筋力)

STRは物理的な力を表します。どれだけの重さを持てるか、どれだけ強く打撃を与えられるかなどに関わります。STRはダメージ修正の構成要素です。キャラクターのSTRが0になると、物を動かしたり持ち上げたりする能力を失います。

#### 体力 (体力)

CONは健康と耐久力の尺度です。CONはヒットポイントと治癒率を決定する構成要素です。何らかの理由でCONが0になると、キャラクターは死亡します。

#### 体格 (体格)

SIZは質量を測定し、身長や体重を示す目安となります。SIZはヒットポイントの算出に使用されます。より大きく重い生物の方がダメージに対する耐久力が高い傾向にあるためです。また、質量は打撃の威力を高めるのに役立つため、キャラクターのダメージ修正を決定する際にもSIZが使用されます。

#### 敏捷性 (敏捷性)

敏捷性、バランス感覚、反射神経はDEXで測定されます。これは行動ポイントとイニシアチブにおいて重要な要素です。キャラクターのDEXが0になると、機能的な麻痺状態に陥ります。

#### 知力 (知力)

INTは認知能力の尺度です。INTスコアが低いからといって必ずしも愚かであるとは限りませんが、知恵をどれだけ創造的に使えるかという点で制限される可能性が高いです。INTは行動ポイントとイニシアチブを計算する際の要素となります。INTが0になると、キャラクターは完全に理性を失います。

#### 霊力 (霊力)

POWはキャラクターの魂、精神、内なる衝動、あるいは魔法の潜在能力の尺度です。POWはキャラクターのマジックポイントと幸運ポイントを管理します。キャラクターのPOWが0になると、独立した意志をすべて失います。

#### 魅力 (魅力)

魅力は存在感と人柄の尺度であり、外見とは無関係です。CHAはキャラクターの経験修正に影響を与えます。CHAが0になると、キャラクターは他者と社会的な交流ができなくなり、あまりにも極端に内気または反社会的になるため、無視されるか、あるいは排除されてしまいます。

---
### 能力値の算出

各能力値には、その強さを決定するための数値があります。各ダイスロールの後の括弧内の数値は種族平均であり、自分のキャラクターの結果を種族の他のメンバーと比較する際の指標として使用されます。能力値を決定するための推奨方法は以下の通りです。

- **ダイスロール:** 筋力、体力、体格、敏捷性、知力、霊力、CHAの各能力値をダイスで決定し、出た目の値をそのまま使用します。これらのロールの結果はランダムであるため、ダイスを振った後にキャラクターコンセプトを決める方が良い場合が多いです。そうしないと、最終的な能力値が想定していたロールと合わなくなる可能性があります。筋力、体力、敏捷性、霊力、CHAには3d6をロールし、SIZとINTには2d6+6をロールします。
- **ダイスロール（割り当て）:** 上記と同様ですが、プレイヤーは同じダイス範囲を持つ能力値間で値を交換できます。例えば、人間を作成する場合、同じ3d6範囲を共有するSTR、体力、敏捷性、霊力、CHAの間で値を交換したり、2d6+6範囲を共有するSIZとINTの間で値を交換したりできます。ただし、必ず同じダイス範囲グループ内で行う必要があり、グループ間での交換はできません。
- **ダイスロール（高値）:** 各能力値に対して指定されたダイスを1つ余分に振り、その中から最も低い目を除外します。
- **ポイントビルド:** プレイヤーはあらかじめ決められた80ポイントのプールから能力値スコアを割り当てます。能力値はロールした最小値より低くすることはできず、最大値より高くすることもできません。

## ステップ3：特性値

各キャラクターには特性値も設定されています。これらは能力値から算出されるか、能力値によって決定される能力であり、ゲームプレイの特定の要素を管理するために使用されます。

#### 行動ポイント

キャラクターが戦闘ラウンド中に何回行動できるかは、行動ポイントによって決定されます。すべての『Mythras Imperative』のキャラクターは2の行動ポイントを持ちます。

#### ダメージ修正

体格が大きく筋力が高いキャラクターや生物は、特定の状況で追加のダメージを得ることがあります。逆に、弱く小さなキャラクターは与えるダメージが減少することがあります。ダメージ修正は通常、戦闘状況で使用されますが、物を破壊しようとする際にも使用できます。ダメージ修正は武器や道具によって与えられるダメージに加算または減算される追加のダイスロールです。負のダメージ修正によって武器のダメージが0以下になった場合、ダメージはまったく与えられません。

STRとSIZを合計し、以下のダメージ修正表を参照してください。

#### 経験修正

プレイを通じてキャラクターは技能や能力を向上させます。これは経験ロールを使用して達成されます。詳細は[ゲームシステム](0004_Game_System.md?id=experience-rolls)セクションで説明されています。

キャラクターのCHAスコアは、そのキャラクターが受け取る経験ロールの数を調整する場合があります。これは彼らが仲間と持つ関係や、コミュニティ内での評判を反映しています。CHAが高いと、キャラクターが教育を受けている間、人々は喜んで助けたり支援したりしてくれます。逆に、特にCHAが低いと、他者の助けなしに能力を向上させるのが難しい場合があり、例えばスパーリング相手を見つけることなどが困難になります。

#### 治癒率

負傷した後、キャラクターは回復する必要があります。治癒率は、自然に傷が治る速度を決定します。怪我の重症度に応じて、治癒率は1日、1週間、あるいは1ヶ月あたりの回復ヒットポイント数を示します。

##### 治癒率表

| 体力 | 治癒率 |
| :-:| :-:|
| 6以下 | 1 |
| 7-12 | 2 |
| 13-18 | 3 |
| 6ポイントごと | +1 |

#### ヒットポイント

ヒットポイントは、体の部位が使用不能になるまでに耐えられる負傷の程度を表し、無力化や最終的な死亡につながる可能性があります。すべての生物の体は別々の部位に分かれています。例えば人間には7つの部位（頭部、胸部、腹部、腕、脚）があり、各部位には独自のヒットポイントがあります。

モンスターや異なる種類の動物など、一部の生物はその性質上、根本的に異なる身体構造を持っていますが、彼らが持つ各部位にもヒットポイントが存在します。何らかのダメージによって部位のヒットポイントがあるレベルまで減少すると、キャラクターはその負傷の重症度を反映した特定の結末を被ります。傷に関する詳細は[ダメージと負傷レベル](0004_Game_System.md?id=damage-and-wound-levels)セクションを参照してください。

#### イニシアチブ

戦闘中に誰がいつ反応するかはイニシアチブによって決定されます。イニシアチブはイニシアチブロールへの修正として機能し、高いほど戦闘状況下での反応が速くなり、行動順が決まります。防具などのさらなる要因が修正を与えます。[戦闘](0005_Combat.md?id=combat-style)の章でイニシアチブの使用方法について詳しく説明します。

イニシアチブはDEXとINTの平均値です。

#### 幸運ポイント

幸運ポイントは、冒険する英雄と一般の人々を区別する奇妙な力を表します。運命、カルマ、あるいは単純な幸運と呼ぶこともできるでしょう。幸運ポイントは以下に使用できます。

- 不利な場合にダイスを振り直す。
- 物理的なダメージやその他の不運な状況を緩和する。
- 戦闘の重要な瞬間に優位を得る。

正確にいつ、どのように使用するかは[ゲームシステム](0004_Game_System.md?id=game-system)セクションで説明されています。幸運ポイントを消費すると、プールは減少します。幸運ポイントがなくなると、ゲームマスターが即興で授与しない限り、次のゲームセッションまで追加のポイントは得られず、通常の最大値に補充されます。

##### 幸運ポイント表

| 霊力 | 幸運ポイント |
| :-- | :-: |
| 6以下 | 1 |
| 7-12 | 2 |
| 13-18 | 3 |
| 6ポイントごと | +1 |

#### マジックポイント

『Mythras Imperative』で使用される神秘的な能力、パワー、呪文は通常、マジックポイントに依存します。魔法の入手可能性はキャンペーン設定や特定の魔法職に制限される可能性があるため、一部のキャラクターにとってはこの特性値は不要かもしれません。

そのような能力を使用できるキャラクターの場合、マジックポイントはPOWに等しいです。これらのポイントは呪文の詠唱に使用され、コストは使用する魔法の種類に依存します。詠唱者がマジックポイントを使い果たすと、補充されるまで呪文を詠唱する能力は尽きてしまいます。

#### 移動速度

すべての生物には移動速度があります。これは特定の期間内に移動できる距離（メートル）です。移動速度は能力値から計算されるのではなく、種族ごとに異なるデフォルト値です。人間の基本移動速度は6メートルです。

「歩き」より速い歩容は移動速度に倍率を適用します。
- **走る:** 移動 x3  
- **全力疾走:** 移動 x5

## ステップ4：技能

技能は2つのクラスに分類されます。誰でも標準技能（忍び足や他者を説得するようなこと）を持っています。一方、専門技能は試みる前に特定の訓練が必要なものです（野生動物の追跡、宇宙船の操縦、古代言語の理解など）。キャラクターには技能を取得するために割り振るポイントが3つのプールで与えられます。最初のプールは育った文化、2番目は子供時代以降に就いた職業、最後は技能セットをさらに充実させるためのものです。デフォルトでは、新規キャラクターは文化技能プールに100ポイント、職業技能プールに100ポイント、さらに補完用として150のボーナスポイントを割り当てます。各文化と職業には、これらの技能ポイントを割り当てることができる標準技能および専門技能の定義済みの範囲があります。

## ステップ5：文化

文化はキャラクターが育った社会の種類を決定し、その結果、キャラクターが持つ可能性のある特定の視点や哲学を規定します。より実用的な点では、文化はキャラクターの全体的な能力を形成するさまざまな技能の値を増強するのに役立ちます。人間には、野蛮、文明、遊牧、原始の4つの基本的な文化があります。各文化的背景には適した標準技能の範囲が記載されており、プレイヤーは提示された専門技能から最大3つを選択できます。これにより、同じ文化的背景を持つプレイヤーでも、発展させた分野が異なる冒険者を作ることができます。100の文化技能ポイントを職業のリストにある標準技能および選択した専門技能に分配し、ポイントを費やすごとに技能を1%増加させます。ゲームマスターは、特定の技能に割り当てることができる技能ポイントに上限を設けることを望むかもしれません。

### 野蛮

部族的な性質を持つ野蛮人は文明を忌避する傾向があり、大きな町や都市に住む人々を弱く腐敗したものと見なします。彼ら自身の集落も定住型ですが、はるかに小さく、自然に近い傾向があります。野蛮部族は狩猟、放牧、農耕の目的で、自分たちのものと見なす明確な領域（多くは半分開拓された荒野）を占有しています。彼らのほとんどは武器の使用に長けており、野生の生物と対峙したり、敵対部族から自分たちの土地を守るために結集したりと、人生を通じて多くの危険を乗り越えなければならないためです。小さなコミュニティで生活しているため、親族関係や氏族の絆が社会の強い要素となっています。

#### 技能

- **標準技能:** 運動、腕力、持久力、応急手当、地域、知覚。さらに操船または乗馬のいずれか。加えて、プレイヤーは文化的な戦闘スタイルを1つ選択できます。
- **専門技能:** 工芸（任意）、治療、伝承（任意）、音楽演奏、航海術、操船技術、サバイバル、追跡。

### 文明

文明文化は、複雑な社会規範に裏打ちされ、官僚制度によって支えられた法と秩序の形によって典型化されます。文明人は、自分たちの業績が永続的なもの（広大な都市、威圧的な神殿、記念碑、本や墓石や巻物に記録された歴史と出来事）であるため、他のすべての文化よりも優れていると信じています。もちろん、これは薄い上塗りです。最も文明化された都市でさえ、野蛮人の辺境集落よりも無法である可能性があり、社会規範は遊牧民のホスピタリティの儀式よりも粗野であるかもしれません。しかし、文明文化は自らの業績、インフラ、専門的な職人、そして望む場所に容易に手を伸ばせる能力を誇りとしています。

#### 技能

- **標準技能:** 隠蔽、欺瞞、運転、説得、洞察、地域、意志力。加えて、プレイヤーは文化的な戦闘スタイルを1つ選択できます。
- **専門技能:** 芸術（任意）、商業、工芸（任意）、礼儀、言語（任意）、伝承（任意）、音楽演奏、路地裏事情。

### 遊牧

遊牧民は常に移動しており、自分たちの家や火床を持ちません。彼らは目的もなく歩き回ることもあれば、年間を通じて移動するいくつかのキャンプを持っているかもしれません。彼らはほとんど作物を育てず、代わりに動物や魚の移動に従い、おそらく自分たちの家畜を群れで飼うでしょう。遊牧民は周囲から素早く簡単に拾えるもので生活することに長けており、何も無駄にしません。遊牧文化の技能は彼らの環境に合わせて調整されるべきです。ある者は徒歩で広大な距離を旅し、ある者は隊商で生活したり奇妙な生き物に乗ったりし、またある者は大きな浮き筏に乗って海を漂流します。

#### 技能

- **標準技能:** 持久力、応急手当、地域、知覚、隠密。そして、移動の主要手段に応じて運動、操船、水泳、運転、乗馬の中から2つ。加えて、プレイヤーは文化的な戦闘スタイルを1つ選択できます。
- **専門技能:** 工芸（任意）、文化（任意）、言語（任意）、伝承（任意）、音楽演奏、航海術、サバイバル、追跡。

### 原始

あらゆる人々の中で、原始人は土地の隠された秘密と調和し、土地と最も密接に生きる人々です。大家族グループで生活し、原始文化は洞窟や自然の避難場所から、差し掛け小屋や非常に基本的な小屋まで、さまざまな非常に単純な住居の周りに集まります。原始人は通常、狩猟採集民であり、農業や畜産のためのシステムはほとんど、あるいは未発達です。

しかし、多くの場合迷信に基づいた特定の文化的信念は、非常に明確に定義されることがあります。絵画やその他の絵記号がコミュニケーションの手段として機能するものの、書かれた言語に近いものを発達させた原始文化はほとんどありません。#### 技能

- **標準技能:** 腕力、持久力、回避、地域、知覚、隠密。それに加えて、運動、操船、水泳のいずれか1つ。さらに、プレイヤーは文化に応じた戦闘スタイルを1つ選択できる。
- **専門技能:** 工芸（任意）、応急手当、伝承（任意）、音楽、航海術、生存、追跡。

## ステップ6：キャリア

## ステップ7：ボーナス技能ポイント

最終ステップとして、150の技能ポイントが与えられ、キャラクターを完成させるために使用する。これらは任意の標準技能、または文化やキャリアの一環として獲得した専門技能に適用できる。繰り返すが、ゲームマスターは特定の技能に適用できる技能ポイントに上限を設けることができる。

### 経験豊富なキャラクターの作成

キャラクターは新鮮な状態で始め、実際的な経験はほとんど、あるいは全くない状態からスタートすることが推奨される。もちろん、キャラクターのレベルは設定や、ゲームが短い単発の冒険か長期的なキャンペーンかによって大きく異なる。また、プレイ中に死亡したキャラクターを交代させる場合や、既存のキャンペーンに参加する場合に、プレイヤーがより経験豊富なキャラクターを作成することも一般的である。

経験を年齢カテゴリに分類した表が提供されている。キャラクターの経験は、年齢および技能の熟練度と直接的な相関関係がある。経験豊富なキャラクターは、当然ながら若い仲間に比べて人生経験が豊富である。ただし、記載されている年齢ボーナスは目安として扱うべきである。キャンペーンはさまざまなペースで進行するため、冒険の間に多くのゲーム時間が経過するキャンペーンもあれば、中断のない連続した冒険が続くキャンペーンもあるからである。既存のキャラクターを変換する場合は、実際の年齢を、表に記載されている年齢に置き換えるだけでよい。

#### 経験表

| カテゴリ | 年齢 | ボーナス技能ポイント | 最大技能上昇値 |
| :-- | :-: | :-: | :-: |
| 若年 | 10+1d6 | 100 | +10 |
| 成人 | 15+2d6 | 150 | +15 |
| 中年 | 25+3d6 | 200 | +20 |
| 高年 | 40+4d6 | 250 | +25 |
| 老年 | 60+5d6 | 300 | +30 |

#### 経験表に関する注記

- ボーナス技能ポイントは、キャラクターが技能の発展のために費やさなければならないポイント数を決定する。
- 最大技能上昇値は、ボーナスポイントのうち、単一の技能に適用できるポイント数を制限する。

### 技能ピラミッド

『Mythras Imperative』の技能ポイント割り当てプロセスは、文化（100）、キャリア（100）、ボーナス技能ポイント（150）の3つのソースから350ポイントを得る。これらのポイントを割り当てるのは時間がかかる場合があり、キャラクターの文化を決定することがそれほど重要でない場合や、プレイヤーがコア・ルールのテンプレートでは対応しきれない特定の職業を想定している場合もあるだろう。ここでは、時間が差し迫っている場合や、プレイヤーがやる気に満ちている場合のために、技能ポイントを割り当てるための代替システムを提示する。

文化、キャリア、ボーナス技能ポイントのプールからポイントを割り当てる代わりに、技能ピラミッドを使用する。これは350ポイントを5つの固定ポイントのブロックに分割する。

50%の技能×1、40%の技能×2、30%の技能×3、20%の技能×4、10%の技能×5。

これが便利なピラミッドを形成する。割り当てるたびに各値を消し込んでいけばよい。

```
    50

   40 40

  30 30 30

 20 20 20 20

10 10 10 10 10
```

#### いくつかの簡単なルール

- ピラミッドからのポイントはすべて割り当てなければならない。
- いかなる技能も、ピラミッドからの割り当てを複数受けることはできない。
- 習慣と母国語は、コア・ルールに従ってそれぞれ+40を獲得し、さらにピラミッドからの割り当てを追加できる。
- 情熱は[情熱](0002_Characters.md?id=step-8-passions)セクションに記載された値を得る。これはピラミッドからの割り当てに追加して行われる。
- 割り当ての結果として、いかなる技能も80%を超えることはできない。例えば、キャラクターの筋力16と敏捷性17で基本値が33%の場合、プレイヤーはその戦闘スタイルに50ポイントの値を割り当てることはできない。
- 値のうち6つは専門技能に割り当てなければならない。
- キャラクターは引き続き文化と職業を選択し、適切な説明に記載されている技能を割り当てのガイドとして使用できる。あるいは、完全に自由な形式で割り当てることもできる。
- 値の少なくとも1つを戦闘スタイルに割り当てることが推奨されるが、これは必須ではない。
- ゲームマスターが常に最終決定権を持つ。

### 超人的な英雄

『Mythras Imperative』は主に普通の人間を扱うが、時折、特別な英雄的行為を必要とする場合や、英雄や悪役が超人的な傾向を持つパルプ・アクションの設定など、別の何かを必要とすることがある。

そのような英雄は必ずしも超能力を持っている必要はない（もしそれが必要であれば、「魔法と能力」の章を使用できる）が、少し強く、少し速く、少し回復力があり、通常、意志もはるかに強い。キンメリア出身のあの野蛮人、殺しのライセンスを持つエージェント、青銅の男、億万長者のプレイボーイでもあるマントをまとった自警団員、あるいは数多くの人気ある英雄的なキャラクターを思い浮かべてほしい。彼らはしばしば、普通の人間なら崩れ落ちるような状況に直面する。しかし英雄として、彼らはプロットが投げかけるあらゆる事態に耐え、次の冒険へと（比較的）無傷で参加することができる。

これらのキャラクタータイプをゲームに導入するつもりなら、すべてのプレイヤーが同じレベルのキャラクターを持っていることを確認すること。これらのキャラクタータイプは、風景を噛み砕き、物語を牽引するように設計されている。平凡なキャラクターは（魔法やその他の利点がない限り）、影に追いやられてしまう可能性がある。

### パルプ・ヒーロー・キャラクター

これらは伝統的なパルプ・ヒーローである。彼らはスーパーヒーローや半神ではなく、至近距離からのショットガンの一撃は依然として彼らの命を奪う可能性があるが、彼らはよりタフで、より賢く、より有能であり、一般的に普通の人々より1、2段階上である。また、彼らの人生は冒険で満たされている傾向がある。英雄的なキャラクターは平穏に暮らそうと決意することもできるが、多くの場合、トラブルや助けを必要とする誰かがキャラクターの扉を叩くことになる。

#### 能力値

パルプ・ヒーロー的なキャラクターを作成するときは、[キャラクター](0002_Characters.md?id=calculating-characteristics)セクションのダイスロール割り当て法を使用する。4d6を振り、最も低いダイスを捨てて、それを5回行い、その結果を筋力、体力、敏捷性、霊力、魅力に割り当てる。次に、3d6+6を振り、最も低いダイスを2回捨てて、その数字を体格と知力に割り当てる。ポイントビルド法を使用する場合、プレイヤーは設定された90ポイントのプールからキャラクターを構築する。

#### 特性値

これらは通常通り計算されるが、パルプ・ヒーロー的キャラクターは以下から選択した2つの有利な点を得る（有利な点は積み重ねられないことに注意）。

- +1 行動ポイント
- +1 幸運ポイント
- 各部位判定への+1 ヒットポイント
- 持久力判定が1等級簡単になる
- 隠密判定が1等級簡単になる
- 意志力判定が1等級簡単になる

すべてのパルプ・ヒーロー的キャラクターは、軽傷または重傷を負った際、治癒率を2倍にする。ただし、致命傷はキャラクターの標準的な治癒率で処理される。

#### 技能

パルプ・ヒーロー的キャラクターは、必要に応じて割り当てられる50のボーナス技能ポイントを追加で得る。

### パラゴン・キャラクター

パラゴン・キャラクターは卓越性の権化である。鞭を操る考古学者や殺しのライセンスを持つスーパー・スパイがパルプ・ヒーロー的キャラクターであるのに対し、あのキンメリア人、青銅の男、ダークナイト・ディテクティブ、そしてシャーロック・ホームズはパラゴン・キャラクターである。パラゴン・キャラクターは単一の専門分野で極めて有能なだけではない。彼らは通常、いくつもの分野で秀でている。二拳を使いこなす射撃の名手である戦争英雄でもある天才的な発明家で物理学者は、パラゴン・キャラクターの好例である。世界最高の探偵たちのもとで学んだ億万長者のプレイボーイにして犯罪と戦う者もまた同様である。パラゴン・キャラクターは、複数の大学の学位、独自の財産、謎の恩人、そして数多くのその他の経験を持っている可能性がある。

その結果、パラゴン・キャラクターは万人向けではないかもしれないが、太陽系全体の運命を変えることができる、あるいはあらゆる挑戦に立ち向かえるキャラクターが必要な設定であれば、パラゴン・レベルのキャンペーンが適している。平凡なキャンペーンや英雄的なキャンペーンでも、国家や惑星の運命といった非常に高い賭けを扱うことがあるが、パラゴン・キャンペーンではそれを日常的に行うべきである。

#### 能力値

[キャラクター](0002_Characters.md?id=calculating-characteristics)セクションのダイスロール割り当て法を使用してキャラクターを作成する際、4d6を振って最も低いダイスを捨てることを6回行い、そのうち5つの結果（通常は最も高い5つ）を選択して筋力、体力、敏捷性、霊力、魅力に割り当てる。次に、3d6+6を振り、最も低いダイスを3回捨てて、そのうち2つの結果（通常は最も高い2つ）を選択して体格と知力に割り当てる。ポイントビルド法を使用する場合、プレイヤーは100ポイントの事前設定プールからキャラクターを構築する。

#### 特性値

これらは通常通り計算されるが、パラゴン・キャラクターは以下から選択した3つの有利な点を得る（有利な点は積み重ねられないことに注意）。

- +1 行動ポイント
- +2 幸運ポイント
- 各部位判定への+2 ヒットポイント
- 持久力判定が1等級簡単になる
- 隠密判定が1等級簡単になる
- 意志力判定が1等級簡単になる

すべてのパラゴン・キャラクターは、軽傷または重傷を負った際、治癒率を2倍にする。ただし、致命傷はキャラクターの標準的な治癒率で処理される。

#### 技能

パラゴン・ヒーロー的キャラクターは、必要に応じて割り当てられる100のボーナス技能ポイントを追加で得る。

## ステップ8：情熱

情熱は、プレイヤーとゲームマスターがキャラクターの性質を深め、キャラクターの欲望や偏見に基づいたプロットフックを導入し、プレイヤーが自分のキャラクターは何者か、何が彼を駆り立てるのかなどを理解するのを助けるために使用される。

情熱は何に対しても抱くことができる。人、組織、理想、あるいは物体でさえも。情熱は通常、「欲望」、「軽蔑」、「破壊」、「支持」、「恐怖」、「逃避」、「放棄」、「憎悪」、「愛」、「忠誠」、「保護」、「拒絶」、「尊敬」、「探求」、「顛覆」、「苦悩」、「擁護」といった動詞で記述される。

情熱は技能と同じ方法で測定される。それらは1から100（あるいはそれ以上）の間で評価される。情熱は技能と同じ方法で向上させることができ、状況に応じて審判によって増加または減少させることができる。

開始時のキャラクターは最大3つの情熱を持つことができ、それぞれが2つの特性値に基づいて、最初の一つに+40、二つ目に+30、三つ目に+20のボーナスを得る。プレイヤーは重要度の順序を決定する。これらは文化、職業、あるいは個人の性格に関連付けることができる。例えば、「ソード＆ソーサリー」キャンペーンでは、キャラクターは「憎悪（スティギア人）」、「不信（ソーサラー）」、「欲望（アルコール）」を持つかもしれない。一方で、ディストピアSFゲームでは、代わりに「忠誠（大統領）」、「破壊（エイリアン）」、「擁護（法）」を選択するかもしれない。#### 情熱表

| 情熱の対象 | 初期パーセンテージ |
| :-- | :-- |
| 恋愛や家族関係にある人物 | 霊力+魅力 |
| 組織や集団 | 霊力+知力 |
| 人種や種族 | キャラクターの霊力 x2 |
| 場所 | キャラクターの霊力+知力 |
| 物体や物質 | キャラクターの霊力 x2 |
| 性格的特性 | キャラクターの霊力+魅力 |

### 情熱の使用

情熱とは、プレイ中の出来事に影響を与える能力を持つ、深く抱かれた信念のことである。これらは独立した能力として使用できるが（技能と呼ぶには役不足である）、以下に『Mythras Imperative』のキャラクターとキャンペーンにおいて、情熱がどのように機能し、影響を与えるかを詳しく説明する。

要約すると、情熱は以下のように使用できる：

- 他の技能を増強するために使用する。これは、自身の感情の深さと、それがどのように行動を駆り立てるかを反映するものである。この目的で使用する場合、その増強がテーマ的かつ劇的に重要であれば、情熱はその技能値の20%を上乗せする。
- 選択、欲望、感情的な行動や反応を導くための能力として使用する。この方法で使用する場合、キャラクターが何についてどれほど強く考え、感じているかを判定するために、情熱に対して標準的な判定を行う。成功した場合、キャラクターは情熱が指示する通りに行動する。判定に失敗した場合、キャラクターは情熱の衝動に縛られることなく自由に行動できる。
- 他の情熱（同一キャラクターが持つものを含む）に対抗するために使用する。これは通常、二つの情熱が対立する場合に使用される。例えば、個人的な愛が、誓いや忠誠心とは矛盾する行動を要求する場合などである。この場合、二つの情熱の間で対抗判定を行い、より成功した側がキャラクターの行動を決定する。
- 大義に対する献身、信念、忠誠心の深さを測る一般的な尺度として使用する。情熱の値が高いほど、キャラクターはその大義に深く献身していることになる。同様の情熱を持つキャラクター同士は、自身の数値を比較して、どちらがより深い献身を示しているかを判断できる。
- 心理的な操作や魔法による支配に抵抗するために使用する。キャラクターが情熱に反する行動を強制されるような特定の状況では、対抗判定において、意志力の代わりに情熱を使用することができる。

新たな情熱は、状況がそれを正当化するならば、ゲームセッション中のいつでも習得できる。誰かが憎悪を強くかき立てるようなことをした場合、即座に「憎悪（対象）」を習得するかもしれない。領主や首長が誓いを求めた場合、その誓いが立てられた瞬間に「忠誠（対象）」という情熱が確立される。

このようにプレイ中に新たに習得した情熱は、経験ロールを消費せず、その場ですぐに確立される。もちろん、キャラクターが成長の過程で経験ロールを消費して、情熱を基本値で習得することを選択することもできる。

### 深まりと衰え

情熱は、それを引き起こした出来事の強さに応じて、経験ロールとは無関係にゲーム中に上昇することがある。また、情熱は衰えることもあり、実際に衰える。強く抱かれた信念も多くの出来事によって揺さぶられ、情熱が低下したり、極端な場合には完全に反転したりする可能性がある。

例えば、「首長への信頼」を持つキャラクターは、もし首長が背信行為を行えば、その情熱を低下させるか、あるいは同じパーセンテージで「首長への不信」に変化させることができる。情熱が低下するか反転するかは、ゲームマスターが判断する必要がある。低下する場合、その変化は変化の源の強さに応じて行われる。

「深まりと衰え表」は、情熱がどれだけ変化するかを示している。

#### 深まりと衰え表

| 変化の度合い | 情熱の修正値 |
| --- | --- |
| 弱い | 1d10 |
| 中程度 | 1d10+5 |
| 強い | 1d10+10 |

## ステップ 9: 装備

キャラクターがほぼ完成したところで、彼または彼女は装備をいくつか必要とする。これには、特定の職業で使用される武器、防具、その他の重要な用具が含まれる。冒険の間、より多くの装備を入手する機会は多くあるが、初期作成キャラクターはそれぞれ、直ちに以下のものを所持している：

- そのキャラクターの職業と設定に適した衣服一式。
- ポケットマネー：困窮することなくしばらくの間過ごせるだけの金額。
- 個人的な家宝、形見、あるいは相対的に価値の低い何らかの小間物。
- 職業に適した取引道具や持ち運び可能な装備（該当する場合）。
- キャラクターの戦闘スタイルに応じた個人的な武器。
- その他、設定に応じて適切であり、かつGMの承認を受けたアイテム。
