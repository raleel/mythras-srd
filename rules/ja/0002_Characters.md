# キャラクター

_Mythras Imperative_ におけるすべてのプレイヤーは、キャラクターを操作します。キャラクターとはプレイヤーの分身であり、通常、身体的にも精神的にもプレイヤーとは大きく異なります。キャラクターはゲームの設定に応じて様々な種族から選ぶことができます。歴史的な設定であれば人間のみとなりますが、ファンタジー設定であればドワーフ、エルフ、さらにはリザードマンなども含まれるかもしれません。基本的なキャラクターは、その能力を説明する一連の異なる要素によって定義されます。これらの要素は以下の通りです。

- **能力値:** 筋力や魅力など
- **特性値:** 身長や移動速度など
- **技能:** 基本的な能力における専門知識

これらの要素のほとんどは数値で表され、一部は他の要素に依存したり、それらから算出されたりします。各要素が何を意味し、どのように決定されるかは、以下のセクションで説明します。

---
## ステップ 1: キャラクターコンセプト

まず初めに、どのようなキャラクターをプレイしたいかというアイデアを持つことから始めると良いでしょう。例えば、狡猾な戦士や、悪知恵の働く密輸業者などが考えられます。あるいは、勤勉な学者や、賢明な魔術師を好むかもしれません。キャラクターコンセプトはこの段階では精巧である必要はありません。単に文化やキャリアといった選択を導く助けとなるアイデアであれば十分です。

---
## ステップ 2: 能力値

すべてのキャラクターは、その個性を表す7つの能力値によって定義されます。これらは、キャラクターの強さや速さ、賢さや健康状態を示します。能力値はすべての _Mythras_ _Imperative_ のキャラクターの核心であり、特性値や技能といった他の要素のほとんどの基礎となります。7つの能力値は以下の通りです。

- 筋力 (筋力)
- 体力 (体力)
- 体格 (体格)
- 敏捷性 (敏捷性)
- 知力 (知力)
- 霊力 (霊力)
- 魅力 (魅力)

能力値を算出する前に、各能力値が何を表すかを次のセクションで説明します。

#### 筋力 (筋力)

STRは身体的な強さを表します。どれだけ持ち上げられるか、どれだけ強く叩けるかなどです。STRはダメージ修正の構成要素です。もしキャラクターのSTRが0まで低下すると、移動したり物を持ち上げたりする能力を失います。

#### 体力 (体力)

CONは健康と頑強さの尺度です。CONはヒットポイントと治癒率を決定する構成要素です。もし何らかの理由でCONが0まで低下すると、キャラクターは死亡します。

#### 体格 (体格)

SIZは質量を測定し、身長と体重を示す指標となります。SIZはヒットポイントを算出する際に使用されます。より大きく重いクリーチャーは、ダメージに対してより高い耐久力を持つ傾向があるためです。SIZはキャラクターのダメージ修正を決定するためにも使用されます。質量が打撃の力を高める助けとなるためです。

#### 敏捷性 (敏捷性)

敏捷性、平衡感覚、反射神経はDEXで測定されます。これは行動ポイントとイニシアチブの重要な側面です。もしキャラクターのDEXが0まで低下すると、機能的な麻痺に苦しみます。

#### 知力 (知力)

INTは認知能力の尺度です。INTスコアが低い者が必ずしも愚かであるとは限りませんが、機知をどれだけ創造的に活用できるかという点において制約を受ける可能性が高いです。INTは行動ポイントとイニシアチブを算出する要因となります。もしINTが0まで低下すると、キャラクターは完全に精神を失います。

#### 霊力 (霊力)

POWはキャラクターの魂、精神、内なる衝動、あるいは魔法の容量の尺度です。POWはキャラクターのマジックポイントと幸運ポイントを左右します。もしキャラクターのPOWが0まで低下すると、自立した意志をすべて失います。

#### 魅力 (魅力)

魅力は存在感と人柄の尺度であり、外見とは無関係です。CHAはキャラクターの経験修正に影響を与えます。もしCHAが0まで低下すると、そのキャラクターは他者と社会的に交流することができなくなり、ひどく内向的または反社会的になって無視されるか、あるいは追い払われてしまうことさえあります。

---
### 能力値の算出

各能力値には、その強さを決定するための数値が割り当てられます。各ダイスロールの後の括弧内の数字は種族平均であり、自分のキャラクターの結果を種族の他のメンバーと比較して評価するための基準として使用されます。能力値を決定するための推奨方法は以下の通りです。

- **ダイスロール:** 筋力、体力、体格、敏捷性、知力、霊力、CHAのダイスを振り、出た目をそのまま受け入れます。これらのロールの結果はかなりランダムになる可能性があるため、ダイスを振った後にキャラクターコンセプトを決める方が良い場合が多いです。そうしないと、最終的な能力値が事前に考えていた役割と合わなくなる可能性があります。筋力、体力、敏捷性、霊力、CHAは3d6を振り、SIZとINTは2d6+6を振ります。
- **ダイスロール、割り当て:** 上記と同じですが、プレイヤーは同じダイス範囲を持つ能力値間で数値を交換できます。例えば、人間を作成する場合、プレイヤーはSTR、体力、敏捷性、霊力、CHAの間で数値を入れ替えることができます（これらは3d6の範囲を共有しているため）。あるいは、2d6+6の範囲を共有するSIZとINTの間で入れ替えることもできます。ただし、必ず同じダイス範囲グループ内で行う必要があります。グループ間でロールを入れ替えることはできません。
- **ダイスロール、高値選択:** 筋力、体力、体格、敏捷性、知力、霊力、CHAについてそれぞれ指定された数より1つ多くダイスを振り、最も低い結果をそれぞれ除外します。
- **ポイント割り当て:** プレイヤーは事前に決められた80ポイントのプールから能力値スコアを割り当てます。能力値は、ロールによって決まる最小値よりも低くすることはできず、最大値よりも高くすることはできません。

---
## ステップ 3: 特性値

各キャラクターには一連の特性値もあります。これらは能力値から導き出された、または能力値によって決定される能力であり、ゲームプレイの特定の要因を管理するために使用されます。

#### 行動ポイント

キャラクターが戦闘ラウンド中にどれだけ頻繁に行動できるかは、行動ポイントによって決定されます。すべての _Mythras_ _Imperative_ のキャラクターは2点の行動ポイントを持ちます。

#### ダメージ修正

より大きく強いキャラクターやクリーチャーは、特定の状況で追加のダメージを得る場合があります。逆に、より弱く小さいキャラクターは、与えるダメージが減少する場合があります。ダメージ修正は一般的に戦闘状況で使用されますが、物を破壊しようとする際にも使用されます。ダメージ修正は追加のダイスロールであり、武器や道具が与えるダメージに加算または減算されます。もしマイナスのダメージ修正によって武器のダメージが0以下になった場合、ダメージはまったく与えられません。

STRとSIZを合計し、以下のダメージ修正表を参照してください。

#### 経験修正

プレイを通じてキャラクターは技能や能力を向上させます。これは経験ロールを使用して達成されます。経験ロールについては [ゲームシステム](0004_Game_System.md?id=experience-rolls) セクションで詳しく説明されています。

キャラクターのCHAスコアは、キャラクターが受け取る経験ロールの数を調整する場合があります。これは、仲間との関係や地域社会での評判を反映しています。高いCHAがあれば、キャラクターが指導を受けている間に、人々は進んで助けたり支援したりしてくれるでしょう。逆に、非常に低いCHAの場合、例えば対戦相手を探すなど、他人の助けなしに能力を向上させることは困難かもしれません。

#### 治癒率

怪我をした後、キャラクターは回復する必要があります。治癒率は、怪我から自然にどれだけ早く回復するかを決定します。怪我の深刻さに応じて、治癒率は1日、1週間、または1ヶ月あたりに回復するヒットポイントの数を示します。

##### 治癒率表

| :-:| :-:|
| 6以下 | 1 |
| 7-12 | 2 |
| 13-18 | 3 |
| 6ポイントごと | +1 |

#### ヒットポイント

ヒットポイントは、体の部位が使い物にならなくなるまで、あるいは無力化や最終的な死亡に至るまでにどれだけの損傷に耐えられるかを表します。すべてのクリーチャーの体は個別の位置に分割されています。例えば人間には7つの部位（頭部、胸部、腹部、腕、脚）があり、各部位には独自のヒットポイントがあります。

モンスターや異なる種類の動物など、一部のクリーチャーは、その性質上、根本的に異なる身体構造を持つことがよくありますが、彼らが持つ各部位も依然としてヒットポイントを持っています。何らかの種類のダメージによって部位のヒットポイントがあるレベルまで減少すると、キャラクターはその怪我の深刻さを反映した特定の結果に苦しみます。傷に関する詳細については [ダメージと傷のレベル](0004_Game_System.md?id=damage-and-wound-levels) セクションを参照してください。

#### イニシアチブ

戦闘中に反応する瞬間はイニシアチブによって決まります。イニシアチブはイニシアチブロールに対する修正値として機能します。イニシアチブが高いほど、戦闘状況においてより速く反応し、いつ行動できるかが決定されます。防具などの他の要因がイニシアチブを修正します。[戦闘](0005_Combat.md?id=combat-styles) の章で、イニシアチブの使用方法について詳しく説明します。

イニシアチブはDEXとINTの平均値です。

#### 幸運ポイント

幸運ポイントは、冒険する英雄と一般人を区別する不思議な力を表します。運命、カルマ、あるいは単純な幸運と呼ぶこともできます。幸運ポイントは以下のために使用できます。

- 不利な結果が出た場合にダイスを振り直す。
- 物理的なダメージやその他の不運な状況を軽減する。
- 戦闘の重要な瞬間に優位を得る。

正確にどのように、いつ使用するかについては [ゲームシステム](0004_Game_System.md?id=game-system) セクションで説明されています。幸運ポイントを一度消費すると、プールが減少します。幸運ポイントがなくなると、ゲームマスターが即興で授与しない限り、次のゲームセッションで通常の値に補充されるまで利用できません。

##### 幸運ポイント表

| 霊力 | 幸運ポイント |
| :-- | :-: |
| 6以下 | 1 |
| 7-12 | 2 |
| 13-18 | 3 |
| 6ポイントごと | +1 |

#### マジックポイント

_Mythras_ _Imperative_ で使用される神秘的な能力、力、呪文は通常マジックポイントに依存します。魔法の利用可能性はキャンペーンの設定や特定の魔法職に限定される場合があるため、この特性値が不要なキャラクターもいるでしょう。

そのような力を使用できる者にとって、キャラクターのマジックポイントはPOWに等しいです。これらのポイントは呪文を唱えるために使用され、そのコストは使用される魔法の種類によって異なります。術者のマジックポイントが尽きると、回復するまで呪文を唱える能力を使い果たしたことになります。

#### 移動速度

すべてのクリーチャーは移動速度を持っています。これは特定の期間内に移動できるメートルの数です。移動速度は能力値から計算されるものではなく、種族ごとに異なるデフォルト値です。人間の基本移動速度は6メートルです。

歩行よりも速い移動には、移動速度に乗数がかかります：
- **走行:** 移動速度 x3
- **全力疾走:** 移動速度 x5

## ステップ 4: 技能

技能は2つのクラスに分けられます。誰もが標準技能を持っています（忍び歩きや他者への影響など）。一方で専門技能は、試みる前に特定の訓練が必要なものです（野生動物の追跡、宇宙船の操縦、古代言語の理解など）。キャラクターには技能を取得するために割り振るポイントのプールが3つ与えられます。1つ目は育った文化用、2つ目は子供時代を終えた後に採用するキャリア用、最後は技能セットをさらに補完するためのものです。デフォルトとして、新規キャラクターは文化技能プールに100ポイント、キャリア技能プールに100ポイントを割り当て、さらに補完用に150のボーナスポイントを割り当てます。各文化とキャリアには、それらの技能ポイントを割り当てることができる標準技能と専門技能の定義済みの範囲があります。

## ステップ 5: 文化

文化はキャラクターが育った社会の種類を決定し、そのため彼らが持つであろう特定の視点や哲学を規定します。より実用的な面では、文化はキャラクターの全体的な能力を形作る様々な技能の値を向上させるのに役立ちます。人間には4つの基本的な文化があります：蛮族、文明人、遊牧民、原始人です。各文化的背景はそれに見合う標準技能の範囲をリストし、提示された専門技能の中から最大3つを選択するようプレイヤーを促します。こうすることで、同じ文化的背景を持つプレイヤーでも、発達させた分野において自分の冒険者が異なることを確実にできます。100の文化技能ポイントを、キャリアにリストされた標準技能と選択した専門技能のいずれかに割り当て、改善するために費やした各ポイントにつきその技能を1%ずつ増加させます。ゲームマスターは、特定の技能に適用できる技能ポイントに上限を設けることを望むかもしれません。

### 蛮族

部族的な性質を持つ蛮族は、文明を避ける傾向があり、大きな町や都市に住む人々を弱く不純だと見ています。彼ら自身の集落も定住型ですが、はるかに小さく、自然に近い傾向があります。蛮族の部族は明確な領土を占有しており、多くは手付かずの荒野であり、彼らは狩猟、放牧、農業のためにそれらを自分たちのものと見なしています。ほとんどの者は武器の使用に熟練しています。彼らは生涯を通じて、荒野のクリーチャーと対峙したり、ライバル部族に対して土地を守るために集結したりと、多くの危険を乗り越えなければならないからです。彼らは小さな共同体で暮らしているため、親族と部族の絆が彼らの社会の強い要素となっています。

#### 技能

- **標準技能:** 運動、腕力、持久力、応急手当、地域、知覚。さらに操船または乗馬のいずれか。加えて、プレイヤーは文化的戦闘スタイルを選択することもできます。
- **専門技能:** 工芸（任意）、治療、伝承（任意）、音楽、航海、船乗り、生存、追跡。

### 文明人

文明人の文化は、複雑な社会規範と官僚制度によって支えられた、法と秩序の外観によって体現されています。文明人は、自分たちの業績が都市の拡大、威圧的な寺院、祝賀の記念碑、本や墓石、巻物への歴史や出来事の記録といった永続的なものへと向かっているため、他のすべての文化よりも優れていると信じています。もちろん、これは薄いベニヤ板のようなものです。最も文明化された都市でさえ、蛮族のフロンティアの入村地よりも法が守られていない場合があり、社会規範は遊牧民の歓待の儀式よりも未熟である可能性があります。しかし、文明文化は自らの業績、インフラ、専門の職人、そして望む場所へ容易に到達を拡大できる能力を誇りに思っています。

#### 技能

- **標準技能:** 隠蔽、欺瞞、運転、説得、洞察、地域、意志力。加えて、プレイヤーは文化的戦闘スタイルを選択することもできます。
- **専門技能:** 芸術（任意）、商業、工芸（任意）、礼儀、言語（任意）、伝承（任意）、音楽、ストリートワイズ。

### 遊牧民

遊牧民は常に移動しており、自分たちの家や炉辺を持っていません。彼らはあてもなくさまよったり、一年を通じて移動するいくつかのキャンプを持っていたりします。彼らはほとんど作物を育てず、動物や魚の移動に従い、おそらく自分たちで家畜を飼育することさえあります。遊牧民は、周囲から素早く容易に調達できるもので生活することに長けており、何も無駄にしません。遊牧民文化の技能は彼らの環境に合わせて調整されるべきです。徒歩で広大な距離を旅する者もいれば、キャラバンに住んだり、奇妙なクリーチャーに乗ったりする者、巨大な浮かぶいかだで海を漂う者もいます。

#### 技能

- **標準技能:** 持久力、応急手当、地域、知覚、隠密。加えて、以下のうち2つを選択：運動、操船、水泳、運転、または乗馬（主要な移動手段による）。加えて、プレイヤーは文化的戦闘スタイルを選択することもできます。
- **専門技能:** 工芸（任意）、文化（任意）、言語（任意）、伝承（任意）、音楽、航海、生存、追跡。

### 原始人

すべての民の中で、原始人とは土地と最も密接に関わり、その隠された秘密と調和して生きる人々です。大家族単位で生活する原始文化は、洞窟や自然のシェルターのある場所から、仮設小屋や非常に基本的な小屋まで、非常にシンプルな住居の周りに集まります。原始人は通常、農業や牧畜のためのシステムがほとんど、あるいは十分に発達していない狩猟採集民です。

しかし、多くの場合迷信に基づいた特定の文化的な信念は、非常によく定義されていることがあります。絵画やその他の絵記号がコミュニケーションの手段として役立っていますが、文字言語に近いものを発達させた原始文化はほとんどありません。#### 技能

- **標準技能:** 腕力、持久力、回避、地域、知覚、隠密。それに加え、運動、操船、水泳のいずれか1つ。さらに、プレイヤーは文化に応じた戦闘スタイルを1つ選択できる。
- **専門技能:** 工芸（任意）、応急手当、伝承（任意）、音楽、航法、生存、追跡。

## ステップ7: ボーナス技能ポイント

最終ステップとして、キャラクターを完成させるために最後の150技能ポイントが割り当てられます。これらは任意の標準技能、または文化やキャリアの一環として得た専門技能に適用できます。繰り返しますが、ゲームマスターは特定の技能に適用できる技能ポイントに上限を設けることができます。

### 経験を積んだキャラクターの作成

初心者のキャラクターは、実務経験がほとんどない、あるいはまったくない状態でゲームを開始することが推奨されます。もちろん、キャラクターのレベルは設定や、ゲームが短い単発の冒険になるか、長期的なキャンペーンになるかに大きく依存します。また、プレイ中に死亡したキャラクターを交代させる場合や、既存のキャンペーンに参加する場合に、プレイヤーがより経験を積んだキャラクターを作成することも一般的です。

経験を年齢層に分類した表が提供されています。キャラクターの経験は、年齢と技能習熟度に直接相関します。より経験を積んだキャラクターは、当然ながら若い仲間に比べて人生経験が豊富です。ただし、記載されている年齢ボーナスは概算として扱う必要があります。キャンペーンは異なる速度で進行するためです。冒険と冒険の間にゲーム内の時間がたくさん経過するキャンペーンもあれば、中断のない冒険の連続であるキャンペーンもあります。既存のキャラクターを変換する場合は、表に記載されている年齢を実際の年齢に置き換えるだけです。

#### 経験表

| カテゴリ | 年齢 | ボーナス技能ポイント | 最大技能上昇値 |
| :-- | :-: | :-: | :-: |
| 若年 | 10+1d6 | 100 | +10 |
| 成人 | 15+2d6 | 150 | +15 |
| 中年 | 25+3d6 | 200 | +20 |
| シニア | 40+4d6 | 250 | +25 |
| 老年 | 60+5d6 | 300 | +30 |

#### 経験表の注釈

- ボーナス技能ポイントは、キャラクターが技能の習熟に費やさなければならないポイント数を決定します。
- 最大技能上昇値は、ボーナスポイントのうち、どの単一技能に適用できる上限を制限します。

### 技能ピラミッド

『Mythras Imperative』の技能ポイント割り当てプロセスは、文化（100）、キャリア（100）、ボーナス技能ポイント（150）の3つのソースから合計350ポイントを導き出します。これらのポイントを割り当てるのは時間がかかる場合があり、キャラクターの文化を決定することがそれほど重要ではない場合や、プレイヤーがコア・ルールのテンプレートでは対応しきれない特定の職業を想定している場合も間違いなくあります。ここでは、時間が差し迫っている場合や、プレイヤーが急いでいる場合に備えて、技能ポイントを割り当てるための代替システムを提示します。

文化、キャリア、ボーナス技能ポイントのプールからポイントを割り当てる代わりに、技能ピラミッドを使用します。これは350ポイントを以下のように固定ポイントの5つのブロックに分割します。

50%の技能を1つ、40%の技能を2つ、30%の技能を3つ、20%の技能を4つ、10%の技能を5つ。

これは便利なピラミッドを形成します。割り当てられた各値を単純に消し込んでいくだけです。

```
    50

   40 40

  30 30 30

 20 20 20 20

10 10 10 10 10
```

#### いくつかの簡単なルール

- ピラミッドからのすべてのポイントを割り当てなければなりません。
- どの技能も、ピラミッドから複数の割り当てを受けることはできません。
- 習慣と母国語は、コア・ルールに従いそれぞれ+40を得ます。これはピラミッドからの割り当てに追加されます。
- 情熱は[情熱](0002_Characters.md?id=step-8-passions)セクションに記載されている値を得ます。これもピラミッドからの割り当てに追加されます。
- 割り当ての結果として、どの技能も80%を超えてはなりません。したがって、キャラクターの筋力が16、敏捷性が17で基本値が33%の場合、プレイヤーは50ポイントの値を戦闘スタイルに割り当てることはできません。
- 6つの値は専門技能に割り当てなければなりません。
- キャラクターは引き続き文化と職業を選択し、適切な説明に記載されている技能を割り当てのガイドとして使用できます。あるいは、完全に自由に割り当てることも可能です。
- 値の少なくとも1つは戦闘スタイルに割り当てることが推奨されますが、これは必須ではありません。
- 最終的な決定権は常にゲームマスターが持ちます。

### 超常的な英雄

『Mythras Imperative』は主に普通の人間を扱いますが、特に特殊な英雄的行為を求める場合や、英雄や悪役が超常的である傾向があるパルプ・アクション設定で行われる場合など、時には別のものが必要になることがあります。

そのような英雄は必ずしも超能力を持っているわけではありませんが（もし望むのであれば、魔術と超能力の章を使用できます）、少し強く、少し速く、少し打たれ強く、そして通常ははるかに意志が強いです。キンメリアのあの野蛮人、殺しのライセンスを持つ諜報員、青銅の男、億万長者のプレイボーイでもあるマントを纏った自警団員など、数多くの人気のある英雄的キャラクターを思い浮かべてください。彼らはしばしば、普通の人間なら崩れ落ちるような状況に直面します。しかし英雄として、彼らはプロットが投げかけるあらゆる事態に耐え、次の冒険へと（比較的）無傷で挑むことができるのです。

このようなキャラクタータイプをゲームに導入するつもりなら、すべてのプレイヤーが同じレベルのキャラクターを持つようにしてください。これらのキャラクタータイプは、風景を食い物にし、アクションを推進するように設計されています。平凡なキャラクターは（魔術やその他の利点がない限り）、影に隠れてしまう可能性があります。

### パルプ・ヒーロー・キャラクター

これらは伝統的なパルプ・ヒーローです。彼らはスーパーヒーローや半神ではなく、至近距離からの散弾銃の一撃で命を落とすこともありますが、彼らはよりタフで、賢く、有能で、一般的に普通の人々より一歩か二歩抜きん出ています。また、彼らの人生は冒険で満たされている傾向があります。英雄的キャラクターは落ち着いて平穏な生活を送ることを選択できますが、しばしば厄介事や助けを必要とする誰かがキャラクターの扉を叩くことになります。

#### 能力値

パルプ・ヒーロー的なキャラクターを作成するときは、[キャラクター](0002_Characters.md?id=calculating-characteristics)セクションの「ダイスロール割り当て」メソッドを使用してください。4d6を振って最も低い目を捨て、これを5回行い、結果を筋力、体力、敏捷性、霊力、魅力に割り当てます。次に、3d6+6を振って最も低い目を2回捨て、これらの数値を体格と知力に割り当てます。ポイント構築メソッドを使用する場合、プレイヤーは90ポイントのプリセット・プールからキャラクターを構築します。

#### 特性値

これらは通常通り計算されますが、パルプ・ヒーロー的キャラクターは以下から選ばれた2つの「利点」を得る点が異なります（利点は重ねがけできないことに注意してください）：

- 行動ポイント +1
- 幸運ポイント +1
- 各部位判定のヒットポイント +1
- 持久力判定が1等級簡単になる
- 隠密判定が1等級簡単になる
- 意志力判定が1等級簡単になる

すべてのパルプ・ヒーロー的キャラクターは、軽傷または重傷を負った際に治癒率が2倍になりますが、致命傷はキャラクターの標準的な治癒率で処理されます。

#### 技能

パルプ・ヒーロー的キャラクターは、必要に応じて割り当てることができる50のボーナス技能ポイントを追加で獲得します。

### パラゴン・キャラクター

パラゴン・キャラクターは卓越性の権化です。鞭を使うあの考古学者や殺しのライセンスを持つスーパー・スパイはパルプ・ヒーロー的キャラクターですが、あのキンメリア人、青銅の男、暗黒騎士の探偵、そしてシャーロック・ホームズはパラゴン・キャラクターです。パラゴン・キャラクターは単にある専門分野で極めて有能というだけでなく、通常は複数の分野で秀でています。二刀流で射撃の名手でもある戦争の英雄であり、かつ天才的な発明家で物理学者でもある人物は、パラゴン・キャラクターの優れた例です。世界中の最高の探偵の頭脳で学んだ億万長者のプレイボーイで犯罪と戦う者もまた同様です。パラゴン・キャラクターは複数の大学の学位、独立した資産、謎の恩人、そして数多くの他の形の経験を持っているかもしれません。

その結果、パラゴン・キャラクターは誰にでも合うわけではありませんが、太陽系全体の運命を変えることができるキャラクターや、どんな挑戦にも立ち向かえるキャラクターが必要な設定であれば、パラゴン・レベルのキャンペーンが最適です。凡人や英雄的なキャンペーンでも、国家や惑星の運命のような非常に高い賭けが関わることがありますが、パラゴン・キャンペーンではそれが日常的に行われるべきです。

#### 能力値

[キャラクター](0002_Characters.md?id=calculating-characteristics)セクションの「ダイスロール割り当て」メソッドを使用してキャラクターを作成する際、4d6を振って最も低い目を捨てる作業を6回行い、選択した5つの結果（通常は最も高い5つ）を筋力、体力、敏捷性、霊力、魅力に割り当てます。次に、3d6+6を振って最も低い目を3回捨て、選択した2つの結果（通常は最も高い2つ）を体格と知力に割り当てます。ポイント構築メソッドを使用する場合、プレイヤーは100ポイントのプリセット・プールからキャラクターを構築します。

#### 特性値

これらは通常通り計算されますが、パラゴン・キャラクターは以下から選ばれた3つの「利点」を得る点が異なります（利点は重ねがけできないことに注意してください）：

- 行動ポイント +1
- 幸運ポイント +2
- 各部位判定のヒットポイント +2
- 持久力判定が1等級簡単になる
- 隠密判定が1等級簡単になる
- 意志力判定が1等級簡単になる

すべてのパラゴン・キャラクターは、軽傷または重傷を負った際に治癒率が2倍になりますが、致命傷はキャラクターの標準的な治癒率で処理されます。

#### 技能

パラゴン・ヒーロー的キャラクターは、必要に応じて割り当てることができる100のボーナス技能ポイントを追加で獲得します。

## ステップ8: 情熱

情熱は、プレイヤーやゲームマスターがキャラクターの性質を深め、キャラクターの欲求や偏見に基づいたプロットフックを導入し、プレイヤーが自分のキャラクターが何者であり、何が彼を駆り立てているのかを理解するのを助けるために使用されます。

情熱は何に対してでも抱くことができます。人、組織、理想、あるいは物体でさえ対象となり得ます。情熱は通常、Desire（切望）、Despise（軽蔑）、Destroy（破壊）、Espouse（支持）、Fear（恐怖）、Flee（逃避）、Forswear（誓絶）、Hate（憎悪）、Love（愛）、Loyalty to（忠誠）、Protect（保護）、Repudiate（拒絶）、Respect（尊敬）、Seek（探求）、Subvert（打倒）、Torment（苦悩）、Uphold（守護）といった動詞によって説明されます。

情熱は技能と同じ方法で測定され、1から100（あるいはそれ以上）の間で評価されます。情熱は技能と同様の方法で向上させることができ、状況に応じて審判によって増加または減少させることもできます。

初心者のキャラクターは最大3つの情熱を持つことができます。それぞれが2つの特性値に基づいており、最も重要なものから順に+40、+30、+20のボーナスを得ます（順序はプレイヤーが決定します）。これらは文化、職業、あるいは個人的な癖と結びつけることができます。例えば、ソード＆ソーサリーのキャンペーンでは、キャラクターは「憎悪（スティジア人）」、「不信（ソーサラー）」、「切望（アルコール）」を持つかもしれません。一方、ディストピアSFゲームでは、「忠誠（大統領）」、「破壊（エイリアン）」、「守護（法）」を代わりに選択するかもしれません。#### 情熱表

| 情熱の対象 | 開始パーセンテージ |
| :-- | :-- |
| 恋愛や家族関係にある人物 | 霊力+魅力 |
| 組織や人々の集団 | 霊力+知力 |
| 種族 | キャラクターの霊力×2 |
| 場所 | キャラクターの霊力+知力 |
| 物や物質 | キャラクターの霊力×2 |
| 個人の性格的特徴 | キャラクターの霊力+魅力 |

### 情熱の使用

情熱とは、プレイ中の出来事に影響を及ぼす能力を持つ、深く抱かれた信念のことである。情熱はそれ単体で能力値として使用できるが（「技能」と呼ぶのは不適切である）、以下で詳しく説明するように、その仕組みや、『Mythras Imperative』のキャラクターおよびキャンペーンに与える影響についてさらに詳しく解説する。

要約すると、情熱は以下のように使用できる。

- 他の技能を増強するために使用する。これは、感情の深さと、それがどのように行動を駆り立てるかを反映する。この目的で使用する場合、その増強がテーマ的および劇的に重要であれば、情熱はその値の20%を技能に加算する。
- 選択、欲望、感情的な行動や反応を促進する能力として使用する。このように使用する場合、キャラクターがその物事についてどの程度強く考え、感じているかを決定するために、情熱に対して標準の判定を行う。成功した場合、キャラクターはその情熱が指示する通りに行動する。失敗した場合、キャラクターは情熱の衝動に縛られることなく自由に行動できる。
- 他の情熱に対抗するために使用する（同じキャラクターが持つ情熱同士であってもよい）。これは通常、2つの情熱が対立する場合に使用される。例えば、個人的な愛が、誓いや忠誠心に反する行動を指示する場合などである。ここでは2つの情熱の間で対抗ロールを行い、より成功度の高かった方がキャラクターの行動を決定する。
- 信念、大義への忠誠心、献身の深さを測る一般的な尺度として使用する。情熱の値が高いほど、キャラクターはその大義に深く献身していることになる。同様の情熱を持つキャラクター同士は、その値を比較してどちらがより深い献身を示しているかを判断できる。
- 心理的な操作や魔法的な支配の一種に抵抗するために使用する。キャラクターが情熱に反する行為を強制される特定のケースでは、対抗ロールにおいて意志力の代わりに情熱を使用できる。

新しい情熱は、状況が許せばゲームセッション中のいつでも習得できる。誰かが憎悪を強くかき立てるようなことをした場合、即座に「憎悪：X」を習得するかもしれない。領主や首長が誓いを求めた場合、その誓いが立てられた瞬間に「忠誠：X」という情熱が確立される。

このようにプレイ中に新たに習得した情熱は、経験修正を消費せず、その場ですぐに確立される。もちろん、キャラクターが成長の過程で情熱を確立することを選択することもでき、その場合は経験修正を1回消費して、情熱を基本値で獲得する。

### 深まりと衰退

情熱は、それを増加させるきっかけとなった出来事の強さに応じて、経験修正とは無関係にゲーム中に増加することがある。また、情熱が衰退することもある。強く抱かれた信念は多くの出来事によって揺さぶられる可能性があり、その結果、情熱が低下したり、極端な場合には完全に逆転したりすることさえある。

例えば、「首長への信頼」を持つキャラクターが、もしその首長が裏切り行為を働いた場合、情熱を低下させるか、あるいは同じパーセンテージの「首長への不信」に変化する可能性がある。ゲームマスターは、情熱が低下するのか、それとも逆転するのかを判断する必要がある。低下する場合、その変化の源の強さに応じて減少する。

深まりと衰退表は、情熱がどれだけ変化するかを示している。

#### 深まりと衰退表

| 変化の深度 | 情熱の修正値 |
| --- | --- |
| 弱い | 1d10 |
| 中程度 | 1d10+5 |
| 強い | 1d10+10 |

## ステップ9：装備

キャラクター作成がほぼ完了したので、装備を整える必要がある。これには武器、防具、または特定の職業で使用されるその他の重要な用具が含まれる。冒険の間、さらなる装備を入手する機会は多くあるが、各開始キャラクターは手元に以下のものを所持している：

- キャラクターの職業と設定に適した一揃いの衣服。
- 困難なくしばらくの間生活できる程度の小銭。
- 個人の家宝、形見、あるいは相対的に価値の低い何らかの小物。
- 適切であれば、キャラクターの職業に適した取引道具や持ち運び可能な装備。
- キャラクターの戦闘スタイルに応じた個人武器。
- その他、設定に応じて適当であり、かつゲームマスターの承認を受けたアイテム。
