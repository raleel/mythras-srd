# キャラクター

『_Mythras Imperative_』のすべてのプレイヤーは、ひとりのキャラクターを操作します。キャラクターとはプレイヤーの分身であり、通常は肉体的にも精神的にもプレイヤー自身とは大きく異なります。キャラクターの種族はゲームの舞台設定によって多様です。歴史的な舞台であれば人間のみですが、ファンタジーの舞台であればドワーフやエルフ、あるいはリザードマンなどが登場することもあります。基本的なキャラクターは、その能力を記述する一連の要素によって定義されます。これらの要素は以下の通りです。

- **能力値（Characteristics）：** 筋力や魅力など
- **属性値（Attributes）：** 身長や移動力など
- **技能（Skills）：** 基本的な能力に対する熟練度

これらの要素のほとんどは数値で表され、一部は他の値に依存していたり、他の値から算出されたりします。各要素の意味と決定方法は、以下のセクションで説明します。

---
## ステップ1：キャラクター・コンセプト

まず最初に、どのようなキャラクターをプレイしたいかというアイデアを持つことから始めると良いでしょう。狡猾な戦士や悪賢い密輸業者かもしれませんし、あるいは勉強熱心な学者や賢明な魔術師が良いかもしれません。キャラクター・コンセプトはこの段階では詳細である必要はありません。「文化」や「職業」といった特定の選択を導くための指針となるアイデアがあれば十分です。

---
## ステップ2：能力値

すべてのキャラクターは、そのキャラクターの特徴を示す7つの能力値によって定義されます。どれほど力強く速いか、どれほど賢く健康かといった指標です。『_Mythras Imperative_』のすべてのキャラクターの中核を成すのがこの能力値であり、属性値や技能といった他の要素のほとんどの基礎となります。7つの能力値は以下の通りです。

- 筋力（STR）
- 体力（CON）
- 体格（SIZ）
- 敏捷性（DEX）
- 知性（INT）
- 精神力（POW）
- 魅力（CHA）

能力値を算出する前に、それぞれの能力値が何を表しているかを以下のセクションで説明します。

#### 筋力（STR）

STRは肉体的な力を表します。どれだけの重さを持ち上げられるか、どれだけ強く叩けるかなどです。STRはダメージ修正の構成要素です。STRが0になったキャラクターは、移動したり物を持ち上げたりする能力を失います。

#### 体力（CON）

CONは健康と頑健さの尺度です。CONは耐久度（ヒットポイント）と回復率を決定する要素となります。何らかの理由でCONが0まで低下すると、キャラクターは死亡します。

#### 体格（SIZ）

SIZは質量を測定するもので、身長や体重を示す助けとなります。SIZはヒットポイントを算出するのに使われます。より大きく重い生物は、ダメージに対する耐性が高い傾向にあるためです。また、質量は打撃力を高める助けとなるため、キャラクターのダメージ修正を決定するためにも使われます。

#### 敏捷性（DEX）

敏捷性、バランス感覚、反射神経はDEXで測定されます。これは行動ポイントとイニシアチブの重要な側面です。DEXが0まで低下したキャラクターは、機能的な麻痺状態に陥ります。

#### 知性（INT）

INTは認知能力の測定値です。INTが低いからといって必ずしも愚かであるとは限りませんが、機転を利かせて創造的に行動する際には制約を受ける可能性が高くなります。INTは行動ポイントとイニシアチブを計算する際の要素です。INTが0になると、キャラクターは完全に思考力を失います。

#### 精神力（POW）

POWはキャラクターの魂、精神、内なる衝動、あるいは魔法的な容量の測定値です。POWはキャラクターの魔力ポイントと幸運ポイントを支配します。POWが0まで低下すると、キャラクターはすべての自主的な意志を失います。

#### 魅力（CHA）

魅力は存在感と人柄の尺度であり、外見の良し悪しとは無関係です。CHAはキャラクターの経験修正に影響します。CHAが0まで低下すると、キャラクターは他人と社会的に交流することができなくなり、ひどく内気になったり反社会的な状態になったりして、周囲から無視されるか追い払われることになります。

---
### 能力値の算出

各能力値には、その強さを決定するための数値があります。各ダイスロールの後の括弧内の数値は種族平均であり、自分のキャラクターの結果を同種の他のメンバーと比較する際の目安となります。能力値を決定するための提案は以下の通りです。

- **ダイスロール：** STR、CON、SIZ、DEX、INT、POW、CHAをダイスで振り、出た目をそのまま採用します。これらの結果はランダム性が高いため、ダイスを振った後にキャラクター・コンセプトを決めるのが良いでしょう。そうしないと、最終的な能力値が想定していた役割に合わなくなる可能性があります。STR、CON、DEX、POW、CHAには3d6を、SIZとINTには2d6+6を振ってください。
- **ダイスロール＆割り当て：** 上記と同様ですが、同じダイスの範囲を持つ能力値同士で値を入れ替えることができます。例えば、人間を作成する場合、STR、CON、DEX、POW、CHAはすべて3d6の範囲なので、その中であれば値を入れ替え可能です。SIZとINTも2d6+6の範囲なので入れ替え可能です。ただし、異なるダイスグループ間での入れ替えはできません。
- **ダイスロール・ハイ：** 各能力値に対して指定されたダイスにさらに1個を追加して振り、最も低い結果をそれぞれ除外します。
- **ポイント購入：** 80ポイントのあらかじめ決められたプールから能力値を割り当てます。能力値は、ダイスで振った場合の最小値より低くならず、最大値より高くすることもできません。

---
## ステップ3：属性値

各キャラクターは一連の属性値も持っています。これらは能力値から派生したもの、あるいは能力値によって決定されるもので、ゲームプレイの特定の要素を管理するために使用されます。

#### 行動ポイント

戦闘ラウンド中にキャラクターがどれだけ頻繁に行動できるかは、行動ポイントによって決定されます。すべての『_Mythras Imperative_』のキャラクターは2の行動ポイントを持ちます。

#### ダメージ修正

より大きく筋力のあるキャラクターや生物は、特定の状況で追加のダメージを得ることがあります。逆に、より弱く小さなキャラクターは与えるダメージが減少することがあります。ダメージ修正は通常、戦闘状況で使用されますが、物を破壊しようとする際にも使用できます。ダメージ修正は追加のダイスロールであり、武器やツールが与えるダメージに加算されるか、または減算されます。マイナスのダメージ修正によって武器のダメージが0以下になった場合、ダメージはまったく与えられません。

STRとSIZを合計し、以下のダメージ修正表を参照してください。

#### 経験修正

プレイを通じて、キャラクターはその技能と能力を向上させます。これは経験ロールを使用して達成されます。詳細は[ゲームシステム](0004_Game_System.md?id=experience-rolls)セクションで説明されています。

キャラクターのCHAスコアは、そのキャラクターが受ける経験ロールの回数を調整することがあります。これは、仲間との関係性やコミュニティ内での評判を反映したものです。CHAが高ければ、人々はキャラクターが学んでいる間に喜んで訓練に協力したり、支援したりするでしょう。逆にCHAが特に低いと、他人の助けなしに能力を向上させることは困難になるかもしれません（例えば、対戦相手を見つけるなど）。

|:-:| :-:|
| 6以下 | -1 |
| 7-12 | +0 |
| 13-18 | +1 |

#### 回復率

負傷した後、キャラクターは療養する必要があります。回復率は、傷から自然に回復する速度を決定します。怪我の重症度に応じて、回復率は1日、1週間、あるいは1ヶ月あたりに何ヒットポイントが回復するかを示します。

##### 回復率表

| CON | 回復率 |
| :-:| :-:|
| 6以下 | 1 |
| 7-12 | 2 |
| 13-18 | 3 |
| 6ポイントごと | +1 |

#### ヒットポイント

ヒットポイントは、身体の各部位が使い物にならなくなるまで、あるいは最終的に行動不能や死亡に至るまで、どれだけの損傷に耐えられるかを表します。すべての生物の身体は部位に分かれています（例えば人間は7つ：頭部、胸部、腹部、腕2本、脚2本）。各部位は独自のヒットポイントを持ちます。

モンスターや異なる種類の動物のような一部の生物は、その性質上、身体構造が根本的に異なることがよくありますが、どの部位であってもヒットポイントを持ちます。ダメージによって部位のヒットポイントがあるレベルまで減少すると、キャラクターはその怪我の深刻さを反映した特定の結末を被ることになります。負傷の詳細については、[ダメージと負傷レベル](0004_Game_System.md?id=damage-and-wound-levels)セクションを参照してください。

#### イニシアチブ

戦闘で誰がいつ反応するかはイニシアチブによって決まります。イニシアチブはイニシアチブ・ロールに対する修正値として機能します。イニシアチブが高いほど、戦闘状況において素早く反応でき、行動順が早くなります。鎧などのさらなる要素がこれを修正します。[戦闘](0005_Combat.md?id=combat-style)の章では、イニシアチブがどのように使用されるかについて詳しく説明しています。

イニシアチブは、DEXとINTの平均値です。

#### 幸運ポイント

幸運ポイントは、冒険する英雄と日常の人々を区別する不思議な力を表します。運命、カルマ、あるいは単なる幸運と呼んでもいいでしょう。幸運ポイントは以下のために使用できます：

- 不利なダイスロールを振り直す。
- 物理的なダメージやその他の不運な状況を軽減する。
- 戦闘の重要な瞬間に優位を得る。

正確にいつどのように使用されるかは、[ゲームシステム](0004_Game_System.md?id=game-system)セクションで説明されています。幸運ポイントを消費するとプールが減少し、ポイントがなくなると（ゲームマスターが即興で与えない限り）、次のゲームセッションで通常の量に回復するまでそれ以上は使用できません。

##### 幸運ポイント表

| POW | 幸運ポイント |
| :-- | :-: |
| 6以下 | 1 |
| 7-12 | 2 |
| 13-18 | 3 |
| 6ポイントごと | +1 |

#### 魔力ポイント

『_Mythras Imperative_』で使用される神秘的な能力、パワー、呪文は、通常魔力ポイントに依存します。キャンペーン設定によって魔法の使用が制限されていたり、特定の魔法職に限定されていたりする場合があるため、一部のキャラクターにとってこの属性は不要かもしれません。

そうしたパワーを使用できる場合、キャラクターの魔力ポイントはPOWに等しくなります。これらのポイントは呪文を唱えるために使用され、そのコストは使用される魔法のタイプによって異なります。術者の魔力ポイントが尽きると、魔力ポイントが回復するまで呪文を唱える能力を失います。

#### 移動速度

すべての生物は移動速度を持っています。これは、特定の期間内に移動できるメートル数です。移動速度は能力値から計算されるものではなく、種族ごとに異なるデフォルト値です。人間の基本移動速度は6メートルです。

歩行よりも速い歩容（Gait）には、移動速度に乗数を適用します：
- **走行（Run）：** 移動 x3  
- **全速力（Sprint）：** 移動 x5

## ステップ4：技能

技能には2つのクラスがあります。誰もが「標準技能」を持っています（こっそり歩く、他人を説得するなど）。一方、「専門技能」は試みる前に特定の訓練を必要とするものです（野生動物の追跡、宇宙船の操縦、古代言語の理解など）。キャラクターには技能を取得するために割り振るポイントが3つのプールで与えられます。最初のプールは育った「文化」のため、2番目は子供時代以降に就いた「職業」のため、最後は技能セットをより充実させるためのものです。デフォルトでは、新規キャラクターは文化技能プールに100ポイント、職業技能プールに100ポイント、そして充実のためのボーナスポイントを150ポイント割り振ります。各文化と職業には、技能ポイントを割り当てることができる標準技能と専門技能の定義された範囲があります。

##### 戦闘スタイル

戦闘スタイルは、続く文化の説明に記載されています。戦闘スタイルの詳細については[戦闘](0005_Combat.md?id=combat-style)セクションで説明されており、基本パーセンテージはSTR+DEXです。

## ステップ5：文化

文化はキャラクターが育った社会の種類を決定し、それによって彼らが持つ特定の価値観や哲学を規定します。より実用的な側面として、文化はキャラクターの全体的な能力を形作るさまざまな技能の値を増強するのに役立ちます。基本的な人間文化には、「野蛮（Barbarian）」「文明（Civilized）」「遊牧（Nomadic）」「原始（Primitive）」の4つがあります。各文化的背景には適切な標準技能の範囲が記載されており、プレイヤーは提示された専門技能から最大3つを選択できます。これにより、同じ文化的背景を持つプレイヤーでも、発達させた分野において冒険者が異なることを保証できます。文化のリストにある標準技能および選択した専門技能に100の文化技能ポイントを分配し、技能を向上させるために費やした1ポイントごとに1%上昇させます。ゲームマスターは、特定の技能に適用できる技能ポイントの数に上限を設けることを望むかもしれません。

### 野蛮人（Barbarian）

部族的な性質を持つ野蛮人は文明を避ける傾向があり、大きな町や都市に住む人々を弱く不道徳だとみなします。彼ら自身の集落も定住型ではありますが、はるかに小さく自然に近いものです。野蛮人の部族は明確な領土を占有しており、狩猟や放牧、農業のために自分たちのものとみなしている手付かずの荒野であることが多いです。野生生物と対峙したり、敵対する部族から自分たちの土地を守るために結集したりと、人生を通じて多くの危険を乗り越える必要があるため、彼らのほとんどは武器の使用に長けています。小さなコミュニティで生活しているため、血縁と氏族の絆が社会の強い要素となっています。

#### 技能

- **標準技能：** 運動、筋力、耐久、応急処置、地元知識、知覚；および「ボート漕ぎ」か「乗馬」のいずれか。加えて、プレイヤーは文化的な「戦闘スタイル」を選択してもよい。
- **専門技能：** 製作（任意）、治療、伝承（任意）、音楽、航海術、船乗り、生存術、追跡。

### 文明人（Civilized）

文明文化は、複雑な社会規範に支えられ、官僚機構によって裏打ちされた法と秩序の体裁によって象徴されます。文明人は、自分たちが他のどの文化よりも優れていると信じています。彼らの業績が永続的なものへと向かうからです。広大な都市、威圧的な寺院、記念碑、そして本や墓石、巻物に記録される歴史や出来事などです。もちろん、これは薄い見せかけにすぎません。最も文明的な都市でさえ、野蛮人の辺境の集落よりも無法である可能性があり、社会規範は遊牧民の歓待の儀式よりも粗野であるかもしれません。しかし、文明文化は自らの業績、インフラ、専門的な職人、そしてどこへでも容易に手を伸ばせる能力を誇りに思っています。

#### 技能

- **標準技能：** 隠密、詐術、運転、説得、洞察、地元知識、意志力。加えて、プレイヤーは文化的な「戦闘スタイル」を選択してもよい。
- **専門技能：** 芸術（任意）、商業、製作（任意）、礼儀作法、言語（任意）、伝承（任意）、音楽、世間話。

### 遊牧民（Nomadic）

遊牧民は絶えず移動しており、自分たちの家や暖炉と呼べる場所がありません。あてもなく彷徨うこともあれば、年間を通じて移動するキャンプをいくつか持っていることもあります。彼らは作物をほとんど育てず、動物や魚の移動に従い、あるいは自分たちが飼い慣らした獣を放牧することさえあります。遊牧民は周囲から素早く簡単に手に入れられるもので自給自足することに長けており、何も無駄にしません。遊牧文化の技能は、その環境に合わせて調整されるべきです。徒歩で広大な距離を移動する者もいれば、キャラバンに住んだり奇妙な生き物に乗ったりする者、巨大な浮き筏で海を漂流する者もいます。

#### 技能

- **標準技能：** 耐久、応急処置、地元知識、知覚、忍び寄り；および以下から2つ：運動、ボート漕ぎ、水泳、運転、乗馬（主な移動手段による）。加えて、プレイヤーは文化的な「戦闘スタイル」を選択してもよい。
- **専門技能：** 製作（任意）、文化（任意）、言語（任意）、伝承（任意）、音楽、航海術、生存術、追跡。

### 原始人（Primitive）

すべての民族の中で、原始人は土地と最も密接に生き、その隠された秘密と調和している人々です。拡大家族単位で生活する原始文化は、洞窟や自然のシェルターから、リーン・トゥ（雨よけ）や非常に基本的な小屋に至るまでの、非常に単純な住居に集まって暮らします。原始人は通常狩猟採集民であり、農業や畜産のためのシステムはほとんど、あるいは未発達です。

しかし、しばしば迷信に基づいた特定の文化的信念は、非常に明確に定義されていることがあります。原始文化のほとんどは文字言語に近いものを発展させていませんが、絵画やその他の絵画的シンボルがコミュニケーションの手段として役立っています。

#### 技能

- **標準技能：** 筋力、耐久、回避、地元知識、知覚、忍び寄り；および「運動」「ボート漕ぎ」「水泳」から1つ。加えて、プレイヤーは文化的な「戦闘スタイル」を選択してもよい。
- **専門技能：** 製作（任意）、治療、伝承（任意）、音楽、航海術、生存術、追跡。

## ステップ6：職業

すべてのキャラクターは、特定の職業の訓練を受けた状態でゲームを開始します。選択した職業が、冒険を始めた後のキャラクターが継続して従事する職業である必要はありませんが、成人への移行の一部として着手した職業であり、技能の向上をさらに定義します。各職業には適切な標準技能の範囲が記載されており、プレイヤーはリストされた専門技能から最大3つを選択できます。100の職業技能ポイントを職業の標準技能リストおよび選択した専門技能に分配し、技能を向上させるために費やした1ポイントごとに1%上昇させます。文化と同様に、ゲームマスターは特定の技能に適用できる技能ポイントの数に上限を設けることができます。

## ステップ7：ボーナス技能ポイント

最終段階として、キャラクターを完成させるために最後の150技能ポイントを割り当てます。これらは標準技能、または文化や職業の一部として獲得した専門技能に適用できます。ここでも、ゲームマスターは特定の技能に適用できる技能ポイントの数に上限を設けることができます。

### 経験豊富なキャラクターの作成

初心者のキャラクターは、実戦経験がほとんど、あるいは全くない状態で新鮮にスタートすることを推奨します。もちろん、キャラクターのレベルは設定や、ゲームが短編の冒険か長期のキャンペーンかによって大きく異なります。プレイ中にキャラクターが死亡した場合や、既存のキャンペーンに参加する場合に、より経験豊富なキャラクターを作成することも一般的です。

経験を年齢層（Age Categories）に分けた表を提供します。キャラクターの経験は年齢および技能能力と直接的な相関関係があります。経験豊富なキャラクターは当然ながら、若い仲間よりも人生経験が豊富です。ただし、記載されている年齢ボーナスは目安として扱うべきです。キャンペーンはそれぞれ異なるペースで進行するためです（冒険の間に多くのゲーム時間が経過するキャンペーンもあれば、中断のない一連の冒険が続くキャンペーンもあります）。既存のキャラクターを変換する場合は、表に記載されている実際の年齢に置き換えるだけです。

#### 経験表

| カテゴリ | 年齢 | ボーナス技能ポイント | 最大技能上昇値 |
| :-- | :-: | :-: | :-: |
| 若年 | 10+1d6 | 100 | +10 |
| 成年 | 15+2d6 | 150 | +15 |
| 中年 | 25+3d6 | 200 | +20 |
| 高年 | 40+4d6 | 250 | +25 |
| 老年 | 60+5d6 | 300 | +30 |

#### 経験表の注意点

- ボーナス技能ポイントは、キャラクターが技能開発に費やさなければならないポイント数を決定します。
- 最大技能上昇値は、ボーナスポイントのうち、どの1つの技能に適用できるかを制限します。

### 技能ピラミッド

『_Mythras Imperative_』の技能ポイント割り当てプロセスは、文化（100）、職業（100）、ボーナス技能ポイント（150）の3つのソースから350ポイントを導き出します。これらのポイントを割り当てるには時間がかかることがあり、文化の決定があまり重要ではない場合や、コア・ルールにはない特定の職業を想定しているプレイヤーがいることもあります。ここでは、時間が差し迫っている場合や、プレイヤーが熱心な場合に備えて、技能ポイントを割り当てるための代替システムを提示します。

文化、職業、ボーナス技能ポイントプールからポイントを割り当てる代わりに、「技能ピラミッド」を使用します。これは350ポイントを5つの固定ポイントのブロックに分割します：

50%が1つ、40%が2つ、30%が3つ、20%が4つ、10%が5つ。

これで便利なピラミッドが形成されます。割り当てられた各値を単純に消し込んでいきます。

```
    50

   40 40

  30 30 30

 20 20 20 20

10 10 10 10 10
```

#### いくつかの簡単なルール

- ピラミッドからのポイントはすべて割り当てなければなりません。
- どの技能もピラミッドからの割り当てを複数受けることはできません。
- 「慣習」と「母国語」は、コア・ルールに従って+40を得ますが、これはピラミッドからの割り当てに追加されます。
- [情熱（Passions）](0002_Characters.md?id=step-8-passions)セクションに記載された値を得る「情熱」も、ピラミッドからの割り当てに追加されます。
- いかなる技能も、割り当ての結果として80%を超えることはできません。したがって、キャラクターのSTRが16、DEXが17で、基本値が33%の場合、プレイヤーはその50ポイントの値を「戦闘スタイル」に割り当てることはできません。
- 6つの値は「専門技能」に割り当てなければなりません。
- キャラクターは引き続き「文化」と「職業」を選択し、適切な説明に記載されている技能を割り当てのガイドとして使用できます。また、割り当ては完全に自由に行うこともできます。
- 値のうち少なくとも1つを「戦闘スタイル」に割り当てることを推奨しますが、これは必須ではありません。
- ゲームマスターが常に最終決定権を持ちます。

### 超人的な英雄

『_Mythras Imperative_』は主に普通の人間を扱いますが、時折、特別な英雄的行為が求められる場合や、英雄や悪役が超人的な傾向を持つ「パルプ・アクション」設定で行われるキャンペーンでは、何か他のものが必要になります。

そのような英雄は必ずしも超能力を持っているわけではありませんが（もし望むのであれば、「魔法と能力」の章を使用できます）、少し強く、少し速く、少し回復力があり、通常ははるかに強い意志を持っています。キンメリア出身のあの蛮族、殺しのライセンスを持つエージェント、青銅の男、億万長者のプレイボーイでもある仮面の自警団員など、多くの人気ある英雄的キャラクターを考えてみてください。彼らは普通の人間なら崩れ落ちるような状況に頻繁に直面しますが、英雄として、プロットが投げかけるあらゆる事態に耐え、次の冒険に参加するために（比較的）無傷で生き残ることができます。

もし、これらのキャラクタータイプをゲームに導入するつもりなら、すべてのプレイヤーが同じレベルのキャラクターを持っていることを確認してください。これらのキャラクタータイプはアクションを牽引するために設計されています。凡人のキャラクターは（魔法やその他の利点がない限り）、日陰に追いやられる可能性があります。

### パルプ・ヒーロー・キャラクター

これらは伝統的なパルプ・ヒーローです。彼らはスーパーヒーローや半神ではなく、至近距離からのショットガンの一撃は依然として彼らの命を絶ちますが、彼らはよりタフで、より賢く、より有能であり、一般的に普通の人々より一歩か二歩抜きん出ています。また、彼らの人生は冒険で満ちている傾向があります。英雄的なキャラクターは平凡な生活を送ろうと決めることもできますが、多くの場合、トラブルや助けを必要とする誰かがキャラクターの扉を見つけることになります。

#### 能力値

パルプ・ヒーロー・キャラクターを生成する際は、[能力値の算出](0002_Characters.md?id=calculating-characteristics)セクションの「ダイスロール＆割り当て」方法を使用してください。4d6を振って最も低いダイスを破棄する作業を5回行い、その結果をSTR、CON、DEX、POW、CHAに割り当てます。次に、3d6+6を振って最も低いダイスを2回破棄する作業を2回行い、この数値をSIZとINTに割り当てます。「ポイント購入」方法を使用する場合は、90ポイントのプリセット・プールからキャラクターを構築します。

#### 属性値

これらは通常通り計算されますが、パルプ・ヒーロー・キャラクターは以下から選択された2つの利点（Advantages）を得ます（利点は重ねがけできないことに注意してください）：

- 行動ポイント +1
- 幸運ポイント +1
- 各部位のヒットポイント +1
- 耐久ロールが1段階容易になる
- 隠密ロールが1段階容易になる
- 意志力ロールが1段階容易になる

すべてのパルプ・ヒーロー・キャラクターは、軽傷または重傷を負った際の回復率が2倍になります。ただし、重症の場合はキャラクターの標準回復率で処理されます。

#### 技能

パルプ・ヒーロー・キャラクターは、必要に応じて割り当てるための追加の50ボーナス技能ポイントを得ます。

### パラゴン・キャラクター

パラゴン・キャラクターは卓越性の権化です。鞭を使う考古学者や殺しのライセンスを持つスーパーエージェントが「パルプ・ヒーロー」であるのに対し、あのキンメリア人、青銅の男、闇の騎士探偵、シャーロック・ホームズは「パラゴン」キャラクターです。パラゴン・キャラクターは単にある専門分野で非常に有能なだけではありません。通常、複数の分野で優れています。二刀流の凄腕戦士であると同時に天才的な発明家や物理学者である人物は、パラゴン・キャラクターの優れた例です。世界最高の探偵の精神を学んだ億万長者のプレイボーイの犯罪ファイターもそうです。パラゴン・キャラクターは、いくつかの大学の学位、独立した富、謎の支援者、その他多くの経験を持っている可能性があります。

結果として、パラゴン・キャラクターは万人のためのものではありませんが、太陽系の運命を変えることができる、あるいはどんな挑戦にも立ち向かえるキャラクターが必要な設定であれば、パラゴン・レベルのキャンペーンが適しています。「凡人」キャンペーンと「英雄」キャンペーンの両方で、国家や惑星の運命といった非常に高いリスクが関わることが時折ありますが、パラゴン・キャンペーンではそれが日常的に行われるべきです。

#### 能力値

[能力値の算出](0002_Characters.md?id=calculating-characteristics)セクションの「ダイスロール＆割り当て」方法を使用してキャラクターを生成します。4d6を振って最も低いダイスを破棄する作業を6回行い、その中から5つの結果（通常は最も高い5つ）を選択してSTR、CON、DEX、POW、CHAに割り当てます。次に、3d6+6を振って最も低いダイスを3回破棄し、その中から2つの結果（通常は最も高い2つ）を選択してSIZとINTに割り当てます。「ポイント購入」方法を使用する場合は、100ポイントのプリセット・プールからキャラクターを構築します。

#### 属性値

これらは通常通り計算されますが、パラゴン・キャラクターは以下から選択された3つの利点を得ます（利点は重ねがけできないことに注意してください）：

- 行動ポイント +1
- 幸運ポイント +2
- 各部位のヒットポイント +2
- 耐久ロールが1段階容易になる
- 隠密ロールが1段階容易になる
- 意志力ロールが1段階容易になる

すべてのパラゴン・キャラクターは、軽傷または重傷を負った際の回復率が2倍になります。ただし、重症の場合はキャラクターの標準回復率で処理されます。

#### 技能

パラゴン・キャラクターは、必要に応じて割り当てるための追加の100ボーナス技能ポイントを得ます。

## ステップ8：情熱

「情熱（Passions）」は、キャラクターの性質を深め、キャラクターの欲望や偏見に基づいたプロットフックを導入し、プレイヤーが自分のキャラクターが誰で、何が彼を駆り立てるのかなどを理解するのを助けるために使用されます。

情熱は、人、組織、理想、あるいは物体など、何に対してでも持つことができます。情熱は通常、「Desire（欲望）」「Despise（軽蔑）」「Destroy（破壊）」「Espouse（信奉）」「Fear（恐怖）」「Flee（逃走）」「Forswear（誓い破棄）」「Hate（憎悪）」「Love（愛）」「Loyalty to（忠誠）」「Protect（保護）」「Repudiate（拒絶）」「Respect（尊敬）」「Seek（探求）」「Subvert（転覆）」「Torment（苦悶）」「Uphold（支持）」といった動詞で記述されます。

情熱は技能と同じ方法で測定され、1から100（あるいはそれ以上）の評価を受けます。情熱は技能と同じ方法で向上させることもでき、状況に応じて審判によって増減させることもできます。

新規キャラクターは最大3つの情熱を持って開始でき、それぞれ2つの能力値に基づきます。1番目には+40、2番目には+30、3番目には+20のボーナスを得ます（順序はプレイヤーが決める）。これらは文化、職業、あるいは個人的な癖と結びつけることができます。例えば、剣と魔法のキャンペーンでは、キャラクターは「憎悪（スティギア人）」「不信（魔術師）」「欲望（アルコール）」を取るかもしれません。一方でディストピアSFゲームでは、「忠誠（大統領）」「破壊（エイリアン）」「支持（法）」を選ぶかもしれません。

#### 情熱表

| 情熱の対象 | 開始パーセンテージ |
| :-- | :-- |
| 恋愛または家族的な文脈での人物 | POW+CHA |
| 組織または人々のグループ | POW+INT |
| 人種または種族 | キャラクターのPOW x2 |
| 場所 | キャラクターのPOW+INT |
| 物体または物質 | キャラクターのPOW x2 |
| 性格特性 | キャラクターのPOW+CHA |

### 情熱の使用

情熱とは、プレイ中にイベントに影響を与える可能性を持つ、深く抱かれた献身のことです。これらを単独の「能力」として使用できますが（これらを単に技能と呼ぶのは不当な評価でしょう）、情熱については以下でさらに詳細に説明し、それらがどのように機能し、『_Mythras Imperative_』のキャラクターやキャンペーンにどう影響するかを解説します。

要約すると、情熱は以下のように使用できます：

- 他の技能を増強する（Augment）。感情の深さと、それがどのように行動を駆り立てるかを反映します。この目的で使用される場合、その増強がテーマ的かつ劇的に重要であれば、情熱はその技能値の20%を技能に加算します。
- 選択、欲望、感情的な行動や反応を駆り立てる「能力」として。この方法で使用される場合、キャラクターが何かについてどれほど強く考え、感じているかを決定するために、情熱に対して標準ロールを行います。ロールが成功すれば、キャラクターはその情熱が指示する通りに行動します。ロールが失敗すれば、キャラクターは情熱の衝動に縛られることなく自由に動けます。
- 他の情熱に対抗する。同じキャラクターが持つ情熱同士が対立する場合に使用されます。例えば、個人的な愛が誓いや忠誠に反する行動を指示するかもしれません。この場合、2つの情熱の間で対抗ロールを行い、より成功した方がキャラクターの行動を決定します。
- 大義に対する献身、信念、忠誠心の深さを一般的に測定する尺度として。情熱の値が高いほど、そのキャラクターは献身的です。同様の情熱を持つキャラクターは、誰がより深い献身を示すかを評価するために、その値を比較できます。
- 心理操作や魔法による支配を抵抗するため。キャラクターが情熱に反する行動を強制される場合、対抗ロールにおいて意志力の代わりに情熱を代用できることがあります。

新しい情熱は、状況が正当化されればゲームセッション中のいつでも発達させることができます。誰かが憎悪を強く誘発するような行動をした場合、即座に「憎悪（X）」が発達するかもしれません。王や指導者が誓いを求める場合、その誓いが立てられた瞬間に「忠誠（X）」という情熱が確立されます。

このようにプレイ中に発達した新しい情熱には経験ロールのコストはかからず、その場で確立されます。もちろん、プレイヤーは経験ロールを消費して、基本値で情熱を獲得することも選択できます。

### 深化と衰退

情熱は経験ロールとは独立して、それを誘発する出来事の強さに応じてゲーム中に増加することがあります。また、衰退することもあります。強く抱いていた信念は多くの事柄によって揺らぎ、その情熱が減少したり、極端な場合には完全に反転することもあります。

例えば、「首長への信頼」を持つキャラクターが、もしその首長が裏切り行為を働いた場合、情熱を減少させるか、あるいは同じパーセンテージで「首長への不信」に変化する可能性があります。ゲームマスターは情熱が減少するか反転するかを決定する必要があります。減少する場合、変化の源泉の強さに応じて減少します。

「深化と衰退表」は、情熱がどれだけ変化するかを示しています。

#### 深化と衰退表

| 変化の深さ | 情熱の修正 |
| --- | --- |
| 弱い | 1d10 |
| 中程度 | 1d10+5 |
| 強い | 1d10+10 |

## ステップ9：装備

キャラクターがほぼ完成したので、装備品が必要です。これには武器、防具、または特定の職業で使用されるその他の重要な用具が含まれます。冒険の過程でより多くの装備品を手に入れる機会はたくさんありますが、各キャラクターは開始時点で以下のものを所持しています：

- キャラクターの職業と設定に適した衣服。
- 小遣い（困難なくしばらく生活できる程度の額）。
- 個人的な家宝、形見、または相対的に価値の低い装身具。
- 適切であれば、職業に適した交易道具または運搬可能な装備。
- キャラクターの「戦闘スタイル」のための個人武器。
- その他、設定に適しており、ゲームマスターの承認を得たアイテム。
