# 技能

技能は標準技能と専門技能の2つのカテゴリーに分類されます。すべてのキャラクターは同一の標準技能セットを保持します。専門技能はキャラクター個人によって異なり、その経歴や、ある程度はその文化の中で培われた専門知識を反映します。これらの区別にもかかわらず、標準技能と専門技能は同じ仕組みで機能します。

---
## 技能の仕組み

技能には2つの能力値、あるいは1つの能力値を2倍して算出される基本値があります。技能値に上限はなく、100を超えることもあります。プレイ中、キャラクターの技能値がそれほどまでに高まることは珍しくありません。

キャラクターがある種のテスト、挑戦、または専門的な能力の解決を求められるたび、1d100をロールし、その値を技能値と比較します。

- 技能値以下であれば成功
- 技能値より大きければ失敗

成功と失敗に関して注意すべき特定の特殊ケースがあります。

- 01〜05のロールは常に成功
- 96〜00のロールは、技能値がどれほど高くても常に失敗

#### クリティカルとファンブル

クリティカルとファンブルは、華々しい成功と破滅的な失敗を表します。これらはキャラクターが試みに卓越した結果を出した、あるいは悲惨かつ完全に失敗したケースです。

- クリティカル成功は、技能値の10分の1（端数は切り上げ）です（これには修正を受けた技能も含まれるため、修正された技能はクリティカルの確率が高くなったり低くなったりすることがあります）。例えば、ある技能が通常の2倍（33%から66%へ）に修正された場合、クリティカルの範囲は07以下のロールとなります。
- ファンブルは99または00のロールです。技能値が100%を超えている場合、ファンブルは00のロールのみとなります。

クリティカルまたはファンブルの結果の正確な性質は、ゲームマスターが決定します。その結果は状況に応じて素晴らしくも、悲惨なものにもなり得ます。

#### 自動成功

ある状況下では、特定の技能に対するロールが必要ない場合があります。それは作業が容易に達成できる場合や、十分な時間と集中力があれば成功が保証されている場合です。草原を馬でゆっくりと駆け抜けるのは自動成功の一例であり、その活動に習熟しているだけで、単純な行動であれば解決のために技能ロールを必要としません。職人が木材を椅子の脚に彫るのも、技能ロールが不要な一例です。達成には時間がかかりますが、職人はそのやり方を知っており、急いでいなければ成功は確実です。静かな環境で鍵開け道具を持ったローグなら、十分な時間があれば宝箱の単純な錠を問題なく開けられます。

#### 技能の修正

技能ロールが必要であっても、既存の状況を反映するために成功率を調整しなければならない場合があります。例えば、逃げる盗賊を追うには運動ロールが必要かもしれません。しかし、もしキャラクターが暗闇の中や、歩きにくい下草の中を逃げている場合はどうでしょうか？そのような場合、ゲームマスターは状況を反映するためにキャラクターの技能に修正を加えるよう指示できます。

『Mythras Imperative』では、技能の修正方法を決定するために一連の等級を使用します。これらは以下の通りです。2種類の修正方法が提供されていることに注意してください。前者はデフォルトの方法であり、多少の計算を伴いますが、特に高い技能パーセンテージが関与する場合、スケーリングのためのより優れたシミュレーションを提供します。簡易技能修正は単純な加減算であり、導入が容易です。どちらの方式がゲームに最適かを選択し、同じ修正システムが一貫して適用されるようにしてください。

##### 難易度テーブル

| 難易度 | 技能修正 | 簡易技能修正 |
| :-- | :-- | :--: |
| 判定不要 | ロール不要 | ロール不要 |
| 非常に簡単 | 技能値を2倍 | +40% |
| 簡単 | 技能値に半分を加算 | +20% |
| 標準 | 調整なし | なし |
| 困難 | 技能値を3分の1減少 | -20% |
| 至難 | 技能値を半分に減少 | -40% |
| 超人的 | 技能値を5分の1に減少 | -80% |
| 絶望的 | 試行不可能 | 試行不可能 |

キャラクターが他の状況によって既にペナルティを受けている場合、最も厳しい難易度が優先されます。

戦闘以外では、『Mythras Imperative』は技能修正を伴う状況や課題の決定的なリストを提供していません。特定の技能や文脈に対してどのような修正が必要かは、最終的にゲームマスターがキャラクターの能力、状況の困難さについての自身の認識、そしてその瞬間における劇的な緊張感に基づいて決定します。

## 標準技能

#### 運動 (筋力+敏捷性)

運動は、登攀、跳躍、投擲、走行を含む幅広い身体活動をカバーします。これらの活動の技能ロールはすべて、運動技能に対する単一のロールで処理されます。登攀、跳躍、走行の詳細については、[移動](0005_Combat.md?id=situational-movement-rates)を参照してください。

#### 操船 (筋力+体力)

操船技能は、川、湖、海岸近くでの小型船舶の操作をカバーします。適切な船舶は一般的に、短距離を移動するボート、カヌー、筏であり、外海の荒波には適していません。ほとんどはオール、パドル、竿、あるいは単純な帆を使って推進するか、動物によって牽引されます。大規模な乗組員を必要とする船や、海外への長旅を目的とした船は、専門技能である船員技能でカバーされます。

#### 腕力 (筋力+体格)

腕力は、生の身体的力を発揮する際の効率的な技術の応用です。この技能は、持ち上げ、扉の破壊、力比べなど、物理的な力の行使を伴う行動をカバーします。

#### 戦闘スタイル (筋力+敏捷性)

各戦闘スタイルは、その設定における特定の経歴や文化で予期される武器を使用する技能です。ほとんどの戦闘伝統は、複数の武器の訓練と、それらを単独または組み合わせて効果的に使用するために必要な技術を網羅しています。さらに、密集歩兵として戦う、あるいは騎乗して戦うといった状況的な要素を前提とすることもよくあります。戦闘スタイルは非常に多様であり、例えば剣闘士の戦いから宇宙海兵隊の機動歩兵まで多岐にわたります。

#### 隠蔽 (敏捷性+霊力)

隠蔽は隠密の対極に位置する技能であり、キャラクター自身ではなく大型の物体を隠すことを指します。例えば、隠蔽は岩の陰に戦車を隠したり、その道筋を辿られないように車輪の轍を掃き清めたりするために使用されます。この技能は応用範囲が広く、図書館にある巻物を隠すことから、罠や秘密の通路の存在を偽装することまで何でも可能です。

#### 習慣 (知力 x2 +40)

習慣は、自身のコミュニティに対する知識、すなわち社会的な規範、儀式、タブーなどを表します。この技能は、社会的に重要な慣習を正確に解釈・遂行したり、特定の状況下で適切な振る舞いをしたりするために不可欠です。

#### 舞踊 (敏捷性+魅力)

ほぼすべての文化において、レクリエーションとして、あるいは重要な儀式の一部として何らかの形で舞踊が取り入れられています。宮廷舞踊、戦いの踊り、あるいは祈りや儀式の詠唱に伴う単純な動作の集まりかもしれません。舞踊技能は、求められた際にリズミカルかつ正確に（ある程度の水準で）動くキャラクターの能力を測定します。

#### 欺瞞 (知力+魅力)

欺瞞は、キャラクターが真実を覆い隠し、何らかの嘘をつこうとするあらゆる事例をカバーします。露骨な嘘、警備員の欺き、カードゲーム中のブラフ（またはイカサマ）などです。また、真の感情や動機を隠す必要がある場合（ひどく失望しているのに喜びを装う、あるいは逆の気持ちなのに歓迎的でオープンに見せようとする場合など）もカバーされます。欺瞞は洞察技能の対抗技能であり、他者が真実や動機を見抜こうとしている際に、洞察ロールに対抗するために使用できます。

#### 運転 (敏捷性+霊力)

運転は、荷車やそり、帆をつけたカート、あるいはガソリン車のような、1頭以上の役畜やより秘教的な手段で動力化された車両の制御をカバーします。運転する車両が、ドライバーが慣れているものとは異なる手段（例えば牛の代わりに馬、あるいは動物の代わりにモーターなど）で牽引または動力化されている場合もロールが必要です。

#### 持久力 (体力 x2)

持久力は、肉体的なストレス、痛み、疲労に耐えるキャラクターの能力です。身体が潜在的に有害な、あるいは衰弱させる状態に対処する能力を測定するもので、レジリエンス、スタミナ、代謝の一般的な指標です。持久力は意志力と同様に多くの用途で使用されますが、特に傷害、有害な毒物、病気の影響に抵抗するために使用されます。

#### 回避 (敏捷性 x2)

回避は、視認した差し迫った危険から逃れるために使用されます。遠隔武器に対する（飛び込んで遮蔽物に隠れるなど）、罠の回避、戦闘中の交戦距離の変更、そして一般的に物理的な危険から身をかわすために用いられます。一部の魔法に対する抵抗ロールとして使用することも可能です。回避を使用すると通常、キャラクターは伏せ状態になります。「命知らず」という戦闘スタイルの特性を持つ者は、近接攻撃を伏せ状態にならずに回避でき、遠隔攻撃に対してはロールに失敗した場合のみ伏せ状態になります。

#### 応急手当 (敏捷性+知力)

応急手当技能は、軽度の怪我を治療し、より深刻な怪我を安定させるキャラクターの能力を測定します。応急手当は特定の怪我に対して1回のみ適用可能で、1d3ポイントのダメージを回復します。

#### 説得 (魅力 x2)

これは、個人の魅力を通じて他者を望ましい行動へと促すキャラクターの能力を測定するものです。人の考えを変えることから、役人や警備員への賄賂まで、幅広い状況で使用されます。説得ロールは通常、状況に応じて知覚、意志力、あるいは相手の説得技能によって対抗され、キャラクターがどれほど強く行動を促そうとしているかによって修正を受けます。親しい友人に馬を貸してくれるよう頼むのは比較的簡単かもしれません。通常は買収に応じない役人に賄賂を受け取らせるのはより困難です。

#### 洞察 (知力+霊力)

洞察は、他者の言語的・非言語的行動（ボディランゲージや話し方など）を読み解き、あるいは直感的に定義して、その動機や精神状態を特定する能力です。洞察は相手が嘘をついているかどうかを判断するため（相手の欺瞞技能で対抗可能）、あるいは特定の状況に対して相手がどう感じているかを予測するために使用されます。洞察は人だけでなく特定の状況にも適用可能です。あの酒場はトラブルの巣窟ではないか？盗賊が近くの丘で待ち伏せを計画しているのではないか？といった具合です。

#### 地域 (知力 x2)

地域は、キャラクターが人生の大半を過ごした場所、通常はコミュニティ内における地元の植物相、動物相、地形、天候に対する理解を測定します。キャラクターは一般的な植物、木、動物、それらの性質や行動を知っています。どこで一番良い魚が獲れるか、獲物の動き、避難場所の探し方、季節ごとの予想される天候、そして地域特有の一般的な危険などです。近隣ではあるが不慣れな場所では、地域技能の難易度は1段階以上困難になります。

#### 母国語 (知力+魅力 +40)

母国語は、自分の属する文化で育つ間に習得した、自身の言語を話す・読む能力です。母国語は、表現力、雄弁さ、語彙の深さを測定します。

他の技能とは異なり、母国語は直接ロールされません。その代わりに、会話のレベルを制限する流暢さの静的な指標として扱われます。これについては言語技能で詳しく説明されますが、初期キャラクターは通常、母国語に完全に精通した状態でプレイを開始します。

#### 知覚 (知力+霊力)

知覚は、受動的な観察と焦点を絞った探知の両方に使用されます。特定の対象を捜索する場合や、エリア全体をスキャンする場合、あるいは周囲への単純な警戒などが含まれます。暗闇などの特定の条件は、使用される主要な感覚に応じて技能ロールの難易度を変化させます。強い臭気があれば嗅覚による知覚ロールは「標準」ではなく「簡単」になる可能性がありますが、混雑して騒がしい酒場で会話を盗み聞きしようとする場合はロールが「困難」になります。

#### 乗馬 (敏捷性+霊力)

乗馬は、騎乗用に訓練された生物を制御し、騎乗し続ける能力をカバーします。この技能はラバから象まで幅広い種類の獣に適用でき、巨大な鷲やイルカのような飛行・遊泳生物にさえ適用可能です。不慣れな種への騎乗は常に1段階難易度が高くなり、異なる環境の種（例えば馬の乗り手がドラゴンに乗るなど）への騎乗は2段階難易度が高くなります。野生の未調教な生物は、手懐けられ騎乗用に訓練されるまでは、建設的に騎乗することはできません。

#### 歌唱 (霊力+魅力)

歌唱は、単調な詠唱から複雑なアリアまで、旋律を奏でることをカバーします。歌唱はほとんどの文化において不可欠な要素であり、娯楽の主要な源であり、おそらく儀式でも使用されます。重要な歌は求愛や、戦い前の兵士の鼓舞、あるいは歴史的偉業の語り継ぎなどに使われます。この技能はリズムを保ち、音程を合わせ、正しい歌詞を覚えているユーザーの能力を反映します。

#### 隠密 (敏捷性+知力)

視界から隠れる、あるいは最小限の音で動くことは隠密技能でカバーされます。遮蔽物や暗闇、騒音などの環境条件は、環境の詳細に応じて技能等級を改善します。同様に、遮蔽物の欠如や静かな夜などの逆境は、技能等級を低下させます。状況も試行の難易度に影響します。例えば、重い防具を着た戦士は、じっとしているか非常にゆっくり動くならば壁の裏に簡単に隠れられますが、速く動くと防具が音を立てるかもしれません。

#### 水泳 (筋力+体力)

訓練を受けていない場合、水泳能力はもがいて短時間だけ頭を水面上に保てる程度に限られます。水泳のパーセンテージが高いほど、溺れるリスクを減らしつつ、より深く激しい水域を渡れることを示します。したがって、水泳ロールの成功は完全に条件に依存します。荒れた海、強い海流、激流、離岸流はすべて、キャラクターの適性に関係なく技能等級を低下させます。泳ぎの速度の計算を含む水泳の詳細については、[移動](0005_Combat.md?id=situational-movement-rates)を参照してください。

#### 徒手 (筋力+敏捷性)

徒手は全キャラクターに共通する普遍的な戦闘技能であり、武器の助けなしに自身を守る能力を測定します。徒手技能は、その文化で知られている喧嘩やレスリングの技術をカバーします。

徒手は戦闘技能であるため、クリティカルとファンブルの効果は[戦闘](0005_Combat.md)の章で詳述されている戦闘ルールでカバーされます。

#### 意志力 (霊力 x2)

意志力は、集中し、自身の意志力を特定の方向に向け、あるいは精神的なショックに対して精神を硬化させるキャラクターの能力の尺度です。また、個人の決意の尺度でもあります。この技能は精神的な回復力が必要とされるあらゆる状況で使用され、魔法への抵抗も含まれます。正気度の測定ではありませんが、最も正気で安定した精神すら揺るがすようなトラウマ体験に耐えるために使用可能です。意志力は持久力の精神的な対極に位置します。

持久力や回避と同様に、意志力は対抗ロールで最も頻繁に使用されます。標準テストとして使用される場合、クリティカル意志力ロールは、キャラクターが精神と魂を硬化させ、今後自身を操作したり決意を揺るがそうとしたりする試みが一切通用しなくなったことを示します。魔法への抵抗の場合、クリティカル成功は、対戦相手が唱えた精神に影響を及ぼす呪文が、その遭遇の間はキャラクターに何の影響も与えなくなることを意味します。

## 専門技能

専門技能はキャラクターごとに異なり、より専門化された訓練や経験を反映します。一部の専門技能はその名の通り、文化的背景やキャラクターの経歴を通じて習得されます。キャラクター間で異なりますが、標準技能と同じ方法で機能します。

#### 演技 (魅力 x2)

演技は、舞台公演であろうと社会的な状況であろうと、全く異なる人物になりきって伝える芸術を司ります。役者は自分自身とは異なる人格や身振りを説得力を持って演じます。変装技能や欺瞞技能と組み合わせることで、これは全くの別人に成り代わる強力な手段となります。

#### アクロバット (筋力+敏捷性)

アクロバットはバランス、体操、ジャグリング、宙返りなどをカバーします。この技能は観客を感銘させるために使用できますが、落下によるダメージを軽減するためにも役立ちます。ロールに成功すれば、キャラクターは不安定な場所や狭い場所を全速力で確実に移動できます。予期せぬ落下によるダメージを軽減しようとする場合、アクロバットロールの成功は被るダメージを半分にします。さらに、ロールが成功し、その落下によって重傷や致命傷を負わなかった場合、キャラクターは比較的安全に着地し、伏せ状態になりません。

アクロバットは、状況が許せば回避の代わりに代用できます。その利点は、キャラクターが伏せ状態になるのではなく、自動的に体勢を立て直せることです。

#### 天体航法 (知力 x2)

天体航法は航海術と同等の技能ですが、宇宙船のパイロットが恒星間や星系間の距離で航路をプロットできる点が異なります。

#### 芸術 (霊力+魅力)

絵画から詩、文学から彫刻まで、多くの特定の芸術形式が存在します。キャラクターはこの技能を取得する際、芸術の専門分野を選択します。以降の芸術形式は個別に成長させます。キャラクターが自身の芸術的媒体を通じて感銘を与えたり、納得させたりする必要があるたびにロールを行います。

#### 官僚 (知力 x2)

行政手続き、記録、暗黙の慣習の理解は、官僚技能によってカバーされます。これは役人とやり取りしたり、適切な市民情報を発見したりするために使用されます。文化の洗練度に応じて、官僚は必ずしも読み書きができる必要はありません。お役所仕事や行政の状況を切り抜ける必要があるときはいつでも、官僚ロールが必要です。

#### 商売 (知力+魅力)

商売は、商品や産物の価値を評価し、最良の価格で取引するために使用されます。また、利益の確保に加え、ビジネス取引の複雑な仕組みを理解するためにも使用されます。さらに、盗品や不正品を処分するための最良の方法を見つける際にも役立ちます。商売は取引時に使用され、相手の商売技能または意志力に対抗させることができます。これは、交渉を有利に進めようとする相手側の試みを反映します。また、商品の市場価値を判断したり、価格の目安を立てたり、どこで取引するのが最適かを判断するためにも使用されます。

#### 通信 (知力 x2)

この技能は、通信トラフィックを検知、隠蔽、またはブロックするための通信機器を使用する能力を与えます。また、暗号化されたメッセージを解読するチャンスも与えます（ユーザーが暗号解読器にアクセスできることが条件です）。

#### コンピュータ (知力 x2)

コンピュータは、プログラミングコード、特定のソフトウェアの詳細な使用、ハッキング、さらにはソフトウェアやハードウェアの問題の診断・修理などを通じて、コンピュータシステムを使用して複雑な問題を解決したり、複雑な情報を抽出したりするキャラクターの能力を反映します。一般的なコンピュータの使用には、通常ロールは必要ありません。#### 礼儀 (知力+魅力)

この技能は、社会的な状況や公的な場でどのように振る舞うべきかを理解するためのものである。挨拶の作法、儀式、慣習的な行動などが含まれる。誰に対して、いつ、どの程度深くお辞儀をするか、特定の肩書きをいつ使うべきか、いつ非公式な態度をとるのが適切かなど、あらゆる状況をカバーする。

#### 工作 (敏捷性+知力)

各工作は専門化されており、職業の数だけ工作の技能が存在する。芸術（Art）と同様に、工作はその対象となるアイテムを作成するために使用される。完成までにかかる時間は、製品の性質によって完全に異なる。例えば、ラグを織ることは壺を作るよりも時間がかかるが、時間は必ずしも最も重要な要素ではない。最も重要なのは、作り手の技能、資源の質、そして細部へのこだわりである。

#### 文化 (知力 x2)

文化は標準技能である「習慣（習慣）」のより特殊な形態であり、キャラクター自身のものとは異なる社会に関連する。各文化技能は、それが適用される特定の国家や社会に対して習得しなければならない。メカニクス的には「習慣」技能と同じように機能する。

#### 解体 (知力+霊力)

この技能により、キャラクターは爆発物を安全に取り扱い、使用することができる。設置する際も、解体する際も同様である。

#### 変装 (知力+魅力)

適切な素材（衣装、化粧品、かつら、ヘアーピースなど）を使用して説得力のある変装を行うには、変装技能が必要となる。変装を作り上げるには時間と細部への注意が必要であり、説得力を持たせるための正しい素材へのアクセスも必要である。これらの要素の一部、あるいはすべてが欠けている場合、変装判定の難易度は1段階以上上昇する。

変装は、演技（Acting）と組み合わせることで欺瞞の効果全体を高めることができる（逆もまた同様で、演技を行う際にも有効である）。そのため、この二つの技能は補完的な関係にある。

#### 電子機器 (敏捷性+知力)

この技能により、ユーザーは電子機器をいじったり、バイパスしたり、修理したりすることができる。多くの応用範囲があり、最も頻繁に行われるのは、損傷した機器を一時的に補修したり、壊れた回路を予備の部品と交換したりすることである。

#### 工学 (知力 x2)

家から橋、門から攻城兵器に至るまで、大規模な構造物の設計と建設は、工学技能の管轄である。大規模なプロジェクトを計画する際、正しい建設を保証するために判定が必要となるが、工学者が（例えば修理の状態や弱点など、何らかの理由で）構造物の完全性を評価したい場合にも判定が行われる。

#### 偽造 (敏捷性+知力)

偽造技能は、公式文書の作成や偽造を可能にする。

#### 賭博 (知力+霊力)

賭博技能は、チャンスゲーム、特に結果に金銭が賭けられている場合におけるキャラクターの能力を測定する。成功や失敗の確率を評価したり、誰かがイカサマをしているかを見抜いたりするために使用される。この技能は、状況に応じて対抗判定または単独判定として使用できる。無名の賭博場で一晩過ごす場合は単純なテストで済むかもしれないが、著名な人物が関わる高額なダイスゲームでは、数ラウンドにわたる対抗判定が必要になるかもしれない。

#### 応急手当 (知力+霊力)

応急手当は、文化的な慣習に基づいた医学的手順に関する詳細な知識であり、より深刻な怪我（通常、ヒットポイントが0以下になった場合）を治療するために使用される。例えば、原始的または野蛮な文化では、応急手当はハーブや自然療法に関する知識に基づいている。文明化された文化では、薬品やより高度な治療が一般的である。どの文化においても、応急手当には骨折の固定や傷の縫合などの能力が含まれる。当然のことながら、応急手当を行うには適切な資源が必要であり、ほとんどの治療者はそれらを（針、縫合用の腸線や糸、湿布用のハーブなど、あるいは現代的な設定であれば医療キットを）手元に用意している。

#### 言語 (知力+魅力)

この技能は、キャラクター自身の言語以外の言語を話し、理解する能力をカバーする。この技能は、全体的な流暢さを表す静的な数値として扱われる。1〜25%は基本的な単語をいくつか知っている程度、26〜50%は簡単な文章を話せる程度、51〜75%は一般的な会話に流暢、76%以上は雄弁に会話できる能力を示す。この値は、プレイヤーがゲーム内のキャラクターと対話する際に、ゲームマスターが会話レベルを制限するために使用される。また、（官僚制のような）他の特定の技能の上限として機能することもある。そのような場合、官僚制のような技能の値は、使用している言語技能の値を上回ることはできない。

#### 識字 (言語指定) (知力 x2)

言語を流暢に話せるからといって、読み書きができるとは限らない。識字は特定の技能であり、社会によってその扱い方やレベルは異なる。識字が貴族、官僚、あるいは宗教的階級のために予約されている社会もあれば、口承伝統が優先され、識字そのものが存在しない社会もある。現代や未来的な社会では、識字はデフォルトで習得しており、個別の技能は必要としない。

#### 開錠 (敏捷性 x2)

開錠は、鍵やロック専用のデバイスを使わずに機械的なロックシステムを開ける能力である。これには、損傷を与えずにボルト締めされたドアや窓をこじ開ける技術も含まれる。開錠は、鍵がないときにドアや宝箱などに鍵をかける際にも使用できる。

#### 知識 (知力 x2)

知識は、技能を習得する際に選択しなければならない特定の知識体系をカバーする。錬金術、占星術、天文学、地理学、紋章学、歴史、助産術、鉱物学、モンスター学、政治学、宗教、戦略戦術などが、知識技能の典型的な例である。知識技能があるということは、キャラクターがその基礎を理解し、差し迫った課題や問題にどのように適用できるかを知っており、その知識を使って有用な情報を想起できることを意味する。

#### 魔術 (霊力+魅力)

魔術技能は、[魔術と超能力](0007_Magic.md)セクションで説明されている呪文を詠唱するために使用される。呪文が機能するためには成功判定が必要だが、呪文は意志力などの対抗技能によって抵抗される可能性がある。

#### 機構学 (敏捷性+知力)

機構学は、罠のような機械装置を組み立てたり分解したりするための知識と技能を表す。機構学は一般的に小さな可動部品を持つ繊細な装置の作成に関わり、大規模な建造物を扱う工学（Engineering）とは異なる。これは開錠技能とは別の専門分野であり、開錠と入れ替えることはできない。

#### 音楽 (敏捷性+魅力)

音楽は楽器の演奏をカバーする。単純なリード管からハープのような複雑な弦楽器まで様々であり、各音楽技能は類似した楽器のグループに適用される。リード管を演奏できる音楽家は、同じ基本原理を持つフルート、パンパイプ、リコーダーも演奏できる。しかし、彼らはハープやリュートを演奏することはできない。

#### 航海術 (知力+霊力)

目立つランドマーク、星々、あるいは海水の味の変化などを使用して、正確に進路を定める能力は航海術技能によってカバーされる。各航海術技能は、外洋や地下など、特定の地域や環境をカバーする。これは、通常ではない旅をしているときや、完全に不慣れな土地にいるときに判定を行うべきである。

#### 演説 (霊力+魅力)

演説は、大勢の聴衆に対して、ある視点を伝えたり揺さぶったりする目的でスピーチを行う技術である。政治家が政策を推進するために頻繁に使用する技能だが、指揮官が軍隊を鼓舞したり戦場で規律を強制したりするためにも使用される。大衆への説得が必要なあらゆる場面で、説得（説得）ではなく演説が使用される。

#### 操縦 (敏捷性+知力)

操縦技能は、指定されたクラス（グライダー、プロペラ機、ジェットエンジンなど）の飛行車両の制御を可能にする。

#### 政治学 (知力+魅力)

政治学技能を持つキャラクターは、地方および国家レベルで政府の廊下をどのように歩き、交渉するかを理解している。

#### 調査 (知力+霊力)

調査は、望む情報を発見するために、さまざまなリソース（図書館、新聞のアーカイブ、コンピュータネットワークなど）を利用する。

#### 科学 (知力 x2)

科学には何十もの専門分野があり、複数回習得可能な科学技能は、常に特定の分野に関連付けられる（例：科学（生物学）、科学（化学））。現代や未来の設定では、科学は知識技能に取って代わる。

#### 船員術 (知力+体力)

この技能は操船（操船）と同じように使用されるが、帆やオールで動く大型の水上船舶に適用される。また、修理が必要な時期の評価、安全な停泊場所の特定、荒天時の危険など、船舶の保守や維持もカバーする。

#### 誘惑 (知力+魅力)

誘惑は、他の人に対するロマンチックあるいは性的説得であり、説得（説得）とは大きく異なる技能である。口頭および非言語的な明白なシグナルを使用して、性的に肯定的な反応を引き出す。また、かなりの時間を要する。成功する誘惑は、ターゲットの道徳観によっては数時間、数日、あるいは数週間かかる場合があり、ターゲットは常に意志力を使用して誘惑に抵抗を試みることができる。

#### センサー (知力+霊力)

この技能は、化学的な検知装置から軍事用の長距離スキャナーまで、センサーデバイスを正確に使用し分析することを可能にする。

#### 手品 (敏捷性+魅力)

手品は、小さな物を手のひらに隠したり（手練手品や奇術）、ポケットから物を盗んだり、財布を切ったり、視覚的な気を逸らしたりする試みをカバーする。当然のことながら、これは盗賊にとって不可欠な技能である。

#### 街の知識 (霊力+魅力)

街の知識は、集落内の場所や社会的なコネクションに関する知識を表す。危険な地域の特定から、合法的または非合法的な現地のサービスの発見まで、あらゆることをカバーする。街の知識の判定にかかる時間は、何を求めているかによって異なる。良い宿を見つけるのは、盗品の換金所や偽の取引許可証を探すよりも時間がかからない。

#### サバイバル (体力+霊力)

この技能は、文明の恩恵がない農村や荒野の環境で生き残ることをカバーする。食料の調達、火起こし、避難場所や安全な寝場所の確保などが含まれる。適切な装備がある場合、キャラクターはテントや食料品などを持っている可能性があるため、判定は通常不要である。装備から離れたときや、環境条件が悪化したときにのみ、この技能を使用することが不可欠になる。そのような状況では、通常1日1回判定が行われる。

#### 教導 (知力+魅力)

教導により、ユーザーは自身の知識や技術を、理解しやすく建設的な方法で他者に伝えることができる。この技能がなければ、最も有能な師匠でさえ、他者を指導する際に問題を抱えることになる。

#### 追跡 (知力+体力)

追跡技能は、あらゆる種類の獲物や対象を追跡するために使用される。足跡、傷ついた葉、散らばった花粉、動かされた岩など、通行の明白な兆候と曖昧な兆候の両方を使用して、獲物の足取りを追い続ける。これらは、技能を持たない者には見えない小さな手がかりである。追跡判定は定期的に行う必要があり、特に条件が急激に変化した場合（例えば雨が降ると特定の兆候が乱れる）は重要となる。頻度は、獲物がどれほど狡猾であったかに依存する。隠密（隠密）判定を使用して、追跡判定に対抗することができる。

## さまざまな状況における技能ルール

『ミサス・インペラティブ』における技能使用の基本ルールは非常に単純だが、プレイ中には少し異なる方法で技能を扱う必要があるさまざまな状況が多々発生する。以下のセクションでは、こうした状況とそれらの処理方法を見ていく。

### 技能の再試行

状況によっては、キャラクターが技能の試行に失敗しても、再び試みる可能性がある状況に置かれることがある。例えば、鍵を開けたり、切り立った壁を登ろうとしたりする場合がこれに当たる。単にそれ以上の試行を拒否するのではなく、寛大なゲームマスターは、最後のあがきとしての追試を許可するかもしれない。ただし、キャラクターはいくらかの不安や自信の欠如を感じるため、技能ロールの難易度が1段階上昇する。

この二度目の試行でも失敗に終わった場合、キャラクターは「全力を尽くした」ものとみなされ、当面の間、それ以上の試行を行うことはできない。

### 対抗判定

技能は、しばしば他の技能と対抗させられる。例えば、ならず者が貴族の財布を切ろうとする際の「隠密 vs 知覚」、あるいはそのならず者が捕まったときにそれを否認しようとする際の「欺瞞 vs 洞察」などは、技能が互いに競い合うよい例である。これらは対抗判定として知られ、勝つか負けるか、成功か失敗かという結果が生じる挑戦の際に使用される。

- 対抗判定は次のように決定される。両参加者がそれぞれの技能でロールを行う。勝者は、より良い技能等級を得た方である。もし参加者が同じ技能等級（両者とも標準成功、あるいは両者ともクリティカルなど）を出した場合、勝者は、その技能の成功範囲内でより高いダイス目を出した方である。

対抗判定で両者が失敗した場合、以下のいずれかを行う：

- 状況をドラマチックな緊張感の中に留めて記述し、勝者を決めるために再ロールを行う。
- ゲームマスターは、失敗の性質に合うような説明や状況を提示する。

対抗判定は、負傷の影響を克服したり、戦闘の特殊効果に対抗したりするために、特定の戦闘状況で頻繁に使用される。また、毒や病気に抵抗したり、邪悪な魔術の効果を振り払ったりするためにも使用される。

##### 対抗判定の例

| 活動 | 対抗技能の例 |
| :-- | :-- |
| 交渉/値切り | 商売 vs 商売、説得 vs 商売 |
| 追跡/レース | 運動 vs 運動、運動 vs 持久力、乗馬 vs 乗馬 |
| 欺瞞または嘘 | 欺瞞 vs 洞察、手品 vs 知覚 |
| 忠誠心の誇示 | 情熱 vs 情熱、情熱 vs 洞察、情熱 vs 説得 |
| 回避 | 回避 vs 運動、回避 vs 機構学、回避 vs 乗馬 |
| 隠れるまたは忍び込む | 隠密 vs 知覚、隠密 vs 追跡 |
| 階級の押し付け | 説得 vs 意志力、欺瞞 vs 意志力 |
| 継続 | 持久力 vs 持久力、持久力 vs 腕力 |
| 群衆の扇動 | 演説 vs 意志力 |
| 力の証明 | 腕力 vs 腕力、腕力 vs 持久力 |
| 意志の証明 | 意志力 vs 意志力、誘惑 vs 意志力 |

### 微分判定

微分判定は対抗判定に似ているが、単純な勝ち負けの結果ではなく、技能等級の差が計算される点が異なる。主に戦闘の解決に使用されるが、微分判定はゲームマスターが対決の結果を詳細にしたい他の状況でも使用できる。

微分判定は次のように決定される：両参加者がそれぞれの技能に対してロールを行い、個別にテストされたかのようにロールの結果を受ける。厳密には「勝者」は存在しないが、より高い技能等級を得た方が、彼らの成功レベルの差に等しい利益を得る（少なくとも一方が標準成功以上を得た場合）。両参加者が同じ技能等級（両者とも標準成功、あるいは両者ともクリティカル）を得た場合、追加の効果はない。

##### 微分判定の結果

| ロールの結果 | 敵対者クリティカル | 敵対者成功 | 敵対者失敗 | 敵対者ファンブル |
| :-- | :-: | :-: | :-: | :-: |
| 主人公クリティカル | 利益なし | 主人公が1等級勝つ | 主人公が2等級勝つ | 主人公が3等級勝つ |
| 主人公成功 | 敵対者が1等級勝つ | 利益なし | 主人公が1等級勝つ | 主人公が2等級勝つ |
| 主人公失敗 | 敵対者が2等級勝つ | 敵対者が1等級勝つ | 利益なし | 利益なし |
| 主人公ファンブル | 敵対者が3等級勝つ | 敵対者が2等級勝つ | 利益なし | 利益なし |

### 100%を超える対抗技能

対抗判定または微分判定において、最も高い技能を持つ参加者が100%を超える技能値を持っている場合、その参加者は100と自身の技能値との差分を、自身を含むコンテスト内の全員の技能から差し引く。これにより対戦相手の技能値は減少するが、本人は優位性を維持する。

誰が最も高い技能を持っているかの特定は、状況に応じた他のすべての修正値が適用された後に計算されなければならない。

### さて、君の腕前はどの程度かな？

技能の値がどの程度の能力レベルに相当するか、ゲームマスターとプレイヤーが共通の基準を持つことは非常に有益である。「工作：木工 48%」を持つ職人は、優れた大工なのか、それとも単に有能な大工なのか？「能力レベル表」は、技能の値が示す期待される能力レベルを要約するのに役立つ。これはまた、ノンプレイヤーキャラクター（NPC）や敵対者に一般的な技能値を割り当てる際の便利な参照資料でもある。NPCの技能にランダムな値が必要な場合は、「ランダム値」の列が、希望する能力レベル内の値を得るためのダイスコードを示している。
