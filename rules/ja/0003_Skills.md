# 技能

技能は標準技能と専門技能の2つのカテゴリーに分類されます。すべてのキャラクターは同一の標準技能セットを所持しています。専門技能は個々のキャラクターによって異なり、キャリアを通じて培った専門知識や、ある程度はそのキャラクターの文化を反映しています。これらの区別にかかわらず、標準技能と専門技能は同じ仕組みで機能します。

---
## 技能の仕組み

技能には2つの能力値を合計したもの、あるいは1つの能力値を2倍したものに基づく基本値があります。技能値に上限はなく、100を超えることもあり、プレイ中にはキャラクターがそれほど高い技能値に達することもあるでしょう。

キャラクターが何らかのテスト、試練、あるいは専門能力の判定を行う必要があるときはいつでも、1d100をロールし、その結果を技能値と比較します。

- 技能値以下であれば、成功
- 技能値より大きければ、失敗

成功と失敗に関しては、注意すべきいくつかの特別なケースがあります。

- 01〜05の出目は常に成功となる
- 96〜00の出目は、技能値がどれほど高くても常に失敗となる

#### クリティカルとファンブル

クリティカルとファンブルは、劇的な成功と失敗を表します。キャラクターが試みに秀でた成果を出した、あるいは悲惨かつ完全な失敗をした場合です。

- クリティカル成功は、技能値の10分の1（端数切り上げ）の出目となります（修正値を受けた技能も含まれるため、修正後の技能値によってクリティカルの範囲は広くなることも狭くなることもあります）。例えば、技能が通常の2倍（例：33%から66%）に修正された場合、クリティカルの範囲は07以下となります。
- ファンブルは99または00の出目です。技能値が100%を超える場合、ファンブルは00の出目のみとなります。

クリティカルまたはファンブルの結果の正確な性質は、ゲームマスターが決定します。状況に応じて、素晴らしい結果にも、悲惨な結果にもなり得ます。

#### 自動成功

ある技能に対するロールが必要ない場合もあります。これは、目の前の課題が簡単に達成できる場合や、十分な時間と集中力をかければ成功が保証されている場合です。穏やかな牧草地で馬をゆっくりと走らせることは自動成功の例であり、単にその活動に熟練しているだけで、単純な行動であれば判定を行う必要はありません。職人が木片から椅子の脚を削り出すのも、技能判定が不要な例です。これには時間がかかりますが、職人は仕事のやり方を知っており、急いでいなければ成功は確実です。盗賊が誰にも邪魔されず、鍵開け道具のセットを持っていれば、十分な時間さえあれば宝箱の単純な鍵を確実に解錠できます。

#### 技能の修正

技能ロールが必要だが、成功率を現在の状況に合わせて調整しなければならない場合があります。例えば、盗賊から逃げる際には運動ロールが必要になるかもしれません。しかし、キャラクターが闇の中や、歩きにくい藪の中を逃げている場合はどうでしょうか？ そのような場合、ゲームマスターは状況を反映させるためにキャラクターの技能を修正するよう指示できます。

『Mythras Imperative』では、技能の修正方法を決定するために一連の等級を使用します。それらは以下の通りです。なお、2種類の修正方法が提供されています。1つ目はデフォルトの方法で、少し計算が必要ですが、特に高い技能パーセンテージに関与する場合、スケーリングのための優れたシミュレーションを提供します。簡略化された技能修正は単純な加算または減算であり、実装が容易です。どちらの方法がゲームに適しているかを選択し、同じ修正システムが一貫して適用されるようにしてください。

##### 難易度テーブル

| 難易度 | 技能修正 | 簡略化された技能修正 |
| :-- | :-- | :--: |
| 判定不要 | ロール不要 | ロール不要 |
| 非常に簡単 | 技能値を2倍にする | +40% |
| 簡単 | 技能値に半分を加える | +20% |
| 標準 | 調整なし | なし |
| 困難 | 技能値を3分の1減らす | -20% |
| 至難 | 技能値を半分にする | -40% |
| 超人的 | 技能値を5分の1にする | -80% |
| 絶望的 | 試みることすらできない | 試みることすらできない |

キャラクターが他の状況によってすでにペナルティを受けている場合は、最も厳しい難易度が優先されます。

戦闘以外では、『Mythras Imperative』は技能修正が発生する状況や試練の決定的なリストを提供していません。特定の技能や文脈に対してどのような修正が必要かは、最終的にキャラクターの能力、状況の難易度に対するゲームマスターの認識、そしてその瞬間の劇的な緊張感に従って、ゲームマスターが決定します。

## 標準技能

#### 運動 (筋力+敏捷性)

運動は、登攀、跳躍、投擲、走行を含むさまざまな身体活動をカバーします。これらの活動のいずれかに対する技能ロールは、運動技能に対する単一のロールで処理されます。登攀、跳躍、走行の詳細については、[Movement](0005_Combat.md?id=situational-movement-rates)を参照してください。

#### 操船 (筋力+体力)

操船技能は、川、湖、および沿岸近くでの小型船の操作をカバーします。適切な船舶は、一般的にボート、カヌー、または筏であり、短距離を移動するもので、外海の荒波には適していません。ほとんどはオール、パドル、竿、または単純な帆を使用して推進するか、動物に牽引させることもできます。大規模な乗組員を必要とする船や、海外への長距離航海を目的として設計された船は、専門技能の「航海術」でカバーされます。

#### 腕力 (筋力+体格)

腕力は、生の身体的力を発揮する際の効率的な技術の応用です。この技能は、重量挙げ、扉の破壊、力比べなど、加えられる力による行為をカバーします。

#### 戦闘スタイル (筋力+敏捷性)

各戦闘スタイルは、設定されたキャリアや文化で期待される武器を使用するための技能です。ほとんどの戦闘の伝統には、複数の武器の訓練と、それらを単独または組み合わせて効果的に使用するために必要な技術が含まれています。さらに、密集歩兵として戦う場合や騎乗時など、状況に応じた要素を想定することもよくあります。戦闘スタイルは非常に多様で、例えば剣闘士の戦闘から宇宙海兵隊の機動歩兵まで多岐にわたります。

#### 隠蔽 (敏捷性+霊力)

隠蔽は、キャラクター自身ではなく、大きな物体を隠すための隠密技能に対するカウンターパートです。例えば、隠蔽は岩の陰に戦車を隠したり、その道筋を追跡されないように轍を掃き消したりするために使用できます。この技能は応用範囲が広く、図書館にある巻物を隠すことから、罠や秘密の通路の存在を偽装することまで、何でもこなせます。

#### 習慣 (知力 x2 +40)

習慣は、自身のコミュニティ（社会規範、儀式、慣習、タブーなど）に対するキャラクターの知識を表します。この技能は、社会的に重要な習慣を正確に解釈または実行したり、特定の方法で振る舞うことが不可欠な場合に使用されます。

#### 舞踊 (敏捷性+魅力)

ほぼすべての文化が、娯楽として、あるいは重要な儀式の一環として、何らかの形で舞踊を使用しています。それは宮廷舞踊、戦いの舞踊、あるいは祈りや儀式の詠唱に伴う単純な動きかもしれません。舞踊技能は、求められたときに（ある程度の範囲で）リズミカルかつ正確に動くキャラクターの能力を測定します。

#### 欺瞞 (知力+魅力)

欺瞞は、キャラクターが真実を隠蔽し、何らかの偽りを提供するすべての事例をカバーします。あからさまな嘘、警備員を欺くこと、さらにはカードゲーム中のブラフ（またはイカサマ）などが含まれます。この技能は、本当の感情や動機を隠す必要がある場合（ひどく失望しているのに喜びを装ったり、あるいはその逆であるにもかかわらず歓迎的でオープンであるように見せかけようとする場合など）もカバーします。欺瞞は洞察技能のカウンターパートを形成し、他者が真実や動機を見抜こうとしている際に、洞察ロールに対抗するために使用できます。

#### 運転 (敏捷性+霊力)

運転は、車輪付きの車両や牽引される車両の制御をカバーします。これには、1頭以上の荷役獣によって牽引されるものや、戦車、そり、帆付きカート、さらにはガソリン車などのより難解な手段で動力化されたものが含まれます。また、運転されている車両が、運転者が慣れているものとは異なる手段（馬の代わりに牛、または動物の代わりにモーターなど）で牽引または動力化されている場合もロールが必要です。

#### 持久力 (体力 x2)

持久力は、身体的ストレス、痛み、疲労に耐えるキャラクターの能力です。これは、損傷や衰弱を招く可能性のある状態に対処する体の能力を測定するものであり、回復力、スタミナ、代謝の一般的な尺度です。持久力は、そのカウンターパートである意志力と同様に、さまざまな方法で使用されますが、最も具体的には負傷、有害な毒物、病気の影響に抵抗するために使用されます。

#### 回避 (敏捷性 x2)

回避は、観測された差し迫った危険から逃れるために使用されます。遠隔武器に対して（例えば、身を投げて遮蔽物に入るなど）、罠を避ける、戦闘中の間合いを変更する、一般的に物理的な危険の邪魔にならないようにするために使用できます。また、特定の種類の魔法に対する抵抗ロールとしても使用できます。通常、回避を使用するとキャラクターは伏せ状態になります。戦闘スタイル特性の「命知らず」を持つキャラクターは、伏せ状態にならずに近接攻撃を回避でき、遠隔攻撃に対しては、ロールに失敗した場合にのみ伏せ状態になります。

#### 応急手当 (敏捷性+知力)

応急手当技能は、軽傷を治療し、より重篤な怪我を安定させるキャラクターの能力を測定します。応急手当は特定の怪我につき1回のみ適用でき、1d3ポイントのダメージを回復します。

#### 説得 (魅力 x2)

これは、個人のカリスマ性を通じて他者を望ましい行動へと説得するキャラクターの能力の尺度です。これは、人の考えを変えることから、役人や警備員に賄賂を贈ることまで、幅広い状況で使用されます。説得ロールは通常、状況に応じて知覚、意志力、または別の説得技能によって対抗され、キャラクターがどれだけ行動を操作しようとしているかによって修正されます。親しい友人に馬を貸すように説得するのは比較的簡単かもしれません。通常は腐敗しない官僚に賄賂を受け取らせるのはより困難です。

#### 洞察 (知力+霊力)

洞察は、相手の動機や精神状態を特定するために、言葉による行動や言葉によらない行動（ボディランゲージや話し方など）を読み取ったり直感的に定義したりする能力です。洞察は、誰かが嘘をついているかどうかを判断するため（相手の欺瞞技能と対抗できる）、または誰かが特定の状況についてどのように感じているかを予測するために使用されます。洞察は、他人に限らず特定の状況にも等しく適用できます。その居酒屋はトラブルの温床か？ 盗賊が近くの丘で待ち伏せを計画しているのではないか？ などです。

#### 地域 (知力 x2)

地域は、キャラクターが人生の大半を過ごした場所（通常はコミュニティ内）の地元の植物相、動物相、地形、および天候に関するキャラクターの理解度を測定します。キャラクターは一般的な植物、木、動物、その特性と行動を知っています。どこで最も良い魚が見つかるか、獲物の動き、避難場所の見つけ方、季節ごとの予想される天候、そして最も一般的な地域的な危険などです。近隣であっても馴染みのない場所では、地域技能は1段階以上難しくなるはずです。

#### 母国語 (知力+魅力 +40)

母国語は、自分の文化圏で育つ間に習得した、自分の言語を話し、読む能力です。母国語は、明瞭さ、雄弁さ、語彙の深さを測定します。

他の技能とは異なり、母国語は直接ロールされません。代わりに、全体的な流暢さを表す静的な表現として扱われ、会話のレベルを制限します。これについては言語技能で詳しく説明されますが、初期キャラクターは通常、母国語が完全に流暢な状態でプレイを開始します。

#### 知覚 (知力+霊力)

知覚は、受動的な観察と焦点を絞った探知の両方に使用されます。特定のものを探す、エリア全体をスキャンする、あるいは単に周囲を意識している場合などです。闇などの特定の条件は、使用される主要な感覚に応じて技能ロールの難易度に影響を与える可能性があります。強い臭いがあれば、嗅覚による知覚ロールは標準よりも「簡単」になる可能性がありますが、混雑して騒がしい居酒屋で会話を盗み聞きしようとすれば、ロールは「困難」になります。

#### 乗馬 (敏捷性+霊力)

乗馬は、乗用に訓練された生き物を制御し、騎乗し続ける能力をカバーします。この技能は、ラバから象まで、あらゆる種類の獣に適用できます。巨大なワシやイルカのような飛行生物や水泳生物にも応用可能です。馴染みのない種に騎乗する場合は常に難易度が1段階上がります。異なる環境の種（例えば、馬の乗り手がドラゴンに乗るなど）に騎乗する場合は、難易度が2段階上がります。野生の未調教の生物は、慣らして騎乗用の獣として訓練されるまで、建設的な方法で乗ることはできません。

#### 歌唱 (霊力+魅力)

旋律を奏でることは歌唱でカバーされます。単調な詠唱から複雑なアリアまで何でも含まれます。歌唱はほとんどの文化に固有のものであり、エンターテインメントの主要な源であり、儀式でも使用される可能性があります。重要な歌は、求愛、戦いの前に兵士を鼓舞するため、あるいは単に歴史的な功績を語り継ぐために使用されます。この技能は、リズムを維持し、キーを合わせ、正しい言葉を覚えているユーザーの能力を反映します。

#### 隠密 (敏捷性+知力)

目立つ場所から隠れることや、最小限の音で移動することは隠密技能でカバーされます。遮蔽物や、闇や騒々しい背景音などの状況は、環境の詳細に応じて技能の等級を改善します。同様に、隠れ場所がないことや静かな夜などの不利な条件は、技能の等級を低下させます。状況も試みの難易度に影響します。例えば、重い防具を着た戦士は、じっとしているか非常にゆっくり動くなら壁の後ろに簡単に身を隠せますが、素早く動くと防具が音を立てるかもしれません。

#### 水泳 (筋力+体力)

訓練を受けていない場合、泳ぐ能力は、暴れ回り、短時間だけ頭を水面上に保てる程度に限られます。水泳のパーセンテージが高いほど、溺れるリスクを抑えつつ、より深く強い水域を攻略できることを示します。したがって、水泳ロールを行うことは、完全にその状況に依存します。荒海、激流、急流、離岸流は、キャラクターの泳ぎの適性に関係なく、技能の等級を低下させます。水泳速度の計算を含む詳細については、[Movement](0005_Combat.md?id=situational-movement-rates)を参照してください。

#### 徒手 (筋力+敏捷性)

徒手はすべてのキャラクターに共通する普遍的な戦闘技能であり、武器の助けを借りずに身を守る能力を測定します。徒手技能は、その文化で知られている喧嘩やレスリングの技術をカバーします。

徒手は戦闘技能であるため、クリティカルとファンブルの効果は、[Combat](0005_Combat.md)の章で詳述されている戦闘ルールでカバーされます。

#### 意志力 (霊力 x2)

意志力は、集中したり、特定の方向に意志の力を向けたり、精神的なショックに対して精神を強化したりするキャラクターの能力の尺度です。また、個人の決意の尺度でもあります。この技能は、精神的な回復力が必要なあらゆる状況で使用され、魔法への抵抗も含まれます。正気度の尺度ではありませんが、正気で安定した精神さえも揺さぶるようなトラウマ的な出来事に耐えるために使用できます。意志力は、持久力の精神的なカウンターパートです。

持久力や回避と同様に、意志力も対抗ロールで最もよく使用されます。標準テストとして使用される場合、意志力のクリティカルロールは、キャラクターが精神と魂を強化し、彼に影響を与えたり、決意を揺るがそうとするこれ以上の試みが通用しないことを示します。魔法への抵抗の場合、クリティカル成功は、対戦相手が唱えたこれ以上の精神的な苦痛を与える呪文が、その遭遇の間、キャラクターには一切効果がないことを意味します。

## 専門技能

専門技能はキャラクターごとに異なり、より専門的な形の訓練と経験を表します。一部の専門技能は、名前が示すように、文化的背景やキャラクターのキャリアを通じて習得されます。キャラクターごとに異なりますが、標準技能と同じ方法で機能します。

#### 演技 (魅力 x2)

演技は、舞台公演であれ社会的な状況であれ、完全に異なるキャラクターになりきり、それを伝える芸術を司ります。俳優は自分とは異なる個性や仕草を納得のいく方法で演じます。変装および欺瞞技能と組み合わせることで、これはまったくの別人になるための強力な手段となります。

#### アクロバット (筋力+敏捷性)

アクロバットはバランス、体操、ジャグリング、宙返りの行為をカバーします。この技能は観客を感動させるために使用できるだけでなく、落下によるダメージを軽減するのにも役立ちます。ロールが成功すると、キャラクターは不安定な場所や狭い場所を全力で、かつ確実に移動できます。予期せぬ落下によるダメージを軽減しようとする場合、アクロバットの成功は受けたダメージを半分にします。さらに、ロールが成功し、その落下によって重傷や致命傷を負わなかった場合、キャラクターは比較的安全に着地し、伏せ状態にはなりません。

アクロバットは、状況が許せば回避の代わりに代用できます。この利点は、キャラクターが伏せ状態にならずに自動的に足場を取り戻せることです。

#### 天体航法 (知力 x2)

天体航法は、星間距離や恒星間距離で航路をプロットできる点を除いて、航海術と同等です。

#### 芸術 (霊力+魅力)

絵画から詩、文学から彫刻まで、多くの特定の芸術形式があります。キャラクターはこの技能を取得する際に芸術の専門分野を選択します。以降の芸術形式は個別に習得します。キャラクターが芸術的媒体を通じて感動させたり納得させたりする必要があるときはいつでもロールが行われます。

#### 官僚 (知力 x2)

行政手続き、記録、暗黙の慣習を理解することは、官僚技能によってカバーされます。これは、役人とやり取りしたり、関連する市民情報を発見したりするために使用されます。文化の洗練度に応じて、官僚は必ずしも読み書きができる必要はありません。お役所仕事や行政の状況を乗り切る必要があるときはいつでも、官僚ロールが必要です。

#### 商業 (知力+魅力)

商業は、商品や産品の価値を評価し、最良の価格で取引するために使用されます。また、利益の確保に加えて、ビジネス取引の複雑さを理解するためにも使用されます。さらなる用途として、盗品や不正品を処分する最善の方法を見つける際にも使用され、この場合も最良の価格で取引できます。商業は取引時に使用され、取引を自らに有利に進めようとする相手の商業技能または意志力に対抗される場合があります。また、商品の市場価値を判断したり、価格の目安を立てたり、どこで取引するのが最も良いかを知るためにも使用されます。

#### 通信 (知力 x2)

この技能は、通信トラフィックを検知、隠蔽、またはブロックするための通信機器を使用する能力を与えます。また、暗号化されたメッセージを解読するチャンス（ユーザーがコードクラッカーにアクセスできることを条件とする）も与えます。

#### コンピュータ (知力 x2)

コンピュータは、プログラミングコード、特定のソフトウェアの詳細な使用、ハッキング、さらにはソフトウェアやハードウェアの問題の診断/修理を通じて、コンピュータシステムを使用して複雑な問題を解決したり、複雑な情報を抽出したりするキャラクターの能力を反映しています。コンピュータの一般的な使用には、通常ロールは必要ありません。#### 礼儀 (知力+魅力)

この技能は、社会的または公式な状況においてどのように振る舞うべきかを理解する能力をカバーする。呼びかけ方、儀式、行動の慣習などが含まれる。誰に、いつ、どれほど深くお辞儀をするかから、特定の称号をいつ使うべきか、いつ非公式に振る舞うのが適切かまで、あらゆる状況に対応する。

#### 工作 (敏捷性+知力)

各「工作」は専門化された形態であり、それに見合う職業の数だけ工作の数も存在する。芸術技能と同様に、工作は対象となるアイテムを作成するために使用される。どの程度の時間がかかるかは、製品の性質に完全に依存する。例えば、絨毯を織るには壺を作るよりも時間がかかるが、時間が必ずしも最も重要な要素というわけではない。職人の腕前、資源の質、そして細部へのこだわりこそが重要である。

#### 文化 (知力x2)

文化は「習慣」という標準技能のより具体的な形態であり、キャラクター自身のものとは異なる社会に関連する。各「文化」技能は、それが適用される特定の国家や社会を指定しなければならない。メカニズム的には「習慣」技能と同じように機能する。

#### 爆破 (知力+霊力)

この技能により、キャラクターは爆発物を使用したり、設置や解体を行ったりする際に安全に取り扱うことができる。

#### 変装 (知力+魅力)

適切な素材（衣装、化粧、かつら、付け毛など）を使用して説得力のある変装を行うことは、「変装」技能で扱われる。変装を完成させるには時間と細部への注意、そして説得力を持たせるための適切な素材へのアクセスが必要である。これらの要素の一部または全部が欠けている場合、「変装」判定の難易度は1段階以上上昇する。

変装は「演技」と組み合わせることで、欺瞞の効果全体を高めることができる（演技を行う際も同様）。そのため、これら二つの技能は相互補完的である。

#### 電子機器 (敏捷性+知力)

この技能により、ユーザーは電子機器をいじったり、バイパスしたり、修理したりすることができる。応用範囲は広く、損傷した機器を一時的に修理したり、壊れた回路を予備の部品と交換したりする際によく使用される。

#### 工学 (知力x2)

家屋から橋、門から攻城兵器に至るまで、大規模な構造物の設計と建設は「工学」技能の管轄である。大規模なプロジェクトを計画する際に正しい建設を保証するためには判定が必要だが、何らかの理由（修理状況や弱点の把握など）で構造物の健全性を評価したい場合にも判定が行われる。

#### 偽造 (敏捷性+知力)

「偽造」技能は、公式文書の作成や改ざんを可能にする。

#### 賭博 (知力+霊力)

「賭博」技能は、運が絡むゲーム、特に結果に対して金銭が賭けられる状況におけるキャラクターの能力を測定する。成功や失敗の確率を評価したり、誰かがイカサマをしていないかを見抜いたりするために使用される。状況に応じて、対抗ロールとしても、単独のロールとしても使用できる。素性の知れない賭博場で夜を過ごすだけなら単純な判定で済むかもしれないが、著名な人物が関わる高額なダイスゲームでは、数ラウンドの対抗ロールが必要になる可能性がある。

#### 治療 (知力+霊力)

治療は医学的処置に関する深い知識であり、文化的な慣習に基づいている。より深刻な負傷（通常、ヒットポイントが0以下になった場合）を治療するために使用される。例えば原始的または野蛮な文化では、治療はハーブや自然療法に関する知識に基づくだろう。文明化された文化では、薬物やより高度な治療が一般的である。あらゆる文化において、「治療」には骨折の接合、傷口の縫合などの能力が含まれる。当然のことながら、「治療」を行うには適切なリソースが必要であり、ほとんどの開業医はそれを手元に備えている（針、縫合糸、湿布用のハーブなど、あるいは現代的な設定なら救急キット）。

#### 言語 (知力+魅力)

この技能は、キャラクター自身の言語以外の言語を話したり理解したりすることをカバーする。この技能は、全体的な流暢さを表す静的な数値として扱われる。1〜25%は基本的な単語が少し、26〜50%は単純な文章、51〜75%は一般的な会話が流暢、76%以上は流暢に会話できる。この値は、プレイヤーがゲーム内のキャラクターと会話する際、ゲームマスターが会話の相互作用のレベルを制限するために使用される。また、官僚主義のような他の特定の技能の上限として機能することもある。そのような場合、官僚主義のような技能は、使用されている「言語」の技能値を超えることはできない。

#### 識字 (特定の言語) (知力x2)

言語を流暢に話せることが、読み書きができることを意味するわけではない。「識字」は特定の技能であり、社会によってそれに対するレベルやアプローチが異なる。識字が貴族、官僚、宗教階級のために予約されている社会もあれば、口承伝統が優先され、識字が存在しない社会もある。現代や未来的な社会では、識字はデフォルトで習得しており、別個の技能を必要としない。

#### 鍵開け (敏捷性x2)

「鍵開け」は、鍵や鍵専用の装置を使用せずに機械的な施錠システムを開ける能力である。ボルトや閂のかかったドアや窓を、損傷を与えずにこじ開ける技術も含まれる。鍵がない場合、ドアや宝箱などに鍵をかけるために使用することもできる。

#### 知識 (知力x2)

知識は、技能を初めて習得する際に選択しなければならない特定の知識体系をカバーする。錬金術、占星術、天文学、地理、紋章学、歴史、助産術、鉱物学、モンスター、政治学、宗教、戦略戦術などが典型的な「知識」技能の例である。特定の知識技能を持っているということは、その基礎を理解しており、それを差し迫った課題や問題にどのように適用できるかを把握し、役立つ情報を思い出すためにその知識を使用できることを意味する。

#### 魔法 (霊力+魅力)

「魔法」技能は、[魔法と能力](0007_Magic.md)セクションに記載されている呪文を唱えるために使用される。呪文を発動させるにはロールの成功が必要だが、呪文は「意志力」のような対抗技能によって抵抗される場合がある。

#### 機械工作 (敏捷性+知力)

機械工作は、罠のような機械装置を組み立てたり分解したりするための知識と技術を表す。機械工作技能は一般的に、大規模な建設を扱う「工学」とは対照的に、小さな可動部品を持つ繊細な装置の作成を伴う。これは「鍵開け」とは異なる分野であり、それらの技能を入れ替えることはできない。

#### 音楽 (敏捷性+魅力)

「音楽」は楽器の演奏をカバーする。単純な葦の笛からハープのような複雑な弦楽器まで、この技能の各反復は同様の楽器のグループに適用される。葦の笛を演奏できる音楽家は、フルート、パンパイプ、リコーダーも演奏できる。なぜなら、基礎は同じだからである。しかし、ハープやリュートを演奏することはできない。

#### 航海術 (知力+霊力)

目立つランドマーク、星、あるいは海水の味の変化のいずれを使用する場合でも、正確に移動を指示する能力は「航海術」技能がカバーする。各「航海術」技能は、外洋や地下など、特定の地域や環境をカバーする。通常のルートを外れる旅の際や、完全に未知の領域にいる際に使用されるべきである。

#### 演説 (霊力+魅力)

「演説」は、視点を伝えたり揺さぶったりする目的で、大勢の人々に向けてスピーチを行う芸術である。政治家が政策を推進するためによく使う技能だが、指揮官が軍隊を鼓舞し、戦場で規律を維持するためにも使用される。大衆の説得が必要なあらゆる場面で、「説得」ではなく「演説」が使用される。

#### 操縦 (敏捷性+知力)

「操縦」技能は、特定のクラス（グライダー、プロペラ機、ジェットエンジン機など）の飛行機体を制御することを可能にする。

#### 政治 (知力+魅力)

「政治」技能を持つキャラクターは、地方レベルおよび国家レベルで政府の回廊をどのように移動し、交渉するかを理解している。

#### 調査 (知力+霊力)

「調査」は、目的の情報を見つけるために、さまざまなリソース（図書館、新聞のアーカイブ、コンピュータネットワークなど）を使用する。

#### 科学 (知力x2)

数十の科学分野が存在し、複数回習得可能な「科学」技能は、常に特定の分野に関連付けられる。例えば、科学（生物学）や科学（化学）などである。現代や未来的な設定では、科学が「知識」技能に取って代わる。

#### 船員術 (知力+体力)

この技能は「操船」と同様の方法で使用されるが、帆や櫂の列によって推進される大型の水上船に適用される。船の保守や維持、修理が必要な時期の評価、停泊の安全性の判断、荒天の危険性なども含まれる。

#### 誘惑 (知力+魅力)

「誘惑」は、他者に対するロマンチックまたは性的な説得であり、「説得」とは大きく異なる技能である。口頭および非言語的な明白な信号を使用して、性的にポジティブな反応を引き出す。また、かなりの時間が必要となる。成功した「誘惑」は、ターゲットの道徳観によっては数時間、数日、あるいは数週間かかる場合があり、ターゲットは常に「意志力」で誘惑に抵抗を試みることができる。

#### センサー (知力+霊力)

この技能により、化学探知機から軍用の長距離スキャナーに至るまで、センサー機器の正確な使用と分析が可能になる。

#### 手品 (敏捷性+魅力)

「手品」は、小さな物体を手のひらに隠したり（奇術や早業）、隠匿したりする試みをカバーし、スリ、財布切り、あるいは視覚的な注意をそらす試みも含まれる。当然ながら、これは泥棒にとって必須の技能である。

#### 街の知識 (霊力+魅力)

「街の知識」は、居住地内の場所や社会的コネクションに関する知識を表す。危険な可能性のある地区の特定から、合法または非合法を問わず地元のサービスの発見に至るまで、すべてをカバーする。街の知識の判定にどれだけの時間がかかるかは、何を探しているかによる。良い宿屋を見つけるのは、盗品を扱うブローカーや偽造の取引許可証を探すよりも時間がかからない。

#### サバイバル (体力+霊力)

この技能は、文明の恩恵が存在しない地方や荒野の環境で生き延びることをカバーする。食料の採集、火起こし、避難場所や安全な寝場所を見つけることなどである。適切に装備されていれば、キャラクターはテントや食料品などを持っているため、通常はロールの必要はない。装備と離れ離れになった時や、環境条件が悪化した時にのみ、この技能を使用することが不可欠になる。そのような状況では、通常1日1回ロールを行う。

#### 教導 (知力+魅力)

「教導」は、ユーザーが自分の知識や技術を、理解しやすく建設的な方法で他者に伝えることを可能にする。この技能がなければ、最も有能な師匠であっても、他人に指導する際に問題が生じるだろう。

#### 追跡 (知力+体力)

「追跡」技能は、あらゆる形態の獲物を追跡するために使用される。足跡、傷ついた葉、散らばった花粉、動かされた岩など、通行を示す明白な兆候と曖昧な兆候の両方を使用して、獲物の足跡を追い続ける。これらは熟練していない者には見えない、小さな手がかりである。特に条件が急激に変化した場合（例えば、雨が降ると特定の兆候が乱される）、定期的に追跡ロールを行う必要がある。頻度は獲物がどれほど狡猾かによる。追跡ロールに対しては「隠蔽」ロールで対抗することができる。

## さまざまな状況における技能ルール

_Mythras Imperative_ における技能使用の基本ルールは非常に簡単だが、プレイ中には少し異なる方法で技能を扱う必要が生じる多様な状況が数多く存在する。以下のセクションでは、こうした状況や場面を見て、それらをどのように扱うかを示す。

### 技能の再試行

状況によっては、キャラクターが技能判定に失敗しても、再び試みることができる状況に置かれることがある。例えば、鍵を開けようとしたり、切り立った壁を登ろうとしたりする場合である。単純にそれ以上の試行を拒否するのではなく、慈悲深いゲームマスターは、後続の「最後の一手」となる試行を許可するかもしれない。しかし、キャラクターはいくらかの不安や自信の欠如に苦しみ、その技能ロールの難易度が1段階上昇する。

もしこの二度目の試行も失敗に終わった場合、キャラクターは「全力を尽くした」とみなされ、当面の間はそれ以上の試行を行うことはできない。

### 対抗ロール

技能は頻繁に他の技能と競い合う。例えば、悪党が貴族の財布を切り取ろうとする際の「隠密」対「知覚」、あるいは同じ悪党が見つかった時にその試みを否定しようとする際の「欺瞞」対「洞察」は、技能が互いにぶつかり合う良い例である。これらは「対抗ロール」として知られ、勝つか負けるか、成功するか失敗するかという結果が出る挑戦に使用される。

- 対抗ロールは次のように決定される：両方の参加者がそれぞれの技能でロールを行う。より高い「成功等級」を得た者が勝者となる。参加者が同じ成功等級（共に標準成功、または共にクリティカル）を出した場合、勝者は技能の成功範囲内でより高い出目を出した者となる。

対抗ロールで双方が失敗した場合、以下のいずれかを行う：

- 状況を描写し、双方をドラマチックな緊張感の中に置いたまま、勝者を決めるために再ロールを行う。
- ゲームマスターは、失敗の性質に適した説明や状況を作り出すべきである。

対抗ロールは、負傷の効果を克服したり、戦闘の「特殊効果」に対抗したりするために、特定の戦闘状況で頻繁に使用される。また、毒や病気に抵抗したり、邪悪な魔法の効果を振り払ったりするためにも使用される。

##### 対抗ロールの例

| 行動 | 対抗技能の例 |
| :-- | :-- |
| 交渉/値切り | 商業 vs 商業、説得 vs 商業 |
| 追跡/レース | 運動 vs 運動、運動 vs 持久力、乗馬 vs 乗馬 |
| 騙し、嘘 | 欺瞞 vs 洞察、手品 vs 知覚 |
| 忠誠を示す | 情熱 vs 情熱、情熱 vs 洞察、情熱 vs 説得 |
| 避ける | 回避 vs 運動、回避 vs 機械工作、回避 vs 乗馬 |
| 隠れる、忍び寄る | 隠密 vs 知覚、隠密 vs 追跡 |
| 階級をかざす | 説得 vs 意志力、欺瞞 vs 意志力 |
| 継続する | 持久力 vs 持久力、持久力 vs 腕力 |
| 群衆を揺さぶる | 演説 vs 意志力 |
| 力の試験 | 腕力 vs 腕力、腕力 vs 持久力 |
| 意志の試験 | 意志力 vs 意志力、誘惑 vs 意志力 |

### 微分ロール

「微分ロール」は対抗ロールと似ているが、単純な勝敗の結果ではなく、成功等級の差を計算する点が異なる。主に戦闘の解決に使用される微分ロールは、ゲームマスターが対戦の詳細な結果を増やしたいと考える他の状況でも使用できる。

微分ロールは以下の方法で決定される：両参加者がそれぞれの技能に対してロールを行い、個別に判定されたかのように結果を適用する。絶対的な「勝者」は存在しないが、より高い成功等級を得た側が、双方の成功等級の差に等しい利益を得る（少なくとも一方が標準成功以上の結果を得た場合とする）。双方が同じ成功等級（共に標準成功、または共にクリティカル）を得た場合、追加の効果は発生しない。

##### 微分ロールの結果

| ロールの結果 | 敵対者クリティカル | 敵対者成功 | 敵対者失敗 | 敵対者ファンブル |
| :-- | :-: | :-: | :-: | :-: |
| 主人公クリティカル | なし | 主人公が成功等級1差で勝利 | 主人公が成功等級2差で勝利 | 主人公が成功等級3差で勝利 |
| 主人公成功 | 敵対者が成功等級1差で勝利 | なし | 主人公が成功等級1差で勝利 | 主人公が成功等級2差で勝利 |

### 100%を超える対抗技能

対抗ロールや微分ロールにおいて、最も高い技能を持つ参加者の技能が100%を超えている場合、その参加者は100と自分の技能値との差を、自分自身を含む対戦者全員の技能から差し引く。これにより対戦相手の技能値は低下するが、自分自身は優位性を保持する。

誰が最も高い技能を持っているかの特定は、状況による他の修正値がすべて適用された後に計算されなければならない。

### それで、あなたはどれくらい上手いのか？

ゲームマスターとプレイヤーの両方にとって、技能値がどの程度の能力レベルに相当するかという共通の基準を持つことは非常に有益である。工作（木工）48%の職人は優れた大工なのか、それとも単に有能なだけなのか？「能力レベル表」は、技能の数値が表すであろう能力のレベルを要約するのに役立つ。また、ゲームマスターがノンプレイヤーキャラクターや敵対者の技能に一般的な値を割り当てる際の便利な参照資料でもある。ノンプレイヤーキャラクターの技能にランダムな値が必要な場合は、「ランダム値」の列にあるダイスコードを使用することで、望む能力レベル内の値を得ることができる。
