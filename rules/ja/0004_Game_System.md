# ゲームシステム

_Mythras Imperative_ のゲーム中には、さまざまな事象が発生します。それらのいくつかは技能の使用、あるいは戦闘や魔法といった主要なゲームメカニクスのいずれかを通じて解決されますが、また別のものは、それら独自の裁定ルールを必要とします。この章では、プレイヤーがゲームをプレイする際に遭遇する、多種多様なシナリオのためのルールと指針を提供します。

このリストは網羅的なものではありませんが、最も一般的な状況を網羅しているはずです。ゲームマスターがこの章で扱われていない状況に対して何らかのゲームシステム上の裁定が必要だと判断し、かつその状況が頻繁に発生するように思われるなら、この章で提示されたルールを模倣または発展させる基礎として利用し、独自のルールを作成することを推奨します。

## 窒息

キャラクターは持久力技能に等しい秒数の間、呼吸を止めることができます。ただし、キャラクターは準備をしておく（肺をできるだけ多くの空気で満たす）必要があります。準備ができていない場合、キャラクターが受動的な状況であればその期間は半分になり、激しい活動に従事していた場合は5分の1に減少します。

息を止めている期間が終わると、キャラクターは持久力判定を行わなければなりません。

- 判定が「大成功」なら、それ以上の悪化は起こりません。
- 判定が「成功」なら、キャラクターは疲労レベルを1段階追加で蓄積します。
- 判定が「失敗」なら、キャラクターはそのラウンド中に1d2段階の疲労を追加で受けます。
- 判定が「ファンブル」なら、キャラクターはそのラウンド中に1d3段階の疲労を追加で受けます。

助けがなければ、窒息による死は通常迅速です。窒息が終わる前にキャラクターが死亡しなかった場合、窒息によって失われた疲労レベルは比較的早く回復し、1分につき1段階ずつ回復します。

窒息の方法によっては、ゲームマスターは完全な回復を防ぎ、永続的な疲労レベルを課すことを望むかもしれません（[疲労](0004_Game_System.md?id=fatigue)のセクションを参照）。これは煙や水の吸入によって肺が受けたダメージを表現するためです。

## キャラクターの成長

すべての _Mythras Imperative_ のキャラクターは、時間と経験とともに成長できます。成長はいくつかの領域で行うことができます。

- 既存の技能を上昇させる
- 情熱を上昇させる
- 新しい技能を習得する
- 新しい能力を習得する

#### 経験ロール

ほとんどのキャラクター成長のためのメカニズムは経験ロールです。ゲームマスターは、キャンペーンの適切な節目（各シナリオやストーリーラインの終了時、あるいは完結までに時間がかかる長いストーリーであれば2～3回のセッション終了後など）で経験ロールを配布します。頻度はゲームマスターの裁量です。経験ロールの頻度が高いほど、キャラクターはより速い速度で成長します。

経験ロールを与えるのに正しいタイミングや間違ったタイミングはありませんが、ストーリーの自然な区切りが適切な時期を示唆している可能性があります。しかし、決定を下すのは常にゲームマスターです。プレイヤーは経験ロールを要求することはできませんが、ある時点ではそれを期待する権利があります。なぜなら、経験ロールなしではキャラクターは成長できないからです。

付与される経験ロールの数もゲームマスターによって決定されます。ただし、前回の付与からセッションごとに1〜3回の経験ロールを与えるのが目安として適切です。

#### 既存の技能の上昇

キャラクターシート上の標準技能または専門技能は、経験ロールを1つ消費することで上昇させることができます。プレイヤーは経験ロールを技能の上昇に使わず、他のもの（クラス能力など、後述）を上昇させるために蓄えておくことを選ぶこともできます。

プレイヤーは1d100を振り、上昇させる対象の技能と比較します。この判定にはキャラクターの知力修正値が加算されます。

- 出目が上昇させる技能の値以上であれば、技能は1d4+1%上昇します。
- 出目が選択した技能の値未満であれば、技能は上昇しますが、1%のみとなります。
- 前回のセッション中（最後の経験ロール配布から今回までの間）にその技能で「ファンブル」したことがあれば、その技能は1%の無料上昇を得ます。我々は成功よりも失敗から多くを学ぶものであり、これは破滅的な失敗の後にキャラクターが行う反省を表現しています。同じ技能で複数回ファンブルしても累積はしません。ファンブルした技能を経験ロールで上昇させる場合、ファンブルによる1%は、上昇のための判定を行う前に適用されます。

同じ技能は、1回のセッションにつき1回しか経験ロールの恩恵を受けられません。

#### 情熱の上昇

[情熱](0002_Characters.md?id=step-8-passions)のセクションで説明したように、情熱の値は技能と同じ方法で経験ロールを使用して上昇させることができます。ゲームプレイで裏付けがある場合、ゲームマスターは経験ロールを使用して情熱を減少させることを許可してもよいでしょう。

_例えば、報われない恋による絶え間ない拒絶は、たとえ最も熱烈な恋人であっても、特に過去の亡霊に悩まされることなく新しい関係を追求したいと願うのであれば、その情熱を最終的に摩耗させてしまうかもしれません。_

#### 新しい技能の習得

キャラクターの中には、自身の文化からは学ぶ機会のなかった新しい専門技能を学びたいと望む者がいるかもしれません。経験ロールを投資し始める前に、まず学習するための知識源を見つける必要があります。これは、騎士団やギルドが提供する専門の教師のような平凡なものかもしれません。あるいは、古くボロボロになった訓練の巻物のような、よりエキゾチックな教育源かもしれません。

学習源を見つけたら、キャラクターはその技能の基本的な基礎（初期レベルでの習得）を得るために、1か月間まるごとの学習と練習に費やさなければなりません。これには3つの経験ロールに加え、教師が存在する場合はその報酬、および必要となる可能性のある道具や機材の購入（またはレンタル）に必要なゲーム内費用がかかります。

## 病気と毒

キャラクターに影響を与える可能性のある最も恐ろしいもののいくつかは、世界の暗く陰惨な場所に蔓延する無数の病気と毒です。自分の住む都市を襲う疫病、特にまだその門の中にいるときにそれを知ることは、これ以上ないほど不穏なものです。同様に、ベッドの中に毒蛇を見つけたり、巨大なサソリに襲われたりすることは、高いドラマ性を生む瞬間となり得ます。

病気と毒の種類は無限に近いですが、ゲームの目的上、どちらも同じ方法で扱われます。

#### 病気と毒の特性

すべての病気と毒は、その効果にとって重要な多くの特性を発現させます。

**適用:** 病気や毒が犠牲者に侵入する方法。

- **摂取:** 飲食を通じて効果が現れる。
- **吸入:** 呼吸や鼻からの吸入を通じて効果が現れる。
- **接触:** 皮膚からの吸収を通じて効果が現れる。
- **注射:** 突き刺しにより物質が体内に注入されたときに効果が現れる。

**効力:** 病気や毒の毒性。この値は対抗ロールにおいて適切な抵抗技能（通常は持久力または意志力）と競われます。キャラクターが判定に勝てば、その効果を跳ね除けます。判定に負ければ、病気や毒のすべての状態変化を、それぞれ適切なタイミングで被ることになります。

**抵抗:** 病気や毒にどのように抵抗するか。通常は持久力または意志力ですが、よりエキゾチックな抵抗が必要な場合もあります。抵抗は暴露した瞬間に判定することも、キャラクターが感染や中毒している事実を隠すために発症時間まで先送りにすることも可能です。

**発症時間:** 多くの病気や毒は即座に効果を発揮しません。この遅延を発症時間と呼び、秒、分、時間、あるいはそれ以上の場合もあります。複数の効果を持つ毒や病気は、状態変化のセクションで説明されているように、それぞれに対して異なる発症時間を持つ場合があります。

**持続時間:** 病気や毒の状態変化が続く期間。

**状態変化:** すべての毒素は1つ以上の状態変化を持ちます。これらは以下の「状態変化表」で説明されている特定の効果を持ち、犠牲者が抵抗に失敗した場合、説明されているすべての状態変化を被ります。

**解毒剤/治療法:** 毒素が治療可能な場合は、ここに記載されます。治療に成功すればそれ以上の状態変化の発生を防げますが、状況によっては犠牲者に既に与えられた永続的な影響が残る場合があります。

##### 状態変化表

| 状態変化 | 効果 |
| :-- | :-- |
| 激痛 | 犠牲者は激しい痛みに妨げられる。部位判定または全身のいずれであれ、影響を受けた部位を使用するすべての技能判定は、キャラクターの意志力以下でなければならず、そうでなければ判定は失敗し、苦痛のあまり呻いたり叫んだりする。 |
| 窒息 | 犠牲者は窒息を被る。行動不能となって崩れ落ち、呼吸ができなくなる。[窒息](0004_Game_System.md?id=asphyxiation)セクションのルールが使用される。窒息は喘息のような性質を持つ場合があり、その場合は息切れのみを引き起こすか、あるいは死に至る完全な呼吸不全を引き起こす可能性がある。後者の場合、犠牲者は応急手当技能による病気や毒の効力との対抗判定に勝利することで生き延びることができる。 |
| 出血 | 犠牲者は内出血または表面的な出血を被り、以下の[疲労](0004_Game_System.md?id=fatigue)および[失血](0004_Game_System.md?id=blood-loss)セクションで説明される疲労と回復時間につながる。 |
| 伝染性 | 犠牲者は接触によって毒や病気を移すことができる。 |
| 死亡 | 犠牲者は行動不能となって崩れ落ち、体力特性値に等しいラウンド後に死亡する。 |
| 発熱 | 犠牲者の体温が激しく変動する（暑くなったり寒くなったりする）とともに、筋肉痛が起こる。すべての技能判定は「困難」の難易度を受ける。 |
| 狂気 | 犠牲者は、水を避ける、偏執病、自傷行為など、何らかの強迫観念に従うよう駆り立てられる。病気や毒によって引き起こされる狂気の種類は、その説明に記される。 |
| 吐き気 | 犠牲者は食事ができず、ストレスのかかる物理的行動を行うたびに、物理的に嘔吐するのを避けるために持久力で判定しなければならない。嘔吐は1d3ラウンド続き、その間は行動不可となる。長期間の吐き気は飢餓を引き起こす可能性がある。 |
| 麻痺 | 犠牲者は物理的に動くことができない。影響を受けた部位は、その持続時間中は使用できない。全身に影響がある場合、キャラクターは全く動けなくなる。 |

#### 病気の例：赤斑病（レッドポックス）

赤斑病は、既に感染している人物との皮膚接触、またはその人物が触れたものを通じて広がる厄介な病気である。物体からの感染の可能性は接触後1d3日間続くため、一度発生すると封じ込めるのが非常に困難である。

犠牲者は最初に小さな発疹を患うが、1日以内に重い発熱に見舞われ、通常は全期間を通じて寝たきりになる。この間、発疹は恐ろしく痒い膿疱へと進化し、わずかな動きで破裂して少量の血液が滲み出る。これは特に脇の下や鼠蹊部から顕著である。この段階は1週間以上続く可能性があり、致命的となる恐れがある。

- **適用:** 接触
- **効力:** 50
- **抵抗:** 持久力
- **発症時間:** 1d6+6時間
- **持続時間:** 1d6+3日
- **状態変化:** 病気が発症すると、犠牲者は「伝染性」を持つようになる。1日後、彼らは「発熱」と「出血」に苦しみ始める。膿疱が血を流す各日、犠牲者は疲労レベルを1段階失い、これは病気の持続期間が終了するまで回復しない。
- **解毒剤/治療法:** 応急手当技能で治療可能。

## 落下

落下によって受けるダメージは、落下の距離に依存する。防具は落下ダメージを軽減しないが、落下したキャラクターやクリーチャーのダメージ修正は、落下から被るダメージに適用される。

##### 落下距離表

| 落下距離 | 被るダメージ |
| :-- | :-- |
| 1メートル以下 | ダメージなし。 |
| 2-5メートル | ランダムな1部位に1d6ダメージ。 |
| 6-10メートル | ランダムな2部位に2d6ダメージ。 |
| 11-15メートル | ランダムな3部位に3d6ダメージ。 |
| 16-20メートル | ランダムな4部位に4d6ダメージ。 |
| +5メートルごと | +1d6ダメージ。 |

#### 落下物

落下物は、その体格と落下距離に基づいてダメージを与える。物体は体格6ポイント（またはその端数）につき1d6のダメージを与え、さらに「落下距離表」の「被るダメージ」列に等しいダメージ量を加算する（小さいサイズの物体に対する減算を含む）。

## 疲労

疲労は疲れと、その累積的な影響を測定する。これは激しい活動から病気の無力化させる影響まで、さまざまな事象を追跡するために使用される。

疲労を蓄積する主な方法は、何らかの身体活動に従事することである。運動や作業が過酷であればあるほど、キャラクターはより早く疲労する。ゲームマスターの裁量により、キャラクターは疲労レベルの増加を抵抗するために、適切な技能（運動、腕力、または持久力）で判定を行わなければならない。

判定に失敗するたびに、疲労レベルが1段階増加する。各疲労レベルは、技能使用、移動、イニシアチブ、および行動ポイントに対するペナルティを伴う。窒息、失血、その他の設定依存の影響も疲労の蓄積に寄与する。

ほとんどのキャラクターにとって、「無力化」のレベルに達すると、あらゆる種類の活動がほとんど不可能になる。この段階では、キャラクターは意識はあるものの、最も必死な活動以外のことは何もできない。

「無力化」を超えると、キャラクターは全く行動できなくなる。「半意識」「昏睡」「死亡」といった疲労レベルは、一般的に窒息、病気、失血、飢餓、露出などの最も極端な影響を測定するために予約されている。

#### 疲労からの回復

キャラクターは自身の治癒率に応じて疲労から回復する。蓄積された疲労の各レベルから回復するために必要な完全な休息の量は、回復期間をキャラクターの治癒率で割ったものに等しい。

| 息切れ | 困難 | ペナルティなし | ペナルティなし | ペナルティなし | 15分 |
| 疲れ | 困難 | -1メートル | ペナルティなし | ペナルティなし | 3時間 |
| 困憊 | 至難 | -2メートル | -2 | ペナルティなし | 6時間 |

## 火

火は武器として使用されるとき、あるいは制御不能になって燃え広がるとき、常に危険の源となる。以下の火炎強度表は、熱ダメージに対する5つの異なる強度と、いくつかの例を示している。ラウンドごとに与えられるダメージは「ダメージ」列に記載されている。比較的サイズが小さいため、強度1および2の光源は、通常は接触している単一の部位判定に対してそのダメージを適用する。強度3および4の光源はより大きく、放射熱の度合いに応じて、最も近い1d4+1の部位判定にダメージを適用する。強度5の光源は、すべての部位判定に同時に影響を与える。

火は可燃物に引火する可能性がある。即座に消火されない場合、そのような物質は火炎の強度によって示されるラウンド数以内に燃焼する。一度引火すると、可燃物は物理的に消火されるまで燃え続ける。ダメージは防具を無視して物質のヒットポイントに直接適用され、その下にある肉体にも適用される。制御されずに放置された場合、その強度と同じ数の部位判定にラウンドごとに燃え広がる。

##### 火炎強度表

| 強度 | 例 | 引火までの時間 | ダメージ |
| :-: | :-- | :-: | :-: |
| 1 | ろうそく | 1d4 | 1d2 |
| 2 | 松明 | 1d3 | 1d4 |
| 3 | キャンプファイア | 1d2 | 1d6 |
| 4 | 部屋を満たす大火災 | 1d2 | 2d6 |
| 5 | 火山の溶岩 | 即時 | 3d6 |

火炎ベースの攻撃は通常、1ラウンドで終了するため、一般的に可燃物に引火するパーセンテージの確率を持つ。特に記載がない限り、この確率は火炎ベースの攻撃では「ダメージ出目×5%」、電気ベースの攻撃では「ダメージ出目×1%」である。一度引火すると、可燃物は物理的に消火されるまで毎ラウンド1d3-1ダメージ分燃焼する。このダメージを、防具を無視して物質のヒットポイントに直接適用し、その下にある肉体にも適用する。ただし、クリーチャーの自然防具は通常の保護を提供する。犠牲者は伏せて横たわり、「運動」判定に成功することで炎を消そうと試みることができる。これには行動ポイントが必要であり、各ターンに試みることができる。他者が何らかの方法で炎を消すのを助ける場合、判定の難易度は1段階簡単になる。ダメージ判定の結果がゼロの場合、その部位では火は自然に消えている。自然に消えた部位ごとに、炎を消すための判定も1段階簡単になる。

## ゲーム時間

_Mythras Imperative_ において、時間は重要な要素である。これは主に、どの順序で何が起こるかを決定し、ゲームメカニクスを適切なタイミングで適用するために使用される。ゲーム内の時間は、通常プレイに費やされる時間とは等しくないことを覚えておいてほしい。ゲームマスターは、「城アンソラックスに到達するまで1週間かかる」といった一文で数日間の出来事を要約する必要がある場合もあれば、特に戦闘中など、わずか数秒の行動を解決するために数分以上かかる場合もある。

以下は、ゲーム時間における重要な区別である。

#### 戦闘ラウンド

戦闘ラウンドは、現実時間の5秒間を表す。これは、完了するまでに瞬間的な激しい活動のバーストを測定したり、一撃ごとの解決を必要とする非常に詳細な活動を測定するために使用される。例えば、狩人と獲物の間の追跡において、各ラウンドが追跡の紆余曲折を決定する場合などである。

#### 技能時間

技能時間は数分から数時間の範囲を表し、戦闘ラウンドのような詳細な注意を必要としないが、明確な結果を伴う特定の努力の熟慮を必要とする活動を測定するために使用される。鍵を開けるには5分かかるかもしれないが、城壁の周囲を警備する衛兵隊のパトロールを観察するには数時間を必要とする場合があり、これらは両方とも技能時間の例である。#### ナラティブ・タイム

これは、ゲームマスターがプレイヤーに対して物語を語っているとき、あるいはプレイヤー同士で議論しているときに経過する時間のことである。特別な理由がない限り、実際のロールプレイの大部分はこのナラティブ・タイムの中で行われる。ロールプレイ中、ナラティブ・タイムは現実の時間と似た経過をたどり、会話にかかる時間はプレイするのにかかる時間と同じである。ゲームセッションに長旅が含まれている場合や、正確な時間が重要ではない活動期間がある場合、時間はゲーム内時間において数瞬という形に大幅に圧縮される。

## 部位判定

成功した（武器による）攻撃のほとんどは、特定の部位判定に命中する。これはランダムに決定することもできるし、状況によっては「部位選択」のような特殊効果によって選択することもできる。どの部位に命中したかをランダムに算出するには、d20をロールし、その数値を適切な人型生物またはクリーチャーの部位判定表と比較する。

動物やモンスターは通常、人型生物とはわずかに異なる部位判定表を持っており、それら独自の生理機能を反映している。これらは各存在の記述の一部として記載されており、通常はゲームマスターのみが使用するものである。

人型生物の部位判定表をここにも再掲する。

##### 人型生物の部位判定

| 1d20 | 位置 |
| :-: | :-- |
| 1-3 | 右脚 |
| 4-6 | 左脚 |
| 7-9 | 腹部 |
| 10-12 | 胸部 |
| 13-15 | 右腕 |
| 16-18 | 左腕 |
| 19-20 | 頭部 |

魔法や技術による攻撃、あるいは特定のモンスター（ドラゴンの火炎の息や手榴弾の爆発など）によって発生する攻撃の一部は、複数の位置に同時に命中する場合があることに注意されたい。個々の位置は、着用している防具によって、あるいはクリーチャーの体表の自然な硬さによって、防具として機能する場合がある。これは、以下のダメージと負傷段階を考慮する際に重要となる。

## ダメージと負傷段階

攻撃が成功した場合、その武器のダメージ定数に従ってダメージが発生する。例えば、ショートソードは1d6のダメージを与える。

武器や攻撃によって算出されたダメージは、特定の条件によって以下の順序で修正される。

1. 攻撃を行うキャラクターのダメージ修正を適用する。
2. 武器を強化（あるいは減少）させる魔法によるダメージ修正を行う。
3. パリー（受け流し）された場合、武器サイズの比較に従ってダメージを適切に減少させる。
4. 命中した位置に防具がある場合、その防具の防具値の分だけダメージを減少させる。

攻撃によって与えられたダメージがゼロより大きい場合、その位置はその分のダメージを受け、その合計値が直ちにその位置のヒットポイントから差し引かれる。その位置に残ったヒットポイントと、結果として生じる負傷カテゴリーに留意すること。

- **軽傷:** 位置のヒットポイントがプラスの状態。
- **重傷:** 位置のヒットポイントがゼロ以下になった状態。
- **致命傷:** 位置のヒットポイントが、初期ヒットポイントと同等かそれ以上のマイナス値になった状態。

位置が重傷または致命傷を受けた場合は、以下のルールを使用する。耐久力判定を必要とする負傷については、元の攻撃ロールの数値に対する抵抗ロールとして判定を行うことに留意されたい。これは、熟練した戦士がより致命的な一撃を与える能力を反映している。耐久力ロールは、その部位が再び負傷しない限り繰り返されない。

### 軽傷

軽傷とは、切り傷、擦り傷、打撲、捻挫などのことである。痛みがあり出血することもあるが、被害者の動きを鈍らせたり妨げたりするほどのものではない。

### 重傷

ある部位がヒットポイントゼロ以下に減少した場合、被害者は重傷を負う。その部位には永久的な傷が残り、被害者は（パリーや回避は可能だが）痛みによる混乱や集中力の欠如のため、次の1d3ターンの間、攻撃や呪文の詠唱開始を行うことができない。

四肢に重傷を負ったキャラクターは、即座に自身の耐久力と敵の攻撃成功ロールを比較する抵抗ロールを行わなければならない。失敗すると、その部位がプラスのヒットポイントに回復するまで、その四肢は使用不能となる。脚であれば被害者は伏せ状態になる。腕であれば、ストラップなどで固定されている場合を除き、手に持っていたものはすべて取り落とす（ここには常識を適用すること）。

腹部、胸部、または頭部に重傷を負ったキャラクターは、即座に自身の耐久力と敵の攻撃成功ロールを比較する抵抗ロールを行わなければならない。失敗すると、重傷を引き起こした攻撃のダメージ量と同じ分だけ（単位は分）意識を失う。応急手当または治癒の技能を使用して、意識不明の被害者の意識を取り戻す手助けをすることができる。

ゲームマスターの裁量により、キャラクターが行動可能であっても、その部位を使用するすべての作業は、負傷が軽傷に回復するまで、継続して難易度が一段階上昇するペナルティを受ける。

### 致命傷

ある部位がその初期ヒットポイントと同等かそれ以上のマイナス値に減少した場合、キャラクターは致命傷を負う。キャラクターは即座に無力化され、戦闘を継続することができなくなる。致命傷を受けると、四肢が切断されるか、貫通されるか、粉砕されるか、あるいは引きちぎられる。キャラクターは伏せ状態になり、物理的に無力化される。そして即座に自身の耐久力と敵の攻撃成功ロールを比較する抵抗ロールを行わなければならない。失敗すると、激痛により意識を失う。切断、貫通、引きちぎられた部位が、自身の治癒率の5倍の分（単位は分）以内に手当てされない場合、キャラクターは失血とショックにより死亡する。

腹部、胸部、または頭部に致命傷を負った被害者は意識を失い、完全に無力化され、即座に自身の耐久力と敵の攻撃成功ロールを比較する抵抗ロールを行わなければならない。失敗すると、即死（斬首、胴体切断、心臓貫通、四肢引き裂きなど）となる。生存した場合でも、キャラクターの治癒率の2倍の分（単位は戦闘ラウンド）以内にその部位が手当てされない限り、やはり失血とショックにより死亡する。

ほとんどの致命傷は手術や大規模な魔法による治療を必要とするため、負傷者が戦闘に復帰できるほど回復することは極めて難しい。利用可能な治療法に応じて、負傷した部位は後遺症が残る可能性がある（以下の[負傷からの回復](0004_Game_System.md?id=healing-from-injury)を参照）。

### 失血

通常は戦闘で負う外傷や内傷による失血は、キャラクターを非常に急速に衰弱させる可能性がある。その影響は、窒息と同様に疲労レベルの蓄積によって測定される。制限のない失血は、通常、何らかの医療処置がなければ死に至る。窒息とは異なり、深刻な失血による疲労への影響は持続する。キャラクターが出血による疲労を回復する速度は1日につき1レベルで、出血が止まった翌日から開始される。

### 英雄的な最後の行動

重要なキャラクターが致命傷を負うような特別なケースでは、ゲームマスターは英雄的な最後の行動を許可するかもしれない。例えば、最後の呪文を唱える、自分を殺した相手を倒そうとする、這いずって隠れる、あるいは自分自身の傷に止血帯を巻こうとするなどである。彼らはその行動に適した機能する四肢を持っており、幸運ポイントを消費しなければならない。彼らは行動を試みる機会を1回だけ得て、その後すぐに意識を失い、死に至る可能性が高い。

## 負傷からの回復

傷や怪我からの自然治癒は、キャラクターの治癒率に基づいている。治癒率は、怪我の性質に応じて、部位のヒットポイントがどれだけ回復するかを決定する。

- **軽傷:** 日
- **重傷:** 週
- **致命傷:** 月

したがって、治癒率が3のキャラクターがダメージを受けて、ある部位が-3（重傷）になった場合、その部位のヒットポイントがプラスになるまで週に3ヒットポイントずつ自然治癒し、その後は完全に回復するまで1日につき3ヒットポイントずつ回復する。

自然治癒には特定の制限がある。

- 治癒中のキャラクターは激しい活動を行うことができない。さもなければ、治癒率は1d3減少する。したがって、軽傷から回復中のキャラクターであっても、怪我を悪化させる可能性のある物理的な作業に従事することを選択すれば、治癒の進捗が止まってしまう可能性がある。
- 自然治癒は、被害者が応急手当のロールを成功させるか、何らかの治癒魔法を受けるまでは、致命傷を回復させない。切断に至らない致命傷で、治癒技能の20分の1（単位は日）以内に手当てされなかったものは、後遺症が残り、その部位のヒットポイントが永久的に減少する。

## 無生物

すべての無生物は、ダメージに対する抵抗力と破壊を判定するために使用される防具値とヒットポイントを持つ。防具値はヒットポイントに影響が出る前にダメージを減少させる。一度オブジェクトのヒットポイントがゼロに減少すると、それは無用となる。

破壊の試みには、キャラクターがダメージを与えるために適切に筋力、徒手、または戦闘スタイルでロールを行う必要がある。成功すればアイテムにダメージを与える。

#### 武器 vs 無生物

武器の防具値と同等かそれ以上の防具値を持つ無生物に対して武器を使用すると、対象物と武器の両方にダメージを与える。例えば、鉄の扉に斧を使用すると扉にダメージを与える可能性があるが、斧そのものは鉄の扉よりもずっと先に破壊されるだろう。ゲームマスターは、どの武器や道具がどの対象物に影響を与えられるかについて裁量を行使すべきである。例えば、タガネは明確に木や石を削るために設計されているが、剣は鋭いとはいえ、そうではない。したがって、タガネは自分が削ろうとしているものからダメージを受けることはないが、剣はダメージを受ける可能性が高い。

## 幸運ポイント

幸運ポイントは、英雄と一般人を区別するのに役立つ。これはキャラクターが失敗を成功に変え、死さえも回避する可能性のある能力を象徴している。

幸運ポイントはプレイ中に使用でき、次のセッションの開始時に通常の数値まで補充される。

#### 幸運ポイントの使用

幸運ポイントはさまざまな方法で使用できる。特定の行動を支援するために使用できる幸運ポイントは1点のみである。幸運ポイントを経験や訓練のロールに消費することはできない。以下の各オプションは、幸運ポイントを1点消費する。

#### 運命の操作

キャラクターは幸運ポイントを使用して、自分が行うあらゆるダイスロールを振り直す、または入れ替える（例えば75を57にするなど）ことができる。これは技能ロール、ダメージロール、あるいは何らかの影響を与えるその他のすべてのロールが対象となる。キャラクターは、対戦相手に自分に対して行われた攻撃ロールやダメージロールを振り直させることさえできる。

#### 必死の努力

戦闘中にキャラクターが行動ポイントを使い果たし、悲惨な結末を回避するために最後の一押しとなる必死のエネルギーが必要な場合、幸運ポイントを消費して行動ポイントを1点追加で得ることができる。

#### ダメージの軽減

致命傷を負ったキャラクターは幸運ポイントを消費して、その怪我を重傷へと一段階引き下げることができる。これにより、受けるダメージは致命傷を与えるために必要な数値より1ヒットポイント少ない値まで軽減される。
