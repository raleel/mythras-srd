# ゲームシステム

_Mythras Imperative_のゲーム中には、さまざまな事象が発生します。そのいくつかは、技能の使用や、戦闘や魔法といった主要なゲームメカニクスを通じて解決されます。また、それ以外の場合は、判定のための独自のルールが必要になります。本章では、プレイヤーがゲームをプレイする際に遭遇する、多種多様なシナリオに対するルールとガイダンスを提供します。

ここに挙げたリストがすべてではありませんが、最も一般的な状況を網羅しています。もしゲームマスターが、本システムで何らかの判定を必要とする他の状況に頻繁に遭遇する場合、本章で示されたルールを基準にして、それらの特別な状況をカバーするための独自のルールを作成することを推奨します。

## 窒息（Asphyxiation）

キャラクターが息を止めていられる秒数は、〈耐久力〉技能の値と同じです。ただし、キャラクターは事前に準備（肺にできる限りの空気を吸い込む）をしている必要があります。もし準備をしていなければ、その時間は半分になります。キャラクターが受動的な状況にあった場合はさらに短縮され、激しい活動に従事していた場合は、その時間は5分の1に減少します。

息を止めていられる時間が過ぎると、キャラクターは〈耐久力〉判定を行わなければなりません。

- クリティカル成功の場合、それ以上の悪化は起こりません。
- 成功の場合、キャラクターは〈疲労〉レベルを1段階余分に受けます。
- 失敗の場合、そのラウンドで〈疲労〉レベルを1d2段階余分に受けます。
- ファンブルの場合、そのラウンドで〈疲労〉レベルを1d3段階余分に受けます。

助けがなければ、窒息による死は通常すぐ訪れます。キャラクターが死亡する前に窒息状態が終了した場合、窒息によって失った〈疲労〉レベルは比較的速やかに回復し、1分ごとに1レベルずつ回復します。

窒息の方法によっては、ゲームマスターは完全な回復を妨げたいと考えるかもしれません。その場合、煙や水の吸い込みによる肺への損傷を表現するために、持続的な〈疲労〉レベルを課すこともできます（[「疲労」](0004_Game_System.md?id=fatigue)のセクションを参照してください）。

## キャラクターの成長（Character Improvement）

すべての_Mythras Imperative_のキャラクターは、時間と経験を経て成長することができます。成長は以下のいくつかの分野で行うことができます。

- 既存の技能を上昇させる
- 〈情熱〉を上昇させる
- 新しい技能を習得する
- 新しい能力を習得する

#### 経験ロール（Experience Rolls）

キャラクターの成長における大半のメカニズムは「経験ロール」です。ゲームマスターは、キャンペーンの適切な節目で経験ロールを与えます。それは、成功したシナリオやストーリーラインの終了時、あるいは、ストーリーが長く完了までに時間がかかる場合は2～3回のセッション終了後などです。頻度はゲームマスターの裁量に委ねられます。経験ロールの頻度が高ければ、キャラクターはより速いペースで成長します。

経験ロールを与えるのに正しいタイミングや誤ったタイミングはありませんが、物語の自然な区切りが良い目安になります。ただし、最終的な決定権は常にゲームマスターにあります。プレイヤーは経験ロールを要求することはできませんが、経験ロールなしでは成長できないため、一定のポイントでそれを期待する権利はあります。

授与される経験ロールの数もゲームマスターが決定します。ただし、前回の授与からセッションごとに1〜3回の経験ロールを与えるのが目安となります。

#### 既存の技能の上昇

キャラクターシート上の標準技能であれ、プロフェッショナル技能であれ、どのような技能でも、経験ロールを1回消費することで上昇させることができます。プレイヤーは経験ロールを技能の上昇に使わず、蓄積しておいて他のこと（クラス能力など、後述）に使用することもできます。

プレイヤーは1d100を振り、上昇させたい技能と比較します。このロールにはキャラクターの〈知力〉（INT）が加算されます。

- 出目が技能値以上であれば、その技能は1d4+1%上昇します。
- 出目が技能値未満であれば、技能は上昇しますが、1%のみとなります。
- 直前のセッション中（前回の経験ロールから今回までの間）に技能判定でファンブルを起こしていた場合、その技能は1%のボーナス成長を得ます。私たちは成功よりも失敗から多くを学ぶものであり、これは致命的な失敗の後にキャラクターが行う反省を表現しています。同じ技能での複数のファンブルは累積しません。ファンブルした技能を経験ロールで上昇させる場合、ファンブルによる1%の上昇は、改善のためのロールを行う前に適用されます。

同じ技能は、1セッションにつき1回しか経験ロールの恩恵を受けられません。

#### 〈情熱〉の上昇

[「情熱（Passions）」](0002_Characters.md?id=step-8-passions)のセクションで説明されている通り、〈情熱〉の値も技能と同様に、経験ロールを使用して上昇させることができます。ゲーム内での行動によって裏付けられている場合、ゲームマスターは経験ロールを消費して〈情熱〉を減少させることを許可しても構いません。

_例：叶わぬ恋による絶え間ない拒絶は、たとえ最も熱烈な恋人であっても、やがてその〈情熱〉を削り取ってしまうかもしれません。特に、過去の亡霊に取り憑かれることなく新しい関係を築きたいと願うキャラクターにとっては尚更です。_

#### 新しい技能の習得

自分の文化圏では学ぶ機会がなかった新しい「プロフェッショナル技能」を学習したいと望むキャラクターもいるでしょう。経験ロールを投資し始める前に、まずは学習するための知識源を見つけなければなりません。これは、組織やギルドが提供する専門の教師のようにありふれたものかもしれませんし、古く朽ちかけた学習用スクロールのような、より異国情緒あふれる教育源かもしれません。

学習源が見つかったら、キャラクターは1ヶ月間、学習と練習に費やし、その技能の基礎を身につけなければなりません（基本レベルで習得します）。これには経験ロールが3回必要となり、さらに教師がいればその報酬を支払うか、必要な道具や設備を購入（またはレンタル）するためのゲーム内コストがかかります。

## 病気と毒（Disease and Poison）

キャラクターに影響を与える最も恐ろしいものの一つが、世界の暗く陰惨な場所に蔓延する無数の病気と毒です。キャラクターの故郷の都市を襲う疫病ほど不安をかき立てるものはありません。特に、キャラクターがまだその門の中にいる時は尚更です。同様に、ベッドの中に毒蛇を見つけたり、巨大なサソリに襲われたりすることは、高い緊張感を生む瞬間となるでしょう。

病気や毒の種類は無限に近いですが、ゲーム目的上は、どちらも同様に扱われます。

#### 病気と毒の特性

すべての病気と毒は、その効果にとって重要な数多くの特性を示します。

**感染経路（Application）：** 病気や毒が犠牲者の体内に侵入する方法。

- **経口（Ingestion）：** 飲食物を通じて効果が現れる。
- **吸入（Inhaled）：** 呼吸や鼻からの吸引を通じて効果が現れる。
- **接触（Contact）：** 皮膚からの吸収を通じて効果が現れる。
- **注射（Injected）：** 刺傷などによって直接体内に注入される。

**効力（Potency）：** 病気や毒の毒性。この値は、対抗ロールにおいて適切な抵抗技能（通常は〈耐久力〉か〈意志力〉）と対比されます。キャラクターがロールに勝てば、その影響を振り払うことができます。ロールに負けた場合、病気や毒のすべての「状態」を、それぞれのタイミングで被ります。

**抵抗値（Resistance）：** 病気や毒への抵抗方法。通常は〈耐久力〉か〈意志力〉ですが、より特殊な抵抗が求められる場合もあります。抵抗ロールは曝露した際に行うか、キャラクターが感染・中毒したことを隠すために「発症時間」まで先延ばしにすることもできます。

**発症時間（Onset Time）：** 多くの病気や毒は即座に効果が現れません。この遅延を発症時間と呼び、数秒、数分、数時間、あるいはそれ以上かかる場合があります。複数の効果を持つ毒や病気の場合、それぞれ「状態」に記載された通りに異なる発症時間を持つことがあります。

**持続時間（Duration）：** 病気や毒の「状態」が継続する期間。

**状態（Conditions）：** すべての毒素は一つ以上の「状態」を持っています。これらは以下の状態表に記載されている特定の効果を持ち、犠牲者が抵抗に失敗すると、記載されているすべての状態を被ります。

**解毒剤/治療（Antidote/Cure）：** 毒素を治療可能な場合、ここに記載されます。成功した治療は、それ以上の「状態」の発生を防ぎますが、状況によっては、すでに負わされた永続的な影響が犠牲者に残る場合があります。

##### 状態表

| 状態 | 効果 |
| :-- | :-- |
| 激痛 (Agony) | 犠牲者は激しい痛みに苦しむ。部位に関わらず、全身の痛みにより、影響を受けた部位を使う技能ロールはすべて、キャラクターの〈意志力〉以下でなければ成功しない。そうでなければ判定は失敗し、犠牲者は痛みでうめき声を上げたり叫んだりする。 |
| 窒息 (Asphyxiation) | 犠牲者は窒息する。気絶して崩れ落ち、呼吸ができなくなる。[「窒息」](0004_Game_System.md?id=asphyxiation)のセクションのルールを使用する。窒息は喘息的なもので息切れのみを引き起こす場合もあれば、死に至る完全な呼吸不全を引き起こす場合もある。後者の場合、病気や毒の効力に対して〈応急手当〉技能の対抗判定に勝利することで、犠牲者を生かしておくことができる。 |
| 出血 (Bleeding) | 犠牲者は内出血または表面的な出血に苦しむ。これは後述の[「疲労」](0004_Game_System.md?id=fatigue)および[「失血」](0004_Game_System.md?id=blood-loss)セクションで記述される疲労と回復時間のペナルティを招く。 |
| 伝染性 (Contagious) | 犠牲者は触れることで毒や病気を他者に移すことができる。 |
| 死 (Death) | 犠牲者は気絶して崩れ落ち、〈体格〉（CON）特性値に等しいラウンド後に死亡する。 |
| 発熱 (Fever) | 体温が激しく上下し（悪寒と高熱）、筋肉が痛む。すべての技能判定の難易度が「困難」になる。 |
| 狂気 (Mania) | 犠牲者は何らかの衝動に駆られる（水を避ける、偏執狂、自傷行為など）。病気や毒によって引き起こされる狂気の内容は、その記述に記される。 |
| 吐き気 (Nausea) | 犠牲者は食事をとれず、ストレスの多い身体行動をとるたびに〈耐久力〉判定を行わなければならず、失敗すると嘔吐してしまう。嘔吐は1d3ラウンド続き、その間は行動できない。長期にわたる吐き気は飢餓を引き起こす可能性がある。 |
| 麻痺 (Paralysis) | 犠牲者は身体的に動くことができない。部位への麻痺ならその間は使用不能となる。全身への麻痺なら、キャラクターは全く動くことができない。 |

#### サンプル病：赤斑病（Red Pox）

赤斑病は、すでに感染している人物、あるいは感染者が触れた物との皮膚接触によって広がるひどい病気です。物から感染する可能性は接触後1d3日間残るため、一度アウトブレイクが起こると収束させるのは困難です。

犠牲者は最初に軽度の発疹に苦しみますが、1日以内に深刻な発熱を伴い、通常は持続期間中ずっと寝たきりになります。この間、発疹はひどい痒みを伴う膿疱へと進化し、わずかな動きで破裂し、特に脇の下や股間から少量の血が滲み出ます。この段階は1週間以上続く可能性があり、致死的な結果を招く恐れがあります。

- **感染経路：** 接触
- **効力：** 50
- **抵抗値：** 〈耐久力〉
- **発症時間：** 1d6+6時間
- **持続時間：** 1d6+3日
- **状態：** 病気が発症すると、犠牲者は「伝染性」となる。1日後、「発熱」と「出血」に苦しみ始める。膿疱から血が滲み出るたびに犠牲者は〈疲労〉レベルを1失い、これは病気の持続期間が終了するまで回復しない。
- **解毒剤/治療：** 〈治療〉技能で治癒可能。

## 落下（Falling）

落下によって被るダメージは、落下距離に依存します。アーマーポイントは落下ダメージを軽減しませんが、落下したキャラクターやクリーチャーの「ダメージ修正値」は、落下で被るダメージに適用されます。

##### 落下距離表

| 落下距離 | 被ダメージ |
| :-- | :-- |
| 1メートル以下 | ダメージなし。 |
| 2-5メートル | 1d6ダメージをランダムな1部位に受ける。 |
| 6-10メートル | 2d6ダメージをランダムな2部位に受ける。 |
| 11-15メートル | 3d6ダメージをランダムな3部位に受ける。 |
| 16-20メートル | 4d6ダメージをランダムな4部位に受ける。 |
| 5メートル増すごとに | ダメージ+1d6。 |

#### 落下物

落下物は、そのSIZと落下距離に基づいたダメージを与えます。物体はSIZ 6ポイント（またはその端数）ごとに1d6のダメージを与え、さらに落下距離表の「被ダメージ」列に等しいダメージを加えます（小さなサイズの物体に対する軽減を含む）。

## 疲労（Fatigue）

疲労は、疲れとその累積的な影響を測定するものです。激しい活動から病気の衰弱効果に至るまで、さまざまなことを追跡するために使用されます。

疲労を蓄積する主な方法は、何らかの身体活動に従事することです。運動や作業が過酷であればあるほど、キャラクターはより早く疲労します。ゲームマスターの判断により、キャラクターは〈運動〉、〈筋力〉、または〈耐久力〉技能ロールを行い、疲労レベルの上昇に抵抗しなければなりません。

ロールに失敗するたびに、疲労レベルが1段階蓄積されます。各疲労レベルには、技能使用、移動力、イニシアチブ、アクションポイントに対するペナルティが伴います。窒息、失血、その他の設定に応じた影響も、疲労の累積に寄与します。

ほとんどのキャラクターにとって、「無力状態（Incapacitated）」に達すると、あらゆる活動がほぼ不可能になります。この段階では、キャラクターは意識はあるものの、最も絶望的な活動以外のことは何もできません。

無力状態を超えると、キャラクターは一切行動できなくなります。「半意識状態」、「昏睡状態」、「死亡」という疲労レベルは、一般的に窒息、病気、失血、飢餓、露出などによる極限の影響を測定するために予約されています。

#### 疲労からの回復

キャラクターの疲労回復は「治癒率（Healing Rate）」に依存します。蓄積された疲労の各レベルから回復するために必要な完全な休息時間は、「回復期間」をキャラクターの治癒率で割ったものに等しくなります。

以下の表は身体的労力に対する疲労回復を表していることに注意してください。窒息からの回復はより速くなる可能性があり、失血からの回復の場合はより遅くなる可能性があります。

| 疲労 | 困難 | -1メートル | ペナルティなし | ペナルティなし | 3時間 |
| 消耗 | 絶望的 | -2メートル | -2 | ペナルティなし | 6時間 |

## 火（Fires）

火は、武器として使用される場合も、制御不能になって燃え広がる場合も、常に危険の源です。以下の「火の強度表」は、熱ダメージに対する5つの異なる強度といくつかの例を示しています。ラウンドごとに与えられるダメージは「ダメージ」列に記載されています。比較的規模が小さい強度1と2の火源は、そのダメージを1つのヒットロケーションに適用します（通常は火源に触れている場所）。強度3と4の火源はより大きく、放射熱の度合いに応じて、最も近い1d4+1箇所のヒットロケーションにダメージを適用します。強度5の火源は、すべてのヒットロケーションに同時に影響を与えます。

火は可燃物に引火する可能性があります。直ちに消火されない場合、そのような物質は火の強度に応じたラウンド数で燃え上がります。一度引火すると、可燃物は物理的に消火されるまで燃え続けます。ダメージはアーマーポイントを無視して物質のヒットポイントに直接適用され、その下の肉体にも適用されます。放置すると、強度に等しいヒットロケーション数ずつ、ラウンドごとに火は広がります。

##### 火の強度表

| 強度 | 例 | 引火までの時間 | ダメージ |
| :-: | :-- | :-: | :-: |
| 1 | ろうそく | 1d4 | 1d2 |
| 2 | 松明 | 1d3 | 1d4 |
| 3 | キャンプファイヤー | 1d2 | 1d6 |
| 4 | 部屋を満たす火災 | 1d2 | 2d6 |
| 5 | 火山の溶岩 | 即時 | 3d6 |

火による攻撃は、通常1ラウンドで終了するため、一般的に可燃物に引火するパーセンテージチャンスを持ちます。特に注記がない限り、この確率は「火による攻撃はダメージロール×5%」、「電気による攻撃はダメージロール×1%」です。一度引火すると、可燃物は物理的に消火されるまで、毎ラウンド1d3-1のダメージを燃焼させます。このダメージをアーマーポイントを無視して物質のヒットポイントに直接適用し、その下の肉体にも適用します。ただし、クリーチャーの自然装甲は通常通り機能します。犠牲者は伏せ状態になって〈運動〉ロールを成功させることで消火を試みることができます。これにはアクションポイントが必要であり、各ターン試みることができます。他者が何らかの形で消火を助ける場合、そのロールの難易度は1段階易しくなります。ダメージロールの結果が0ダメージであった場合、その部位の火は自然に消えたことになります。自然に消えた部位ごとに、消火ロールの難易度も1段階易しくなります。

## ゲーム時間（Game Time）

_Mythras Imperative_において時間は重要な要素であり、主にどの順序で何が起こるかを決定し、ゲームメカニクスを適用すべき時に適用するために用いられます。ゲーム内時間は、プレイに費やす時間と必ずしも一致しないことを忘れないでください。ゲームマスターは「城に到着するまで1週間かかります」と一言で数日間の出来事を要約する必要があるかもしれません。その一方で、特に戦闘中は、わずか数秒の出来事を解決するのに数分以上かかることもあります。

以下は、ゲーム時間における重要な区別です。

#### 戦闘ラウンド（Combat Rounds）

戦闘ラウンドは現実時間の5秒を表します。これは完了するまでに瞬間を要する短く熱狂的な活動、あるいは一挙手一投足の解決を必要とする非常に詳細な活動を測定するために使用されます。例えば、狩人と獲物の追跡劇において、各ラウンドが追跡の紆余曲折を決定する場合などがこれに当たります。

#### 技能時間（Skill Time）

技能時間は数分から数時間を表し、戦闘ラウンドのような詳細な注意は必要としないものの、明確な結果を伴う特定の努力を測定するために使用されます。鍵開けは5分かかるかもしれませんし、城壁の周囲を巡回する衛兵の様子を観察するのは数時間を要するかもしれません。これらはいずれも技能時間の例です。

#### ナラティブ時間（Narrative Time）

これはゲームマスターがプレイヤーに語っている時、あるいはプレイヤー同士が議論している時に経過する時間です。特別な理由がない限り、実際のロールプレイの大半はナラティブ時間で行われます。ロールプレイにおいて、ナラティブ時間は現実時間に近い性質を持ち、会話にはプレイするのと同じだけの時間がかかります。セッションに長い移動や、正確な時間を必要としない活動が含まれる場合、時間は大幅に圧縮され、数瞬のゲーム時間となります。

## ヒットロケーション（Hit Locations）

成功した（武器による）攻撃のほとんどは、特定の「ヒットロケーション（命中部位）」に当たります。これはランダムに決定されるか、あるいは「部位選択（Choose Location）」のような特殊効果によって選択されます。命中した場所をランダムに計算するには、1d20を振り、該当する人型種族やクリーチャーのヒットロケーション表と比較してください。

動物やモンスターは通常、独自の特徴的な生理構造を反映して、人型種族とはわずかに異なるヒットロケーション表を持っています。これらは各生物の記述の一部としてリストされており、通常はゲームマスターのみが使用します。

人型種族のヒットロケーション表を、参照のしやすさのためにここに再掲します。

魔法、テクノロジー、特定のモンスター（ドラゴンの炎や手榴弾の爆発など）による攻撃は、同時に複数のヒットロケーションを打撃する場合があることに注意してください。個々のヒットロケーションは、装着している防具や、クリーチャーの外皮の自然な頑強さによって装甲化されている場合があります。これは以下のダメージおよび負傷レベルを考慮する際に重要です。

## ダメージと負傷レベル（Damage and Wound Levels）

攻撃が成功すると、武器のダメージレートに応じたダメージを与えます。例えば、ショートソードは1d6のダメージを与えます。

武器や攻撃のダイスによるダメージは、以下の順序で特定の条件により修正されます：

1. 攻撃を行うキャラクターの「ダメージ修正値」を適用する。
2. 武器を強化（または減少）させる魔法による修正を加える。
3. パリーされた場合、武器サイズの比較に基づいてダメージを適切に減少させる。
4. ヒットロケーションが装甲化されている場合、アーマーポイントの値をダメージから差し引く。

与えられたダメージが0より大きい場合、そのヒットロケーションはそのダメージを被り、ダメージ合計がその部位のヒットポイントから直ちに差し引かれます。その部位のヒットポイントが残りどれくらいか、そしてどのような負傷カテゴリになるかを確認してください。

- **軽傷（Minor Wound）：** ヒットロケーションのヒットポイントがプラスの状態。
- **重傷（Serious Wound）：** ヒットロケーションがヒットポイント0以下になった状態。
- **致命傷（Major Wound）：** ヒットロケーションが、開始時のヒットポイントと同等以上のマイナス値になった状態。

部位が「重傷」または「致命傷」を負った場合、以下のルールを使用してください。耐久力チェックが必要な負傷は、敵の元の攻撃ロール値との対抗判定として行います。これは、熟練した戦士がより致命的な一撃を与える能力を反映したものです。耐久力判定は、その部位が再び負傷しない限り繰り返されません。

### 軽傷

軽傷は切り傷、擦り傷、打ち身、捻挫です。痛みはあり、出血するかもしれませんが、犠牲者の動作を遅らせたり妨げたりするほどのものではありません。

### 重傷

ヒットロケーションがヒットポイント0以下になると、犠牲者は重傷を負います。その部位には永久的な傷が残り、犠牲者は次の1d3ターンの間、痛みによる気絶や混乱のため、攻撃したり呪文の詠唱を開始したりすることができません（ただし、パリーや回避は可能です）。

四肢に重傷を負ったキャラクターは、直ちに敵の攻撃ロールと自身の〈耐久力〉を競う対抗判定を行わなければなりません。失敗すると、その部位のヒットポイントがプラスに戻るまで、その四肢は使用不能になります。脚であれば、犠牲者は伏せ状態になります。腕であれば、保持しているものは落とします（固定されている場合などは常識的に判断してください）。

腹部、胸部、または頭部に重傷を負ったキャラクターは、直ちに敵の攻撃ロールと自身の〈耐久力〉を競う対抗判定を行わなければなりません。失敗すると、攻撃によって被ったダメージ値と同じ分だけの「分」の間、意識を失います。〈応急手当〉や〈治療〉技能を使用して、気絶した犠牲者の意識を戻すことができます。

ゲームマスターの裁量により、キャラクターが行動可能であっても、そのヒットロケーションを使用するすべてのタスクは、その負傷が「軽傷」に軽減されるまで、難易度に1段階のペナルティを課される可能性があります。

### 致命傷

ヒットロケーションが開始時のヒットポイントと同等以上のマイナス値になると、キャラクターは「致命傷」を負います。キャラクターは即座に「無力状態」となり、戦闘を継続できなくなります。致命傷により、四肢は切断されたり、貫通されたり、粉砕されたり、引きちぎられたりします。キャラクターは伏せ状態となり、肉体的に無力化され、直ちに敵の攻撃ロールと自身の〈耐久力〉を競う対抗判定を行わなければなりません。失敗すると、激痛により意識を失います。切断・貫通・引きちぎられた部位が「治癒率×5分」以内に治療されない場合、キャラクターは失血とショックで死亡します。

腹部、胸部、または頭部への致命傷の犠牲者は意識を失い、完全に無力化され、直ちに敵の攻撃ロールと自身の〈耐久力〉を競う対抗判定を行わなければなりません。失敗すると、即死（斬首、胴体切断、心臓貫通、引き裂かれるなど）します。生き延びたとしても、その部位が「治癒率×2ラウンド」以内に治療されない場合、失血とショックで死亡します。

ほとんどの致命傷は外科手術や強力な魔法による治療を必要とするため、戦闘中に復帰できるほど回復することはまずあり得ません。利用可能な治療法に応じて、負傷した部位は障害が残る可能性があります（後述の[「負傷からの回復」](0004_Game_System.md?id=healing-from-injury)を参照）。

### 失血（Blood Loss）

戦闘で被る外部および内部の傷による失血は、キャラクターを非常に素早く消耗させます。その影響は、窒息と同様に〈疲労〉レベルの蓄積によって測定されます。抑制されない失血は、通常、医療措置なしでは死を招きます。窒息とは異なり、深刻な失血が〈疲労〉に与える影響は永続的です。キャラクターは出血が止まった翌日から、1日1レベルの割合で、失血により失った〈疲労〉を回復します。

### 英雄的な最期の行動（Heroic Last Actions）

主要なキャラクターが致命傷を負った特別な場合、ゲームマスターは英雄的な最期の行動を許可するかもしれません。例えば、最後の呪文を唱える、とどめを刺そうとする、這いずって隠れる、自ら止血を試みるなどです。キャラクターはその行動に適した使用可能な四肢を持ち、〈幸運ポイント〉を消費しなければなりません。行動を試みる機会を1回だけ得た後、即座に意識を失い、おそらくは死を迎えます。

## 負傷からの回復（Healing from Injury）

傷や負傷からの自然治癒は、キャラクターの「治癒率」に基づきます。治癒率は、負傷の性質に応じて、各部位でどれだけのヒットポイントが回復するかを決定します：

- **軽傷：** 日単位
- **重傷：** 週単位
- **致命傷：** 月単位

したがって、治癒率3のキャラクターがヒットロケーションで-3のダメージを受けた（重傷）場合、傷が0以上になるまで週に3ヒットポイントずつ回復し、その後は完治まで1日に3ヒットポイントずつ回復します。

自然治癒には特定の制限があります：

- 治癒中のキャラクターは激しい活動に従事できません。さもなければ、治癒率は1d3減少します。したがって、軽傷からの回復中であっても、怪我を悪化させる可能性のある身体的作業に従事すれば、回復の進捗が止まる可能性があります。
- 致命傷の自然治癒は、〈治療〉ロールの成功や何らかの治癒魔法の詠唱による処置を受けるまで始まりません。治療されなかった非切断の致命傷は、〈治療〉技能の20分の1の「日」数が経過すると、その部位のヒットポイントが永続的に減少する障害（Maimed）となります。

## 無生物（Inanimate Objects）

すべての無生物は、ダメージへの抵抗力と破壊を決定するために使用される「アーマーポイント」と「ヒットポイント」を持っています。アーマーポイントはヒットポイントに影響が出る前にダメージを減少させます。物体のヒットポイントが0になると、それは使用不能になります。

破壊の試みには、適切な〈筋力〉、〈素手〉、あるいは〈戦闘スタイル〉ロールを行ってダメージを与える必要があります。成功すれば、アイテムにダメージを与えます。

#### 武器 対 無生物

武器のアーマーポイントと同等以上のアーマーポイントを持つ無生物に対して武器を使用すると、物体と武器の両方にダメージを与えます。例えば、鉄の扉に斧を使うと、扉はダメージを受けるかもしれませんが、斧自体は鉄の扉が壊れるよりずっと早く破壊されてしまうでしょう。ゲームマスターは、どの武器や道具がどの物体に影響を与えられるかを慎重に判断してください。例えば、のみ（鑿）は木や石を彫るために明確に設計されていますが、剣は鋭利ではあってもそうではありません。したがって、のみは彫ろうとしている対象からダメージを受けませんが、剣は受けやすいでしょう。

## 幸運ポイント（Luck Points）

幸運ポイントは、英雄と一般人を区別する要素です。これらは失敗を成功に変え、死さえも回避するキャラクターの能力を象徴しています。

幸運ポイントはプレイ中に使用でき、次のセッションの開始時に通常の最大値まで補充されます。

#### 幸運ポイントの使用

幸運ポイントは様々な方法で使用できます。特定の「行動」を支援するために使用できる幸運ポイントは1回につき1ポイントのみです。経験ロールやトレーニングロールに幸運ポイントを消費することはできません。以下の各選択肢には、幸運ポイントを1消費します。

#### 運命の操作（Cheat Fate）

キャラクターは幸運ポイントを消費して、自分が行ったダイスロールを振り直すか、入れ替える（例えば75なら57にするなど）ことができます。これは技能ロール、ダメージロール、あるいは何らかの影響を与えるその他のロールに使用できます。キャラクターは対戦相手に対し、自分に向けられた攻撃ロールやダメージロールを振り直させることさえ可能です。

#### 決死の努力（Desperate Effort）

戦闘中にアクションポイントを使い果たし、惨めな死を回避するために最後の一押しが必要な場合、キャラクターは幸運ポイントを消費して、追加のアクションポイントを得ることができます。

#### ダメージの軽減（Mitigate Damage）

致命傷を負ったキャラクターは、幸運ポイントを1消費して、その負傷を重傷に格下げすることができます。これにより、被ダメージは致命傷を負うために必要な値より1ヒットポイント低い値まで軽減されます。
