# ゲームシステム

_Mythras Imperative_ のゲーム中には、様々な事象が発生します。それらのいくつかは技能の使用、あるいは戦闘や魔法といった主要なゲームメカニクスを通じて解決されますが、また別のものは、判定のために独自のルールを必要とします。本章では、プレイヤーがゲーム中に遭遇するであろう多種多様なシナリオのためのルールと指針を提供します。

このリストは網羅的なものではありませんが、最も一般的な状況を網羅しているはずです。ゲームマスター（GM）が本章でカバーされていない状況でゲームシステム上の裁定が必要であると感じ、かつそのような状況が頻繁に発生する場合は、本章の記述を複製または発展させる基礎として、独自のルールを作成することを推奨します。

## 窒息

キャラクターは、自身の持久力技能に等しい秒数の間、息を止めることができます。ただし、キャラクターは（肺をできるだけ多くの空気で満たすなどの）準備をしておく必要があります。準備ができていない場合、受動的な状況であればこの時間は半分に減り、激しい活動に従事していた場合は5分の1に減少します。

息を止めている時間が終了すると、キャラクターは持久力判定を行わなければなりません。

- クリティカル成功の場合、さらなる悪化は発生しません。
- 成功の場合、キャラクターは疲労レベルを1段階追加で蓄積します。
- 失敗の場合、キャラクターはそのラウンド中に1d2段階の疲労を追加で受けます。
- ファンブルの場合、キャラクターはそのラウンド中に1d3段階の疲労を追加で受けます。

助けがなければ、窒息による死は通常迅速です。キャラクターが死亡する前に窒息が終了した場合、窒息によって失われた疲労レベルは比較的早く回復し、1分ごとに1レベルが回復します。

窒息の方法によっては、ゲームマスターは完全な回復を妨げ、（[疲労](0004_Game_System.md?id=fatigue)のセクションを参照）煙や水の吸引によって肺に受けたダメージを表現するために、永続的な疲労レベルを課すことを望むかもしれません。

## キャラクターの成長

すべての _Mythras Imperative_ のキャラクターは、時間と経験を経て成長することができます。成長は以下のいくつかの領域で行うことができます。

- 既存の技能の向上
- 情熱の向上
- 新しい技能の習得
- 新しい能力の習得

#### 経験ロール

ほとんどのキャラクター成長のメカニズムは、経験ロールです。ゲームマスターは、キャンペーンの適切な節目（成功した各シナリオやストーリーラインの終了時、あるいはストーリーが長い場合はプレイ2〜3セッションごとなど）に経験ロールを分配します。その頻度はゲームマスターの裁量に委ねられます。経験ロールの頻度が高いほど、キャラクターはより速い速度で成長します。

経験ロールを与えるべき正しいタイミングや間違ったタイミングというものはありませんが、ストーリーの自然な区切りが良い機会となるでしょう。ただし、最終的な決定者は常にゲームマスターです。プレイヤーが経験ロールを要求することはできませんが、ある時点でそれを受け取ることを期待する権利はあります。キャラクターは経験ロールなしでは成長できないからです。

授与される経験ロールの数もゲームマスターによって決定されます。ただし、前回の授与以降のセッションあたり1〜3回の経験ロールを与えるのが目安として適切です。

#### 既存の技能の向上

キャラクターシート上の標準技能または専門技能は、経験ロールを1つ消費することで向上させることができます。プレイヤーは経験ロールを技能の向上に消費せず、クラス能力（後述）などの他のものを向上させるために貯蓄しておくことを選択できます。

プレイヤーは1d100を振り、向上させようとしている技能と比較します。このロールには、そのキャラクターの知力修正値が加算されます。

- 出目が向上させようとしている技能の数値以上であれば、その技能は1d4+1%上昇します。
- 出目が選択した技能の数値未満であれば、技能は上昇しますが、1%のみとなります。
- 直前のセッション間（つまり、前回の経験ロールから現在まで）にキャラクターが何らかの技能でファンブルした場合、そのファンブルした技能は1%の無料上昇を得ます。私たちは成功よりも失敗から多くを学びます。これは破滅的な失敗の後にキャラクターが行う内省を表現しています。同一技能で複数回ファンブルしても累積はしません。ファンブルした技能を経験ロールで上昇させる場合、ファンブルによる1%は、向上させるためのロールを行う前に適用されます。

同一セッション中に同一技能が複数の経験ロールから恩恵を受けることはできません。

#### 情熱の向上

[情熱](0002_Characters.md?id=step-8-passions)のセクションで説明されているように、情熱の数値は技能と同様の方法で経験ロールを使用して向上させることができます。プレイ内容によっては、ゲームマスターは経験ロールを使用して情熱を低下させることを許可するかもしれません。

_例えば、報われない愛によって絶えず拒絶されることは、過去の亡霊に付きまとわれることなく関係を追求したいと願う愛好家にとって、最も熱烈な情熱をもすり減らしていく可能性があるでしょう。_

#### 新しい技能の習得

キャラクターの中には、自身の文化では学ぶ機会がなかった新しい専門技能の習得を望む者がいるかもしれません。経験ロールを投資し始める前に、その技能を学ぶための知識源を見つけなければなりません。これは、騎士団やギルドが提供するような専門の家庭教師というありふれたものかもしれません。あるいは、古く朽ちかけた訓練用巻物といった、よりエキゾチックな教育源かもしれません。

教育源が見つかったら、キャラクターはその技能の基礎（基本レベルでの習得）を得るために、丸1ヶ月の研究と練習を費やさなければなりません。これには経験ロールが3つ必要であり、さらに（もし教師がいれば）その支払いや、必要となる道具や機材の購入（または賃借）など、ゲーム内でのコストがかかります。

## 病気と毒

キャラクターに影響を与える恐ろしいものの中でも特に恐れられているのが、世界の暗く陰惨な場所にはびこる無数の病気と毒です。自分の住む都市が疫病に襲われること、それもまだ門の内側にいる時にそうなることほど不安なことはありません。同様に、ベッドの中に毒蛇を見つけたり、巨大なサソリに襲われたりすることは、非常にドラマチックな瞬間となり得ます。

病気と毒は種類がほぼ無限に存在しますが、ゲームの目的上、すべて同じ方法で処理されます。

#### 病気と毒の特性

すべての病気と毒は、その効果において重要な多くの特性を示します。

**適用:** 病気や毒が犠牲者に導入される方法。

- **経口:** 食事または飲水によって効果が現れる。
- **吸入:** 呼吸または鼻からの吸引によって効果が現れる。
- **接触:** 皮膚からの吸収によって効果が現れる。
- **注射:** 刺し傷などを通じて体内に物質が注入されることで効果が現れる。

**効力:** 病気や毒の毒性。この値は対抗ロールにおいて適切な抵抗技能（通常は持久力または意志力）と競わせます。キャラクターがロールに勝てば、効果を振り払うことができます。ロールに負ければ、病気や毒のすべての状態を、それぞれ適切なタイミングで被ることになります。

**抵抗:** 病気や毒にどのように抵抗するか。通常は持久力または意志力ですが、よりエキゾチックな抵抗を要求される場合もあります。抵抗ロールは曝露時に行うこともできますし、キャラクターが感染や中毒している可能性を隠すために、発症時間まで延期することもできます。

**発症時間:** 多くの病気や毒は即座に効果が現れるわけではありません。この遅延を発症時間と呼び、数秒、数分、数時間、あるいはそれ以上の場合もあります。複数の効果を持つ毒や病気の場合、状態の項で説明するように、それぞれに異なる発症時間がある場合があります。

**持続時間:** 病気や毒の状態が続く期間。

**状態:** すべての毒素には1つ以上の状態があります。これらは以下の「状態表」で説明されている特定の効果を持っており、犠牲者が抵抗に失敗した場合、記述されたすべての状態を被ることになります。

**解毒剤/治療:** 毒素が治療可能な場合はここに記載されます。治療に成功すればそれ以上の状態の発生を防げますが、状況によっては、既に与えられた永続的な影響が犠牲者に残る場合があります。

##### 状態表

| 状態 | 効果 |
| :-- | :-- |
| 激痛 | 犠牲者は激しい痛みによって妨害される。部位あるいは身体全体に関わらず、影響を受けた部位を使用するあらゆる技能ロールは、キャラクターの意志力以下の数値でなければならず、さもなければ判定は失敗し、痛みでうめいたり叫んだりする。 |
| 窒息 | 犠牲者は窒息を被る。無力化して倒れ、呼吸ができなくなる。[窒息](0004_Game_System.md?id=asphyxiation)セクションのルールが使用される。窒息は喘息のような性質を持つ場合があり、その場合犠牲者は息切れのみを被るか、あるいは呼吸不全による死に至る。後者の場合、病気や毒の効力に対する応急手当技能の対抗判定に勝利することで、犠牲者を生存させ続けることができる。 |
| 出血 | 犠牲者は内部出血または表面的な出血を被り、以下の[疲労](0004_Game_System.md?id=fatigue)および[失血](0004_Game_System.md?id=blood-loss)セクションで説明される疲労と回復時間を引き起こす。 |
| 伝染性 | 犠牲者は接触によって毒や病気を移すことができる。 |
| 死亡 | 犠牲者は無力化して倒れ、自身の体格特性値に等しいラウンド後に死亡する。 |
| 発熱 | 犠牲者の体温が激しく変動し（熱から寒気へ）、筋肉が痛む。すべての技能判定は難易度「困難」となる。 |
| 狂気 | 犠牲者は、水を避ける、偏執病、自傷行為など、何らかの強迫観念に従うよう駆り立てられる。病気や毒によって引き起こされる狂気の内容はその記述に記される。 |
| 悪心 | 犠牲者は食事ができず、身体的に嘔吐を避けるために、ストレスのかかる身体的行動を行うたびに持久力判定を行わなければならない。嘔吐は1d3ラウンド続き、その間犠牲者は行動不能となる。悪心が長時間続くと餓死を引き起こす可能性がある。 |
| 麻痺 | 犠牲者は物理的に動くことができない。部位として影響を受けた場合、その期間中はその場所を使用できない。身体全体に影響する場合、キャラクターは全く動くことができない。 |

#### 病気の例：赤斑病

赤斑病は、既に感染している人との皮膚接触、またはその人が触れたものとの接触によって広がる恐ろしい病気です。物体から感染する可能性は接触後1d3日間続くため、一度発生すると封じ込めるのが非常に困難です。

犠牲者は最初は小さな発疹を被りますが、1日以内に重い発熱に見舞われ、通常は病気の間中ずっと寝たきりになります。この間、発疹はひどくかゆい膿疱へと進化し、わずかな動きでも破裂して血をにじませます。特に脇の下や鼠径部から顕著です。この段階は1週間以上続く可能性があり、致命的となることもあります。

- **適用:** 接触
- **効力:** 50
- **抵抗:** 持久力
- **発症時間:** 1d6+6時間
- **持続時間:** 1d6+3日間
- **状態:** 病気が発症すると犠牲者は「伝染性」を持つ。1日後、発熱と出血を被り始める。膿疱が血を流す毎日、犠牲者は疲労レベルを1段階失う。これは病気の持続時間が終わるまで回復しない。
- **解毒剤/治療:** 治療技能によって治癒可能。

## 落下

落下で被るダメージの量は、落下の距離に依存します。防具によるダメージ軽減は落下ダメージには適用されませんが、落下したキャラクターまたはクリーチャーのダメージ修正値は落下ダメージに適用されます。

##### 落下距離表

| 落下距離 | 被ダメージ |
| :-- | :-- |
| 1メートル以下 | ダメージなし。 |
| 2-5メートル | 1d6ポイントのダメージをランダムな1部位に受ける。 |
| 6-10メートル | 2d6ポイントのダメージをランダムな2部位に受ける。 |
| 11-15メートル | 3d6ポイントのダメージをランダムな3部位に受ける。 |
| 16-20メートル | 4d6ポイントのダメージをランダムな4部位に受ける。 |
| +5メートルごと | +1d6ダメージ。 |

#### 落下物

落下物は、その体格と落下距離に基づいたダメージを与えます。物体は体格6ポイント（またはその端数）ごとに1d6のダメージを与え、さらに「落下距離表」の「被ダメージ」列に等しいダメージ量を加算します（小さいサイズの物体に対する減算を含む）。

## 疲労

疲労は疲れとその累積的な効果を測定します。激しい活動から病気の衰弱効果に至るまで、様々な事象を追跡するために使用されます。

疲労を蓄積する主な方法は、何らかの身体的活動に従事することです。運動や作業が過酷であればあるほど、キャラクターは早く疲れます。ゲームマスターの裁量により、キャラクターは疲労レベルの獲得を防ぐために、運動、腕力、持久力のいずれか適切な技能ロールを行わなければならない場合があります。

ロールに失敗するたびに、疲労レベルが1段階蓄積されます。各疲労レベルは、技能使用、移動、イニシアチブ、行動ポイントに対するペナルティを伴います。窒息、失血、その他の環境依存の効果も疲労蓄積の要因となります。

ほとんどのキャラクターにとって、「無力化」のレベルに達すると、どのような活動もほぼ不可能になります。この段階では、キャラクターは意識を保ってはいますが、極めて絶望的な活動以外のことは何もできません。

無力化を超えると、キャラクターは全く行動できなくなります。半意識、昏睡、死亡といった疲労レベルは、一般的に窒息、病気、失血、飢餓、曝露などの最も極端な効果を測定するために予約されています。

#### 疲労からの回復

キャラクターは自身の治癒率に応じて疲労から回復します。各蓄積疲労レベルから回復するために必要な完全な休息時間は、回復期間をキャラクターの治癒率で割ったものに等しいです。

以下の表は肉体労働による疲労回復を表していることに注意してください。窒息からの回復時は疲労回復がはるかに速くなる可能性があり、失血から回復している場合は遅くなる可能性があります。

| 息切れ | 困難 | ペナルティなし | ペナルティなし | ペナルティなし | 15分 |
| 疲れ | 困難 | -1メートル | ペナルティなし | ペナルティなし | 3時間 |
| 困憊 | 至難 | -2メートル | -2 | ペナルティなし | 6時間 |

## 火

火は、武器として使用される場合や制御不能なほど荒れ狂う場合、常に危険の源となります。以下の火の強度表には、熱ダメージに対する5つの強度が示されており、いくつかの例が含まれています。ラウンドごとに与えられるダメージは「ダメージ」列に示されています。比較的規模の小さい強度1と2のソースは、そのダメージを単一の部位（通常、ソースに触れている部位）に適用します。強度3と4のソースはより大きく、1d4+1の近接する部位にダメージを適用し、放射熱の程度を示します。強度5のソースはすべての部位に同時に影響を与えます。

火は可燃物に引火する可能性があります。直ちに消火しなければ、そのような物質は火の強度によって示されるラウンド数以内に燃焼します。一度引火すると、可燃物は物理的に消火されるまで燃え続けます。ダメージは防具の装甲ポイントを無視して物質の耐久力に直接適用され、その下の肉体にも適用されます。制御を放置した場合、強度に等しい数の部位にラウンドごとに拡散します。

##### 火の強度表

| 強度 | 例 | 引火までの時間 | ダメージ |
| :-: | :-- | :-: | :-: |
| 1 | 蝋燭 | 1d4 | 1d2 |
| 2 | 松明 | 1d3 | 1d4 |
| 3 | キャンプファイヤー | 1d2 | 1d6 |
| 4 | 部屋を満たす大火災 | 1d2 | 2d6 |
| 5 | 火山の溶岩 | 即時 | 3d6 |

火炎ベースの攻撃は、通常1ラウンドで終了するため、可燃物に引火する確率がパーセンテージで設定されています。特に断りのない限り、この確率は火炎ベースの攻撃の場合はダメージロール×5%、電気ベースの場合はダメージロール×1%です。一度引火すると、可燃物は物理的に消火されるまで毎ラウンド1d3-1のダメージを燃やし続けます。このダメージを防具の装甲ポイントを無視して物質の耐久力に直接適用し、その下の肉体にも適用してください。ただし、クリーチャーの自然防具は通常の保護を提供します。犠牲者は伏せ状態になり、運動技能判定に成功することで炎を消そうと試みることができます。これには行動ポイントが必要で、各ターンに試みることができます。他者が何らかの形で消火を支援した場合、判定は1段階簡単になります。ダメージロールが0になった場合、その部位の火は自然に消えたことになります。自然に消えた部位ごとに、消火の判定も1段階ずつ簡単になります。

## ゲーム内の時間

_Mythras Imperative_ において、時間は重要な要素です。主に何がどの順番で起こるかを決定し、ゲームメカニクスが適切なタイミングで適用されるようにするために使用されます。ゲーム内の時間は、プレイに費やされた時間と等価ではないことに注意してください。ゲームマスターが「城アンソラックスに到達するまで1週間かかる」のように何日ものイベントを1文でまとめる必要がある場合もあれば、特に戦闘中などは、わずか数秒の行動を解決するのに数分以上かかる場合もあります。

以下は、ゲーム内の時間の重要な区別です：

#### 戦闘ラウンド

戦闘ラウンドは5秒のリアルタイムを表します。完了するまでに一瞬を要する短く熱狂的な活動や、打撃ごとの解決が必要な非常に詳細な活動を測定するために使用されます。例えば、狩人と獲物の追跡など、各ラウンドで追跡の紆余曲折を決定します。

#### 技能時間

技能時間は数分から数時間を表し、戦闘ラウンドのような詳細な注意を必要としないものの、明確な結果を出すために特定の努力と検討を必要とする活動を測定するために使用されます。鍵開けには5分かかるかもしれませんが、城壁の周りを守る警備隊の巡回を観察するには数時間を要するでしょう。これらは両方とも技能時間の例です。#### 物語上の時間

これはゲームマスター（GM）がプレイヤーに対して物語を語る際、あるいはプレイヤー同士で議論している際に経過する時間のことです。特別な理由がない限り、実際のロールプレイの大半はこの物語上の時間内に行われます。ロールプレイにおいて、物語上の時間は現実の時間と似ており、会話にかかる時間はプレイする時間と同じだけ経過します。ゲームセッションに長距離の移動が含まれる場合や、正確な時間が重要ではない活動期間がある場合は、時間はゲーム内での数瞬に大幅に圧縮されます。

## 部位判定

ほとんどの成功した（武器による）攻撃は、特定の部位判定に命中します。これはランダムに決定することもあれば、状況によっては「部位選択」のような特殊効果によって選択することも可能です。どの部位に命中したかをランダムに算出するには、1d20をロールし、該当する人型生物またはクリーチャーの部位判定表の数値と比較します。

動物やモンスターは、人型生物とはわずかに異なる部位判定表を持っているのが通常であり、これは彼ら独自の生理構造を反映しています。これらは各存在の説明の一部として記載されており、通常はゲームマスターのみが使用するものです。

人型生物の部位判定表を、参照しやすいようにここに再掲します。

##### 人型生物の部位判定

| 1d20 | 部位判定 |
| :-: | :-- |
| 1-3 | 右脚 |
| 4-6 | 左脚 |
| 7-9 | 腹部 |
| 10-12 | 胸部 |
| 13-15 | 右腕 |
| 16-18 | 左腕 |

魔法や技術による攻撃、あるいは特定のモンスターが放つ攻撃（例えばドラゴンの火炎のブレスや爆発する手榴弾など）は、複数の部位判定に同時に命中する場合があることに注意してください。個々の部位は、着用している防具によって、あるいはクリーチャーの外皮が持つ自然な硬さによって、防護されている場合があります。これは、以下の「ダメージ」と「負傷レベル」を考慮する際に重要となります。

## ダメージと負傷レベル

攻撃が成功した場合、武器のダメージ等級に従ってダメージを与えます。例えばショートソードであれば、1d6のダメージを与えます。

武器や攻撃によってロールされたダメージは、特定の条件によって以下の順番で修正されます：

1. 攻撃を行うキャラクターのダメージ修正を適用する。
2. 武器を強化（または減少）させる魔法によるダメージ修正を行う。
3. パリー（受け流し）された場合、武器サイズの比較に従って適切にダメージを減少させる。
4. 命中した部位が防具を着用している場合、防具の値をダメージから差し引く。

与えられたダメージがゼロより大きい場合、その部位はダメージを受け、ダメージの合計値がその部位のヒットポイントから直ちに差し引かれます。その部位の残りヒットポイントと、結果として生じる負傷カテゴリーに注目してください。

- **軽傷:** 部位のヒットポイントがプラスのままの状態。
- **重傷:** 部位のヒットポイントがゼロ以下になった状態。
- **致命傷:** 部位のヒットポイントが、その部位の初期ヒットポイントと同等以上のマイナス値になった状態。

部位が重傷または致命傷を受けた場合は、以下のルールを使用してください。持久力チェックを必要とする負傷については、元々の攻撃ロールの出目と対抗判定を行ってください。これは、非常に熟練した戦士がより致命的な一撃を放つ能力を反映しています。持久力ロールは、その部位が再度負傷しない限り繰り返されません。

### 軽傷

軽傷とは、切り傷、ひっかき傷、打撲、捻挫などを指します。痛みがあり、出血するかもしれませんが、被害者の動きを遅らせたり妨げたりするほどのものではありません。

### 重傷

ある部位がヒットポイントゼロ以下になった場合、被害者は重傷を負います。その部位には永久的な傷が残り、被害者は衝撃や痛みのために次の1d3ターンの間、攻撃や呪文の詠唱開始を行うことができません（ただし、パリーや回避は可能です）。

四肢に重傷を負ったキャラクターは、直ちに自身の持久力と敵の攻撃ロールの成功値との対抗判定を行わなければなりません。失敗すると、その部位のヒットポイントがプラスに戻るまで、その四肢は使用不能になります。脚であれば、被害者は転倒（伏せ状態）します。腕であれば、保持していたものは全て取り落とします（ここでは常識的に判断してください）。

腹部、胸部、または頭部に重傷を負ったキャラクターは、直ちに自身の持久力と敵の攻撃ロールの成功値との対抗判定を行わなければなりません。失敗すると、重傷を引き起こした攻撃のダメージ量に等しい分（分単位）だけ昏睡状態に陥ります。応急手当や治癒の技能を使用して、昏睡状態の被害者の意識を回復させることができます。

ゲームマスターの裁量により、キャラクターが行動可能であっても、その部位を使用する全ての作業は、損傷が軽傷に回復するまで難易度が一段階上昇するペナルティを継続して受けます。

### 致命傷

ある部位が初期ヒットポイントと同等以上のマイナス値になった場合、キャラクターは致命傷を負います。キャラクターは即座に無力化され、戦闘を続行できなくなります。致命傷によって四肢が切断、貫通、粉砕、あるいは引きちぎられることもあります。キャラクターは転倒し、肉体的に無力化され、直ちに自身の持久力と敵の攻撃ロールの成功値との対抗判定を行わなければなりません。失敗すると、激痛により昏睡状態となります。切断、貫通、あるいは引きちぎられた部位が、治癒率の5倍の数値（分単位）以内に手当されなければ、キャラクターは出血とショックによって死亡します。

腹部、胸部、または頭部に致命傷を受けた被害者は昏睡状態となり、完全に無力化され、直ちに自身の持久力と敵の攻撃ロールの成功値との対抗判定を行わなければなりません。失敗すると、即死（斬首、胴体切断、心臓貫通、引き裂かれるなど）となります。生き残ったとしても、その部位がキャラクターの治癒率の2倍の数値（戦闘ラウンド単位）以内に手当されなければ、出血とショックによってやはり死亡します。

ほとんどの致命傷は治療のために何らかの手術や強力な魔法を必要とするため、負傷者が戦闘に復帰できるほど回復する可能性は極めて低いです。利用可能な治療法に応じて、負傷した部位は恒久的に不具になる可能性があります（下記の[怪我の治癒](0004_Game_System.md?id=healing-from-injury)を参照）。

### 出血

通常は戦闘中に負った外部あるいは内部の傷による出血は、キャラクターを非常に急速に衰弱させる可能性があります。その影響は、窒息と同様に疲労レベルの蓄積によって測定されます。適切な医療処置がない限り、出血を放置すると通常は死に至ります。窒息とは異なり、深刻な出血による疲労への影響は持続的です。キャラクターが出血によって失った疲労は、出血が止まった翌日から、1日につき1レベルの割合で回復します。

### 英雄的最後の一撃

重要なキャラクターが致命傷を負う特別な状況において、ゲームマスターは英雄的最後の一撃を許可するかもしれません。例えば、最期の呪文を唱える、自分を殺した相手を切り倒そうとする、這って隠れる、あるいは自分自身の傷に止血帯を巻こうとするなどです。彼らはその行動に適した機能する四肢を持っており、かつ幸運ポイントを消費しなければなりません。彼らは一度だけ行動を試みるチャンスを得ますが、その後は直ちに意識を失い、おそらくは死亡します。

## 怪我の治癒

傷や怪我の自然治癒は、キャラクターの治癒率に基づいています。治癒率は、怪我の性質に応じて部位のヒットポイントがどれだけ回復するかを決定します：

- **軽傷:** 日単位
- **重傷:** 週単位
- **致命傷:** 月単位

したがって、治癒率3のキャラクターがダメージを受けて部位ヒットポイントがマイナス3（重傷）になった場合、その部位がゼロを超えるまでは週に3ヒットポイントずつ自然治癒し、その後は完治するまで1日につき3ヒットポイントずつ回復します。

自然治癒にはいくつかの制限があります：

- 治癒中のキャラクターは激しい活動に従事できません。さもなくば、治癒率は1d3減少します。したがって、軽傷から回復中のキャラクターであっても、怪我を悪化させるような肉体的作業に従事すれば、回復プロセスが停止する可能性があります。
- 自然治癒は、被害者が「応急手当」技能の成功、あるいは何らかの治癒魔法の詠唱を受けるまで、致命傷を回復し始めることはありません。四肢の切断を伴わない致命傷で、治癒技能の数値の20分の1（日単位）以内に治療されなかったものは不具となり、その部位のヒットポイントが永久的に減少します。

## 無生物

全ての無生物は、ダメージと破壊に対する抵抗力を決定するために使用される防具とヒットポイントを持っています。防具はヒットポイントが影響を受ける前にダメージを軽減します。物体のヒットポイントがゼロに減少すると、それは無用なものとなります。

破壊の試みには、ダメージを与えるために必要に応じて、キャラクターが腕力、徒手、あるいは戦闘スタイルのロールを行う必要があります。成功すれば、そのアイテムにダメージを与えます。

#### 武器 vs 無生物

武器の防具と同等以上の防具を持つ無生物に対して武器を使用すると、物体と武器の両方にダメージを与えます。例えば、鉄の扉に斧を使うと扉を傷つけるかもしれませんが、斧自体は鉄の扉が壊れるよりもはるかに早く破壊されてしまいます。どの武器や道具がどの物体に影響を与えられるかについては、ゲームマスターが裁量を行使すべきです。例えば、ノミは木材や石を彫るために明確に設計されていますが、剣は鋭利であってもそうではありません。したがって、ノミは彫ろうとしている対象からダメージを受けることはありませんが、剣は受ける可能性が高いと言えます。

## 幸運ポイント

幸運ポイントは、英雄と一般人を区別するのに役立ちます。これは、失敗を成功に変え、死さえも回避するキャラクターの潜在的な能力を表しています。

幸運ポイントはプレイ中に使用でき、次のセッションの開始時に通常の数値まで補充されます。

#### 幸運ポイントの使用

幸運ポイントは様々な方法で使用できます。特定の行動を補助するために使用できる幸運ポイントは1ポイントだけです。幸運ポイントを経験点や訓練ロールに消費することはできません。以下の各オプションは、1幸運ポイントを消費します。

#### 運命の操作

キャラクターは幸運ポイントを使用して、自分が行うあらゆるダイスロールを再ロールしたり、出目を入れ替えたり（例えば75を57にするなど）することができます。これには技能ロール、ダメージロール、あるいは何らかの影響を与えるその他のあらゆるロールが含まれます。キャラクターは、自分に対して行われた攻撃ロールやダメージロールを相手に再ロールさせることさえ可能です。

#### 必死の努力

戦闘中にアクションポイントを使い果たし、惨めな最期を回避するために最後の必死のエネルギーを振り絞る必要がある場合、キャラクターは幸運ポイントを消費してアクションポイントを1つ追加で得ることができます。

#### ダメージの軽減

致命傷を負ったキャラクターは、幸運ポイントを1つ消費して、その怪我を重傷に格下げすることができます。これにより、受けるダメージは致命傷を与えるために必要な数値より1ヒットポイント少ない値まで軽減されます。
