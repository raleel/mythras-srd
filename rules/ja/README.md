## Introduction

_Mythras Imperative_は、_Mythras_ルールセットのオープンなORCライセンス版です。本書は包括的ではありますが、網羅的なものではありません。キャラクター作成、技能、一般的な状況におけるルール、戦闘、魔法など、プレイヤーとゲームマスターがゲームを開始し、さらなる発展のための強固な基盤を形成するのに十分すぎる内容を提供します。_Mythras Imperative_は、Mythrasの中核ルールおよび他のORCライセンスのパーセンタイル・ゲーミング・システムと互換性があります。姉妹版である_Classic Fantasy Imperative_も完全に互換性があり、ORCの下でリリースされているため、これら2つのImperativeは容易に組み合わせることができます。

英語以外の翻訳はAIによって行われています。コミュニティからの意見を歓迎します！

## ORCライセンス

_Mythras Imperative_はORCライセンスを使用して公開されています。ORCライセンスは、ゲームクリエイターがゲームのメカニクスをオープンに共有するための手段を提供し、下流のユーザーがこれらのゲームメカニクスの適応版を自由に利用、修正、再共有することを可能にします。

ORCの下でオープンに共有されるものは_**ライセンス素材 (Licensed Material)**_として知られており、ステータスブロック、ゲームルール、キャラクターの特性値、ゲームをプレイする上で固有のメソッドやシステムなど、ゲームの広範な機能的要素に加え、ライセンサーが明示的に共有したいその他のすべてが含まれます。このライセンスは広範であり、印刷書籍、ビデオゲーム、ポッドキャスト、AI、または将来存在する可能性のある技術に関連して、世界中でライセンス素材を使用することを許可します。_Mythras Imperative_に含まれるコンテンツの大部分はライセンス素材を構成しています。

ORCの下で共有され_ない_ものは_**予約素材 (Reserved Material)**_として知られており、商標、ワールドの伝承、ストーリーアーク、特徴的なキャラクター、視覚芸術などが含まれます。以下のORC通知に予約素材を記載しています。

ORCライセンスの下では、公開作品の中に適切な帰属表示を行う限り、ライセンス素材を必要に応じて使用、共有、適応、構築することができます。この通知は、上流のライセンサーとその作品への貢献を称えるとともに、その通知が現れる作品の著者を下流のユーザーが簡単にクレジットできるようにするためのものです。ORCの下でライセンスされた素材を使用することにより、あなたは自動的に、自身の公開作品におけるゲームメカニクスを同じ条件でライセンスすることに同意したものとみなされます。あなた自身の予約素材を開発した場合、それはあなたの独占的な財産となります。

## d100は初めてですか？

_Mythras Imperative_はd100、あるいはパーセンタイル・システムです。パーセンタイル・ダイス、つまり1d100は、技能の使用、戦闘、魔法の詠唱といった主要なアクションを解決するために使用されます。これは下方ロール・システムであり、ターゲットとなる数値がパーセンテージ（例：運動 65%）として表現されることを意味します。ゲームマスターとプレイヤーは、1d100を使用して、このターゲット数値以下の出目を出すことで「成功」を得ることを目指します。好みに応じて1d100をd20に置き換えることは非常に簡単で、すべてのパーセンテージを5で割る（切り上げ）ことで、d20ロールのターゲット数値を得ることができます。例えば、運動 65%は、運動 13となります。

しかし、1d100はゲーム全体を支える柔軟性とニュアンスを提供するため、まずは1d100のアプローチを試すことをお勧めします。何らかの数値より_小さく_出す必要があるというのは直感に反するように思えるかもしれませんが（多くのゲームでは、高いほうが良いとされることが多いため！）、成功に必要なパーセンテージ範囲としてターゲット数値が示されることで、成功の確率を簡単かつ単純に視認でき、対抗ロール、クリティカル、ファンブル、そして本書で後述するいくつかの要素といった「ダイスのトリック」を活用しやすくなります。パーセンタイルによるロールプレイングは、ロールプレイングの黎明期から存在しており、柔軟で直感的であり、プレイ中には意識の外に消えていくような、試行され検証されたコア・メカニクスを持つ確立されたゲームシステムです。

## 単純化

_**Mythras**_の長年のユーザーは、_Mythras Imperative_のルールの一部が単純化されていることに気づくでしょう。これは、ゲームマスターが最小限の手間で新しいプレイヤーに素早くゲームを紹介できるようにするためです。

## 数値と結果の端数処理

時には数値を割る必要がある場合があります。通常は技能の評価値に対して行われます（クリティカル成功を決定する場合など、技能値の1/10）。割り算の結果として端数が出た場合は、常に整数へ切り上げてください。例えば、63%の1/10は6.3ですが、これは7に切り上げられます。

## 使用するダイス

_Mythras Imperative_は、標準的な多面体ダイスセットを使用します：d4、d6、d8、d10、d12、d20、d100。さらに、以下のダイスが必要となります：

d2：任意のダイスを振ります。奇数は1、偶数は2とみなします。またはコインを投げます。

d3：6面体ダイスを振ります。1-2 = 1、3-4 = 2、5-6 = 3
