# Mythras Imperative システムリソースドキュメント

---
## はじめに

_Mythras Imperative_ は、_Mythras_ ルールセットのオープンで ORC ライセンスされたバージョンです。本書には、キャラクター作成、技能、特定の一般的な状況におけるルール、戦闘、魔法など、包括的かつ必要十分なルールが網羅されています。プレイヤーとゲームマスター (GM) の双方がゲームを開始し、さらなる発展のための確固たる基盤を築くには十分すぎる内容です。_Mythras Imperative_ は、_Mythras_ のコア・ルールや、その他の ORC ライセンスのパーセンタイル制ゲームシステムと互換性があります。その姉妹編である _Classic Fantasy Imperative_ も完全に互換性があり、ORC のもとで公開されているため、2つの Imperative を簡単に組み合わせることができます。

英語以外の翻訳は AI によって行われています。コミュニティからのフィードバックを歓迎します！

## ORC ライセンス

_Mythras Imperative_ は ORC ライセンスを使用して公開されています。ORC ライセンスは、ゲームクリエイターが自分たちのゲームのメカニクスをオープンに共有し、下流のユーザーがそのゲームメカニクスの適応版を自由に利用、修正、再共有できるようにする手段を提供するものです。

ORC のもとでオープンに共有されるものは _**ライセンス素材 (Licensed Material)**_ として知られており、ステータスブロック、ゲームルール、キャラクター属性、ゲームプレイに内在する手法やシステム、その他ライセンサーが明示的に共有したいと望むすべての広範な機能的要素が含まれます。このライセンスは広範であり、印刷された書籍、ビデオゲーム、ポッドキャスト、AI、または現在存在する、あるいは将来作成される可能性のあるその他の技術に関連して、ライセンス素材をグローバルに使用することを許可します。_Mythras Imperative_ に含まれるコンテンツの大部分は、ライセンス素材を構成しています。

ORC のもとで共有され**ない**ものは _**留保素材 (Reserved Material)**_ として知られており、商標、世界観の伝承 (ロア)、ストーリーアーク、特徴的なキャラクター、ビジュアルアートが含まれます。留保素材については、以下の ORC 通知に記載しています。

ORC ライセンスのもとでは、公開作品において通知の形式で適切なクレジット表記を行う限り、ライセンス素材を自由に使用、共有、適応、およびそれを基にして発展させることができます。この通知は、上流のライセンサーとその作品への貢献を称えるとともに、通知が掲載されている作品の作者を下流のユーザーが簡単にクレジットできるようにするものです。ORC のもとでライセンスされた素材を使用することにより、あなたは自動的に、自身の公開作品におけるゲームメカニクスを同一の条件のもとでライセンスすることに同意したことになります。独自の留保素材を開発した場合、それはあなたの独占的財産となります。

## d100 は初めてですか？

_Mythras Imperative_ は d100 またはパーセンタイルシステムです。主要なアクション（技能の使用、戦闘、魔法の詠唱など）を解決するために、パーセンタイルダイス、つまり 1d100 が使用されます。これはロールアンダー・システムであり、目標値がパーセンテージで表され（例：〈アスレチック〉65%）、ゲームマスターとプレイヤーの両方が 1d100 を使用してこの目標値「以下」の出目を出し、成功を達成することを目指します。必要に応じて 1d100 を d20 に置き換えることは非常に簡単で、すべてのパーセンテージを 5 で割る（端数切り上げ）ことで d20 ロール用の目標値を得ることができます。上記の例であれば、〈アスレチック〉65% は〈アスレチック〉13 になります。

しかし、1d100 はゲーム全体を支える優れた柔軟性とニュアンスを提供するため、まずは 1d100 のアプローチを試してみることをお勧めします。（多くのゲームでは高い数値のほうが出目が良いため、）何かより「低い」数値を出す必要があるのは直感に反するように思えるかもしれませんが、目標値がダイスを振る範囲のパーセンテージとして表されていることで、成功率が一目でわかりやすくなり、対抗ロール、クリティカルとファンブル、その他これらのルールの後半で解説されるいくつかの「ダイス・トリック」など、多くの要素が可能になります。パーセンタイルRPGは、RPGの初期の頃から存在しており、柔軟で直感的であり、プレイ中に背景に溶け込んでいくような、実績のある中核メカニクスを持つ確立されたゲームシステムです。

## 簡略化

_**Mythras**_ を長年遊んできたプレイヤーは、_Mythras Imperative_ のルールが一部の場所で簡略化されていることに気づくでしょう。これは、ゲームマスターが最小限の手間で、新しいプレイヤーにゲームをより早く導入できるようにするためです。

---
## 数値と結果の丸め

数値を割る必要がある場合があります。通常は技能のレーティング（クリティカル・成功を決定する場合など、技能値の 1/10）です。割り算の結果に端数が出た場合は、常に次の整数へと切り上げてください。したがって、例えば 63% の 1/10 は 6.3 となり、これは切り上げられて 7 になります。

## 使用するダイス

_Mythras Imperative_ では、標準的な多面体ダイスセット（d4、d6、d8、d10、d12、d20、d100）を使用します。さらに、以下のダイスが必要となります：

d2：任意のダイスを振ります。奇数が出れば 1、偶数が出れば 2 とします。あるいは、コインを投げます。

d3：6面体ダイスを振ります。1〜2 = 1、3〜4 = 2、5〜6 = 3
