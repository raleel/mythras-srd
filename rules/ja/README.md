# Mythras Imperative System Resource Document

## はじめに

_Mythras Imperative_ は、_Mythras_ ルールセットのオープンな、ORCライセンス版です。本書は、キャラクター作成、技能、特定の典型的な状況におけるルール、戦闘、魔法など、包括的ですが網羅的ではないルールを提供しています。プレイヤーとゲームマスター（GM）の両方が始めるには十分すぎる内容であり、さらなる発展のための強固な基盤となります。_Mythras Imperative_ は、_Mythras_ コアルールや、その他のORCライセンスに基づいたパーセンタイル・ゲームシステムと互換性があります。その姉妹編である _Classic Fantasy Imperative_ も完全に互換性があり、ORCの下でリリースされているため、これら2つの「Imperative」は容易に組み合わせることが可能です。

英語以外の翻訳はAIによって行われています。コミュニティからのフィードバックを歓迎します！

## ORCライセンス

_Mythras Imperative_ は、ORCライセンスを使用して公開されています。ORCライセンスは、ゲームクリエイターがゲームのメカニクスをオープンに共有し、下流のユーザーがそれらのゲームメカニクスの翻案を自由に利用、修正、再共有できる方法を提供します。

ORCの下でオープンに共有されるものは_**ライセンス対象資料（Licensed Material）**_と呼ばれ、スタットブロック、ゲームルール、キャラクター属性、プレイに固有のメソッドやシステムなど、ゲームの広範な機能要素、およびライセンサーが明示的に共有したいその他のすべてが含まれます。このライセンスは広範であり、印刷書籍、ビデオゲーム、ポッドキャスト、AI、または将来存在する可能性のあるその他の技術に関連して、ライセンス対象資料を世界中で使用することを許可します。_Mythras Imperative_ に含まれるコンテンツの大部分は、ライセンス対象資料を構成しています。

ORCの下で共有され_ない_ものは_**予約資料（Reserved Material）**_と呼ばれ、商標、世界設定の伝承、ストーリーアーク、特徴的なキャラクター、視覚芸術が含まれます。予約資料については、以下のORC通知に記載しています。

ORCライセンスに基づき、出版物に通知という形で適切な帰属表示を行う限り、ライセンス対象資料を自由に使用、共有、翻案、発展させることができます。この通知は、上流のライセンサーとその功績を称えるとともに、下流のユーザーがその通知が表示される作品の著作者を容易にクレジットできるようにするものです。ORCの下でライセンスされた資料を使用することにより、あなたは自身の出版物に含まれるゲームメカニクスを、同じ条件の下でライセンスすることに自動的に同意したことになります。独自の予約資料を開発した場合、それはあなたの独占的な財産となります。

## d100は初めてですか？

_Mythras Imperative_ はd100、つまりパーセンタイル・システムです。技能の使用、戦闘、魔法の詠唱など、主要なアクションを解決するために、パーセンタイルダイス（1d100）が使用されます。これはロールアンダー・システムであり、目標値がパーセンテージで表され（例：〈運動〉65%）、ゲームマスターとプレイヤーの両方が1d100をロールして、目標値以下であれば「成功」となります。必要に応じて1d100をd20に置き換えることは非常に簡単で、すべてのパーセンテージを5で割る（端数切り上げ）ことで、d20ロールの目標値を得ることができます。先ほどの例であれば、〈運動〉65%は〈運動〉13となります。

しかし、1d100はゲーム全体を支える大きな柔軟性とニュアンスを提供するため、まずは1d100のアプローチを試すことをお勧めします。（多くのゲームでは数値が高いほうが良いとされるため）何かより「低い」数値を出す必要があるのは直感に反するように思えるかもしれませんが、目標数値をパーセンテージ範囲で表すことで、成功率を簡単かつ単純に把握できます。また、対抗ロール、クリティカル、ファンブルなど、本書の後半で解説するいくつかの「ダイス・トリック」も容易になります。パーセンタイル・ロールプレイングは、ロールプレイングの黎明期から存在しており、柔軟で直感的であり、プレイ中に意識から消えていくほど馴染みやすい、実績のあるコアメカニクスを備えた確立されたゲームシステムです。

## 簡略化

_**Mythras**_ の長年の愛好家は、_Mythras Imperative_ のルールがいくつかの点で簡略化されていることに気づくでしょう。これは、ゲームマスターが最小限の手間で、より迅速に新規プレイヤーをゲームに導入できるようにするためです。

---
## 数値と結果の端数処理

状況によっては数値を割る必要がある場合があります（スキルの評価値など。クリティカル成功の判定にはスキルの1/10の値を使用します）。除算の結果が小数になった場合は、常に切り上げて整数にします。例えば、63%の1/10は6.3ですが、これは切り上げて7となります。

## 使用するダイス

_Mythras Imperative_ では、標準的な多面体ダイスセット（d4、d6、d8、d10、d12、d20、d100）を使用します。さらに、以下のダイスも必要となります：

d2：任意のダイスを振ります。奇数は1、偶数は2とします。あるいはコインを投げてください。

d3：6面体ダイスを振ります。1-2 = 1、3-4 = 2、5-6 = 3
