# 車両

『Mythras Imperative』における車両は、半抽象的な方法で扱われます。基本的には、詳細な記述や統計値を必要とせず、キャラクターを地点Aから地点Bへ移動させるための背景ツールです。しかし、追跡や戦闘状況で車両を表現する必要がある場合、ゲームマスター（GM）が車両の詳細を求めることがあります。

本節のルールは、ほとんどの種類の車両を表現可能にしていますが、柔軟性を確保し物語性を高めることを目的とした抽象的な手法をとっています。宇宙船や宇宙艇は同様の原則に基づいているものの、少々異なります。

---
## 統計値

すべての車両は、構造（Structure）、船体（Hull）、速度（Speed）、システム（Systems）、特性（Traits）、およびシールド（Shields）（設定内に存在する場合）の観点から記述されます。

- **[体格](0006_Vehicles.md?id=vehicle-size-table):** すべての車両には6段階の体格評価があり、残りの特性値や範囲を決定します。宇宙という過酷な環境と本来の巨大さのため、宇宙船は独自の数値範囲を持ちます。
- **[船体](0006_Vehicles.md?id=terrestrial-hulls):** 防具値（防具 Points）を表します。
- **[構造](0006_Vehicles.md?id=terrestrial-hulls):** 車両のヒットポイントを表します。
- **[シールド](0006_Vehicles.md?id=shields):** 高度なエネルギー操作技術が存在する設定では、車両を保護するシールドが存在する場合があり、継続的な攻撃によって劣化します。
- **[システム](0006_Vehicles.md?id=systems):** 動力炉、乗組員区画など、車両の重要なコンポーネントを表します。
- **[速度](0006_Vehicles.md?id=speed):** すべての車両は基本的な速度評価を持ちます。
- **[特性](0006_Vehicles.md?id=traits):** 車両は1つ以上の特性を持つ場合があります。『Mythras Imperative』ルールのクリーチャーに割り当てられる能力や、戦闘スタイル特性と同様に、特性は車両の性質を反映した追加のゲーム的記述と利点を提供します。
- **[武器](0006_Vehicles.md?id=weapons):** 特性と同様に、設定が許せば車両には武器を装備させることができます。いくつかの推奨例と数値は後述します。

### 船体のサイズ、種類、および構造

車両のサイズと目的は、船体の厚さと内部構造の回復力に影響を与えます。例えばオートバイは、速度と機動性のために作られており、最小限の船体しかありません。ランド・アイアンクラッド（蒸気やディーゼルエンジンで駆動する、巨大な履帯または車輪付きの装甲の怪物）は、戦場用に設計されたはるかに大型の車両であり、はるかに大きな船体を持っています。船体の比較サイズ（および武器からの攻撃に通常どれだけ耐えられるか）は、以下の「車両サイズと船体テーブル」にまとめられています。

車両がダメージを受けるたび、受けたダメージは船体値によって軽減されます。残りのダメージは車両の構造ポイントから差し引かれ、浸透ダメージと同等のパーセンテージでシステムに影響を与える可能性があります。車両の構造が0になった場合、完全に破壊されるか、スクラップにしなければならないほど大破します。

### シールド

偏向シールドは、それを装備できる車両に追加の保護層を提供します。シールドは、そのアブレーション（消耗）的性質のため、船体とはわずかに異なる働きをします。受けたダメージがシールドの数値以下であれば、すべてブロックされます。ダメージがシールド値を上回る場合、超過分がその分だけシールド強度を低下させます。

_例えば、兵員輸送車のエネルギーシールド強度が12ポイントだとします。輸送車がレーザーによる11ダメージを受けた場合、攻撃は貫通せず、追加の効果はありません。一方、15ダメージを与える爆発を受けた場合、超過した3ポイントによってシールド強度は9に低下します。_

偏向シールドの強度が0に低下すると、崩壊します。残りのダメージはすべて船体に伝わります。

### システム

車両が船体を貫通するダメージを受けるたびに、浸透ダメージと同等のパーセンテージで、重要なシステムが影響を受ける可能性があります。

_例えば、船体3、構造24を持つスピードボートに10ダメージが与えられたとします。船体が装甲として機能し、ダメージを7に軽減します。この7が24の構造ポイントから引かれ、さらに7%の確率で車両のシステムのいずれかが損傷します。_

システムが耐えられるダメージは、完全に車両のサイズに基づいています。これは実際のダメージ量ではなく、システムが耐えられるヒット数によってモデル化されています。小サイズの車両は1回のシステムヒットでそのシステムが即座に破壊されます。中サイズの車両は2ヒット、大サイズの車両は3ヒットでシステムが破壊されます（以下同様）。後述の[システム損傷テーブル](0006_Vehicles.md?id=system-damage-table)を参照してください。

損傷を受けたがまだ破壊されていないシステムは、受けたヒット数に比例して機能が低下します。これはパーセンテージでの減少、またはシステムタスクに対する等級ペナルティのいずれかとなります。具体的な効果は、後述の[システムコンポーネント損傷テーブル](0006_Vehicles.md?id=system-component-damage-table)の詳細通り、そのサブシステムが何を制御しているかに基づきます。どのシステムがヒットしたかによって、結果は破滅的なものになる可能性があります。

_例えば、システムヒットが5ある超巨大なランド・アイアンクラッドが「駆動系」に2回ヒットした場合、動力の40%を失い、低速（Slow）速度が2等級低下して「のろま（Ponderous）」になります。同様に、3ヒットの大型貨物船が「エンジン/燃料」システムに2回ヒットした場合、速度に2等級のペナルティを受け、電子システムの使用にも同様のペナルティを受けます。3回目のヒットでエンジン/燃料システムが破壊され、船も道連れになります。_

### 速度

速度、加速度、抗力、慣性（など）の物理法則は複雑な問題であるため、いくらかの簡略化が必要であり、車両には抽象的な速度評価が与えられています。速度特性は、ある車両が別の車両を追い越せるか、追いつけるかを大まかに判断するためにのみ使用されるべきです。

速度評価は、車両の公称運用速度を表します。緊急時には、エンジンの摩耗や損傷のリスクを冒して、この性能を1段階上げることができます。すべての車両タイプで同じテーブルが使用されますが、同クラスの車両のみを比較するように良識を持って判断してください。例えば、宇宙船とスポーツカーの両方が同じ「急行（Rapid）」の加速率を持っている場合、宇宙船の方が比較的に速いことは明らかです。

車両の速度を標準値以上に上げるには、運転判定に成功する必要があります。通常、この追加速度は短期間しか維持できず、車両が標準速度に戻るか、動力源の損傷を冒すまで1d6分間が限界です。運転判定でクリティカルが出た場合、高速走行の時間を1d12分間まで延長できます。

ドライバーは車両の速度を2段階上げようと試みることができますが、これには超人的（超人的）な運転判定が必要であり、車両がこの速度を維持できる最大時間は1d3分間です。クリティカル成功しても、この加速状態の継続時間は延長されません。

### 特性

車両が持てる最大特性数は、船体のサイズと種類によって異なります。

すべての車両は固有の特性、つまり本来設計された移動モードを持っています。そのため、航空機は本来「飛行（Airborne）」特性を、ボートは本来「航海（Seaborne）」特性を保持しています。この本来持っている特性は、選択可能な特性数には含まれません。しかし、空飛ぶ潜水艦のように、車両が2番目の移動モードを含む場合は、飛行特性を空き特性の1つとして取得する必要があります。

設定の技術レベルによっては利用できない特性もあるかもしれません。どの特性を適用できるかはゲームマスターが独自に判断を下さなければなりません。

#### 飛行（Airborne）

車両は大気圏内での飛行が可能です。

#### 全地形対応（All Terrain）

この特性は地上車両で使用する必要があります。車両は、履帯、高度なサスペンションと駆動システム、あるいは強力なドライブデファレンシャルを使用して、不毛で困難な地形や急峻な地形を横断できます。

#### 掘削（Burrowing）

車両は地面を掘削してトンネルを抜けるように設計されています。船体値×5メートルの最大深度に到達できます。

#### 迷彩（Camouflaged）

車両は迷彩塗料または擬態センサーを装備しており、周囲に溶け込むことができます。車両を視覚的に発見しようとする試みの難易度は1段階上昇します。

#### 貨物（Cargo）

車両は乗客ではなく貨物を運ぶために特別に設計されています。客室は最小限に抑えられ、残りの使用可能なスペースは、適切な区分け、ツール、さらには（腐敗しやすいものを輸送するための冷凍セクションといった）環境調整設備を備えた貨物収容に充てられます。貨物を積載している間、車両の速度は船体サイズが本来許可する値より2段階低くなります。

#### 母艦（Carrier）

この車両は、民間用または軍用を問わず、より小型で少人数の乗組員、あるいは遠隔操作の車両を運搬するために特別に設計されています。この特性を持つ車両は、少なくとも超巨大（Enormous）でなければなりません。搭載される小型艇の数は任務の種類や目的によって異なりますが、最低10台から最大でその車両の構造ポイント数までとなります。

#### 建設（Construction）

車両は重建設作業用装備を備えています。この特性を持つすべての車両は「全地形対応」特性も持ちますが、速度は船体サイズが本来許可する値より2段階低くなります。車両には、クレーンのジブ、掘削ショベル、ダンプカートなど、作業に適したツールが取り付けられています。

#### EMP耐性（EMP Resistant）

車両は電磁パルス攻撃に対して遮蔽されています。

#### 強化性能（Enhanced Performance）

車両の速度評価は、そのサイズに対する最大値より1段階高くなります。

#### 脱出シート（Ejector Seat）

緊急時には、脱出シートが乗員を上空数百メートルまで射出し、その後パラシュートを展開して安全に着陸させます。パラシュートはオプションです。ヘリコプターには推奨されません（カモフKa-52アリゲーターは顕著な例外です）。

#### 超光速（FTL）

宇宙船のみ。この船には超光速エンジン（ハイパードライブ、ワープドライブ、ワームホールジェネレーターなど）が装備されています。FTLドライブは個別の速度評価を持ち、これは本質的に恒星船が1パーセク（3.26光年、約31兆キロメートル、または約19兆マイル）を横断する速度を測定するものです。以下の通りです：

##### FTL速度評価テーブル 

| 速度評価 | 1パーセク横断の係数 |
| :-- | :-: |
| のろま（Ponderous） | 10 |
| 鈍重（Sluggish） | 8 |
| 低速（Slow） | 7 |
| 平凡（Mediocre） | 6 |
| 緩慢（Gentle） | 5 |
| 中速（Moderate） | 4 |
| 急行（Rapid） | 3 |
| 高速（Fast） | 2 |
| 快速（Fleet） | 1 |

係数の時間は、その設定のFTL開発レベルに応じてゲームマスターが決定します。例えば、基本係数が「1日」であれば、FTL速度が「のろま」の船は旅を完了するのに10日かかり、「快速」の船は1日で旅を完了します。FTL技術の効率がはるかに低い別の設定では、係数時間は日単位ではなく月単位で測定されるかもしれません。

船には往復の燃料があるか、目的地で燃料を補給する手段があると想定されます。

設定にもよりますが、あらゆるサイズの宇宙船にFTLドライブを搭載できると想定してください。

FTLドライブは、恒星の1.5天文単位（約2億2500万キロメートル、または2億7000万マイル）以内では起動できません。つまり、船はFTLシステムを起動する前に、亜光速ドライブを使用して火星ほどの距離まで移動する必要があります。

#### 地上車両（Ground Vehicle）

車両は地上を移動可能です。

#### ホバー（Hover）

車両はエアクッションまたは反重力リパルサーを使用して地面の上をホバー走行します。

#### 豪華（Luxurious）

車両は乗客を一定レベルの豪華さで運ぶように特別に設計されています。余分な貨物スペースは豪華な客室、プール、ホットタブ、乗客の気まぐれに応えるための追加の乗組員などに充てられます。

#### レール（Rails）

車両はレールシステムに依存します。この特性を持つ車両は、船体サイズが本来許可する値より3段階高い速度評価を自然に達成できますが、当然ながらレールシステム上のみの移動に制限されます。

#### 頑強（Resilient）

すべてのシステムは、サイズで決定されるより1回多くヒットに耐えられます。この特性は累積可能です。つまり「頑強2」は、2特性ポイントをコストとして、システムが通常より2回多くヒットに耐えられることを示します。

#### 航海（Seaborne）

車両は水上に浮きます。

#### 宇宙船（Spacecraft）

車両は真空に対して密閉され、宇宙放射線に対して遮蔽されています。設計によっては大気圏の離脱・再突入や、大気圏内での飛行の持続が可能です。

#### ステルス（隠密）

航空機のみ。車両はレーダーや他の長距離センサーシステムによる探知を回避するように設計されています。電子センサーを使用して車両を発見しようとする試みの難易度は1段階上昇します。

#### 潜水（Submersible）

車両は船体値×10メートルの運用深度まで、海面下に潜水可能です。崩壊深度（潜水艇が押しつぶされずに到達できる絶対的な最大深度）は、運用深度の1.5倍です。

#### 優れた操縦性（Superior Handling）

車両の操縦性は「簡単（簡単）」と評価されます。

#### 監視スイート（Surveillance Suite）

車両はオンボードコンピュータ、通信基地局、盗聴信号用受信機、および100メートル以内のスマートフォンの信号を傍受する装置を備えています。#### Tough

この特性を持つ民間車両は、軍事用車両の欄から船体（Hull）値を算出し、自動的に最大構造値（Structure）を持つ。この特性を持つ軍事用車両は、一段階下の行から船体値と構造値を算出する。

#### Tractor Beam

宇宙船専用。この船はトラクタービームを装備しており、自身の船体値から2段階低いまでの船体値を持つ車両を捕縛し、引き寄せることができる。したがって、巨大（Huge）な宇宙船は、中型（Medium）までのサイズの船体を引き寄せ、保持できる。

#### VTOL

垂直離着陸。この特性は、ローターを組み合わせて揚力を発生させるヘリコプターや同様の車両に固有のものである。固定翼航空機に適用される場合、空気中での姿勢、上昇、降下を制御するために固定または整列可能なスラスターを使用することを意味する。

#### Waterborne

車両は関節脚を使用して推進する。ウォーカー車両の移動速度は、その体格（体格）に関係なく「穏やか（Gentle）」が上限となる。しかし、ウォーカーは他の移動手段を備えた車両では不安定になるような高さに建造することができる。

この車両は水中移動が可能である。

#### Weaponized

車両は武器を搭載できるように改造されている。兵器システムについては、以下の[武器](0006_Vehicles.md?id=weapons)セクションで解説する。

## 操縦と機動

回避行動や急な機動を行うには、運転者または操縦者が車両の制御を維持するために「運転（運転）」または「操船（Pilot）」判定に成功する必要がある。ほとんどの車両は時折かかるストレスや負荷に耐えられるように設計・製造されているが、ゲームマスターは機動の意欲に応じて、特定の機動にはより高い難易度（難易度）での判定が必要であると裁定できる。失敗した場合、車両の制御を失ったことになる。「制御喪失（Loss of Control）」表でロールすること。

なお、「制御喪失」表は地上車両にのみ適用される。同様の効果を航空機や宇宙船に適用することも可能だが、ゲームマスターはその効果の理由を特定のものに合わせる必要がある。例えば、航空機の場合、横滑りではなくスピンに入る可能性がある。

また、車両固有のハンドリングが「運転」判定に追加の影響を与える場合がある。ハンドリングは「非常に簡単（Very 簡単）」、「標準（標準）」、「困難（困難）」、「至難（至難）」、「超人的（超人的）」のいずれかであり、機動を実行する際の「運転」判定の開始点を決定する。その後、機動の難易度がハンドリングに適用され、最終的な難易度が決定される。

例えば、高性能なオートバイにはジャイロスタビライザーが内蔵されており、ハンドリングは「非常に簡単」である。運転者が追跡者をかわすために180度のスキッドターンを行いたい場合、ゲームマスターはその機動を難易度が1段階上がるものと評価する。したがって、運転者は「非常に簡単」ではなく「標準」で「運転」判定を行わなければならない。もしスタビライザーのないオートバイで同じ機動を試みた場合、「運転」判定は「困難」になる。

「優れたハンドリング（Superior Handling）」は特性である。車両の説明にこの特性が含まれていない場合、大型以下のすべての車両のハンドリングは「標準」である。巨大および莫大な車両は、それぞれ本質的に「至難」および「超人的」のハンドリング特性を持っており、ゲームマスターは車両のサイズゆえに特定の機動は単に不可能であると裁定する自由がある。

##### 制御喪失表 

| 1d100 | 結果 |
| :-: | :-- |
| 01-25 | 急旋回。制御喪失は一時的なもの。車両は5秒間、移動速度を1段階下げる。 |
| 26-40 | スキッド。運転者は車両の制御を維持するために抗わなければならない。車両は10秒間、移動速度を2段階下げる。 |
| 41-50 | 激しいスキッド。車両は間違った方向を向いたまま15秒間停止する。 |
| 51-60 | 横転。車両は横滑りして転がり、その構造値に3d10のダメージを受ける。乗員は「持久力」判定に成功しなければ、1d3個の部位判定位置に1d10のダメージを受ける。 |
| 61-70 | 激しい横転。上記と同様だが、車両は3d10+10のダメージを受け、乗員は「持久力」判定に成功しても1d10のダメージ、失敗すれば2d10のダメージを受ける。 |
| 71-80 | 全損。上記と同様だが、車両の構造値は0になる。乗員は「激しい横転」と同じダメージを受ける。 |
| 81-90 | 爆発。上記と同様だが、車両の燃料システムが引火し、1d20+10秒以内に爆発する。脱出できない場合、乗員はさらに1d6個の部位に対して1d6の火炎ダメージを受ける。 |
| 91-98 | 即時爆発。上記と同様だが、爆発は即座に発生する。 |
| 99-00 | 壊滅的な衝突。乗員は「持久力」判定に成功しなければ即死する。「全損」と同等のダメージが必ず発生する。 |
