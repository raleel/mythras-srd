# 戦闘

戦闘はロールプレイングゲームにおいて重要な要素です。暴力的な対立は、宿敵との復讐に燃える戦いから、戦争時における軍隊の衝突に至るまで、常に問題を解決する手段となってきました。とはいえ、戦闘は必ずしも死に至るような野蛮な戦いである必要はありません。戦闘遭遇の中には、怪我をせずに終わる活劇的な決闘や、あるいは少し陽気な酒場での乱闘のようなものもあり得ます。『Mythras Imperative』では、戦闘の核心的な要素を説明するためにいくつかの用語を使用しています。これらについては後続のセクションで説明しますが、概要は以下の通りです。
- **戦闘スタイル:** 文化や職業の一部として習得する、一連の武器を扱う技能。
- **戦闘ラウンド:** 5秒ごとに区切られた管理上の時間単位。
- **戦闘アクション:** 行動ポイントを消費して、ラウンド中にキャラクターが行える行為。
- **武器のサイズ:** 特定の武器をパリィ（受け流し）する難易度。
- **交戦:** 状況に応じて、直接的な相手を攻撃したり、攻撃を受けたりできる状態。
- **特殊効果:** 戦闘において優位に立った際に発動できる戦闘操作。

## 戦闘スタイル

戦闘スタイルは、性質の近い複数の武器を「パッケージ」としてまとめたものであり、武器ごとに個別に学習する必要性を省くものです。

戦闘技能において最も重要な側面は、キャラクターがその技能に含まれる各武器の使い方を、単独でも組み合わせても習得し、必要に応じて交換できるようにすることです。戦闘訓練は、単に特定の武器を最適な状況下で使用することに焦点を当てるだけでなく、深刻な不利な状況に置かれたときに何をすべきかもカバーします。このようなクロストレーニングは、武器の破損や武装解除といった不測の事態が常に起こり得る戦場に備えるために、戦闘員にとって不可欠な部分です。

したがって、ハイパーボリアの野蛮人は槍、手斧、投げ槍、盾の使い方を知っていることが期待されますが、シュメールの戦士は代わりにショートソード、メイス、盾、弓の訓練を受けているかもしれません。いくつの武器を一つのスタイルに含めるかは、最終的にはゲームマスターとゲームの設定によって決定されます。

自分のスタイルに含まれていない武器を使用しようとするキャラクターは、1段階以上の難易度ペナルティを受けることになります。

戦闘スタイルには、単に武器技能のグループを学ぶこと以外の機能もあります。各スタイルは特定の文化やキャリアによって教えられるため、本質的にそのグループが通常戦う環境や軍事戦術に最適化されています。例えば、馬の遊牧民は鞍の上から戦うことを学び、歩兵は密集陣形で戦うための訓練を受けます。したがって、追加のボーナスとして、いくつかの戦闘スタイルには特定の状況下で利点を与える「特性」が1つ以上割り当てられる場合があります。特性は、その特定のスタイルの武器や状況においてのみ使用されることを意図しています。当然ながら特性は無数にあり、その多くは特定の時代やキャンペーンの世界に特有のものです。

##### 戦闘スタイルの特性表

| 特性 | 説明 |
| :-- | :-- |
| 獣上の槍騎兵 | この戦闘スタイルで騎乗突撃を行う際、命中判定に1段階の難易度ペナルティを受けない。 |
| 盲目戦闘 | 照明不足や一時的な盲目化によって課されるペナルティを無視できる。 |
| 向こう見ず | 白兵戦において、転倒せずに回避（回避）技能を使用して攻撃をかわすことができる。 |
| 防御的思考 | パリィ（受け流し）を行う際、そのラウンド中に攻撃的なアクションを行わないことを条件に、武器のサイズを1段階大きくする。 |
| 陣形戦闘 | 3人以上の戦士が側面を突かれていない場合、密集陣形を組むことができる。これにより、開放的または無秩序な敵を不利な状況に追い込み、交戦中の敵の行動ポイントを1減少させる。 |
| ノックアウト・ブロー | 不意打ちで攻撃する際、部位判定による気絶（Stun 位置）を「ターン」ではなく「分」持続するものとして扱う。 |
| 騎乗戦闘 | 乗馬（乗馬）技能による戦闘ロールの技能上限を無視できる。 |
| 遠隔射撃手 | 遠隔武器を使用する際、ランダムな部位判定の結果を隣接する部位に変更できる。 |
| 散兵戦術 | このスタイルでは、歩行中または走行中に遠隔攻撃を行うことができる。 |
| 投擲武器 | このスタイルに含まれる近接武器はすべてペナルティなしで投擲できるが、その際、武器のダメージロールは半分になる。 |
| 徒手練達 | 徒手でのブロックやパリィを「中型」サイズとして扱えるようにし、武装した相手に対してより良く防御できるようになる。 |

## 戦闘の進行

その臨場感を強調するため、戦闘は一撃ごとに追跡されます。管理を容易にするため、戦いは5秒ごとの「戦闘ラウンド」に分割されます。この期間中、戦闘員は白兵攻撃を行ったり、それらに対して防御したり、戦闘に介入・離脱したり、遠隔武器を発射または投擲したりすることができます。現実の生活と同様に、ほとんどの戦闘は、一度開始されると数分ではなく数秒で決着がつきます。ゲーム的な観点からは、これは複数の戦闘ラウンドを意味しますが、参加者がイニシアチブをリセットしたり、戦術的状況を再評価したり、あるいは再開前に少し休憩を取るために離脱しない限りは継続します。実力が拮抗している敵同士、あるいは一連の敵との戦いだけが、それよりも長く続く傾向があります。

## 火器

『Mythras Imperative』のゲームで火器を使用する場合、銃撃戦の致死性を考慮して検討すべき点がいくつかあります。第一に、人間の反射神経よりも速く移動するレーザービームや弾丸を避けることはほぼ不可能です。提示された戦闘ルールを使用する場合、回避（回避）を使用してそのエリアから飛び出さない限り、命中すれば被害者は即座に1つ以上の特殊効果にさらされることになります。また、行動ポイントの経済性も変化します。受動的に自分を守るためにポイントを使えない場合、ほとんどのキャラクターは全ての行動を攻撃に費やすことになり、敵の無能さに賭けることになります。このパラダイムシフトに対処するため、ゲームマスターとプレイヤーは、銃撃戦に対する見方やアプローチを変える必要があるかもしれません。注意すべき点は以下の通りです。

- 銃撃戦は危険である！
- 基本的に、人々は他者を撃つことよりも、撃たれないことを優先する。
- 最も一般的な防御方法は、遮蔽物を取ることである。
- 制圧射撃は、敵の反撃を防ぐ最良の方法である。
- 火器は、構えたり狙いをつける時間を取らない限り、驚くほど不正確である。
- 撃たれると、悪いことが起こる。

銃撃に対して身を守ることは、主に防具、遮蔽物の利用、そして相手の反撃能力を奪うことに帰着します。その結果、ほとんどの銃撃戦は非常に戦術的なものになります。大量の制圧射撃、側面からの機動、そして深い遮蔽物から敵を追い出すといった行動です。その間、キャラクターは敵の射撃が止まるまで、何戦闘ラウンドも釘付けにされて反応できなくなる可能性があります。これは一部のプレイヤーにとって非常に退屈に感じられるかもしれません。

弾切れによって片方が諦める、あるいは完全に戦場から逃走するなど、銃撃戦全体で負傷者が一人も出ないということも十分にあり得ます。結局のところ、全自動射撃が可能な武器の掃射を浴びるリスクを冒したいと思う人はほとんどいないからです。

これらの戦闘ルール全体を通して、特定のアクションの種類、特殊効果、および状況は火器を使用した戦闘のみに適用され、それらは適宜マークされています。

## 戦闘ラウンドとイニシアチブ

戦闘ラウンドではいくつかの重要な用語が使用されます。

- **イニシアチブ:** 戦闘ラウンドのターン中に誰がいつ行動するかを決める順序。ゲームマスターはイニシアチブ値を高い順から低い順へカウントダウンするため、各参加者は自分の番号になった時にターンを取る機会を得ます。
- **ターン:** 5秒間の戦闘ラウンド中、各参加者は自分の持つ行動ポイントと、それらの使用方法に応じて、1回以上のターンを取る機会があります。自分のターンになると、参加者は戦闘アクションを1回実行します。これには宣言、移動の可能性、必要なダイスロール（リアクションを含む）、およびアクションの解決が含まれます。行動ポイントが残っている場合、プレイヤーはイニシアチブ順に再度ターンを取ることができます。行動ポイントがなくなるか、または残りがリアクションのために保留された場合、プレイは次の戦闘ラウンドへ進行します。

各用語については、以下で詳しく説明します。

#### イニシアチブ

イニシアチブは、戦闘ラウンドにおける参加者の行動順序を決定します。これは戦闘開始時にロールされ、各キャラクターがいつ行動するかを決定します。特定の戦闘アクションや特殊効果など、状況を変化させる何かが起こらない限り、イニシアチブは強制的に振り直されるまで維持されます。

イニシアチブは、各参加者が1d10をロールし、イニシアチブ修正値を加算することで算出されます。最も高い結果を出した者が最初に行動し、次に高い者が続くといった具合です。2人以上の参加者が同点になった場合、敏捷性（敏捷性）が高い方が先に行動します。それでも同点の場合は、各々がダイスをロールし、出目が大きい方を先とします。

#### 戦闘中のアクション

イニシアチブが決定されると、参加者は各戦闘ラウンド中に複数の戦闘アクションを実行する可能性があります。全てのキャラクターはラウンドごとに2行動ポイントを得ますが、行動できるタイミングは、そのアクションが能動的か受動的かによって制限されます。

能動的アクションは、キャラクター自身のターン、つまりイニシアチブの最中にのみ試みることができます。能動的アクションとは、武器による攻撃など、キャラクターが主体となって行うものです。

受動的アクションとは、自分に対して行われる行為に対抗、または抵抗するためにキャラクターが取るものです。各脅威に対して1回のリアクション試行のみが許可されます。その例としては、攻撃のパリィ（受け流し）が挙げられます。

未使用の行動ポイントは、次のラウンドに持ち越すことはできません。

## 戦闘アクション

戦闘アクションとは、戦闘中に行える行為のことです。武器を抜く、呪文を唱える、攻撃から飛び退くなどは、全て戦闘アクションの例です。ほとんどは戦闘そのものに関わる要素ですが、呪文や武器の領域外の活動に関連するものもあります。

前述の通り、キャラクターがラウンドごとにどれだけ行動できるかは、利用可能な行動ポイントによって制限されます。これらは、様々な戦闘アクションを実行するために各戦闘ラウンドを通して消費されます。戦闘員が行動ポイントを使い切ると、そのラウンドの残りの期間は行動できず、次のラウンドの開始時にポイントがリセットされるまで待たなければなりません。

特に指定がない限り、どんな戦闘アクションも（「フリー」アクションを除いて）1行動ポイントを消費します。そのため、戦闘員は行動ポイントをいつ、どのように使用するかを慎重に検討する必要があります。彼らは望むままに攻撃的、あるいは防御的に行動し、戦闘の進化する状況に動的に対応できます。

### 能動的アクション

以下は、キャラクターが行動ポイントを消費して自分のターンに試みることができる活動です。呪文の詠唱や再装填など、完了までに複数のターンを要するアクションがあることに注意してください。各ターンはそれぞれ1行動ポイントを消費します。

#### 攻撃 (Attack)

キャラクターは近接武器で打撃を行うか、遠隔武器を使用しようとすることができます。

#### 構え (Brace)

キャラクターはしっかりとした姿勢を取り、来るべき攻撃の方向に重心をかけて構えます。ノックバックや跳躍攻撃への抵抗に関して、キャラクターの体格（体格）は50%大きいものとして扱われます。殴打（殴打）特殊効果に対しては、体格（体格）が2倍になります。

#### 呪文詠唱/能力使用 (Cast Magic/Use 霊力)

キャラクターは呪文を唱えたり、特定の能力を発動したりしようとすることができます。複雑な魔法は、詠唱を完了するために複数のアクションを必要とする場合があります。完了すると、魔法は詠唱者の次のターンまでいつでも解放できます。その時点で後の効果のために保持することもできますが、これには後の解放に向けて準備を維持するための「呪文/能力保持」アクション（下記参照）が必要です。

#### 射程変更 (Change 射程)

キャラクターは、近接戦闘で相手と交戦していないか、遠隔戦闘の状況で敵の射撃によって釘付けにされていない限り、相手に接近または離脱しようとすることができます。

#### 突撃 (Charge)

突撃アクションにより、キャラクターは走行または疾走速度で交戦射程まで移動し、突撃の勢いを利用してより強力な近接攻撃を行うことができます。これらのルールについては、以下の[突撃](0005_Combat.md?id=charging)セクションで詳しく説明します。

#### 遅延 (Delay)

キャラクターは、割り込みやパリィ（受け流し）といった後の受動的アクションを行うために、1つ以上のアクションを温存します。遅延のアクションポイント消費は、最終的に実行された行為によってカバーされます。キャラクターの次のターンまでに遅延させたアクションが実行されなかった場合、キャラクターは躊躇した（下記参照）とみなされ、行動ポイントは失われます。

#### 躊躇 (Dither)

他のアクションが選択されない場合のデフォルトのオプションであり、キャラクターはターンを無駄に過ごします。

#### 呪文/能力保持 (Hold Magic/霊力)

詠唱が完了すると、キャラクターは呪文や能力を一時的にチェックした状態で保持し、解放する最適な瞬間を待つことができます。魔法はキャラクターが後続のターンでこのアクションを取り続ける限り保持できますが、これを行うと、その呪文に関連する場合、敵によるカウンター・スペル（Counter Spell）のリアクションを自由に使用されてしまいます。保持された呪文を詠唱するための実際の技能ロールは、解放されるまで行われません。

#### 騎乗 (Mount)

キャラクターは、乗騎や乗り物に乗り降りできます。特に大きな乗騎の場合は、完了までに複数のターンが必要になる場合があります。

#### 移動 (Move)

相手と交戦していない限り、キャラクターはゲームマスターが状況に応じて適切と判断する距離を移動できます。

#### 機動戦 (Outmaneuver)

キャラクターは、回避（回避）技能の対抗ロールのグループで複数の相手を交戦させることができます。彼らのロールに勝てなかった者は、その戦闘ラウンドで彼を攻撃できません。以下の[機動戦](0005_Combat.md?id=outmaneuvering)セクションを参照してください。

#### 武器準備 (Ready Weapon)

キャラクターは武器やその他の物体を回収、抜刀、収納、取り出し、または再装填できます。近くに落ちている物体を回収するには2つのアクションが必要です。1つは移動してその物体に手を伸ばすため、2つ目は準備された姿勢に戻るためです。一部のミサイル武器は再装填に複数のアクションを必要とします。

#### 再装填 (再装填 - 火器)

武器準備と同様です。再装填時間は武器の種類によって大きく異なります。単発の黒色火薬式マスケット銃は、弾倉や動力源を交換するよりもはるかに再装填に時間がかかります。

#### 足場回復 (Regain Footing)

相手と交戦していない場合、キャラクターは転倒やノックダウンの状態から自動的に足場を回復できます。交戦中の場合、キャラクターは立ち上がる前に相手との腕力（腕力）または運動（運動）の対抗ロールに勝たなければなりません。この対抗判定の解決にアクションポイントは消費されません。

#### 覗き込み (Sneak Peek - 火器)

覗き込みは、現在遮蔽物の後ろに隠れている人物が、戦術的な状況を判断するために素早く様子を見ることを可能にします。このアクションは表面上安全であり、観察者は知覚（知覚）ロールを1回行ってから遮蔽物に戻ることができます。ただし、知覚テストがファンブルだった場合、愚かにも頭を出しすぎたり、敵が射撃するのに十分な時間見えたままになったりします。

#### 武器安定化 (Steady Weapon - 火器)

キャラクターがしっかりとした射撃姿勢を確立し、自動武器が安定するようにサポートすることを可能にします。これには、キャラクターが少なくとも部分的に露出しており、遮蔽物によって完全に保護されていない必要があります。主な利点は、バースト射撃やフルオート射撃の反動ペナルティを1段階軽減することです。この効果は、キャラクターが移動するまで続くという点で「構え」に似ています。

#### もがき (Struggle)

キャラクターがある種の攻撃や特殊効果の犠牲になった場合、状況から自分を脱出させようとすることができます。例えば、敵の拘束から逃れるなどです。

#### 発射モード切り替え (Switch Fire Mode - 火器)

発射モード切り替えにより、自動火器や二目的火器のユーザーは、武器のセレクターを変更して他の発射モードを活用できます。これにより、アサルトライフルをセミオートからバーストに切り替えたり、異なる種類の弾薬を選択したり、あるいは積分式グレネードランチャーのような補助システムを起動したりできます。現代の武器はモードを切り替えるためにキャラクターのターンにアクションポイントを必要としますが、十分に発達したハイテク火器では、電子インプラントやユーザーの思考をサイキック的に読み取ることによってトリガーされるフリーアクションとして許可される場合があります。

#### 遮蔽物を取る (Take Cover)

遮蔽物を取ることは、射撃手がすぐ近くにある遮蔽物に身を隠し、飛来する射撃に対してある程度の保護を得ることを可能にする能動的なアクションです。回避（回避）とは異なり、ユーザーが伏せ状態になることはありませんが、廊下の角に隠れたり、酒場のテーブルの後ろにしゃがんだりと、何らかの遮蔽物が利用可能であることに依存します。状況によっては、利用可能な遮蔽物がキャラクターを完全に守るのに十分でない場合もあります。遮蔽物の種類もその保護品質を決定します。例えば、厚い鋼鉄の扉は弾丸を完全に防ぐかもしれませんが、薄い木の壁は4点分の防具値しか提供しないかもしれません。特定の素材の保護品質に関する一般的なガイドラインについては、[無生物](0004_Game_System.md?id=inanimate-objects)セクションの表を参照してください。

### 受動的アクション

このリストは、差し迫った脅威への対応として戦闘ラウンド中いつでも使用できるリアクションを指定しています。前のリストと同様に、リアクションを実行するには1行動ポイントを消費します。

#### カウンター・スペル (Counter Spell)

キャラクターは、飛来する呪文を打ち消すか、対抗しようとすることができます。これは、対抗する魔法の詠唱時間が1ターンであることを前提としています。そうでない場合は事前に準備し、「呪文/能力保持」アクションを使用して一時的に温存しておく必要があります。この方法で魔法を正常に遮断すると、複数の標的や効果範囲を持つ呪文であっても、呪文全体が無効化されるとみなされます。

#### 回避 (回避)

キャラクターは、飛来するミサイルや突撃攻撃などの脅威から飛び退くために、回避（回避）技能を使用できます。能力や特別な状況で軽減されない限り、これによりキャラクターは伏せ状態になります。したがって、キャラクターの次のターンは通常、再び立ち上がるために足場回復（Regain Footing）アクションを費やすことになります。

#### 割り込み (Interrupt)

遅延キャラクターのみ。この受動的アクションは、相手のターンを任意の時点で停止させ、遅延させたターンアクションを実行します。戦術的な状況に変化がないと仮定すれば、相手はキャラクターのターンが完了した後にターンを続行します。元の宣言を依然として達成できない場合、相手の行動ポイントは無駄になります。割り込みは、遅延キャラクターの近くを通り過ぎる、または武器の間合い内にいる誰かに対する機会攻撃を行うためにも使用できます。

#### パリィ (Parry)

キャラクターは、パリィ、身を乗り出す、しゃがむ、足さばきを組み合わせて打撃を最小限に抑えることで、飛来する攻撃に対して防御を試みることができます。

### フリーアクション

フリーアクション（以下にリスト）は戦闘ラウンド中のいつでも実行でき、アクションポイントを消費しません。

#### 状況評価 (Assess Situation)

交戦していない場合、キャラクターはアクションポイントを消費せずに知覚（知覚）ロールを行えます。成功すると、戦術的な状況に関連する変化（突撃を開始しようとしている敵を見つけるなど）が明らかになります。走行中に評価を行うと知覚（知覚）ロールに困難（困難）のペナルティがかかり、疾走中の場合は至難（至難）となります。

#### アイテムを落とす (Drop Item)

アイテムを落とすことはフリーアクションです。

#### 合図 (Signal)

交戦していない場合、1人以上の参加者にジェスチャーや合図を送る（相手がそのサインを認識できる場合）ことはフリーアクションです。

#### 会話 (Speak)

キャラクターは戦闘中いつでも会話できますが、話す内容は5秒以内に発話できる短いフレーズに制限されるべきです。例えば、「後ろに気をつけろ！」や「地獄へ落ちろ！」などです。

#### 幸運ポイント使用 (Use Luck Point)

幸運ポイントを使用すること（例えば特定の結果を再ロールするため）はフリーアクションです。#### 位置防御

キャラクターは、自身の武器のいずれかをそのエリアの受動的なブロックに割り当てることで、特定の部位判定の被弾を防ぎます。その部位に命中した攻撃は、そのサイズに応じた受け流し武器の通常の処理として、自動的にダメージが減少します。このカバーは、割り当てられた武器で攻撃を行ったり、能動的な受け流しを行ったりするまで持続します。カバーする部位判定の設定または変更は、相手が攻撃判定を行う前に行わなければなりません。シールドはその設計上、複数の部位をカバーすることができます。

詳細については、以下の[受動的ブロッキング](0005_Combat.md?id=passive-blocking)を参照してください。

## 移動

以下のルールは戦闘中の交戦を規定します。

- 移動は「移動」または「突撃」アクションによって行われます。
- 「移動」アクションにより、キャラクターは自身の移動速度に等しい距離を移動できます。
- 移動は、交戦していないキャラクターのみが実行可能です（「出し抜く」などの特殊なケースを除く）。
- 特定のケース（突撃など）を除き、キャラクターが意図した相手の交戦距離に入った時点で、すべての重要な移動は終了します。
- 接触して突撃する場合を除き、相手の交戦ゾーンへ移動することは、互いを交戦状態にします。
- 一度交戦状態になると、近接戦闘から先に離脱しない限り、相手から離れて移動することはできません。
- 「戦闘待機」アクションを使用している非交戦状態の敵のそばを通り抜けようとすると、（特定の例外として）その敵は通過するキャラクターを攻撃するか、キャラクターの進行を阻害して次ターンまたはラウンドで近接戦闘を開始させることができます。

### 状況に応じた移動速度

これらの移動速度は状況に応じたものであり、常に選択できるわけではありません。多くは他の箇所で詳述されていますが、利便性のためにここに記載します。これらの状況に応じた速度のほとんどは、定められた制限下で通常の移動速度に追加して使用可能です。そのような情報は、以下の各説明で詳しく述べられています。

#### 登攀

登攀可能な表面や物体に隣接して移動するか、ターンの開始時に隣接しているキャラクターは、移動速度に等しい速度で登ることができます。キャラクターは「歩き」より速く移動してはならず、かつ移動力を残していなければなりません。登った距離は既に使用した移動力分だけ減少します。装備している防具は、合計の防具ポイントに基づいて登攀者を妨害します。

| 8-15 | 軽度 | -1 |
| 16-23 | 中程度 | -2 |
| 24-31 | 重度 | -3 |

| 40+ | 超人的 | -5 |

## 戦闘の仕組み

『Mythras Imperative』における戦闘は、各攻撃や受け流しを1回の突き、振り、呪文詠唱、あるいは武器の射撃として解決されます。いかなる攻撃アクションも、リアクションによって抵抗される可能性があります。したがって、キャラクターが相手への攻撃に成功したとしても、相手は攻撃が着弾する前に受け流しが可能かどうかを確認するための自身のロールを行うことができます。この哲学は、目標が遮蔽に飛び込むミサイル武器攻撃であろうと、巨大タコの手から逃れようとする場合であろうと、同じように適用されます。

### 攻撃と受け流し

近接戦闘は以下の手順で処理されます：

1. 攻撃側のターンに、攻撃側は行動ポイントを消費し、自身の「戦闘」技能でロールを行い、結果を記録する。
2. 防御側は希望する場合、行動ポイントを消費して「受け流し」を行い、自身の「戦闘」技能でロールを行い、結果を記録する。
3. 結果の成功度を「差分ロール」に従って比較する。
4. 差が生じた場合、優れたロールで成功した戦闘側に1つ以上の「特殊効果」が付与される。
5. 攻撃側が成功またはクリティカルを達成した場合、武器ダメージをロールし、ダメージ修正（あれば）を加算する。該当する場合、打撃の「部位判定」が決定される。
6. 防御側が成功またはクリティカルを達成した場合、関係する武器の相対的なサイズに応じて、加えられたダメージを減少させる。
7. 残りのダメージから、自然または着用している防具の防具ポイントを減算する。

交換の結果として生じる特殊効果は、ダメージが与えられたかどうかに依存しないことに注意してください。防御側がより高い成功度を獲得しながらも、依然として負傷する可能性は十分にあります。

### 武器のサイズ

『Mythras Imperative』のすべての武器は、与えるダメージから両手持ちの必要数に至るまで、いくつかの異なる特性を持っています。サイズは武器の質量、テコ、安定性を組み合わせたものであり、武器がダメージを与えたり受け流したりする能力を決定するために使用されます。サイズ区分は「小」「中」「大」「巨大」「極大」です。クリーチャーの徒手攻撃には、その物理的特徴に応じて同様の区分が割り当てられます。

### ダメージ減少

防御側が受け流しに成功した場合、使用した武器の相対的なサイズに応じて攻撃側のダメージを（あれば）減少させることができます。

- 同等以上のサイズの武器やシールドで攻撃を受け流すと、すべてのダメージをそらす。
- 1段階小さいサイズの武器やシールドで受け流すと、ダメージの半分をそらす。
- 2段階以上小さいサイズの武器やシールドで受け流すと、ダメージを一切そらせない。

_例えば、グレートアックス（巨大）をカイトシールド（巨大）で受け流せばすべてのダメージをブロックできます。ロングソード（大）で受け流せばダメージは半分になり、ショートソード（中）で受け流した場合はダメージを一切止めることができません。_

### 防具

防御側の受け流しを貫通したダメージは、所持している自然の保護（鱗や殻など）や着用している防具の防具ポイントによってさらに減少します。防御側が両方を持っている場合、2つを合計してダメージを減少させます。

その質量と動きへの制限のため、キャラクターが着用している防具のうち、最も高い防具ポイントの値がイニシアチブロールへのペナルティとして作用します。

### 外れた攻撃の受け流し

攻撃側が最初の攻撃ロールに失敗した場合、防御側は行動ポイントを消費して受け流すオプションを持ちます。いずれにせよ外れるはずの攻撃を受け流すのは無意味に思えるかもしれませんが、熟練した防御側はこれを利用して1つ以上の特殊効果を獲得し、敵を弱体化させたり無力化させたりする可能性があり、かつ次のターンの行動ポイントを温存することもできます。

### 受け流し不能または不当な状況

防御側が行動ポイントの残りがなく受け流しができない状況や、打撃を耐えられると確信して受け流さないことを選択した場合、自動的に「失敗」したとして扱われます。これにより、攻撃側が成功した場合、1つ以上の特殊効果を付与されるという結果が生じます。

### 不成功なロールとファンブル

両方の戦闘者がロールに失敗した場合、あるいは防御側が外れた攻撃を利用しないことを選択した場合、攻撃・受け流しのシーケンスは終了し、次に高いイニシアチブを持つ参加者に戦闘が移ります。

## 特殊効果

戦闘とは、単に相手を傷つけたり殺したりすること以上のものです。戦闘芸術は、相手を無力化したり、必ずしも危害を加えることなく降伏を強いるような状況に追い込んだりするなど、敵を倒すための多くの手法を教えます。特殊効果はこれらの技術を表現し、プレイ中にどのように発生するかを制御します。

相手がそれぞれの戦闘技能の差分ロールを行うたびに、成功度の差によって特殊効果が発生する機会が示されます。これは、戦闘者の一方が相手を狡猾なトリックや戦術で利用可能な不利な状況に追い込むことを表しています。

受け取れる特殊効果の数は、成功度の差に依存し、それは「差分成功度」表に示されています。

交換の間に特殊効果を獲得した場合、ダメージや（もしあれば）部位判定をロールする前に選択しなければなりません。受け手が特殊効果を受けると同時に重傷を負う場合、持久力ロールは特殊効果の適用後に解決されます。

特殊効果は、多様な状況や技術をカバーしています。攻撃専用に設計されたものもあれば、防御用のものもあり、両方の状況に適応できるものもわずかにあります。特定の特殊効果は、特定の武器タイプや特定のダイスロール（例えば、技能チェックでのクリティカルやファンブルなど）に制限される場合もあります。

2つ以上の特殊効果を獲得した場合、戦闘者はそれぞれの前提条件が満たされている限り、自由に組み合わせを選択できます。一部の効果はスタック（累積）可能です。例えば、クリティカル成功をロールして2つの特殊効果を獲得した攻撃者は、「ダメージ最大化」を個別の攻撃的マニューバの代わりに2回選択することができます。

### 特殊効果の説明

#### 偶発的負傷

防御側が攻撃者の攻撃をそらしたりひねったりして、攻撃者がファンブルを起こし、自らを傷つけるようにします。攻撃者は使用した武器を用いて、自身のランダムな部位判定に対してダメージをロールしなければなりません。徒手の場合、攻撃者は何か身体の内部を裂いたり折ったりし、ダメージロールはあらゆる防具を無視します。

#### 立ち上がり

防御側が刹那の隙を利用して、足の状態に戻ることを可能にします。

#### 殴打

攻撃者は意図的に相手のバランスを崩します。防御側がどれだけ後ろや横にふらつくかは、使用される武器に依存します。シールドは2ダメージ（防具や受け流しによる減算前）ごとに相手を1メートル後ろに突き飛ばし、打撃武器は3ポイントごとに1メートル突き飛ばします。殴打は攻撃者の体格の2倍までのクリーチャーにのみ有効です。対象が後ろの障害物に強制的に突き飛ばされた場合、転倒を避けるためにアクロバット技能、または難易度「困難」の運動技能でロールしなければなりません。火器については、殴打は純粋な力で後ろに放り投げるというより相手のバランスを崩すことに依存しているため、射撃弾が四肢に命中すれば標的をよろめかせるのは十分に理にかなっています。エネルギー兵器は、ビームの物理特性が何らかの表面爆発を引き起こさない限り、そのような効果をもたらす可能性は低いです。

#### 出血

この攻撃は主要な血管を切り裂きます。一撃が防具ポイントを上回り目標を負傷させた場合、防御側は「持久力」と元の攻撃ロールとの対抗ロールを行わなければなりません。防御側が失敗した場合、大量に出血し始めます。戦闘ラウンドの開始ごとに、対象者は崩れ落ちて死亡する可能性があるまで、疲労レベルを1ずつ失います。出血している傷は「応急手当」技能ロールに成功することで止血できますが、対象者は傷口を再び開くような過酷または暴力的な行動を一切行えなくなります。ゲームシステムセクションの「血液損失」を参照してください。火器については、ほとんどの火器が非常に狭い傷跡を生成するため、切断武器や刺突武器よりも主要な血管を傷つけたり切断したりする方が実際には困難です。そのため、手裏剣、鋭利なフレシェット、平坦化されたフォースフィールドといった異質な弾薬を発射するような特殊な銃でない限り、出血はクリティカル成功時にのみ発生させるべきです。

#### 目つぶし

クリティカル発生時、防御側は砂を投げたり、シールドで日光を反射させたり、その他の戦術によって攻撃者の視界を一時的に妨害し、相手の目をくらませます。攻撃者は自身の「回避」技能（シールドを使用している場合は「戦闘」技能）を用いて、防御側の元の「受け流し」ロールとの対抗ロールを行わなければなりません。攻撃者が失敗した場合、盲目の方法に応じて、続く1d3ターンの間、「困難」または「至難」の状況ペナルティを負います。

#### 防具無視

クリティカル発生時、攻撃者は防御側の自然または着用している防具の隙間を見つけます。防御側が自然保護を上回る防具を着用している場合、攻撃者はそのどちらを無視するかを決定しなければなりません。この効果はスタック可能で、両方を無視することもできます。この効果の目的上、魔法で得られた物理的な防御は着用防具として扱われます。防具無視は一見するとどんな種類の攻撃にも使用できるように見えますが、弾薬の種類によっては（拡散する散弾銃など）この効果を妨げられたり、逆に基本性能に組み込まれていて（テレポーテーション弾など）、他に獲得した特殊効果に加えてボーナスとして付与されたりする場合があります。多くはゲームマスターが武器をどのようにモデリングしたいかによります。#### 部位判定の選択

近接武器を使用している場合、攻撃者はその部位が通常の間合い内にある限り、攻撃が命中する部位を自由に選択できる。遠隔武器（銃器を含む）を使用する場合、「部位判定の選択」はクリティカル成功時のみ可能となる。ただし、標的が至近距離におり、静止しているか、攻撃者に気づいていない場合は例外である。銃器の場合、望遠照準器を使用することでこの射程を延長できる可能性がある。

#### パリー回避

クリティカル成功時、攻撃者は本来成功していたパリーを完全に無効化できる。

#### 武器へのダメージ

攻撃またはパリーの一部として、相手の武器にダメージを与えることができる。攻撃側は防御側のパリー用武器を具体的に狙い、その操縦者ではなく武器に対してダメージロールを適用する。狙われた武器は、その防具ポイントを使用してダメージに抵抗する。ヒットポイントがゼロになると武器は破壊される。銃器の場合、遠距離から手に持った武器を狙い打つことは、特定の部位を狙うよりもさらに困難であるため、原則としてクリティカル成功時に限定すべきである。ただし、いくつか例外がある。第一に、盾はその性質上、命中させやすいはずである。第二に、範囲内の手に持った物体を狙うことができる円錐状のビームを発射するエキゾチックな武器（例えば、金属物体を加熱する誘導銃など）である。

#### 相手の武装解除

キャラクターは、相手の武器を叩き落とす、引き抜く、またはねじり取って手から離させる。相手は、キャラクターの当初の攻撃ロールに対して、自身の戦闘スタイルの対抗ロールを行わなければならない。武装解除された側が敗北した場合、武器は武装解除した側のダメージ修正のロール値に等しいメートル数だけ吹き飛ばされる。ダメージ修正がない場合、武器は武装解除された相手の足元に落ちる。武器の相対的なサイズがロールに影響する。武装解除するキャラクターの武器が1段階大きいごとに、相手のロールの難易度は1段階上昇する。逆に、武装解除するキャラクターの武器が1段階小さいごとに、難易度は1段階容易になる。武装解除は、攻撃者の筋力の2倍までの生物に対してのみ有効である。

#### 標的の転倒

攻撃側、銃器専用。標的が射撃により少なくとも軽傷を負ったと仮定した場合、標的は自身の持久力と攻撃者の命中ロールで対抗判定を行わなければならない。失敗した場合、標的は衝撃と苦痛に屈し、無力化され戦闘を続行できなくなる。無力化からの回復は、応急手当の判定に成功するか、キャンペーン内に存在する技術的または麻薬的なブースターを使用することで行える。それ以外の場合、一時的な無力化は、標的の治癒率で1時間を割った時間に等しい期間持続する。

#### 伏せ込み

攻撃側、銃器専用。この特殊効果により、射手は次のターンの「遮蔽を取る」アクションを待つことなく、即座に遮蔽の背後に身を隠すことができる。この特殊効果を使用するには、キャラクターが既に遮蔽の隣で立っているか、しゃがんでいる必要がある。

#### パリー強化

クリティカル成功時、防御側は武器の体格に関係なく、攻撃の全威力をそらすことに成功する。

#### 絡め取り

鞭や網などの絡め取り武器を使用するキャラクターは、命中した部位を無力化できる。絡め取られた腕は持っているものを使用できなくなり、絡め取られた脚は標的の移動を妨げ、絡め取られた頭部、胸部、または腹部はすべての技能ロールの難易度を1段階上昇させる。次のターン、使用者は行動ポイントを1消費して、自動的に「相手を転倒させる」を試みることができる。絡め取られた犠牲者は自身のターンに、腕力を用いた対抗ロールで引き抜くか、特殊効果を獲得して「武器へのダメージ」、「相手の武装解除」、または「拘束解除」を選択することで脱出を試みることができる。

#### 強制失敗

相手がファンブルした際に使用する。キャラクターは「強制失敗」を、対抗ロールを必要とする他の特殊効果と組み合わせることができる。強制失敗により、相手はデフォルトで抵抗ロールに失敗する。それにより、武装解除、転倒などが自動的に成功する。

#### 掴み

相手が攻撃者の徒手戦闘の間合い内にいる場合、空いている手（または掴む能力のある同等の部位）を使用して相手をホールドし、戦闘から離脱できないようにできる。相手は自身のターンに脱出を試みることができ、その際は掴んでいる側が指定する、腕力または徒手戦闘技能のいずれかによる対抗ロールが必要となる。

#### 突き刺し

武器のダメージを2回ロールし、どちらの結果を攻撃に使用するかを攻撃者が選択する。武器が近接武器であると仮定し、防具を貫通して傷を与えた場合、攻撃者は次のターンに武器を傷口に残したままにするか、引き抜くかを選択できる。武器を傷口に残した場合、犠牲者の今後の技能ロールに難易度を与える。ペナルティの深刻さは、生物とそれを突き刺している武器の双方のサイズに依存し、以下の「突き刺し効果表」の通りとなる。簡略化のため、同じサイズの武器による追加の突き刺しは、追加のペナルティを与えない。近接戦闘中に突き刺さった武器を引き抜くには、戦闘アクションの「武器の準備」を使用する必要がある。使用者は対抗なしの腕力ロールに成功しなければならない（相手が抵抗する場合は対抗腕力ロールに勝利する必要がある）。成功すれば武器は引き抜かれ、同じ部位に対して、ダメージ修正なしで、その武器の通常のダメージロールの半分に等しい追加の損傷を与える。失敗した場合、武器は傷口に刺さったままで効果はないが、使用者は次のターンにもう一度試みることができる。特に有刺武器（銛など）は通常のダメージを与える。防具は引き抜きによるダメージを軽減しない。武器が刺さったままである間、攻撃者はその突き刺した武器をパリーに使用できない。

#### 射撃の名手

射撃で命中した部位を、隣接する部位へと1段階移動させることができる。生理学的な影響があるため、常識を適用すべきである。したがって、人型生物に対してこの特殊効果を使用した場合、脚への命中を腹部へと変更できる。逆に、グリフィンの胸を撃つ場合、前脚、翼、または頭部を選択できる。

#### ダメージ最大化

クリティカル成功時、キャラクターは武器のダメージダイスのうち1つを、その最大値に置き換えることができる。例えば、通常1d6ダメージのハンドアクスは6として扱われ、2d6ダメージのグレートクラブは1d6+6ダメージを与える。この特殊効果は累積可能である。自然武器にも使用できるが、ダメージ最大化は攻撃者のダメージ修正には影響せず、ダメージ修正は通常通りロールされなければならない。

#### 過貫通

クリティカル、銃器専用。一直線上に並んだ相手や密集した集団に対して射撃を行う場合、この特殊効果により、最初の標的のボディアーマーを克服したと仮定して、弾丸が最初の犠牲者を完全に貫通して背後の二人目に命中させることができる。ただし、二人目の犠牲者は、ショットの減衰または減速により、半分のダメージしか受けない。過貫通は一般的に、膨大なダメージを与える高出力武器や、ある種の装甲貫通能力を持つ武器に有効である。最初の標的に与えられた特殊効果は、二人目には適用されない。

#### 鎮圧射撃

銃器専用。「優位の強制」と同様に、この特殊効果により、標的は自身の意志力と攻撃者の命中ロールで対抗判定を行わなければならない。失敗した場合、標的は利用可能な遮蔽物の背後に身を潜め、次のターンに反撃できなくなる。標的に実際にダメージを与えられなかった場合（回避の成功や、遮蔽物への命中など）でも、銃声が至近距離を通過することによる威嚇効果に依存するため、鎮圧射撃は機能することに注意すること。

鎮圧された犠牲者は必要な時間の間反撃できないが、その過程で銃撃に身をさらさない限り、他の行動（別の遮蔽物まで這って移動する、他者と連絡を取る、武器を再装填するなど）を行うことは可能である。

#### カウンターの準備

防御側は敵のパターンを読み、特定の特殊効果（秘密裏にメモしておく必要がある）に対するカウンターを準備する。戦いの中で相手が選んだ特殊効果を自分に対して行おうとした場合、防御側は即座に攻撃者の効果を自分の効果に置き換えることができ、それは自動的に成功する。

#### 速い再装填

遠隔武器を使用する際、攻撃者は次の射撃のための再装填時間を1減少させる。この効果は累積可能である。銃器の場合、黒色火薬や単発銃には有用だが、次の弾が自動的に装填（またはチャージ）される自動火器に適用する場合、この効果の明らかな用途は少ない。しかし、「速い再装填」は武器の弾倉を素早く交換するために代用できる。また、コンデンサを再充電したり、銃身を冷却させたりするために長いサイクル時間を必要とするエネルギー武器にも適用できる可能性がある。

#### 相手に傷跡を刻む

戦闘者は相手に一生語り草となる傷跡を刻み込む。例えば、喉を切り裂きそうになった跡や、胸に芸術的に刻まれた「Z」の文字などである。

#### 標的の選択

攻撃者がファンブルした場合、防御側は打撃を操縦またはそらすことで、隣接する傍観者に命中させることができる。これには、新しい標的が攻撃者の近接武器の間合い内にいるか、遠隔攻撃の場合は射線上に立っている必要がある。新しい犠牲者は予期せぬ事故によって完全に不意を突かれ、自動的に命中する攻撃を回避する機会はない。ただし、その代わりとして、彼らは特殊効果を受けない。

#### 拘束解除

クリティカル成功時、防御側は自動的に「絡め取り」、「掴み」、または「鎮圧射撃」の標的状態から脱出できる。

#### 部位の気絶

攻撃者は打撃武器を使用して、命中した部位を一時的に気絶させることができる。攻撃が防具ポイントを克服して標的を負傷させた場合、防御側は自身の持久力と元の攻撃ロールで対抗ロールを行わなければならない。防御側が失敗した場合、その部位はダメージ量に等しいターン数の間「無力化」される。胴体への一撃は防御側をよろめかせ「息切れ」状態にし、防御しかできなくなる。頭部への一撃は敵を一時的に意識不明にし、「行動不能」にさせる。

#### 破砕

攻撃者は斧などの適切な武器を使用して、相手の防具や自然の保護を損傷させることができる。パリーや魔法による軽減後の武器ダメージはすべて、保護の防具ポイント値に対して適用される。防具ポイントを超過したダメージは、その装甲部位の防具ポイント値を減少させるために使用される。ストラップを引きちぎる、リングを破壊する、プレートをへこませる、あるいはモンスターの皮、鱗、外殻を引き裂くなどである。防具ポイントがゼロになった後もダメージが残る場合、それは命中した部位のヒットポイントに持ち越される。銃器の場合、「破砕」はアブレーション装甲を破壊するように設計されたエネルギーベースの銃器や、重力波銃などのよりエキゾチックな概念に適している。

#### 相手を転倒させる

キャラクターは、相手のバランスを崩すか、地面に投げ倒すことを試みる。相手は、キャラクターの当初の攻撃ロールに対して、自身の腕力、回避、または運動による対抗ロールを行わなければならない。標的が失敗した場合、転倒状態となる。四足歩行の相手（またはそれ以上の脚を持つ生物）は、回避の代わりに「運動」技能を代用でき、ロールの難易度を1段階容易にできる。銃器の場合、質量のある弾薬を発射する銃器であると仮定すれば、着用している防具を貫通しなくても、相手の脚を狙って射撃する際にこの効果を使用できない理由はない。

#### 武器の故障

攻撃側、ファンブル、銃器専用。攻撃者の銃器が故障し、フィールドストリッピング（分解）と清掃に時間を費やすまで使用不能になる。

#### 離脱

防御側は自動的に間合いの外へ退き、その特定の相手との交戦を断ち切ることができる。

## 近接戦闘

近接戦闘とは、戦闘員が武器または自然武器を使用して互いに打ち合う、伝統的な意味での白兵戦のことである。以下のガイドラインは、近接戦闘をより興味深いものにし、この章の前半で示唆されたいくつかの概念をさらに説明するのに役立つ。

### 状況修正

状況修正は、特定の状況で戦う場合、または特殊効果の結果として適用されることがある。例えば、暗闇で戦う場合、難易度が「至難」になる可能性がある。特に明記されていない限り、修正値はゲームマスターが決定する。2つ以上の状況がキャラクターに関連する場合、最も深刻なものを使用する。

一部の修正値は状況に依存するが、難易度を適用するのではなく、関連する技能によって戦闘技能が制限される場合がある。例えば、馬の背から戦う場合、戦闘員の戦闘技能は「乗馬」技能によって上限が定められ、水中で戦う場合はキャラクターの「水泳」の値に制限される可能性がある。#### 近接戦闘における状況修正

| 状況 | 難易度 |
| :-- | :-: |
| 無防備な標的への攻撃 | 自動 |
| 閉所での攻撃 | 困難 |
| 低地から、あるいは騎乗している相手への防御 | 困難 |
| 不安定な足場での戦闘 | 困難 |
| しゃがんだ状態や片膝をついた状態での戦闘 | 困難 |
| 視界不良（濃霧、吹雪など）の中での戦闘 | 困難 |
| 背後からの攻撃に対する防御 | 至難 |
| 伏せた状態での戦闘 | 至難 |
| 薄暗い場所（わずかな照明）での戦闘 | 至難 |
| 真っ暗闇の中での戦闘（照明が一切ない） | 超人的 |
| 目が見えない、または主要な知覚能力を喪失している | 超人的 |

### エンゲージメント（交戦）

キャラクターが対戦相手の近接武器の射程内にいる場合、そのキャラクターは「交戦中」とみなされる。これは必ずしも双方が互いに届く範囲にいなければならないという意味ではなく、どちらか一方がもう一方を攻撃できる可能性があればよい。一度対戦相手と交戦状態に入ると、キャラクターは自由にその場を離れることはできない（駆け抜ける場合は特殊な例外である）。敵との接触を断つには、通常は「機動戦（Outmaneuver）」のような戦闘アクションや、「撤退（Withdraw）」の特殊効果を使用するなど、意図的な行動が必要となる。

### 突撃（Charge）

「突撃」アクションは、素早く移動することで攻撃の威力と衝撃を高める行為である。突撃を行うには、攻撃者は「突撃」アクションを選択し、「駆け足（Run）」または「全力疾走（Sprint）」の歩法で移動する必要がある。歩法については前述の[移動速度](0002_Characters.md?id=movement-rate)セクションを参照のこと。移動に関するルールは『Mythras』のルールブックで網羅されている。

この移動によって相手との接触に至った場合、攻撃者はそこで停止し、突撃による修正を適用した状態で「攻撃」アクションを実行しなければならない。突撃を行うために移動しなければならない最低距離というものは存在しない。なぜなら、移動距離よりも達成された勢いの方が重要だからである。そのため、駆け足や全力疾走が必要となる。

突撃中、攻撃ロールには「困難」の難易度が適用される。その代わり、突撃によって武器の「体格」が一段階上昇し、二足歩行の攻撃者であれば「ダメージ修正」も一段階上昇する。四足歩行（またはそれ以上の脚を持つもの）であれば二段階上昇する。騎乗しているキャラクターは、自身の「ダメージ修正」を乗騎のものに置き換えてもよい。突撃したキャラクターの最終的な位置は、交換の結果と、攻撃者が停止するか、そのまま通り過ぎて即座に交戦を解除するかという意図によって決まる。

突撃を受けた側は、「受け流し（Parry）」や「回避（回避）」を行う代わりに、突撃してくる攻撃者に同時反撃することができる。この場合、より長い武器を持つ者が先に攻撃を行う。槍のように突撃を受け止めることができる武器であれば、受ける側は自身の「ダメージ修正」の代わりに突撃者の「ダメージ修正」を使用することができる。

### 遮蔽（Cover）

対戦相手は遮蔽を利用して攻撃を妨害する。これは、介在する物質の硬さによって物理的に打撃を遮断する場合と、敵の正確な位置を隠蔽する場合の二通りがある。遮蔽の正確な値は、その防御の厚さと覆っている範囲によって決まる。

遮蔽された「部位判定」に着弾した攻撃は、その遮蔽物が本来持つ防御能力の範囲内でブロックされる。遮蔽は、「部位選択（Choose 位置）」の特殊効果を使用して標的の露出している部分を狙うか、武器が貫通可能であれば遮蔽物越しに攻撃することで、部分的に無効化できる。

遮蔽が完全である状況下でも、攻撃者が攻撃は貫通すると信じている場合は、隠れた標的に向かって目隠しで攻撃することができる。その場合、攻撃ロールの難易度は一段階上昇し、特殊効果を獲得しても「部位選択」は選択できない。これは、攻撃者が遮蔽物の背後にいる標的の位置をかなり正確に把握していることを前提としている。

### 回避（Evading）

戦闘における「回避」とは、圧倒的な攻撃から身をかわすことである。これには、防御側の「回避」技能と攻撃側の関連するロールによる対抗ロールが必要となる。これは、突進してくる戦車の「運転」技能から、魔術師の「呪文発動」技能まで、あらゆるものが対象となり得る。攻撃者が勝利した場合、通常通りダメージを与える。防御側が勝利した場合、ダメージは完全に回避される。

対抗ロールの勝者が相手に対して1レベル以上の成功度を得た場合、通常の戦闘と同様に適切な特殊効果を選択できる。結果がどうであれ、回避の試行によって防御側は伏せた状態になる（通常、次のターンに立ち上がる必要がある）。ただし、「立ち上がり（Arise）」の特殊効果を使用できる場合は例外である。

### ノックバック（Knockback）

受け手側の「体格」を上回るダメージを与える攻撃を受けると、デフォルトでそのキャラクターはノックバック（吹き飛ばし）される。この場合のダメージは、受け流しや防具による軽減前の数値である。このような打撃を受けた場合、受け手は「簡単」な「軽業」ロールまたは「標準」の「運動」ロールに成功しなければ、伏せた状態になるのを免れない。さらに、自身の「体格」を上回ったダメージ5点につき1メートル（端数切り捨て）突き飛ばされる。「踏ん張り（Brace）」の戦闘アクションを能動的に使用することで、ノックバックの影響を軽減、あるいは無効化できる場合がある。

### 跳躍攻撃（Leaping Attacks）

跳躍攻撃は様々な状況から繰り出される。多くは待ち伏せの一部として、あるいは突撃の締めくくりとして行われるが、一部のクリーチャーは助走や高所を必要とせず、相手の上に飛び乗ることができる。

跳躍攻撃は、跳躍側の「運動」技能と防御側の「腕力」または「回避」技能との対抗ロールで解決される。四足歩行の標的を相手にする場合、攻撃ロールの難易度は一段階上昇する。跳躍側が勝利した場合、防御側は自動的に伏せ状態となり、攻撃者がその上にまたがる形となる。失敗した場合、防御側はその衝撃を耐え抜いたか、あるいは横にかわしたことになる。対抗ロールの勝者が相手に対して1レベル以上の成功度を得た場合、通常の戦闘と同様に適切な特殊効果を選択できる。

跳躍そのものではダメージは与えられない。しかし、その結果として伏せ状態になった被害者は、攻撃者がその場を離れるか、後に「立ち上がり」を可能にする特殊効果を獲得するまで、体勢を立て直すことができない。さらに、跳躍攻撃は攻撃者の「体格」の最大2倍までのサイズの相手にしか通用しない。標的が跳躍攻撃が来ることを察知していれば、「踏ん張り」の戦闘アクションを能動的に使用することで、倒れにくくすることができる。

### 機動戦（Outmaneuvering）

複数の敵に直面したキャラクターは、移動を利用して同時に攻撃できる敵の数を制限し、絶えず位置を変えて敵同士を干渉させることができる。機動戦を行うには、キャラクターが動き回れるスペースがあり、狭い場所に追い詰められていないことが条件となる。

機動戦を行うには、キャラクターは自身の「回避」技能を用いて対戦相手とのグループ対抗ロールを行う。機動戦を行うキャラクターも、彼を追い詰めようとする敵も、全員が「行動ポイント」を消費しなければならない。その後、各自が一度ずつロールを行い、機動戦を行うキャラクターのロールを上回れなかった者は、味方や地形に阻まれ、その戦闘ラウンドの残りの時間、彼を攻撃できなくなる。

機動戦を行うキャラクターがすべての対戦相手に打ち勝った場合、そのラウンドの残りの時間、単独の敵と安全に交戦するか、あるいは戦いから完全に「撤退」するかを選択できる。

### 受動的ブロック（Passive Blocking）

「受動的ブロック」とは、武器で武装したキャラクターが、選んだ部位（盾を使用する場合は複数の部位）をカバーするように武器を保持することを可能にするが、その代償としてその武器で能動的に「受け流し」を行うことができなくなる（「部位防御」を参照）。その部位に命中した攻撃は自動的に武器や盾の恩恵を受け、通常通りダメージが軽減される。このテクニックは、戦士が弱点や負傷部位を守りたい時によく使用される。二刀流や、武器と盾を装備しているキャラクターが、もう一方の武器で能動的に受け流しを行うことを妨げるものではない。

受動的ブロックは遮蔽と同様の働きをするため、近接戦闘において「部位選択」の特殊効果を使用してブロックを回避することはできない。ただし、対戦相手は依然としてこの特殊効果を使用して、ブロックされていない他の部位を狙うことはできる。盾の後ろでしゃがみ込むことで、受動的ブロック中にカバーできる部位の数を倍にすることができる。

### 奇襲（Surprise）

奇襲は、攻撃者の存在や意図に気づいていない対戦相手に対して、予期せぬ攻撃が仕掛けられたときに発生する。待ち伏せは前者の例であり、友好的な会話の最中に裏切って友人を攻撃するのは後者の例である。

奇襲が標的に与える影響は強力である。

- 標的は「イニシアチブ」に-10のペナルティを受ける。
- 「イニシアチブ」の順番が来るまで、標的は不意を突かれた状態とみなされ、身を守ることができない。
- 標的への最初の攻撃が成功した場合、ボーナスの特殊効果を得る。
- そのラウンドの残り時間、標的はいかなる攻撃的「行動」も実行できない。

### 掃討攻撃（Sweep Attacks）

掃討攻撃は、ゲームマスターの判断で行われる。並外れたサイズを持つ武器やクリーチャーが密集した敵の集団を攻撃する際（例えば、巨大なドラゴンの薙ぎ払う尻尾や、トリケラトプスの止められない突進など）、一度に複数の敵を攻撃する場合に発生する。

掃討攻撃は、その武器やクリーチャーの攻撃ロールを一回行い、経路上のすべての標的に適用することで解決される。各防御側は個別に攻撃の影響を解決し、攻撃者に課された特殊効果は同時に発生したものとして扱われる。

## 遠隔戦闘

遠隔戦闘には、標的に命中させるために射撃、投擲、あるいは投石を必要とするあらゆる形態の武器が含まれる。遠隔攻撃は近接戦闘と全く同じ方法で解決される。しかし、遠隔武器は通常、盾でしか受け流すことができない。盾を持たない者は、自然の遮蔽物に頼るか、「回避」を使用して射線から飛び出すしかない。そのため、軽装の敵に対しては、遠隔武器は恐るべき抑止力となり得る。

各遠隔武器には、その有効性を決定づける特定の「特性値」がいくつか存在する。戦闘に重要な影響を与えるものは以下の通りである。

- **威力（Force）：** 遠隔武器における「体格」に相当する。武器や弾薬の貫通力を表す抽象的な尺度であり、（盾による）受け流しを打ち破れるかどうかを判定する。
- **ダメージ修正（ダメージ 修正値）：** この「特性値」は、攻撃者の「ダメージ修正」を遠隔武器のダメージロールに加算できるかどうかを示す。一般的に、自力で引く弓と投擲武器のみが、ユーザー自身の「ダメージ修正」の適用を許可している。
- **射程（射程）：** スラッシュで区切られた3つの数字。それぞれ武器や弾薬の最大「近距離」、「有効射程」、「長距離」を表す。近距離は、標的が静止しているか、差し迫った攻撃に気づいていない場合に限り、「部位選択」の特殊効果を使用できる距離である。有効射程には顕著な修正はない。長距離では武器は依然として損害を与えることができるが、ダメージは半分になり、「威力」が一段階減少する。
- **再装填（Load）：** 弾薬を発射する武器を装填、あるいは再装填するのにかかる「ターン」数。キャラクターは「高速再装填」の特殊効果を使用することで、装填や準備にかかる時間を短縮できる。
- **刺突サイズ（Impale 体格）：** 突き刺さった武器のサイズは、それが命中した際の「威力」とは異なる。遠隔の刺突武器には、「刺突」の特殊効果によって引き起こされる障害を考慮する際、実際のサイズを示す特別な列が設けられている。

### 状況修正

近接戦闘と同様に、特定の条件下で遠隔武器を使用する際には状況修正が適用されることがある。馬に乗りながら槍を投げるような困難な状況下では、キャラクターの「戦闘技能」に上限が設けられる場合がある。

##### 遠隔戦闘における状況修正

| 状況 | 難易度 |
| :-- | --- |
| 微風\* | 困難 |
| 中程度の風\* | 至難 |
| 強風\* | 超人的 |
| 疾風、嵐、またはそれ以上\* | 絶望的 |
| 標的が「駆け足」中 | 困難 |
| 標的が「全力疾走」中 | 至難 |
| 標的が霧で隠れている、または薄暗い場所 | 困難 |
| 標的が濃い煙で隠れている、または暗闇 | 至難 |
| 標的が完全に隠れている | 超人的 |
| 標的が完全に見えない | 不可能\*\* |
| 標的が伏せ状態 | 至難 |
| 攻撃者が伏せ状態\*\*\* | 超人的 |
| 攻撃者が不安定な足場にいる | 困難 |

_\* 投擲武器や弾薬が横風の影響を受けやすいことを前提としており、通常の技能に対する風の通常ペナルティに優先される。_

_\*\* 標的の一般的な位置が判明しているか知られている場合を除く。その場合は超人的として扱う。_

_\*\*\* 準備された位置からクロスボウや火器を使用している場合、ペナルティは無効化できる。_

### 照準（Aiming）

遠隔武器の照準に余分な時間を費やすことで、キャラクターは命中率を高めることができる。照準には戦闘ラウンド丸々一回分を費やし、武器を安定させて引き金を引く最高の機会を待つ必要がある。例えば、風が一時的に止むのを待つために弓を引いたままにしたり、標的が二つの障害物の間を移動するまで待ったりすることである。照準を行うことで、キャラクターは射程や状況修正の難易度を一段階下げることができる。照準に費やすラウンドを追加しても、それ以上の有利は得られない。

### 自動射撃（自動 Fire）

一部の火器は、前回の射撃による排気ガス、反動、あるいはエネルギーを利用して、自動的に次弾を装填する。再コッキングの必要がないため、武器は弾薬をどれだけ放出したいかに応じて、様々な発射速度を得ることができる。

これらの発射モードは「セミオート」、「バースト」、「フルオート」として知られている。この能力により、一部の銃は恐るべきダメージを与えることができるようになるが、反動のある武器で精度を維持するのは困難である。以下のルールは、主に自動火器による投射物発射に適用されるものとする。

#### セミオート

これはほとんどの銃のデフォルトの発射速度であり、引き金を引くたびに一発が発射され、次の弾が装填される。

#### バースト

バースト射撃では、引き金を引くたびに短い連射が行われ、通常は武器に応じて3〜5発程度である。本来の目的は、限定的な制圧射撃を可能にしつつ、過度な弾薬消費を制限することである。これは射手の命中率を向上させるためのものではない。連続的な反動によって武器の照準が絶えずずらされるからである。バーストモードでの射撃には、攻撃ロールに「困難」のペナルティが課される。しかし、攻撃が成功した場合、射手はダイスを振り、バースト中の弾丸のうち何発が標的に命中したかを判定する。例えば、3点バーストであれば1d3を振る。命中した弾丸それぞれについて、個別に部位とダメージをロールすること。

#### フルオート

通常、複数の標的を釘付けにするための本格的な制圧射撃に使用される。フルオート射撃は、密集した敵の集団に対して発射されると壊滅的な被害をもたらすことがある。射手は何発の弾薬を発射するか（武器のサイクルレートの限界まで）を決定し、それが射撃範囲に含まれるすべての標的に均等に分配される。余った弾薬は、照準を移動させる間に失われたものとみなされる（したがって、6つの標的に向けて15発撃つ場合、各標的に2発ずつとなる）。各標的に対して個別に攻撃ロールを行うが、持続射撃による反動の影響が増大するため、難易度は「至難」となる。命中した標的は、バースト射撃と同様にランダムな数の弾丸を受ける。

なお、バースト射撃やフルオート射撃中に命中した最初の弾丸のみが、特殊効果の恩恵を受けられることに注意すること。したがって、自動射撃モードでクリティカルヒットをロールした場合、「最大ダメージ」を選択できるのは、残りのすべての弾丸が命中したとしても、最初の弾丸に対してのみである。### なぜ自動射撃はこれほど重いペナルティを受けるのか？

自動射撃のルールは、現代の銃器の明らかな精度と比較して、不当に厳しいように見えるかもしれない。これにはいくつかの理由があるが、主な理由は効率化とゲームバランスである。自分のキャラクターの不正確さを批判するプレイヤーは、ルールへの調整が自分たちにも適用されることを思い出すべきである。連射の致死性を考えれば、これは肝に銘じておくべきことである。

もちろん、これらの反動ペナルティの一部は、例えば「武器の固定（Steady Weapon）」を使用して自動火器を支えることで緩和できる。しかし、真実は、銃撃戦は射撃場での標的射撃とは全く異なるということである。弾丸が飛び交う中で身を隠そうとする本能、移動し続ける必要性、そして銃口の閃光や音によって射手の位置が特定されるたびに、照準を合わせたり銃を固定したりする機会はしばしば失われる。「撃ちまくって祈れ（Spray and Pray）」という言葉が生まれたのには、もっともな理由があるのだ！

### 二丁拳銃

キャラクターは二丁の銃器を使用し、自分のターン中に両方の武器を同時に発射して、より速い連射速度を得ることができる。しかし、これには精度のペナルティが伴う。両手にピストルを持って発射する場合、標的への命中判定に「困難」のペナルティを受ける。両手にカービン銃や短機関銃（SMG）を持って同時に射撃しようとする者は、「至難」のペナルティを受ける。

### 群衆への射撃

乱戦の渦中へ向けて発砲するのは危険な行為であり、本来狙った標的以外の誰かに誤って命中させるリスクが常にある。群衆や乱戦の端にいる特定の標的に向かって射撃する場合、攻撃には「困難」の難易度が適用される。群衆越しに撃とうとする場合は、「至難」に引き上げられるべきである。危険を緩和するために「照準」を行うことは可能である。

難易度のペナルティにもかかわらず攻撃ロールに成功した射手は、正確に狙いを定めており、意図した標的に命中させる。しかし、射手がロールに失敗したものの、「群衆への射撃」ペナルティがなければ成功していたはずである場合、代わりに隣接する犠牲者に命中する（犠牲者は通常通り「回避」や「受け流し」を行うことができる）。

射線上に複数の標的がいる場合、ゲームマスターはランダムに犠牲者を決定すべきである。攻撃の一部として得られたいかなる「特殊効果」も、誤って命中した傍観者ではなく、元の標的にのみ適用される。

### 銃器のファンブル

銃撃は通常、対抗する技能によって抵抗されることはないため、射手が攻撃ロールでファンブルした場合には特別な規定を設けるべきである。この場合、意図した標的であった者は、ファンブル固有の「特殊効果」を選択することができ、射手はそれを被ることになる。ファンブル専用の特殊効果「武器の誤作動」も参照すること。

### 盾による銃弾の受け流し

前述の通り、超音速の投射体やエネルギービームを意図的に受け流すことはほぼ不可能である。しかし、盾は実質的に持ち運び可能な「遮蔽物」となるため、一定程度の保護を提供する。銃撃戦で盾を使用するには、前述の[近接戦闘](0005_Combat.md?id=passive-blocking)セクションにある「受動的ブロック」のルールを使用すればよい。

より現代的な銃器やSF的な性質のものに関しては、ゲームマスターは盾が作られている本来の素材に基づいて、サイズを割り当てる代わりに「防具ポイント（AP）」の値を盾に与えることを望むかもしれない。例えば、木製の盾は4防具ポイント、ケブラー製のタクティカル・シールドは8防具ポイント、ユリシーズ31のブレスレット・フォースフィールド・シールドは15防具ポイントとして扱うことができる。

### 望遠照準器

望遠照準器は、使用者が時間をかけて適切に照準を合わせる（「照準」を参照）ことで、長距離における銃器の精度を向上させる。最も基本的な望遠照準器は単なる光学拡大鏡に過ぎないが、技術の進歩に伴い、統合された距離計、弾道計算機、空気移動センサー、大気レンズ補正器、赤外線または低光量増幅器など、有効な「命中」距離を改善する多くのガジェットが組み込まれるようになる。

望遠照準器は、照準器の洗練度に応じて、技能ロールを1段階以上簡単にできる（[技能の修正](0003_Skills.md?id=modifying-skills)を参照）。どのような照準器であっても技能ロールを「自動」成功にすることはできないため、達成可能な最高の難易度は「非常に簡単」である。
