# 戦闘

戦闘はロールプレイングゲームの重要な要素です。暴力的な衝突は、宿敵同士の復讐に燃える戦いから、戦争時における軍隊の激突に至るまで、常に問題を解決する手段となってきました。とはいえ、戦闘は必ずしも死に至るような野蛮な戦いである必要はありません。戦闘遭遇の中には、負傷することなく終わるスワッシュバックリング（剣戟）的な決闘や、あるいは気楽な酒場での乱闘のようなものもあります。_Mythras Imperative_ では、戦闘の核心的な要素を説明するためにいくつかの用語を使用しています。これらについては後述の各セクションで解説しますが、概要を述べると以下の通りです。
- **戦闘スタイル:** 文化や専門職の一部として習得する、武器グループの取り扱い技能。
- **戦闘ラウンド:** 5秒間を1単位とする進行管理のための時間区分。
- **戦闘アクション:** アクションポイントを消費することで、キャラクターがラウンド中に実行可能な行為。
- **武器の体格:** 特定の武器をパリィ（受け流し）することの難易度。
- **エンゲージメント:** 状況に応じて、戦闘員が敵を攻撃できる、または敵から攻撃される状態。
- **特殊効果:** 戦闘員が優位に立った際に行使できる戦闘上の操作。

## 戦闘スタイル

戦闘スタイルとは、性質が関連する複数の武器を「パッケージ」として扱うものであり、武器ごとに個別に習得する必要性を省くことができます。

戦闘技能において最も重要な点は、キャラクターがその技能に含まれる各武器の使い方を、単独および組み合わせの両面で学習し、必要に応じて交換可能になるということです。戦闘訓練は、単に最良の条件下で特定の武器を使うことに集中するだけでなく、深刻な不利な状況に置かれたときにどうすべきかもカバーします。このようなクロストレーニングは、武器の破損や武装解除の可能性が常にある予測不能な戦場において、戦闘員を準備させるための主要な部分です。

したがって、ハイパーボリアの蛮族は槍、手斧、ジャベリン、盾の使い方を知っていることが期待されますが、シュメールの戦士は代わりにショートソード、メイス、盾、弓の訓練を受けている可能性があります。一つのスタイルにいくつの武器を含めるかは、最終的にはゲームマスターとゲームの舞台設定によって決定されます。

自分のスタイルに含まれていない武器を使用しようとするキャラクターは、1段階以上の難易度の技能ペナルティを受けるべきです。

戦闘スタイルには、武器技能のグループを単に学習する以外の機能もあります。各スタイルはその文化やキャリアによって教えられるため、本質的にそのグループが通常戦う環境や軍事戦術に最適化されています。例えば、馬に乗る遊牧民は鞍の上から戦うことを学び、歩兵は密集陣形で戦うための訓練を受けます。したがって、追加ボーナスとして、いくつかの戦闘スタイルには、特定の状況下で優位性を与える「特性」を1つ以上割り当てることができます。特性はその特定のスタイルの武器や状況で使用することのみを目的としています。当然ながら、特性は無数に存在し、その多くは特定の時代やキャンペーンの世界に固有のものです。

##### 戦闘スタイルの特性表

| 特性 | 説明 |
| :-- | :-- |
| 獣上の槍騎兵 | この戦闘スタイルで騎乗突撃を行う際、命中判定に1段階の難易度ペナルティを受けない。 |
| 盲目戦闘 | 照明不良や一時的な目潰しによって課されるあらゆるペナルティを無視できる。 |
| 向こう見ず | 白兵戦において、転倒することなく回避技能を使用して攻撃をかわすことができる。 |
| 防御志向 | 攻撃的なアクションをそのラウンドに行わない限り、パリィ時の武器の体格を1段階上昇させる。 |
| 陣形戦闘 | 側面を突かれていない3人以上の戦士グループが密集陣形を組むことを可能にする。より開放的または無秩序な相手を不利な状況に置き、相手がエンゲージした場合、各敵のアクションポイントを1減少させる。 |
| 渾身の一撃 | 不意打ちで攻撃する際、部位判定による気絶効果の持続時間をターンではなく分として扱う。 |
| 騎乗戦闘 | 乗馬技能によって戦闘ロールに課される技能上限を無視できる。 |
| 遠隔狙撃手 | 遠隔武器を使用する際、ランダムな部位判定の結果を隣接する身体部位に変更できる。 |
| 散兵戦術 | このスタイルでは、歩行中や走行中に遠隔攻撃を行うことが許可される。 |
| 投擲武器 | このスタイルに含まれるあらゆる近接武器を技能ペナルティなしで投擲できる。ただし、この方法で使用する場合、武器のダメージロールは半分になる。 |
| 徒手の達人 | 徒手のブロックやパリィを「中型」の体格として扱うことを許可し、武装した相手からよりうまく身を守れるようにする。 |

## 戦闘の進行

その臨場感を強調するため、戦闘は一撃ごとに追跡されます。事務処理を容易にするため、戦いは5秒間の「戦闘ラウンド」に分割されます。この期間中、戦闘員は白兵攻撃やそれに対する防御、戦闘への出入り、遠隔武器の射撃や投擲などを行うことができます。現実と同じく、ほとんどの戦闘は一旦始まれば、分単位ではなく数秒のうちに決着します。ゲーム用語で言うと、これは数回の戦闘ラウンドを意味しますが、参加者がイニシアチブをリセットするため、戦術状況を再評価するため、あるいは再戦の前に一時的な休息をとるために退避する場合を除きます。よく似た実力の敵同士の戦いや、連続する敵との戦いだけが、より長く続く傾向があります。

## 火器

_Mythras Imperative_ のゲームで火器を使用する場合、銃撃戦の致死性を考慮して検討すべき点がいくつかあります。第一に、人間の反射速度よりも速く移動するレーザービームや弾丸を避けることはほぼ不可能です。提示された戦闘ルールを使用する場合、回避を使ってエリアから飛び退こうとしない限り、命中すれば即座に被害者は1つ以上の特殊効果を受けることになります。また、これはアクションポイントの経済にも変化をもたらします。ポイントを使用して反射的に防御できない場合、ほとんどのキャラクターは全ての行動を攻撃に費やし、敵の無能さに賭けることになります。このパラダイムシフトに対処するため、ゲームマスターとプレイヤーは銃撃戦に対する見方やアプローチを変える必要があるかもしれません。注意すべき点は以下の通りです。

- 銃撃戦は危険である！
- 全体として、人々は他者を撃つことよりも、撃たれないことを優先する。
- 最も一般的な防御方法は、遮蔽物に隠れることである。
- 制圧射撃は、敵の反撃を防ぐ最良の方法である。
- 火器は、構えたり狙いを定めたりする時間をとらない限り、驚くほど不正確である。
- 撃たれると、ひどいことになる。

銃撃に対する防御は、防具、遮蔽物の利用、そして相手に反撃させないようにすることに大きく依存します。結果として、ほとんどの銃撃戦は非常に戦術的になります。大量の制圧射撃、側面への移動、遮蔽物の奥から敵を追い出すといった行動が行われ、その間キャラクターは戦闘ラウンド中ずっと釘付けにされ、相手が射撃を止めるまで対応できないという状況が続くことがあります……これについては、退屈だと感じるプレイヤーもいるかもしれません。

銃撃戦全体で一切負傷者が出ないことも十分にあり得ます。弾薬が尽きるか、戦闘から完全に逃亡することで、片方が諦めるだけというケースです。結局のところ、自動火器の連射を浴びるリスクを冒したいと思う人は少ないのです。

これらの戦闘ルール全体を通して、特定のアクションの種類、特殊効果、状況は火器による戦闘にのみ適用され、それに応じてマークされています。

## 戦闘ラウンドとイニシアチブ

戦闘ラウンドでは、いくつかの重要な用語が使用されます。

- **イニシアチブ:** 戦闘ラウンドのターン中に誰がいつ行動するかという順序。ゲームマスターはイニシアチブ値の高い順からカウントダウンを行い、各参加者が自分の数字に達したときに行動の機会を得るようにします。
- **ターン:** 各5秒間の戦闘ラウンド中、各参加者は、所持しているアクションポイントの数とそれらの使い方に応じて、1回以上のターンをとる機会があります。自分のターンになると、参加者は1回の戦闘アクションを実行します。これには宣言、移動の可能性、必要なダイスロール（リアクションを含む）、およびアクションの解決が含まれます。参加者にアクションポイントが残っている場合、プレイヤーはイニシアチブ順に再度ターンをとることができます。アクションポイントが残っていない場合、または残りがリアクションのために保持されている場合、プレイは次の戦闘ラウンドに進みます。

各用語について、以下で詳しく説明します。

#### イニシアチブ

イニシアチブは、戦闘ラウンドにおける参加者の行動順序を決定します。これは戦闘開始時にロールされ、各キャラクターがいつ行動するかを決定します。特定の戦闘アクションや特殊効果など、状況を変える何かが発生しない限り、イニシアチブは強制的に再ロールされるまで継続されます。

イニシアチブは、各参加者が1d10をロールし、イニシアチブ修正値を加算することで算出されます。最も高い結果を出した者が最初に行動し、次に高い者が続くという具合です。2人以上の参加者が同点になった場合、敏捷性が高い方が先に行動します。それでも同点の場合は、ダイスをロールし、高い目を出した方が先に行動します。

#### 戦闘中のアクション

イニシアチブが決定されると、各戦闘ラウンド中に参加者はいくつかのアクションを実行する可能性があります。すべてのキャラクターはラウンドごとに2アクションポイントを得ますが、行動できるかどうかは、そのアクションがプロアクティブ（能動的）かリアクティブ（受動的）かに制限されます。

プロアクティブ・アクションは、キャラクター自身のターン、つまりイニシアチブの最中にのみ試みることができます。プロアクティブ・アクションとは、キャラクターが仕掛け人となる行動であり、武器による攻撃などが該当します。

リアクティブ・アクションとは、自分に対する行為に対抗または抵抗するためにキャラクターがとる行動です。脅威に対しては1回のみリアクションを試みることができます。例えば、攻撃をパリィしようとする場合などです。

未使用のアクションポイントは、次のラウンドに持ち越すことはできません。

## 戦闘アクション

戦闘アクションとは、戦闘中に実行できる行為のことです。武器を抜く、呪文を唱える、攻撃から飛び退くなどはすべて戦闘アクションの例です。ほとんどは戦闘自体の要素に関係していますが、呪文や武器以外の活動に関係するものもあります。

前述の通り、キャラクターがラウンドごとに行動できる頻度は、利用可能なアクションポイントによって制限されます。これらは各戦闘ラウンド中にさまざまな戦闘アクションを実行するために消費されます。戦闘員のアクションポイントが消費されると、そのラウンド中はこれ以上行動できず、次のラウンドの開始時にポイントがリセットされるまで待たなければなりません。

特に指定がない限り、あらゆる戦闘アクション（「フリー」アクションを除く）は1アクションポイントを消費します。そのため、戦闘員はアクションポイントをいつ、どのように使用するかを慎重に検討する必要があります。彼らは望むように攻撃的にも防御的にも行動でき、戦闘の進化する状況に動的に反応できます。

### プロアクティブ・アクション

以下は、キャラクターが自分のターンにアクションポイントを消費して試みることができる活動です。呪文の詠唱や再装填など、完了までに数ターンかかるアクションがあることに注意してください。各ターンごとにアクションポイントが消費されます。

#### 攻撃
キャラクターは近接武器で打撃を試みるか、遠隔武器を使用できます。

#### 構え
キャラクターはしっかりとした姿勢をとり、来るべき攻撃の方向に体を傾けることで「構え」をとります。ノックバックや跳躍攻撃に抵抗する場合、キャラクターの体格は50%大きいものとして扱われます。特殊効果「殴打」に対しては、体格が2倍として扱われます。

#### 魔法の詠唱/能力の使用
キャラクターは呪文の詠唱や特定の能力の発動などを試みることができます。複雑な魔法は詠唱完了までに複数のアクションを必要とする場合があります。詠唱が完了すると、詠唱者の次のターンまでいつでも魔法を解放できます。それ以降も魔法を保持し続けるには、後述の「魔法/能力の保持」アクションが必要です。

#### 射程の変更
キャラクターは相手との間合いを詰めたり、離脱したりすることを試みることができます。ただし、その相手と白兵戦中でないこと、または遠隔戦闘で敵の射撃により釘付けにされていないことが条件です。

#### 突撃
突撃アクションにより、キャラクターは走行または疾走速度でエンゲージメント範囲内に移動し、突撃の勢いを利用してより強力な近接攻撃を行うことができます。これらのルールについては、後述の[突撃](0005_Combat.md?id=charging)セクションで詳しく説明します。

#### 遅延
キャラクターは1つ以上のアクションを温存し、割り込みやパリィなどのリアクティブ・アクションを後で行うことができます。遅延によるアクションポイントのコストは、最終的に実行された行為によってカバーされます。もし遅延させたアクションをキャラクターの次のターンまでに実行しなかった場合、そのキャラクターは「迷い」（後述）が生じたものとみなされ、アクションポイントは失われます。

#### 迷い
他のアクションが選択されない場合のデフォルトのオプションです。キャラクターはターンを無駄に過ごします。

#### 魔法/能力の保持
詠唱が完了した後、キャラクターは呪文や能力を一時的に維持し、解放するのに最適な瞬間を待つことができます。魔法はキャラクターが後続のターンでこのアクションをとり続ける限り保持できますが、これを行っている間は、その呪文に関連する場合、敵による「呪文への対抗」リアクションを許してしまいます。保持された呪文を唱えるための実際の技能ロールは、解放されるまで行われません。

#### 騎乗
キャラクターは騎獣や乗り物に乗り降りできます。特に大きな騎獣の場合は完了までに数ターンかかる場合があります。

#### 移動
相手と交戦していない限り、キャラクターはゲームマスターがその状況に適していると判断する距離を移動できます。

#### 機動制圧
キャラクターは回避技能の対抗ロールを使用して、複数の相手をグループとして引き受けることができます。キャラクターのロールに勝てなかった者は、その戦闘ラウンド中、キャラクターを攻撃できません。後述の[機動制圧](0005_Combat.md?id=outmaneuvering)セクションを参照してください。

#### 武器の準備
キャラクターは武器やその他の物体を取り出す、抜く、鞘に収める、引き上げる、再装填することができます。近くに落とした物を拾うには2つのアクションが必要です。1つは移動してその物に手を伸ばすアクション、もう1つは準備姿勢に戻るアクションです。一部のミサイル武器は再装填に数アクションを要します。

#### 再装填（火器）
「武器の準備」と同様です。再装填時間は武器の種類によって大きく異なります。単発の黒色火薬式マスケット銃は、弾倉や動力源を交換するよりもはるかに時間がかかります。

#### 足場を立て直す
相手と交戦していない場合、キャラクターは転倒させられたり倒されたりした状態から自動的に足場を立て直せます。交戦中の場合は、立ち上がる前に相手との腕力または運動の対抗ロールに勝たなければなりません。この対抗ロールの解決にアクションポイントは消費されません。

#### 覗き込み（火器）
覗き込みにより、遮蔽物の後ろに隠れている者は、戦術状況を判断するために素早く外の様子を伺うことができます。このアクションは基本的に安全であり、観察者は知覚ロールを1回行ってから遮蔽物に戻ることができます。ただし、知覚テストがファンブルだった場合、愚かにも頭を出しすぎたり、敵が狙撃するのに十分な時間見えていたりしてしまいます。

#### 武器の安定（火器）
キャラクターはしっかりとした射撃姿勢を確立し、自動火器が安定するように支えることができます。これには、キャラクターが少なくとも部分的に露出しており、遮蔽物で完全に保護されていない必要があります。主な利点は、バースト射撃やフルオート射撃による反動ペナルティを1段階軽減することです。この効果は「構え」と同様で、キャラクターが移動するまでその恩恵は持続します。

#### もがき
キャラクターが特定の種類の攻撃や特殊効果の犠牲になった場合、状況から脱出を試みることができます。例えば、敵の拘束から逃れることなどです。

#### 射撃モードの切り替え（火器）
射撃モード切り替えにより、自動火器や二目的火器のユーザーは、他の射撃モードを利用するために武器のセレクターを変更できます。これにより、アサルトライフルをセミオートからバーストに切り替えたり、異なる種類の弾薬を選択したり、あるいは組み込み式のグレネードランチャーのような補助システムを起動したりできます。現代の武器ではモード切り替えにキャラクターのターンでアクションポイントを消費しますが、高度に発達したハイテク火器では、電子インプラントやユーザーの精神を読み取るサイキック機能によって、フリーアクションとして許可される場合があります。

#### 遮蔽をとる
遮蔽をとることは、射撃手が周囲にある遮蔽物の後ろに身を隠し、迫り来る射撃に対してある程度の防御を得ることができるプロアクティブ・アクションです。回避とは異なり、使用者が伏せ状態になることはありませんが、遮蔽物が利用可能であることに依存します。例えば、廊下の角を曲がって隠れる、バーのテーブルの下にしゃがみ込むなどです。状況によっては、利用可能な遮蔽物がキャラクターを完全に保護するのに十分とは限らない場合があります。遮蔽物の種類によっても防御性能が決まります。例えば、厚い鋼鉄の扉は弾丸を通さないかもしれませんが、薄い木の壁は防具ポイント4点分しか提供しないかもしれません。特定の素材の防御特性に関する一般的なガイドラインについては、[無生物](0004_Game_System.md?id=inanimate-objects)セクションの表を参照してください。

### リアクティブ・アクション

このリストは、差し迫った脅威への対応として、戦闘ラウンド中のいつでも使用できるリアクションを指定しています。前のリストと同様に、リアクションの実行にはアクションポイントを1消費します。

#### 呪文への対抗
キャラクターは、向かってくる呪文を打ち消したり対抗したりしようと試みることができます。これには対抗する魔法の詠唱時間が1ターンであることが前提であり、そうでない場合は事前に準備し、「魔法の保持」アクションを使用して一時的に温存しておく必要があります。この方法で魔法を首尾よく妨害すれば、たとえ複数の標的や範囲を持つ呪文であっても、魔法全体を無効化できるとみなされます。

#### 回避
キャラクターは回避技能を使用して、飛来するミサイルや突撃攻撃などの脅威から飛び退くことができます。能力や特殊な状況によって軽減されない限り、キャラクターは伏せ状態になります。そのため、キャラクターの次のターンは通常、立ち上がるための「足場を立て直す」アクションに費やされます。

#### 割り込み
「遅延」を行っているキャラクターのみが対象です。このリアクティブ・アクションは、対戦相手のターンの途中で相手の行動を中断し、遅延させていたターン・アクションを実行します。戦術状況に変更がないと仮定すると、キャラクターのターンが完了した後、相手はそのままターンを続行します。元の宣言を達成できない場合、相手のアクションポイントは無駄になります。割り込みは、遅延キャラクターのすぐ近くを通り過ぎ、かつ武器の間合い内にいる誰かに対する機会攻撃を実行するためにも使用できます。

#### パリィ
キャラクターは、受け流し、体を傾ける、しゃがむ、足さばきで側面へ避けるといった組み合わせを行い、打撃を最小限に抑えることで、向かってくる攻撃に対して防御を試みることができます。

### フリーアクション

フリーアクション（以下にリスト）は戦闘ラウンド中のいつでも実行でき、アクションポイントを消費しません。

#### 状況の評価
交戦中でない場合、キャラクターはアクションポイントのコストなしで知覚ロールを行うことができます。成功すれば、戦術状況に関連する変化（突撃を開始しようとしている敵を見つけるなど）が明らかになります。走行中に評価を行うと知覚ロールは「困難」になり、疾走中の場合は「至難」になります。

#### アイテムを落とす
アイテムを落とすことはフリーアクションです。

#### 合図
交戦中でない場合、1人以上の参加者にジェスチャーや合図を送ること（相手がサインを認識できれば）はフリーアクションです。

#### 発言
キャラクターは戦闘中のいつでも話すことができますが、話す内容は5秒以内に言える短いフレーズに制限されるべきです。例えば「後ろに気をつけろ！」や「地獄へ落ちろ！」などです。

#### 幸運ポイントの使用
幸運ポイントの使用（例えば特定の結果をリロールするためなど）はフリーアクションです。### 部位判定の防御

キャラクターは、武器の1つをその部位をパッシブに防ぐために専念させることで、特定の部位判定に対する被弾を防ぎます。その部位に当たった攻撃は、その武器の体格に応じた通常の武器による受け流しと同様に、ダメージが自動的に軽減されます。このカバーは、その武器を使用して攻撃するか、または能動的に受け流しを行うまで継続します。カバーする部位の指定や変更は、相手がキャラクターへの攻撃判定を行う前に行わなければなりません。その設計上、盾は複数の部位をカバーできます。

詳細な説明については、以下の[パッシブ・ブロッキング](0005_Combat.md?id=passive-blocking)を参照してください。

## 移動

戦闘中の行動は以下のルールに従います。

- 移動は「移動」または「突撃」アクションによって行われます。
- 「移動」アクションにより、キャラクターは自身の基本移動速度と同じ距離だけ移動できます。
- 移動は、交戦状態にないキャラクターのみが行えます（接近戦を出し抜くなどの特殊なケースを除く）。
- 特定のケース（突撃など）を除き、キャラクターが意図した相手の交戦範囲に入ると、すべての有意な移動は終了します。
- 接敵する突撃を除き、相手の交戦ゾーンに入ると、それぞれが互いに交戦状態になります。
- 一度交戦状態になると、近接戦闘から離脱しない限り、相手から離れて移動することはできません。
- 戦闘遅延アクションを使用している交戦状態にない相手の横を通り抜けようとすると、（特定の例外として）相手が移動中のキャラクターを攻撃したり、キャラクターの前進を阻止して次のターンやラウンドで接近戦を開始したりすることが許可されます。

### 状況に応じた移動速度

これらの移動速度は状況に応じたものであり、常に選択できるわけではありません。多くは他の箇所で詳述されていますが、利便性のためにここに記載します。これらの状況に応じた速度のほとんどは、定められた制限の下で通常の移動速度に加えて使用できます。そのような情報は以下の各説明で詳述されています。

#### クライミング

隣接して移動した、あるいはターンの開始時に登攀可能な表面や物体の隣にいたキャラクターは、基本移動速度と同じ速度で登ることができます。「歩行」よりも速く移動することはできず、移動距離を残している必要があります。登った距離は既に使用した移動分だけ減少します。装備している防具は、装備している合計の防具ポイントに基づいてクライマーを妨げます。

## 戦闘の仕組み

『Mythras Imperative』における戦闘は、各攻撃や受け流しが単一の突き、振り、呪文の詠唱、または武器の射撃を表すものとして解決されます。いかなる攻撃的なアクションも、反応によって抵抗される可能性があります。したがって、キャラクターが相手を攻撃することに成功したとしても、敵が攻撃が命中する前に受け流しができるかどうかを確認するための自身のロールが許可されます。この哲学は、遮蔽を求めて飛び込むターゲットに対する遠距離武器攻撃であっても、巨大タコの鉄の締め付けから逃れようとする場合であっても同様に適用されます。

### 攻撃と受け流し

近接戦闘は以下のステップバイステップで行われます：

1. ターンの攻撃者は行動ポイントを消費し、戦闘技能で判定を行い、結果を記録します。
2. 必要に応じて、防御者は受け流しのために行動ポイントを消費し、戦闘技能で判定を行い、結果を記録します。
3. 結果の成功レベルを差分ロールに従って比較します。
4. 差分があれば、より優れたロールで成功した戦闘者に1つ以上の特殊効果を与えます。
5. 攻撃者が「成功」または「クリティカル」を達成した場合、武器ダメージを振り、ダメージ修正（もしあれば）を適用します。該当する場合は、攻撃の部位判定を行います。
6. 防御者が「成功」または「クリティカル」を達成した場合、関与した武器の比較サイズに応じて、与えられたダメージを減少させます。
7. 残りのダメージから、自然の保護または装備している防具の防具ポイントを差し引きます。

やり取りによって生成された特殊効果は、ダメージが与えられたかどうかに関係なく独立していることに注意してください。防御者がより高い成功レベルを得たとしても、依然として負傷する可能性は十分にあります。

### 武器サイズ

『Mythras Imperative』のすべての武器は、与えるダメージから扱うために必要な手の数まで、いくつかの異なる特性を持っています。サイズは武器の質量、梃子、安定性の組み合わせであり、武器のダメージを与え、受け流す能力を決定するために使用されます。サイズカテゴリーは「小型」「中型」「大型」「巨大」「超巨大」です。クリーチャーの徒手攻撃は、その身体的特性に応じて同様のカテゴリーが割り当てられます。

### ダメージ軽減

防御者が受け流しに成功した場合、使用した武器の相対的なサイズに応じて、攻撃者のダメージ（もしあれば）を軽減できます。

- 同等以上のサイズの武器や盾で攻撃を受け流すと、すべてのダメージが無効化されます。
- 1段階小さいサイズの武器や盾で受け流すと、ダメージが半分になります。
- 2段階以上小さいサイズの武器や盾で受け流すと、ダメージはまったく軽減されません。

_例：グレートアックス（巨大）をカイトシールド（これも巨大）で受け流すと全ダメージをブロックします。ロングソード（大型）で受け流すとダメージを半分にします。ショートソード（中型）で受け流すと、ダメージをまったく停止できません。_

### 防具

防御者の受け流しを貫通したダメージは、所持している自然の保護（鱗や甲殻など）または装備している防具の防具ポイントによってさらに軽減されます。防御者が両方持っている場合、それらは積み重なってダメージを軽減します。

その質量と動きへの制限のため、キャラクターが装備している防具の最も高い防具ポイントの値が、イニシアチブロールへのペナルティとして作用します。

### 外れた攻撃の受け流し

攻撃者が最初の攻撃ロールを外した場合、防御者は行動ポイントを消費して受け流すオプションを選択できます。外れるはずの攻撃を受け流すのは見当違いに思えるかもしれませんが、熟練した防御者はこれを利用して1つ以上の特殊効果を得ることで、敵を弱体化させたり無力化したりし、次のターンのために他のアクションを温存できる可能性があります。

### 受け流しができない、またはしたくない場合

行動ポイントが残っていないために防御者が受け流しができない状況、あるいは一撃を耐える自信があるために受け流さないことを選択した状況では、自動的に失敗したとみなされます。これには、攻撃成功者に1つ以上の特殊効果を与えるという結果が伴います。

### 失敗したロールとファンブル

両方の戦闘者がロールに失敗した場合、あるいは防御者が外れた攻撃を利用しないと判断した場合、攻撃・受け流しのシーケンスは終了し、次に高いイニシアチブを持つ参加者へと戦闘が継続されます。

## 特殊効果

戦闘とは、単に相手を傷つけたり殺したりすること以上のものです。格闘技術は、必ずしも相手に危害を加える必要なく、相手を無力化したり、降伏せざるを得ない状況に追い込んだりするなど、敵を倒すための多くの方法を教えます。特殊効果はこれらの技術を表し、プレイ中にどのように発生するかを制御します。

対戦相手がそれぞれの戦闘技能の差分ロールを行う際、生じた成功レベルの差は特殊効果が発生する機会を示します。これは、戦闘者が相手を狡猾なトリックや戦術を使用して活用できる不利な状況に追い込むことを反映しています。

得られる特殊効果の数は、差分成功レベル表で示される成功レベルの差によって異なります。

やり取りの中で特殊効果が得られた場合、ダメージや部位判定（もしあれば）が行われる前に選択しなければなりません。特殊効果を受けると同時にひどく負傷した場合は、特殊効果の適用後に持久力ロールが解決されます。

特殊効果は、多様な状況や技術を網羅しています。攻撃用に特別に設計されたものもあれば、防御用を意図したものもあり、どちらの状況にも適応できるものもわずかに存在します。特定の特殊効果は、特定の武器タイプや特定のダイスロールに限定される場合もあり、例えば技能チェックで「クリティカル」や「ファンブル」の結果を必要とすることもあります。

2つ以上の特殊効果が得られた場合、戦闘者は各々の前提条件が満たされている限り、自由に組み合わせを選択できます。一部の効果は重ね合わせが可能です。例えば、「クリティカル成功」を出し、2つの特殊効果を得た攻撃者は、別々の攻撃操作を選択するのではなく、「ダメージ最大化」を2回選択できます。

### 特殊効果の説明

#### 偶発的負傷

防御者が相手の攻撃を偏向させたりひねったりして、攻撃者がファンブルするようにし、自身を負傷させます。攻撃者は、使用した武器を使用して、ランダムな部位判定で自身に対してダメージロールを行わなければなりません。徒手の場合、攻撃者は内部の何かを損傷または破損し、ダメージロールは防具を無視します。

#### 立ち上がる

防御者が瞬間的な隙を使用して、立ち上がることを可能にします。

#### 殴打

攻撃者は意図的に相手を殴打してバランスを崩させます。防御者がどれだけ後ろや横によろめくかは、使用される武器に依存します。盾はダメージ2点ごとに1メートル相手を突き飛ばし（防具や受け流しによる減算前）、一方、殴打武器は3点ごとに1メートル突き飛ばします。殴打は、攻撃者の体格（体格）の2倍までのクリーチャーにのみ有効です。対象が後ろの障害物に突き飛ばされた場合、転倒や躓きを避けるために「アクロバット」技能ロール、あるいは「運動」技能を「困難」難易度で成功させる必要があります。火器の場合、殴打は純粋な力で後ろに放り投げるよりも相手のバランスを崩すことに重点を置いているため、射出弾が四肢に命中した場合にターゲットをよろめかせることは完全に理にかなっています。エネルギー兵器は、そのビームの物理学が何らかの表面爆発をもたらさない限り、そのような効果を与える可能性は低いです。

#### 出血

攻撃が主要な血管を切り裂きます。一撃が防具ポイントを克服してターゲットを負傷させた場合、防御者は元の攻撃ロールに対して持久力の対抗ロールを行わなければなりません。防御者が失敗した場合、多量に出血し始めます。戦闘ラウンドの開始ごとに、受け手は疲労レベルを1失い、最終的に倒れて死亡する可能性があります。出血している傷は「応急手当」技能ロールに成功することで止血できますが、受け手は傷を再び開くことなく激しい動作を行うことはできなくなります。ゲームシステムセクションの血液損失を参照してください。火器の場合、ほとんどの火器は非常に狭い傷口しか作らないため、切断武器や刺突武器よりも主要な血管を切り裂くのが実際には難しくなります。そのため、出血はクリティカル成功時のみであるべきです（手裏剣、レーザーフレシェット、平坦化されたフォースフィールド、またはそのようなエキゾチックな弾薬を発射する奇妙な武器でない限り）。

#### 目つぶし

「クリティカル」で、防御者は砂を投げたり、盾で日光を反射させたり、その他の戦術によって一時的に相手の視界を妨げ、対戦相手の目をくらませます。攻撃者は自身の「回避」技能（盾を使用している場合は武器技能）で、防御者の元の受け流しロールに対して対抗ロールを行わなければなりません。攻撃者が失敗した場合、盲目化の方法に応じて、次の1d3ターンの間、「困難」または「至難」の状況修正を受けます。#### 防具無視

クリティカルヒット時、攻撃者は防御者の自然防具または着用防具の隙間を突く。防御者が自然防具を上回る防具を着用している場合、攻撃者はどちらを無視するかを選択しなければならない。この効果は累積し、両方を無視することも可能である。この効果の目的において、魔法によって得られる物理的な防御は、着用防具として扱われる。防具無視は一見どのような種類の攻撃でも使用できるように見えるが、特定の種類の弾薬（散弾銃のペレットなど、拡散するため）はこの効果の使用を妨げられたり、あるいは基本性能に組み込まれていたりする場合がある。その場合、他の特殊効果に加えてボーナス特殊効果として付与される（テレポート弾など）。多くの場合、ゲームマスターがその武器をどのように設定したいかによる。

#### 部位判定選択

近接武器を使用する場合、攻撃者はその部位が通常の間合い内にあれば、自由に攻撃が当たる位置を選択できる。遠隔武器（銃火器を含む）を使用する場合、部位判定選択はクリティカル成功時のみ可能である。ただし、ターゲットが近距離（Close 射程）におり、静止しているか、攻撃者に気づいていない場合は例外である。銃火器の場合、望遠スコープを使用することでこの射程を延長できる場合がある。

#### 回避無効

クリティカルヒット時、攻撃者は本来成功するはずだった回避を完全に無効化できる。

#### 武器損傷

攻撃または回避の一環として、対戦相手の武器にダメージを与えることができる。攻撃側は防御側の回避武器を具体的に狙い、その武器の使い手ではなく武器そのものに対してダメージロールを適用する。狙われた武器は、独自の防具ポイントを使用してダメージに抵抗する。ヒットポイントがゼロに減少すると、武器は破損する。銃火器の場合、遠距離から手持ちの武器を攻撃することは特定の身体部位を狙うよりもさらに困難であるため、通常はクリティカル成功時にのみ限定されるべきである。ただし、いくつかの例外がある。まず、盾はその性質上、命中させることがはるかに容易である。第二に、円錐状のビームを発射して効果範囲内の手持ちの物体を狙うことができる特殊な武器（金属物体を加熱する誘導銃など）である。

#### 武装解除

キャラクターは相手の武器を叩き落とすか、引き抜くか、ねじり取って手から離させる。相手は自身の戦闘スタイル技能を用いて、キャラクターの元の判定に対する対抗判定を行わなければならない。武装解除された側が敗北した場合、その武器は武装解除した側のダメージ修正の出目（メートル単位）と同じ距離だけ吹き飛ぶ。ダメージ修正がない場合は、武装解除された者の足元に武器が落ちる。武器の相対的なサイズが判定に影響する。武装解除を試みる側の武器が1段階大きくなるごとに、相手の判定の難易度は1段階上昇する。逆に、武装解除を試みる側の武器が1段階小さくなるごとに、難易度は1段階簡単になる。武装解除は、攻撃者の筋力の2倍までのサイズを持つクリーチャーに対してのみ有効である。

#### 撃倒

攻撃側、銃火器限定。ターゲットが少なくともかすり傷以上のダメージを受けたという前提で、ターゲットは自身の持久力を用いて、攻撃者の命中ロールに対する対抗判定を強制される。失敗した場合、ターゲットは衝撃と痛みに屈し、無力化され、戦闘を継続できなくなる。無力化からの回復は、応急手当の判定に成功するか、キャンペーン内に存在する場合は何らかの技術的または麻薬的なブースターを使用することで行える。それ以外の場合、一時的な無力化は、ターゲットの治癒率で1時間を割った期間だけ持続する。

#### 退避

攻撃側、銃火器限定。この特殊効果により、射手は次のターンの「遮蔽を取る」アクションを待つことなく、即座に遮蔽の背後に戻ることができる。退避を使用するには、キャラクターがすでに何らかの遮蔽に隣接して立っているか、しゃがんでいる必要がある。

#### 回避強化

クリティカルヒット時、防御側は武器のサイズに関係なく、攻撃の力全体をそらすことに成功する。

#### 拘束

鞭や網などの拘束武器を装備したキャラクターは、命中した部位を無力化できる。腕を拘束されれば持っているものを使用できなくなり、脚を拘束されればターゲットは移動できなくなる。頭部、胸部、腹部を拘束された場合、すべての技能判定の難易度が1段階上昇する。次のターン、使用者は行動ポイントを1消費して、「転倒」を自動的に試みることができる。拘束された犠牲者は、自身のターンに腕力を用いた対抗判定を試みて引き抜くか、特殊効果を獲得して武器損傷、武装解除、または離脱を選択することで脱出を試みることができる。

#### 強制失敗

対戦相手がファンブルした際に使用する。キャラクターは強制失敗を、対抗判定を必要とする他の特殊効果と組み合わせることができる。強制失敗により、相手はデフォルトで抵抗判定に失敗するため、自動的に武装解除や転倒などが成立する。

#### 掴み

対戦相手が攻撃者の徒手格闘の間合い内にいる場合、空いている手（または掴むことができる同様の四肢）を使用して対戦相手を保持し、戦闘から離脱できないようにすることができる。対戦相手は自身のターンに、掴んでいる側が選択した腕力または徒手格闘技能のいずれかを用いて、対抗判定を行うことで脱出を試みることができる。

#### 貫通

武器ダメージを2回ロールし、どちらの結果を攻撃に使用するかを攻撃者が選択する。武器が近接武器である場合、防具を貫通して傷を与えたなら、攻撃者は武器を傷の中に残すか、次のターンに引き抜くかを選択できる。武器を傷の中に残すと、被害者のその後の技能判定に難易度ペナルティを与える。ペナルティの深刻さは、クリーチャーとそれを突き刺している武器のサイズの双方に依存し、以下の「貫通効果表」に記載されている。簡略化のため、同じサイズの武器によるさらなる貫通は追加のペナルティを与えない。近接戦闘中に貫通した武器を引き抜くには、「武器の準備」戦闘アクションを使用する必要がある。使用者は非対抗の腕力判定に成功しなければならない（相手が抵抗する場合は対抗腕力判定に勝利する）。成功すれば武器を引き抜くことができ、ダメージ修正なしで、その武器の通常のダメージロールの半分に相当するさらなる負傷を同じ部位に与える。失敗した場合、武器は傷の中に刺さったままで効果はないが、使用者は次のターンに再度試みることができる。特に返し刃のある武器（銛など）は通常のダメージを与える。防具は引き抜きによるダメージを軽減しない。貫通している間、攻撃者はその貫通武器を回避に使用できない。

#### 狙撃手

射手は、自身の射撃で命中した部位判定を、隣接する身体領域へ1段階移動させることができる。生理学的な構造が再ターゲット可能な範囲に影響するため、常識を適用すること。したがって、人型生物に対してこの特殊効果を使用すれば、脚を射抜いた攻撃者が腹部に移動させることが可能となる。逆に、グリフィンの胸を射抜いた場合、前脚、翼、または頭部を選択できる。

#### ダメージ最大化

クリティカルヒット時、キャラクターは武器のダメージダイスのうち1つを、その最大値に置き換えることができる。例えば、通常1d6ダメージを与えるハンドアックスは代わりに6として扱われ、2d6ダメージを与えるグレートクラブは代わりに1d6+6ダメージを与える。この特殊効果は累積できる。自然武器にも使用できるが、ダメージ最大化は攻撃者のダメージ修正には影響せず、ダメージ修正は通常通りロールしなければならない。

#### 過剰貫通

クリティカル、銃火器限定。一直線上に並んだ相手や密集したグループを射撃する場合、この特殊効果により、最初のターゲットの防具を克服することを条件に、一発の銃弾が最初の犠牲者を完全に貫通し、その後ろにいる二人目に命中できる。ただし、二人目の犠牲者が受けるダメージは、弾丸の減衰または減速により半分となる。過剰貫通は、一般的に大ダメージを与える高出力武器や、徹甲能力を持つ武器でより有効である。最初のターゲットに与えられた特殊効果は、二人目には適用されない。

#### 抑圧射撃

銃火器限定。 「優位な態勢」と似ており、この特殊効果は、ターゲットに対し、自身の意志力を用いて攻撃者の命中ロールに対する対抗判定を行うことを強制する。失敗した場合、ターゲットは利用可能な遮蔽物の背後に身を潜め、次のターンに反撃できなくなる。抑圧射撃は、ターゲットに実際のダメージが与えられなくても（回避の成功や、遮蔽物への命中などによる）、銃声が非常に近くを通過する威圧効果に依存しているため機能することに注意すること。

抑圧された犠牲者は必要な期間反撃できないが、その過程で銃撃に身を晒さない限り、別の場所に這って逃げる、他者と通信する、武器を再装填するなど、他のアクションを実行できる。

#### カウンター準備

防御側は相手の動きを読み、特定の特殊効果（秘密裏にメモしておくこと）に対するカウンターを準備する。戦闘中に相手が選択した特殊効果を自分に与えようとした場合、防御側は即座に攻撃者の効果を自分のものに置き換え、自動的に成功させる。

#### 高速再装填

遠隔武器を使用する際、攻撃者は次弾の再装填時間を1段階短縮する。この効果は累積できる。銃火器の場合、黒色火薬式や単発式銃火器には有効だが、自動火器では次弾が即座にチャンバーへ送られる（またはチャージされる）ため、この効果の適用はあまり直感的ではない。しかし、高速再装填は代わりに武器のマガジンを素早く交換するために使用できる。また、コンデンサーの再充電や銃身の冷却に長いサイクル時間を要するエネルギー兵器にも適用できる可能性がある。

#### 敵の傷跡

戦闘者は対戦相手に、その一生涯語り草となるような傷跡を与える。喉をほとんど切り裂かれた傷跡や、胸に芸術的に刻まれた「Z」の文字などである。

#### 標的選択

攻撃者がファンブルした際、防御側は吹っ飛ばされた攻撃を、隣接する傍観者に当たるように操作またはそらすことができる。これには、新しいターゲットが攻撃者の近接武器の間合い内にいるか、遠隔攻撃の場合は射線上に立っている必要がある。新しい犠牲者は予期せぬ事故により完全に不意を突かれ、自動的に命中する攻撃を回避する機会はない。ただしその代わりとして、彼らは特殊効果を受けない。

#### 離脱

防御側は自動的に間合いの外へ退避し、その特定の対戦相手との交戦を打ち切ることができる。

## 近接戦闘

近接戦闘とは、戦闘員が装備した武器や自然武器で互いに打ち合う、古典的な意味での白兵戦のことである。以下のガイドラインは、近接戦闘をより興味深いものにする方法を提案し、この章の序盤で示唆されたいくつかの概念をより詳細に説明するものである。

### 状況修正

状況修正は、特定の状況下での戦闘や、特殊効果の結果として適用されることがある。例えば、暗闇の中での戦闘は「至難」の難易度を被る可能性がある。特に指定がない限り、修正はゲームマスターによって決定される。2つ以上の状況がキャラクターに該当する場合、最も深刻なものを使用すること。

一部の修正は状況依存であるが、難易度を適用するのではなく、戦闘技能が関連する技能によって制限される場合がある。例えば、馬の背からの戦闘は乗馬技能によって戦闘技能が制限され、水中での戦闘は水泳技能の値によって制限される可能性がある。#### 近接戦闘における状況修正

| 状況 | 難易度 |
| :-- | :-: |
| 無防備な標的への攻撃 | 自動 |
| 閉所での攻撃 | 困難 |
| 低い位置や騎乗した敵に対する防御 | 困難 |
| 不安定な足場での戦闘 | 困難 |
| しゃがんだ状態や片膝立ちでの戦闘 | 困難 |
| 視界不良（濃霧、吹雪など）での戦闘 | 困難 |
| 背後からの攻撃に対する防御 | 至難 |
| 伏せた状態での戦闘 | 至難 |
| 部分的な暗闇（薄明かり）での戦闘 | 至難 |
| 真っ暗闇（完全に光源がない）での戦闘 | 超人的 |
| 目が見えない、または主要な知覚能力の喪失 | 超人的 |

### 交戦

キャラクターは、対戦相手の近接武器の射程内にいる場合、「交戦中」とみなされます。これは必ずしも双方の戦闘者が互いに届く範囲にいなければならないという意味ではなく、どちらか一方がもう一方を攻撃できる可能性がある状態を指します。一度キャラクターが対戦相手と交戦状態になると、その戦闘から自由に離脱することはできません（チャージして通り抜ける場合は特別な例外です）。敵との接触を断つには、「機動」のような戦闘アクション、あるいは「撤退」の特殊効果の使用など、何らかの意図的な行動が必要です。

### チャージ

チャージアクションは、攻撃の威力と衝撃を高めるために素早く移動する行為です。チャージを行うには、攻撃者は「走る」または「全力疾走」の歩法で移動するチャージアクションを選択しなければなりません。歩法の詳細については、前述の[移動速度](0002_Characters.md?id=movement-rate)セクションを参照してください。移動に関するルールは『Mythras』ルールブックに完全に記載されています。

チャージによって対戦相手との接触に至った場合、そこで移動を停止し、チャージの修正を適用した状態で攻撃アクションを実行しなければなりません。チャージを行う前に移動しなければならない最低距離は決まっていません。移動距離よりも、得られた勢いの方が重要だからです。そのため、走るか全力疾走します。

チャージ中の攻撃判定には「困難」の難易度が適用されます。その代わり、チャージは攻撃武器の「体格」を1段階、二足歩行の攻撃者であれば「ダメージ修正」を1段階上昇させます。四足歩行（またはそれ以上の脚を持つ）生物であれば2段階上昇します。騎乗しているキャラクターは、自身のダメージ修正の代わりに騎乗動物のダメージ修正を使用できます。チャージを行うキャラクターの最終的な位置は、戦闘の結果と、攻撃者が停止を望むか、あるいはそのまま通り過ぎて即座に交戦を終了させたいかによって決まります。

チャージを受けた側は、「パリィ」や「回避」を行う代わりに、チャージしてきた攻撃者に対して同時に反撃を行うことができます。この場合、より長い武器を持つ者が先に攻撃します。槍のようにチャージを受け止める準備ができる武器であれば、受ける側は自分のダメージ修正の代わりにチャージしてきた側のダメージ修正を使用できます。

### 遮蔽

対戦相手は、物理的に攻撃を遮る素材の頑丈さを利用するか、あるいは相手の正確な位置を隠すことによって、自分への攻撃を阻害するために遮蔽を利用します。遮蔽の正確な値は、その保護の厚さと範囲に依存します。

遮蔽された「部位判定」に着弾した攻撃は、遮蔽物が本来持つ保護能力の分だけ防がれます。遮蔽は、「部位選択」の特殊効果を使用して標的の露出している部分を狙うか、あるいは武器が貫通可能であれば遮蔽を突き抜けて攻撃することで、部分的に無効化できます。

完全な遮蔽がある状況でも、攻撃者が攻撃は貫通すると信じるならば、隠れた標的に向けて盲目的に攻撃を仕掛けることができます。その場合、攻撃判定は1段階難しくなり、特殊効果が発生しても「部位選択」は使用できません。これは、攻撃者が遮蔽物の背後にいる標的の位置をかなり正確に把握していると仮定しています。

### 回避

戦闘における回避とは、圧倒的な攻撃から身をかわすことです。これには、防御側の「回避」技能と、攻撃側の適切な判定（体当たりを行う戦車の「運転」技能から、魔術師の呪文詠唱技能まで様々）との「対抗判定」が必要です。攻撃側が勝利すれば、通常通りダメージを与えます。防御側が勝利すれば、ダメージは完全に回避されます。

対抗判定の勝者が相手に対して1段階以上の「成功度」を達成した場合、通常の戦闘と同様に適切な特殊効果を選択できます。結果がどうあれ、回避を試みた後は防御側は伏せ状態となり、次のターンに態勢を立て直す必要があります（ただし「起き上がり」の特殊効果を使用できる場合を除きます）。

### ノックバック

受ける側は、自身の「体格」を上回るダメージを一度に受けると、原則としてノックバックさせられます。この場合のダメージは、パリィや防具による軽減を適用する前の値です。このような打撃を受けた場合、受ける側は「簡単」な「アクロバット」判定か「標準」の「運動」判定に成功しなければ、伏せ状態になってしまいます。また、自身の「体格」を上回る5ダメージ（またはその端数）ごとに1メートル押し戻されます。戦闘アクションの「踏ん張り」を能動的に使用すれば、ノックバックの影響を軽減、あるいは無効化できます。

### 跳躍攻撃

跳躍攻撃は様々な状況から繰り出されます。そのほとんどは待ち伏せの一部として、あるいはチャージの終わりに発動されますが、一部の生物は助走や高所を必要とせずに相手の上に飛び乗ることができます。

跳躍攻撃は、跳躍側の「運動」技能と防御側の「腕力」または「回避」技能による対抗判定で解決されます。四足歩行の標的に対しては、攻撃判定の難易度が1段階上がります。跳躍側が勝利した場合、防御側は自動的に伏せ状態となり、攻撃者がその上に跨る形になります。失敗した場合は、防御側が衝撃を耐えたか、横にかわしたことを意味します。対抗判定の勝者が相手に対して1段階以上の「成功度」を達成した場合、通常の戦闘と同様に適切な特殊効果を選択できます。

跳躍そのものではダメージは与えられません。しかし、伏せ状態になった被害者は、攻撃者がその場を離れるか、後に「起き上がり」を許可する特殊効果を得るまで態勢を立て直すことができません。また、跳躍攻撃は攻撃者の「体格」の2倍までの大きさの相手にしか有効ではありません。標的は、来るべき跳躍攻撃を察知していれば、能動的に「踏ん張り」の戦闘アクションを使用することで、倒されにくくすることができます。

### 機動

複数の対戦相手に直面しているキャラクターは、移動を駆使して一度に攻撃してくる敵の数を制限し、常に位置を変えながら敵同士を妨害させることができます。機動を行うには、キャラクターが周囲を動くスペースがあり、狭い場所に追い詰められていないことが条件です。

機動を行うには、キャラクターが自分の「回避」技能を用いて対戦相手たちとグループの対抗判定を行う必要があります。機動を行うキャラクターと、彼を追い詰めようとする敵の参加者は全員、行動ポイントを1ポイント消費しなければなりません。その後、それぞれが1回ずつ判定を行い、機動を行うキャラクターの判定値を下回った者は、味方や地形に阻まれて、その戦闘ラウンドの残りの間は彼を攻撃できなくなります。

機動を行うキャラクターがすべての対戦相手を上回った場合、そのラウンドの残りの間、1人の敵と安全に交戦し続けるか、戦闘から完全に「撤退」するかを選択できます。

### 受動的防御

受動的防御により、武器を持つキャラクターは、選択した部位（盾を使用する場合は複数の部位）をカバーするように武器を保持できますが、その代わりその武器で能動的に「パリィ」を行うことができなくなります（「部位守護」を参照）。その部位に命中した攻撃は、自動的に武器や盾の効果による軽減を受け、通常通りダメージが減少します。この技術は、戦士が弱点や負傷した部位を守りたいときによく使われます。二刀流や武器と盾を使用しているキャラクターが、もう一方の武器で能動的にパリィを行うことを妨げるものではありません。

受動的防御は遮蔽と同じ方法で機能するため、近接戦闘において「部位選択」の特殊効果を使用してこの防御を回避することはできません。ただし、対戦相手は引き続きこの効果を使用して、防御されていない他の部位を攻撃することは可能です。盾の後ろにしゃがみ込むことで、キャラクターは受動的防御中にカバーできる部位の数を2倍にすることができます。

### 奇襲

奇襲は、攻撃者の存在や意図に気づいていない対戦相手に対して、予期せぬ攻撃が開始されたときに発生します。待ち伏せは前者の例であり、親しげな会話の最中に不意に裏切り行為に及ぶのは後者の例です。

奇襲が標的に与える影響は強力です。

- 標的は「イニシアチブ」に-10のペナルティを受ける。
- イニシアチブが回ってくるまで、標的は不意打ち状態とみなされ、自らを守ることができない。
- 標的への最初の攻撃が成功した場合、ボーナスとして特殊効果が1つ得られる。
- ラウンドの残りの間、標的はいかなる攻撃的アクションも実行できない。

### 掃討攻撃

掃討攻撃は、ゲームマスターの判断で、異常な大きさの武器や生物が密集した敵の集団を攻撃した際に行われます。巨大なドラゴンの薙ぎ払う尾や、巨大なトリケラトプスの止まらない突進などがその例で、複数の敵を同時に攻撃します。

掃討攻撃は、武器や生物の攻撃判定を1回行うことで、その経路上にいるすべての標的に適用されます。各防御側は個別に攻撃の影響を解決しなければならず、攻撃者に課せられた特殊効果はすべて同時に発生したものとして扱われます。

## 遠隔戦闘

遠隔戦闘には、標的に命中させるために射出、投擲、あるいは投石器を使用するあらゆる形態の武器が含まれます。遠隔攻撃は近接戦闘と全く同じ方法で解決されます。しかし、遠隔武器は通常盾でしかパリィできません。盾を持たない者は、自然の遮蔽に頼るか、「回避」を使用して弾道から飛び出す必要があります。そのため、軽装の敵に対して、遠隔武器は恐るべき抑止力となります。

各遠隔武器には、その有効性を決定するいくつかの特定の能力値があります。戦闘に大きく関わるものは以下の通りです。

- **体格（超能力）:** 遠隔武器における「体格」に相当するもの。武器や弾薬が（盾による）パリィを克服できるかどうかを判断するための、貫通力の抽象的な尺度です。
- **ダメージ修正:** この能力値は、攻撃者の「ダメージ修正」を使用して遠隔武器のダメージ判定を強化できるかどうかを示します。一般的に、自力で引く弓や投擲武器のみが、使用者の「ダメージ修正」の適用を許可します。
- **射程:** スラッシュで区切られた3つの数字で、武器やその弾薬の最大近距離、有効射程、長距離を表します。近距離は、標的が静止しているか、攻撃に気づいていない場合に「部位選択」の特殊効果が使用できる距離です。有効射程には重要な修正はありません。長距離では、武器は依然としてダメージを与えることができますが、ダメージ量は半分になり、「体格（超能力）」が1段階減少します。
- **再装填:** 弾薬を発射する武器を装填、または再装填するのにかかるターン数。「急速再装填」の特殊効果を使用することで、装填や準備にかかる時間を短縮できます。
- **刺突体格:** 刺突武器の「体格」は、それが与える衝撃の強さとは異なります。「刺突」の特殊効果によって引き起こされる障害を考慮する際、遠隔刺突武器にはその実際の大きさを表す特別な列があります。

### 状況修正

近接戦闘と同様に、特定の状況で遠隔武器を使用する際には状況修正が適用される場合があります。馬に乗った状態で槍を投げるなど、困難な状況で武器を使用する場合、キャラクターの「戦闘技能」に上限が設けられることがあります。

##### 遠隔戦闘の状況修正

| 状況 | 難易度 |
| :-- | --- |
| 微風\* | 困難 |
| 中程度の風\* | 至難 |
| 強風\* | 超人的 |
| 疾風、嵐、またはそれ以上\* | 絶望的 |
| 標的が「走っている」 | 困難 |
| 標的が「全力疾走している」 | 至難 |
| 標的が霧や薄明かりで覆われている | 困難 |
| 標的が濃い煙や暗闇で覆われている | 至難 |
| 標的が完全に覆われている | 超人的 |
| 標的が完全に見えない | 不可能\*\* |
| 標的が伏せている | 至難 |
| 攻撃者が伏せている\*\*\* | 超人的 |
| 攻撃者が不安定な足場にいる | 困難 |

_\* 投擲武器や弾薬が横風の影響を受けると仮定しており、通常の技能に風が課す通常のペナルティに優先して適用されます。_

_\*\* 標的の一般的な位置が判明しているか知られている場合を除き、その場合は超人的として扱います。_

_\*\*\* 準備された位置からクロスボウや銃器を使用している場合、ペナルティは無効化できます。_

### 照準

遠隔武器で照準を合わせる時間を追加で費やすことで、キャラクターは命中する確率を向上させることができます。照準には戦闘ラウンド全体を使って武器を安定させ、発射の最良の機会を待つ必要があります。例えば、風が一時的にやむまで弓を引いたまま待つ、あるいは標的が2つの障害物の間を移動するまで待つなどです。照準を合わせることで、キャラクターは射程や状況修正の難易度を1段階下げることができます。追加のラウンドを照準に費やしても、さらなる利点はありません。

### 自動射撃

一部の銃器は、前弾の排ガス、反動、またはエネルギーを利用して、自動的に次弾を薬室に送り込みます。再装填の必要がないため、この機能により、使用者がどれだけの弾薬を消費したいかによって、様々な発射速度が得られます。

これらの発射モードは、セミオート、バースト、フルオートとして知られています。この能力は銃に恐るべきダメージを与える能力をもたらす可能性がありますが、反動のある武器で精度を維持するのは困難です。以下のルールは、主に弾丸を発射する自動火器に適用されるものと想定してください。

#### セミオート

これはほとんどの銃のデフォルトの発射速度であり、引き金を引くたびに1発を発射し、次弾を装填します。

#### バースト

バースト射撃では、引き金を引くたびに武器に応じて通常3～5発以下の限られた弾数が発射されます。その本来の目的は、限定的な制圧射撃を可能にしつつ、過剰な弾薬消費を抑制することでした。連続的な反動によって武器が常に照準から外れるため、射手の命中率を向上させるためのものではありません。バーストモードでの射撃は、攻撃判定に「困難」の難易度ペナルティを課します。しかし、攻撃が成功した場合、射手はダイスを振り、そのバースト中の何発が標的に命中したかを確認します。例えば、3発のバーストなら1d3を振ります。命中した弾丸ごとに、それぞれ個別に部位判定とダメージ判定を行います。

#### フルオート

通常、複数の標的を釘付けにするための本格的な制圧射撃に使用され、密集した敵の集団に撃ち込めば壊滅的な被害を与えられます。射手は、武器のサイクル速度の制限内で何発の弾薬を撃つかを決定し、射撃範囲内のすべての標的に均等に分配します。照準を移動させる際に余った弾丸は失われたものとみなされます（したがって、6人の標的に15発撃つ場合は、それぞれ2発ずつとなります）。各標的に対して個別に攻撃判定を行いますが、持続的な射撃による反動の影響が増大するため、難易度は「至難」となります。命中した標的は、バースト射撃と同様にランダムな弾数分のダメージを受けます。

バーストまたはフルオート射撃中に命中した最初の弾丸のみが特殊効果の恩恵を受けられることに注意してください。したがって、自動モードでの射撃中にクリティカルが発生しても、「最大ダメージ」を選択できるのは最初の弾丸のみであり、残りの弾丸がすべて命中したとしても同様です。#### 自動火器のペナルティはなぜこれほど大きいのか？

自動火器のルールは、現代の銃器が持つ見かけ上の精度と比較して、不当に厳しく見えるかもしれません。これにはいくつかの理由がありますが、主なものは簡略化とゲームバランスです。キャラクターの不正確さを批判するプレイヤーは、ルールへのいかなる調整も自分自身に適用されることを思い出すべきでしょう。連射の致死性を考えれば、これは冷静になるための良い教訓となるはずです。

もちろん、自動火器を支えるために「武器固定」を使用するなどして、これらの反動ペナルティを軽減することは可能です。しかし真実は、銃撃戦が射撃場での標的射撃とは大きく異なるという点にあります。弾丸が飛び交う中での遮蔽物に隠れようとする本能、移動し続けなければならない必要性、そして発砲のたびにマズルファイアや音で射手の位置が特定される状況では、照準や固定を行うチャンスはほとんどありません。「撃ちまくって祈れ（Spray and Pray）」という言葉には、もっともな理由があるのです。

### 二丁拳銃

キャラクターは二丁の銃器を使用し、自分のターン中に両方の武器を同時に発射することで、より素早い発射速度を得ることができます。ただし、これには精度の低下というペナルティが伴います。両手にピストルを持って発射する場合、ターゲットへの命中判定に「困難」のペナルティを受けます。両手にカービン銃や短機関銃を持って同時に射撃しようとする者は、「至難」のペナルティを受けます。

### 群衆への射撃

近接戦闘の渦中で射撃を行うのは危険な行為であり、狙った本来のターゲット以外の誰かに誤って命中させるリスクが常に存在します。群衆や近接戦闘の端にいる特定のターゲットを射撃する場合、攻撃は「困難」の難易度を受けます。もし群衆越しに射撃しようとするならば、それは「至難」に引き上げられます。危険を軽減するために「照準」を行うことは可能です。

難易度ペナルティにもかかわらず攻撃ロールに成功した射手は、正確に狙いを定めており、意図したターゲットに命中させます。しかし、射手がロールに失敗し、もし「群衆への射撃」のペナルティさえなければ成功していたはずであった場合、代わりに隣接する犠牲者に命中します（犠牲者は通常通り「回避」や「受け流し」を自由に行えます）。

射線上に複数のターゲットがいる場合、ゲームマスターはランダムに犠牲者を決定すべきです。攻撃の一部として得られた特殊効果は、誤って命中した傍観者には適用されず、元のターゲットにのみ適用されます。

### 銃器のファンブル

銃撃は通常、対抗する技能によって抵抗されることはないため、射手が攻撃ロールでファンブルした場合には特別な規定を設ける必要があります。この場合、意図したターゲットとなった者は、ファンブル固有の特殊効果を選択することができ、射手はその効果を被ります。ファンブル専用の特殊効果「武器の不具合」も参照してください。

### 盾による銃火の受け流し

前述の通り、超音速の投射物やエネルギービームを意図的に受け流すことはほぼ不可能です。しかし盾は、実質的に携帯可能な「遮蔽物」であるため、依然として一定の保護を提供します。銃撃戦で盾を使用するには、上記の[接近戦](0005_Combat.md?id=passive-blocking)セクションにある「受動的ブロック」のルールを使用してください。

より現代的な銃器やSF的な性質を持つものに関しては、ゲームマスターは盾が作られている素材に基づいて、サイズを割り当てる代わりに「防具ポイント」の値を付与したいと考えるかもしれません。例えば、木の盾は4防具ポイント、ケブラー製のタクティカル・シールドは8防具ポイント、ユリシーズ31ブレスレット・フォースフィールド・シールドは15防具ポイントとして扱うことができます。

### 望遠照準器

望遠照準器は、ユーザーが適切に時間をかけて照準を合わせる（「照準」を参照）ことで、遠距離での銃器の精度を向上させます。最も基本的な望遠照準器は単なる光学拡大鏡ですが、技術が進歩するにつれて、レンジファインダー、弾道計算機、空気移動センサー、大気レンズ補正器、赤外線または微光増幅器など、有効射程を向上させる多くのガジェットが組み込まれるようになります。

望遠照準器は、照準器の洗練度に応じて、技能ロールを1段階以上「簡単」にします（[技能の修正](0003_Skills.md?id=modifying-skills)を参照）。どのような照準器であっても技能ロールを「自動」成功にすることはできないため、到達可能な最高の等級は「非常に簡単」となります。
